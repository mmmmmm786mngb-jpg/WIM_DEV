# Пилот: локальная LLM через LM Studio + Cline

- Модель работает только локально (LM Studio, порт 1234).
- Не отправлять код во внешние API.
- Для 1С: сначала сверять сигнатуры через MCP 1c-platform, поиск по коду через code-index.
- Стиль BSL: PascalCase, ключевые слова с заглавной (Если, Тогда, КонецЕсли), без HTML-сущностей в запросах.

# Экзамен: ОУ — партионный учёт (оптовая торговля)

Учебная конфигурация **ОперативныйУчетУчебная** для сдачи / экзаменационной проверки.

Платформа: **1С:Enterprise 8.3.27** (format 2.20, compatibility `Version8_3_27`).

## Состав комплекта (всё в этой папке)

| Путь | Назначение |
|------|------------|
| `config/` | Полная XML-выгрузка конфигурации (`Configuration.xml` + объекты) |
| `config/BUILD.md` | Детали загрузки XML и опциональной сборки `.cf` |
| `developer-algorithm.html` | **Алгоритм для разработчика** (открыть в браузере) |
| `README.md` | Этот файл: как загружать и что проверять |

Архив всего комплекта (рядом с этой папкой, не внутри неё):  
[`Экзамены/ОУ_ПартионныйУчет.zip`](../ОУ_ПартионныйУчет.zip)

Бинарный `.cf` **не** входит в комплект (нет 1С на Linux-агенте). При необходимости соберите `.cf` по `config/BUILD.md` на Windows с 1С 8.3.27.

Исходная разработка также лежит в `bases/OU_Training/` (тот же XML). Для экзамена используйте **этот** каталог — ходить по репозиторию не нужно.

## Как загрузить

1. Создайте пустую файловую ИБ на платформе **8.3.27**.
2. Откройте **Конфигуратор**.
3. **Конфигурация → Загрузить конфигурацию из файлов…**
4. Укажите каталог: `Экзамены/ОУ_ПартионныйУчет/config` (где лежит `Configuration.xml`).
5. **Конфигурация → Обновить конфигурацию базы данных** (F7).
6. Запустите **1С:Предприятие** (роль по умолчанию: `ПолныеПрава`).

Подробности и командная строка: `config/BUILD.md`.

## Что проверять (чеклист приёмки)

- [ ] XML загружается в пустую ИБ 8.3.27 без ошибок структуры
- [ ] Разделы интерфейса: **Главное** / **Оперативный учет** / **Сервис**
- [ ] Приходная накладная создаёт элементы `ПартииТоваров`; **услуги** не двигают `ТоварыНаСкладах`
- [ ] Расходная накладная списывает по методу УП **на дату документа** (FIFO / LIFO / По средней)
- [ ] Недостача остатка **блокирует** проведение с сообщением пользователю
- [ ] `КорректировкаРегистров` пишет ручные движения по обоим регистрам накопления
- [ ] Отчёты `ПродажиЗаПериод` и `ОстаткиТоваровПоПартиям` открываются и показывают данные

Пошаговые тестовые сценарии с ожидаемыми цифрами:  
`Документация/tasks/task-ou-wholesale-batch-accounting.md`  
(раздел «Тестовые данные и сценарии»).

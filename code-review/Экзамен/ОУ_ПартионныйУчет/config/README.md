# config — XML экзаменационной конфигурации ОУ

XML-выгрузка конфигурации **ОперативныйУчетУчебная** (платформа 8.3.27).

Это копия комплекта для сдачи/экзамена. Корень экзамена: `Экзамены/ОУ_ПартионныйУчет/`.

## Состав каталога

| Путь | Назначение |
|------|------------|
| `Configuration.xml` | Корень выгрузки |
| `Catalogs/`, `Documents/`, `Enums/`, … | Метаданные |
| `CommonModules/` | Алгоритмы FIFO/LIFO/средняя, учётная политика |
| `Reports/` | Продажи за период; остатки по партиям |
| `BUILD.md` | Как загрузить XML / собрать `.cf` на Windows |
| `source-path.txt` | Указатель WORK (по конвенции репозитория) |
| `_meta/` | JSON-заготовки для meta-compile / skd-compile (не нужны платформе) |

# Сборка и загрузка конфигурации OU_Training

Платформа: **1C:Enterprise 8.3.27**.  
Формат выгрузки: **2.20**, режим совместимости: **Version8_3_27**.

## Важно (Linux / cloud)

На Linux-агенте без установленной платформы 1С **нельзя** собрать бинарный файл `.cf` и выполнить `LoadConfigFromFiles` / `DumpConfigToFiles`.  
В git сдаётся **XML-выгрузка** (как исходники EPF) + эта инструкция. Сборка `.cf` — только на Windows (или иной ОС) с установленной 1С 8.3.27.

Пути к `1cv8.exe` **не выдумываются**: используйте фактический путь установки на вашей машине (часто что-то вроде `C:\Program Files\1cv8\8.3.27.XXXX\bin\1cv8.exe`). Проверьте версию через ярлык / каталог `bin`.

## Вариант A. Загрузка XML в пустую ИБ (рекомендуется для приёмки)

1. Создайте пустую файловую информационную базу в 1С 8.3.27.
2. Откройте **Конфигуратор**.
3. Меню: **Конфигурация → Загрузить конфигурацию из файлов…**
4. Укажите каталог: `Экзамены/ОУ_ПартионныйУчет/config` (каталог, где лежит `Configuration.xml`).
   Для разработки можно также грузить `bases/OU_Training` — содержимое то же.
5. Дождитесь окончания загрузки.
6. **Конфигурация → Обновить конфигурацию базы данных** (F7).
7. Запустите **1С:Предприятие**, войдите под пользователем с полными правами (роль `ПолныеПрава` — роль по умолчанию конфигурации).

### Командная строка (если путь к платформе известен на вашей машине)

Подставьте свой `1cv8` и каталог ИБ:

```bat
"%ProgramFiles%\1cv8\8.3.27.<build>\bin\1cv8.exe" DESIGNER /F "<путь_к_ИБ>" /LoadConfigFromFiles "<полный_путь>\Экзамены\ОУ_ПартионныйУчет\config" /UpdateDBCfg /Out load_log.txt
```

Параметры `/F`, пути и номер сборки 8.3.27 — только с вашей рабочей станции.

## Вариант B. Сборка бинарного `.cf` из XML

1. Загрузите XML в ИБ (вариант A).
2. В Конфигураторе: **Конфигурация → Сохранить конфигурацию в файл…** → `ОперативныйУчетУчебная.cf`.
3. Либо из командной строки после загрузки:

```bat
"%ProgramFiles%\1cv8\8.3.27.<build>\bin\1cv8.exe" DESIGNER /F "<путь_к_ИБ>" /DumpCfg "<выход>\ОперативныйУчетУчебная.cf" /Out dump_cf_log.txt
```

Готовый `.cf` можно коммитить отдельно, если ПМ решит хранить бинарник; по умолчанию в git — только XML.

## Проверка после загрузки

1. Разделы интерфейса: **Главное**, **Оперативный учет**, **Сервис**.
2. Есть документы: Приходная / Расходная накладная, Корректировка регистров.
3. Регистр сведений **Учетная политика (управленческий учет)** доступен для записей FIFO / LIFO / По средней.
4. Пройдите сценарии из `../README.md` и `Документация/tasks/task-ou-wholesale-batch-accounting.md`.
5. Алгоритмы для разработчика: `../developer-algorithm.html`.

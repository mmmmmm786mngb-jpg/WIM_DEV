## Идентичность (после ТЗ)

По IMDEV-8815/8837 это **апдейт** «Оплата КЗ по клиентам РДУ», не новая обработка.  
Имя файла `СозданиеПоручений…` путает; при установке идентификация по `ИмяОбъекта=ОплатаКзПоКлиентамРДУ` — перетрёт существующую запись. На UAT уже ставили ветку до **v2.19**.

## Главное vs ФТ

Фон НДФЛ в коде делает **три режима подряд** в одном запуске.  
По ФТ и сценарию дней 1–8 каждый день — **одна ветка** по регистрам 68.01 / ДС заблокированные / Требования.

## Критичные

1. Ветвление фона НДФЛ (C1)
2. Сумма блокировки при учёте остатков б/с (полная вместо обязательство−б/с; условие `<=` вместо `<`)
3. Дата блокировки: календарный T−1, нужен рабочий день
4. `Возврат` вместо `Продолжить` в цикле статусов
5. `СтрШаблон` без аргумента для ВУК-блокировки

Вердикт: **request changes**.

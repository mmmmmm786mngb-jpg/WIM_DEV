Замечание CR Объект — Метод — Ошибочный код Предлагаемое решение
C1 Фон НДФЛ выполняет три режима подряд в одном запуске вместо выбора одной ветки по регистрам (ФТ, сценарий дней 1–8).
Объект: ВнешняяОбработка.ОплатаКзПоКлиентамРДУ
Метод: ВыполнитьОбработкуВФонеНДФЛ 
// Шаг 1 Блокирование ДС
СравниватьСБрокерскимиСуммами = "НеУчитыватьОстаткиНаБрокерскомСчете";
ЗаполнитьНачислениями(НачислениеНДФЛ, Истина);
СформироватьБлокировкуДенежныхСредств();
...
// Шаг 2 Формирование Поручений
СравниватьСБрокерскимиСуммами = "БрокерскимСчетом";
...
СформироватьПлатежноеПоручение();
...
// Шаг 3 Сравнение с Расчетным счетом
СравниватьСБрокерскимиСуммами = "РасчетнымСчетом";
...
СформироватьШаблон();
Разделить запуск на ветки по ФТ:
1) проверить сальдо 68.01;
2) если есть — остаток ДС заблокированные (НДФЛ) на Т−1;
3) если блокировок нет — только режим блокировки + рассылка;
4) если блокировки есть — по Требованиям по ДС выбрать режим «БрокерскимСчетом» или «РасчетнымСчетом» и выполнить только его (с повторным ЗаполнитьНачислениями).
Не выполнять шаги 1–3 подряд в одном сеансе.
C2 При учёте остатков на б/с сумма блокировки должна быть «обязательство − б/с», отбор где б/с меньше обязательства (Блокировка ДС.docx).
Объект: ВнешняяОбработка.ОплатаКзПоКлиентамРДУ
Методы: ПроверкаУсловийДобавления, ЗаполнитьНачислениями 
ИначеЕсли СравниватьСБрокерскимиСуммами = "УчитыватьОстаткиНаБрокерскомСчете"
    И (Выборка.СуммаБрокерскийСчет <= Выборка.СуммаОбязательства) Тогда
    Возврат Истина;

// ...
НоваяСтрока.СуммаБлокировки = Выборка.СуммаОбязательства;
 
// отбор: строго меньше
И (Выборка.СуммаБрокерскийСчет < Выборка.СуммаОбязательства)

// сумма блокировки
НоваяСтрока.СуммаБлокировки =
    Выборка.СуммаОбязательства - Выборка.СуммаБрокерскийСчет;
Для режима «Не учитывать остатки» оставить полную сумму обязательства.
C3 Дата документа блокировки: календарный T−1 вместо T−1 рабочего дня в 09:00.
Объект: ВнешняяОбработка.ОплатаКзПоКлиентамРДУ
Метод: СформироватьБлокировкуДенежныхСредств 
ДатаДок = НачалоДня(НачалоДня(Период) - 1) + 60*60*9;
Вычислять предыдущий рабочий день по производственному календарю (типовой API календаря конфигурации / БСП) и ставить время 09:00:
ДатаДок = НачалоДня(ПредыдущийРабочийДень(Период)) + 9 * 3600;

По ТЗ — дата создания блокировки (T−1 рабочий день).

H3 Ошибка приоритета И/ИЛИ в отборе данных для рассылки.

    ИЛИ СуммаОбязательства = 0 Тогда
    Возврат ДанныеДляРассылки;

        Возврат ДанныеДляРассылки;
    КонецЕсли;

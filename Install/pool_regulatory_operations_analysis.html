2. Целевой алгоритм выполнения

Одна пуловая регламентная операция становится "головным основанием" для массового формирования всех зависимых документов по договорам, входящим в пул.
  1. Определить режим выполнения: обычный или пуловый.
  2. Если режим пуловый, получить список действующих договоров по пулу.
  3. Выполнить расчет на уровне пула и подготовить общий контекст расчета.
  4. На основании результата пакетно сформировать документы по всем договорам.
  5. Сохранить трассировку: связь "пуловая операция -> созданные документы".

4. Производительность и "звездочка"

Задание со звездочкой: пуловое проведение документов, когда для тысяч документов сразу выполняется заполнение и расчет движений.

Практические рекомендации

  • Собирать данные пакетами, не выполнять тяжелые запросы в цикле по одному договору.
  • Использовать промежуточные таблицы/наборы для массового расчета движений.
  • Разделить этапы на "подготовка данных", "расчет", "запись" с замерами по каждому этапу.
  • Проводить документы батчами с контролем размера пакета (например, по 200-500).
  • Добавить диагностические поля в журнал выполнения: размер пула, число документов, длительность этапов.

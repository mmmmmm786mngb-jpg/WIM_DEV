# Отчет о тестировании: обработка "Тест отправки поручений" (FO_SendFixStub 1.0.0.3)

Дата: 14.10.2026. База: разработческая база ФО (WIN_FO_server), платформа 8.3.27.2214, конфигурация 1.4.9.5.

## Объект

Обработка `FO_SendFixStub_ТестОтправки` в тестовом расширении FO_SendFixStub: отбор поручений за период, подготовка
выделенных поручений (статус "Проверено" без проверки лимитов, очистка биржевого номера, снятие блокировки) и
отправка выделенных типовым распорядителем `Распорядители.Отправка` - фоновым заданием или в текущем вызове сервера.
Работает только в тестовых базах (`Адаптеры.ЗаглушкаОтправкиFIXВключена`).

## Тестовые данные

В разработческой базе у поручений нет адаптеров, тикеров, торговых счетов и режимов торгов, поэтому на время теста
создавались и затем удалялись или восстанавливались:

- адаптер вида FIX (с признаком "использовать режимы торгов") и запись `ИспользуемыеАдаптеры`;
- настройки WebSocket-прокси на локальный HTTP-слушатель (счетчик запросов);
- 5 поручений за 07.10.2026: 4 привязаны к тестовому адаптеру, 1 без адаптера FIX (проверка отбора);
- тикер TEST9529 у актива поручений, временный торговый счет TEST9529, режим торгов у 4 поручений
  (запись документов - внешней обработкой `ДанныеТеста9529.epf` в фоновом задании, без проведения);
- снимок регистров тестовых поручений: `СтатусыПоручений`, `БиржевыеЗаявки`, `РасширенияПоручений`,
  `СтатусыПорученийБлокировки`, `СобытияПоручений`, `СобытияПорученийТорговые`, `ПорученияДляОбменаС_CRM`,
  `ХешОбъектов` - восстанавливается после теста.

## Результаты

| № | Проверка | Результат |
|---|---|---|
| 1 | Синтаксический контроль модулей (тонкий клиент, сервер, внешнее соединение, толстый клиент), применимость расширения | ошибок нет, 0 проблем |
| 2 | Найти: период 07.10, без ограничения / N=2 / период 06.10 | 4 поручения (пятое без FIX не попало) / 2 / 0 |
| 3 | Подготовить 2 из 4 | статус "Проверено", биржевой номер очищен, блокировок нет; 2 невыделенных без изменений |
| 4 | Отправить 2 подготовленных, текущий вызов | статус "Отправлено, ожидается подтверждение"; пакет заглушки - 2 заявки; ключевая операция "Отправка" вес 2; 0 HTTP-запросов |
| 5 | Отправить неподготовленное поручение | отклонено типовой проверкой, статус не изменился, пакет не отправлен |
| 6-7 | Повтор: Подготовить и Отправить фоновым заданием | снова "Проверено", затем "Отправлено"; 2 заявки; вес 2; 0 HTTP-запросов |
| 8 | Регрессия: `test_stub_dev.py`, `test_ignore_violations_dev.py` | 6/6, 2/2 |
| 9 | UI, тонкий клиент: выбор периода, Найти, выделение (в том числе Ctrl+A), Подготовить с вопросом, Отправить фоновым заданием и в текущем вызове, вопрос "только подготовленные", предупреждения "Найти" после смены отбора и "нет подготовленных" | все сценарии отработали; итог формы "отправлено 4, отклонено 0, ключевая операция 0,411 с, вес 4"; ошибок клиента нет |

Найдено и исправлено при тестировании:

- имя процедуры команды `Найти` совпадало с глобальной функцией платформы - команда переименована в `НайтиПоручения`;
- таблица формы допускала добавление и удаление строк - сделана только для чтения;
- в тестовых скриптах сравнение ссылок 1С через COM всегда давало "не равно" - сравнение по УИД; остатки предыдущих
  прогонов (20 строк тикера, запись `ИспользуемыеАдаптеры`) удалены.

## Состояние разработческой базы после тестов

Адаптеров 0, записей `ИспользуемыеАдаптеры` 0, тестовых тикеров 0, торговых счетов 0, поручений с торговым счетом или
режимом торгов 0, поручений в статусе "Отправлено, ожидается подтверждение" 0, настройки прокси удалены. Сессии
тонкого клиента UI-теста завершены. Расширение FO_SendFixStub 1.0.0.3 остается загруженным и активным.

Отбор: режим не НеИспользоватьНаПреТрейд; для режима «покупки» или «продажи» сверяется направление. ОткрытиеДепозита проходит всегда. Сортировка: набор данных, лимит.

5. Три ветки

Один вызов на порцию, не на портфель:

ПроверкаЛимитов.Проверить(Запрос, ПараметрыИсх, Окружение)

7. Где менять код, чтобы убрать повторы

Запросы базиса. Место - цикл Для Каждого Строка Из ПорцияДанных в Исполнители.ПроверкаИОтправка_ОбработкаПроверки, вызовы БазисыОтАктивов и РыночнаяСтоимость. Считать их один раз на набор и массив портфелей, положить в соответствие по фокусу, в цикле только читать. Формулы Проверка_* не меняются. Число зон остается прежним.

Запись. Вызов ЗаписатьПорциюРезультатов убрать из цикла порции. Строки трех таблиц копить в КэшВм задания и один раз записать в ВыполнитьЗаписьРезультатовПроверки. Процедуру в РаботаСЛимитами не удалять.

Распорядители.ИсполнитьРаспоряжение, ветка фоновых заданий: для метода Исполнители.ПроверкаИОтправка_ОбработкаПроверки класть в задание один номер, иначе ПланПроверкиИсполнителя по Данные[0] теряет второй номер. Это не сокращение расчетов, а их полнота. Состав и поручение по числу запросов уже на порцию, не на портфель: квалификаторы там трогать не нужно.

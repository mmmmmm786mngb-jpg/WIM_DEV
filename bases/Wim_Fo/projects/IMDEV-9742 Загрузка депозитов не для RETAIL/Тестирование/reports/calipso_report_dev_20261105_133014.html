Отчет повторяет ежедневную загрузку депозитов Calipso во Фронт-офис: те же депозиты и те же правила поиска. Найденный депозит загрузка записывает в фактическую позицию портфеля. Ненайденный депозит в портфели не попадает, а только перечисляется в письме о загрузке в списке ненайденных.

Какие депозиты берутся из Calipso

  • Позиции таблицы депозитов и кредитов Calipso на последнюю дату позиции.
  • Только сделки, где контрагент и организация различаются.
  • Не берутся депозиты, у которых зеркальная сделка на ту же дату - кредит (Loan).
  • Для сделки типа Deposit клиентом считается контрагент сделки, а контрагентом - организация; для остальных сделок - наоборот.

Как Фронт-офис ищет депозит

  1. Номер сделки Calipso (поле TradeId) переводится в 36-ричную запись: цифры 0-9 и латинские буквы A-Z.
  2. Из нее составляется строка поиска: -D + запись номера + -.
  3. В справочнике Субпортфели ищется субпортфель, у которого поле Код счета содержит эту строку. Субпортфели, помеченные на удаление, не учитываются. Если подходят несколько, берется первый. Депозит записывается в портфель найденного субпортфеля.
  4. Валюта депозита (поле Currency) ищется в справочнике Валюты по наименованию, для нее - актив в справочнике Активы.

Пример: сделка 123456 в 36-ричной записи - 2N9C, во Фронт-офисе ищется субпортфель с кодом счета, содержащим -D2N9C-.

Клиент, контрагент, сумма и даты сделки в поиске не участвуют. Депозит находится только по номеру сделки, записанному в код счета субпортфеля. Клиент и контрагент приведены в таблице, чтобы можно было узнать сделку.

Вопросы к бизнесу

  1. Должны ли эти депозиты отражаться в портфелях Фронт-офиса?
  2. Если да - укажите в последнем столбце таблицы портфель Фронт-офиса для каждого депозита. Если у портфеля уже есть субпортфель для депозита, укажите его: сейчас в его коде счета нет строки из столбца "Что ищется в коде счета субпортфеля".
  3. Если депозиты сопоставлять по другому признаку (номер договора, счет, клиент) - укажите какой.
  4. Если отражать депозиты Calipso не нужно - подтвердите, что их загрузку можно отключить.

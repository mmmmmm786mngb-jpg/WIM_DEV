# Отчет по депозитам Calipso для бизнеса (Т-1)

Обработка `ОтчетДепозитыCalipso.epf` запускается в обычном ФО (не в рознице) на Т-1. Она читает депозиты Calipso тем же
запросом и с той же учетной записью SQL, что ежедневная загрузка депозитов (`внЗагрузкаДепозитовИзВнешнихИсточников`
1.19), ищет каждый депозит в ФО по тем же правилам и формирует HTML-файл для бизнеса:

- какие депозиты получены из Calipso (номер сделки, продукт, клиент, контрагент, валюта, номинал, ставка, даты);
- как ФО ищет депозит: номер сделки переводится в 36-ричную запись, в справочнике "Субпортфели" ищется субпортфель,
  у которого поле "Код счета" содержит `-D<запись>-` (помеченные на удаление не учитываются); валюта - в справочнике
  "Валюты" по наименованию, актив - в справочнике "Активы";
- результат по каждому депозиту и столбец, где бизнес укажет нужный портфель ФО.

Данные ФО и Calipso не меняются, в Calipso выполняется только SELECT. В копии Т-1 подключение к Calipso идет на
сервер ПРОД `AMDBRATES\DBMVTBAM01` (так зашито в обработке загрузки), поэтому отчет показывает текущую позицию ПРОД
Calipso, а поиск идет по справочникам ФО Т-1 (копия ПРОД на ночь).

## Шаги

1. Открыть обычный ФО Т-1 (тонкий клиент Windows) пользователем с полными правами. Файл - Открыть -
   `ОтчетДепозитыCalipso.epf`; на вопрос о защите от опасных действий - разрешить.
2. Нажать "Сформировать". Подключение идет с сервера 1С, как у регламентной загрузки (обычно секунды; при недоступном
   сервере ошибка придет примерно через 15-20 секунд).
3. Если в поле результата ошибка подключения - включить флажок "Подключаться к Calipso с компьютера пользователя" и
   нажать "Сформировать" снова: подключение пойдет с вашего компьютера.
4. В поле результата - сводка: число депозитов, найдено, не найдено и строка на каждый депозит. Нажать
   "Сохранить отчет (HTML)" - файл `Депозиты_Calipso_<дата>_<время>.html`.
5. Открыть файл в браузере, проверить, что число депозитов совпадает с письмом о загрузке (ожидается 12, все не
   найдены), и передать бизнесу.

## Что проверено на dev

- dev ФО, синтетические строки в формате ответа Calipso (временный субпортфель `T9742-D...-` создан и удален
  скриптом): найден, не найден, неизвестная валюта, нулевой номер, экранирование HTML, порядок строк, даты -
  `Скрипты/run_calipso_report_dev.py`, 11 из 11.
- Форма открыта в тонком клиенте dev: "Сформировать" в обоих режимах подключения доходит до SQL-сервера и выводит
  ошибку подключения с подсказкой (с dev сервер Calipso недоступен).
- Чтение реальных данных Calipso на dev не проверено - только на Т-1.

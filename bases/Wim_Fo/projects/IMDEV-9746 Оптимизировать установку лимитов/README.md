# IMDEV-9746. Оптимизировать операцию "Установка лимитов"

Строка 3 списка ключевых операций ФО: распространение правил лимитов на новых клиентов после обмена (ВО `внОперацииПослеОбмена`, `ВыполнитьРаспространениеПравилПослеОбмена`). Задача выделена из анализа ключевых операций ФО (папка `Анализ групп 3-15 и 9-13`), материалы скопированы оттуда 31.10.2026. Новых замеров и кода по строке 3 после 28.10 нет.

Кратко из анализа: на ПРОД розница 19.10 - 42 запуска, 10-25 с на запуск, около 1,55 с на пару портфель+класс; обычный ФО - около 24 с на одного клиента (причина не разобрана, п. 3.4). Резервы 3.1 (одно письмо на класс), 3.2 (пауза 2 с на пару в `ВыполнитьЗаписьВерсийЛимитов`), 3.3 (лишний проход `ПорогиЛимитов`); дефект - временные XLS не удаляются.

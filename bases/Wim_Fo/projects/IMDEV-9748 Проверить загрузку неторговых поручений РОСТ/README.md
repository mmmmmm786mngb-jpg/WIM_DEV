# IMDEV-9748. Проверить потребность в оптимизации операции "Загрузка неторговых поручений РОСТ"

Строка 13 списка ключевых операций ФО: ВО `внЗагрузкаНеторговыхПорученийРОСТ` 1.07, каждые 10 минут. Задача выделена из анализа ключевых операций ФО (папка `Анализ групп 3-15 и 9-13`), материалы скопированы оттуда 31.10.2026. 03.11.2026 добавлена выгрузка замеров ПРОД розница за октябрь - начало ноября; разбор по обработке - `Анализ замеров ПРОД 16.10-02.11.md`: 587 запусков за 11 рабочих дней, 234 с в день, медиана 3,6 с, 0,63 с на поручение, оценка "не узкое место" подтверждена.

Кратко из анализа: на ПРОД розница 19.10 - 52 запуска, в среднем 5 с, максимум 35,6 с; около 0,55 с на созданное поручение. Узким местом не является. Дешевые резервы 13.1 (неиспользуемый `ПолучитьСуммуКупоны`) и 13.2 (отбор `ДополнительныеСведения` без `Объект`), 13.3 - на согласование. Ранее (IMDEV-9531, 06.10) было решение обработку не трогать. Открытый вопрос: поручения обработкой не отправляются (`ОтправитьПоручения` не вызывается) - так задумано?

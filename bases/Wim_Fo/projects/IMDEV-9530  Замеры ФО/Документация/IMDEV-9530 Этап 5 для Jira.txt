h3. Что такое вес и какие показатели пишутся дополнительно

Каждая запись замера содержит длительность, вес, номер сеанса и комментарий. Длительность и номер сеанса пишет БСП. Вес и комментарий задает код замера. Во всех четырех обработках используется обычный замер БСП: в регистр пишется полное время участка.

*Вес* - масштаб операции, чтобы длительность можно было сравнивать между прогонами разного размера.
* Где в операции есть портфели (договоры), вес - число портфелей. Так у загрузки депозитов.
* Где портфелей нет, вес - число обработанных объектов: котировки, записи данных индексов, контрагенты.
* Если количество равно 0, в регистр пишется вес 1, а фактический ноль остается в комментарии. Поэтому в комментарии всегда есть число, по которому считается вес.

*Дополнительные показатели* пишутся в комментарий замера (поле {{ДопИнф}} стандартного комментария БСП). Формат: {{Показатель: значение; Показатель: значение}}. Состав полей - в таблицах точек ниже.

*При сбое загрузки замер не пишется:* ни общая запись, ни шаг, на котором произошел сбой, ни шаги после него. Шаги, выполненные до сбоя, остаются. Этим загрузки отличаются от неторговых поручений РОСТ (строка 13), где ошибка помечается в записи. Что считается сбоем:
* депозиты - ни одного депозита ни из одного источника (в письме обработки это {{FAIL}}) или ошибка отправки письма;
* котировки - ошибка сервиса или хотя бы один непроведенный документ котировок;
* индексы - ошибка загрузки (признак ошибки обработки); предупреждения сбоем не считаются;
* TCRIS - база Rates недоступна.

*Общая запись* пишется только у регламентного запуска (команда фонового выполнения). Замеры шагов стоят в процедурах загрузки, поэтому пишутся и при вызове этих процедур с формы обработки. Отдельных замеров кнопок формы нет.

Если константа "Выполнять замеры производительности" выключена, замеры ничего не пишут и обработки работают как прежде.

h3. Измененные и добавленные процедуры

Во всех четырех обработках добавлены переменная модуля {{ПоказателиЗамера}} (показатели шагов для общей записи, начальное значение задается в конце модуля) и область {{ЗамерыПроизводительности}} со служебными функциями. Каждая вставка помечена комментарием, который начинается с {{IMDEV-9530}}.

h4. Загрузка депозитов, 1.19

Изменены:
* {{ВыполнитьКоманду}} - общий замер регламентного запуска.
* {{ЗаполнитьДепозиты}} - шаг получения депозитов, число депозитов по источникам, признак сбоя при пустом ответе всех источников.
* {{ОбновитьФактическуюПозицию}} - шаг обновления позиции: портфели, обновленные и ненайденные депозиты.
* {{ЗапуститьРассылкуПисьма}} - шаг рассылки, признак сбоя при ошибке отправки.

Добавлены:
* {{КомментарийЗамера}} - собирает комментарий замера из показателей.

h4. Загрузка котировок ММВБ, 1.03

Изменены:
* {{ВыполнитьКоманду}} - общий замер регламентного запуска.
* {{ЗагрузитьОбъекты}} - шаг чтения котировок из сервиса.
* {{СоздатьОбъекты}} - шаг записи документов котировок, счетчики записанных и непроведенных документов.

Добавлены:
* {{ЗаполнитьКоличествоКотировокЗамера}} - число котировок к загрузке и котировок с найденной бумагой.
* {{КомментарийЗамера}} - собирает комментарий замера из показателей.

h4. Загрузка индексов, 1.04

Изменены:
* {{ВыполнитьКоманду}} - общий замер регламентного запуска.
* {{ЗагрузитьОбъекты}} - шаг чтения данных индексов из сервиса.
* {{СоздатьОбъекты}} - шаг записи данных и составов индексов.

Добавлены:
* {{ЗаполнитьКоличествоЗаписейЗамера}} - число индексов в запросе, записей данных индексов и записей состава.
* {{КомментарийЗамера}} - собирает комментарий замера из показателей.

h4. Загрузка доп реквизита TCRIS, 1.02

Изменены:
* {{ВыполнитьКоманду}} - общий замер регламентного запуска.
* {{ЗагрузитьTCRIS}} - шаги чтения из Rates, сопоставления контрагентов и записи сведения TCRIS, счетчик контрагентов.

Добавлены:
* {{КомментарийЗамера}} - собирает комментарий замера из показателей.

h3. Замечания по исходным обработкам

Код обработок не менялся, только для сведения:
* Загрузка депозитов, если ни один источник не вернул депозиты, удаляет все позиции депозитов ФО за дату загрузки.
* Загрузка котировок, если документ не провелся, а следующий провелся, пишет в журнал "Успех!". Непроведенный документ виден только в сообщении "Не удалось провести".
* Загрузка TCRIS при недоступной базе Rates завершается ошибкой задания.
* В обработках депозитов и TCRIS учетные данные подключения к SQL Server и веб-сервисам заданы в коде.

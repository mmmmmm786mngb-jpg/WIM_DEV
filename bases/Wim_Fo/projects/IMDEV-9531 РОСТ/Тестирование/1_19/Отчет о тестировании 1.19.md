## 3. Ограничение 300 с

Настройка 500 записана в настройки обработки в обход формы, затем реинвестирование (пакет 200):

- в логе каждого потока: "Кеш цены стакана: 300 с";
- в комментарии замера: "...; Кеш стакана: 300 с";
- запросов стакана - по одному на поток.

В этом прогоне один поток из 10 (номер 3) упал на первом поручении в неизмененном коде записи поручения
(ЗаписатьПоручение, Субпортфель.Стратегия) с ошибкой "Нарушение прав доступа". Это тот же сбой dev-стенда, что 16.10
у 1.16 и 1.18 (поток номер 3, первое поручение, ошибка прав). К настройке срока кеша не относится: ошибка возникает до
запроса цены. Остальные 9 потоков отработали с ограничением 300 с.

## 4а. Истечение срока цены внутри запуска (19.10.2026, срок 3 с)

Срок 3 с меньше длительности прогонов. Заглушка стакана записывает время начала и конца каждого запроса, бумагу и номер
сеанса; для каждой пары "сеанс + бумага" считается пауза от конца запроса до следующего запроса - это время, пока цена
жила в кеше. Скрипт run_ttl_check.py, данные reports/ttl_check.json.

| Сценарий | Время | Запросов стакана | По паре сеанс+бумага | Паузы, с | Итог |
|---|---|---|---|---|---|
| Покупка, 20 поручений одной облигации | 12,0 с | 2 | 2 | 3,30 | OK |
| Продажа, 100 поручений по двум бумагам | 45,1 с | 18 | 9 и 9 | 3,01-3,34 | OK |
| Реинвестирование, 10 потоков по 20 поручений | 30,1 с | 47 | 4-5 в каждом потоке | 3,02-3,75 | OK |

- Пауза не меньше срока: действующая цена повторно не запрашивается.
- Пауза не больше срока плюс одно поручение: устаревшая цена не используется, стакан спрашивается заново.
- У каждого потока реинвестирования свой кеш (отдельные сеансы), срок соблюдается в каждом.
- Замеры: ЦенаИзСтакана 2 / 18 / 47 и ЦенаИзКеша 18 / 82 / 153 - совпадают с числом запросов к заглушке.
- Поручения сверены с эталоном 1.16 того же дня: 320 из 320 совпали, статусы совпадают.
- После проверки срок кеша на dev возвращен в 0.

## 6. Форма "Настройки" вручную (19.10.2026, тонкий клиент в режиме клиента тестирования TESTCLIENT)

Боевая сборка УСКОРЕНО_1_19 открыта в тонком клиенте dev (/Execute), на форме обработки - кнопка "Открыть настройки"
(перед этим закрыто окно лицензии Аванкор, которое dev показывает при старте).

| Действие пользователя | Результат |
|---|---|
| Открыть настройки | Поле "Срок кеша цены стакана, с" под флажком "Контроль по цене закрытия", значение 0, рядом кнопка подсказки "?" |
| Ввести 500 | Платформа: "В поле введены некорректные данные", кнопки "Продолжить ввод" / "Отменить ввод"; после отмены в поле 0 |
| Ввести -5 | То же сообщение, значение не принято |
| Ввести 45, "Установить настройки" | Принято; в настройках элемента справочника в базе 45, остальные настройки (комиссия, стратегии) на месте |
| Открыть настройки снова | В поле 45 |
| "Настройки по умолчанию" | В поле 0. Форма закрыта без сохранения: в базе осталось 45 (кнопка сбрасывает и стратегии, рассылку, адрес веб-сервиса, поэтому на стенде не сохранялась) |
| Ввести 0, "Установить настройки" | В базе 0, стратегии на месте |

Клиент закрыт штатным выходом (shutdown: graceful). На dev срок кеша - 0.

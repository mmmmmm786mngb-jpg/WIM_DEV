# Создание торговых поручений РОСТ, версия 1.18

Основа - версия 1.16 (каталог ОРИГИНАЛ_1_16, с замерами IMDEV-9530). Все правки помечены комментарием IMDEV-9531.

## Что изменено

Цена из стакана для бумаги, которая уже прошла все проверки в текущем запуске, берется из кеша запуска, без повторного
запроса к адаптеру.

- Ключ кеша: бумага, режим торгов поручения, направление поручения, номер цены. Режим торгов определяет код инструмента
  и площадку, по которым адаптер запрашивает стакан, и по которым механизм цен проверяет поручение перед запросом.
- В кеш попадает только цена, прошедшая все проверки: отклонение от лучшей цены не больше 2%, при контроле по цене
  закрытия - отклонение от цены закрытия не больше 2%. Отказ не кешируется: следующее поручение той же бумаги снова
  запрашивает стакан, как в 1.16.
- Срок действия цены в кеше - 60 секунд (функция СрокДействияЦеныСтакана). Старше - новый запрос стакана.
- Кеш живет в пределах одного запуска: регламентная покупка, продажа, один поток реинвестирования, один поток продаж под
  блокировки. В начале каждого запуска кеш очищается.
- Порядок работы с поручением не изменен: создание, первое проведение, цена, проведение с ценой, проведение суммы - в
  той же транзакции и в том же порядке, что в 1.16. Поручений с ценой-заглушкой вне транзакции не появляется.
- В тестовом режиме (ЭтоТест) кеш работает так же, вместо стакана - котировка из регистра.
- Новый шаг замера "ЦенаИзКеша" (цена взята из кеша), шаг "ЦенаИзСтакана" остается для настоящих запросов.

Код проверки стакана перенесен из ИзменитьЦенуПоручения в функцию ЦенаСтаканаСПроверкой без изменения логики
(вместо Возврат Ложь - Возврат 0).

## Отличия от 1.17

| | 1.17 | 1.18 |
|---|---|---|
| Когда запрашивается стакан | один запрос на все поручения продажи и на все поручения потока | первое поручение каждой бумаги в запуске, дальше кеш до 60 с |
| Запись поручения в продаже и реинвестировании | проведение с ценой-заглушкой, фиксация транзакции, цена вторым проходом | как в 1.16: цена ставится до фиксации |
| Ошибка адаптера посреди прогона | остаются проведенные поручения с ценой 1 или 100 | транзакция поручения откатывается, как в 1.16 |
| Поручение, отбракованное проверкой перед запросом цены | может получить цену из кеша | ключ включает режим торгов, отбраковка повторяется |
| Отказ стакана | записывается в кеш на весь пакет | не кешируется, следующее поручение спрашивает заново |
| Срок жизни цены | весь пакет | 60 с |

## Чего нет в 1.18

- Исправлений ошибок 1.15/1.16, не связанных со стаканом (кнопка реинвестирования без потоков, очистка чужого списка
  заданий при продажах под блокировки).
- Сокращения числа проведений поручения.

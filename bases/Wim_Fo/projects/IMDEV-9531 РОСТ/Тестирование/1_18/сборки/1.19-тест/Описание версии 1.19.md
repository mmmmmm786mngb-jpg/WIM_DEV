# Создание торговых поручений РОСТ, версия 1.19

Основа - версия 1.18 (кеш цены стакана). Отличие от 1.18 одно: срок кеша задается в настройках обработки, а не
константой 60 с. Все правки помечены комментарием IMDEV-9531.

## Настройка

Форма "Настройки" обработки, поле "Срок кеша цены стакана, с" (рядом с флажком "Контроль по цене закрытия").

| Значение | Поведение |
|---|---|
| 0 | Кеш выключен. Стакан запрашивается на каждое поручение, как в 1.16. |
| 1-300 | Цена бумаги, прошедшая проверки в запуске, используется для следующих поручений той же бумаги, режима торгов и направления, пока ей не больше указанного числа секунд. |

- По умолчанию 0. В настройках, сохраненных версиями до 1.19, поля нет - после установки 1.19 кеш выключен, пока
  срок не задан явно. Кнопка "Настройки по умолчанию" тоже ставит 0.
- Ограничение: поле формы принимает 0-300. Значение больше 300 или меньше 0, записанное в настройки не через форму,
  обработка приводит к 300 или 0.
- Новое значение действует со следующего запуска: регламентного прогона, кнопки формы, потока реинвестирования или
  продаж под блокировки. Запуск, который уже идет, работает со значением, прочитанным при старте.

## Где видно, с каким сроком шел запуск

- Лог запуска и письмо: строка "[inf] Кеш цены стакана: N с" или "[inf] Кеш цены стакана выключен".
- Комментарий замера СозданиеТорговыхПорученийРОСТ.<операция>: в конце добавлено "Кеш стакана: N с"
  (0 - кеш выключен). По замерам ПРОД можно сравнивать прогоны с кешем и без него на одной сборке.

## Изменения в исходниках относительно 1.18

- Реквизит обработки СрокКешаЦеныСтаканаСек: число 3,0, неотрицательное, допустимые значения 0-300, подсказка.
- Форма "Настройки": поле ввода СрокКешаЦеныСтаканаСек.
- Модуль объекта:
  - УстановитьПользовательскиеНастройки читает поле, при его отсутствии ставит 0;
  - УстановитьПараметры сохраняет поле;
  - НастройкиПоУмолчанию ставит 0;
  - СрокДействияЦеныСтакана возвращает значение настройки, приведенное к целому 0-300;
  - при сроке 0 ЦенаСтаканаИзКеша сразу возвращает "цены нет", ЗапомнитьЦенуСтакана ничего не записывает;
  - новая функция ОписаниеКешаЦенСтакана - строка лога, выводится в начале каждого запуска;
  - комментарий замера дополнен сроком кеша.

## Рекомендуемый порядок включения на ПРОД

1. Установить 1.19, срок 0: работа как у 1.16, замеры IMDEV-9530 пишутся.
2. Собрать замеры "до" несколько дней.
3. Поставить согласованный срок (например 30 или 60 с), собрать замеры "после".
4. Откат - срок 0 в настройках, без переустановки обработки.

# Проект example

Шаблон проекта на базе **Wim_Fo** (Аванкор Фронт-офис). Переименуйте папку под номер задачи или смысл проекта.

## Источник кода базы

Путь к каталогу в WORK (исходники не копировать в проект) — в файле **../../source-path.txt**.

Типовые подкаталоги:

- основная конфигурация: `{source-path}\SRC\CF\`
- расширение ВТБ_Прод: `{source-path}\SRC\CFE\ВТБ_Прод\`

Скрипты и инструменты должны читать корень из `source-path.txt`, затем добавлять `SRC\CF` или `SRC\CFE\...`.

## Структура проекта

- **Расширения/** — доработки конфигурации (новые CFE или фрагменты для сборки)
- **Документация/** — ТЗ, спецификации, разбор WS и регламентов
- **Тестирование/** — сценарии тестов, отчеты (`reports/`), Python COM
- **Скрипты/** — выгрузка/загрузка XML/CF, замеры, интеграции

## Что не класть в проект

- Полную выгрузку `SRC\CF` и `SRC\CFE` — она остается в WORK
- Скомпилированные `.cf` / `.cfe` без необходимости (по согласованию с командой)

## Требования

- Платформа 1С:Предприятие не ниже 8.3.21
- EDT или конфигуратор
- Доработки типовой CF — только через расширения; правки вендорного CF — по процессу вендора/поддержки

Стиль кода 1С — по правилам репозитория (`.cursor/rules/`, `.cursor/skills/`).

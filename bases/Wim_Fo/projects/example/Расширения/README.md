# Расширения

Доработки конфигурации ФО — через расширения (CFE). Исходники базовой конфигурации в `SRC\CF` не изменяются в проектах репозитория.

Продуктивное расширение **ВТБ_Прод** уже выгружено в WORK: `{source-path}\SRC\CFE\ВТБ_Прод\`.

В этой папке храните **новые** расширения проекта или патчи для последующей сборки.

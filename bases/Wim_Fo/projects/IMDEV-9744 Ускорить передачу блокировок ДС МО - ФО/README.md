# IMDEV-9744. Утренняя выгрузка остатков МО - ФО Розница: ускорить передачу блокировок ДС

С 21.10.2026 выгрузка идет 94 мин вместо 41: в МО Розница появились блокировки ДС "Вознаграждение" от 19.10 по 19,4 тыс. мандатам, и обработка выгрузки `внВыгрузкаОстатковМО_ФО` передает каждую в ФО отдельным вызовом `DownloadOrders`. Решение - версия 1.43: блокировки пакета одним вызовом, при ошибке повторная отправка по мандатам.

Задача выделена из анализа ключевых операций ФО (папка `Анализ групп 3-15 и 9-13`), материалы скопированы оттуда 29.10.2026. Пути в скриптах переведены на эту папку и проверены.

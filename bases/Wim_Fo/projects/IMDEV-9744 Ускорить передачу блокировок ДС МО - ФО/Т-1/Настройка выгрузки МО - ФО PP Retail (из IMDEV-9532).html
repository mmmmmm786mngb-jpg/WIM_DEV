Выгрузка остатков МО в тестовую ФО PP Retail

Обработка «Выгрузка остатков МО ФО», версия 1.42. Только тестовая база МО. Получатель: публикация AVC_PP_RETAIL_FO.

Общий шаг Ручной запуск Регламент Проверка
В версии 1.42 поле Адрес WS — это не строка URL, а элемент справочника Внешние информационные базы. Обработка сама собирает адрес: Адрес web-сервиса + /ws/ + Имя web-сервиса + .1cws?wsdl. И ручной запуск, и регламент должны указывать на один и тот же элемент этого справочника.
Чтобы выгрузка не ушла на прод:
  • Работайте в тестовой МО, не в продуктивной.
  • Не меняйте элемент справочника, у которого в адресе уже есть amapfront, ammgavancore или PROD_. Заведите отдельный элемент для PP Retail.
  • На узле ВыгрузкаОстатков_ФОРозн снимите флажок Регламентное задание разрешено и запишите узел до того, как поменяете адрес. Иначе утренний запуск уйдет по старому адресу.
  • Кнопку Настройки по умолчанию на форме настроек не нажимайте: она подставляет продуктивный адрес и для этой версии имеет неверный тип.
  • Узел ВыгрузкаОстатков_ФО (корпоративный ДУ) не открывайте и не меняйте.

1. Общий шаг. Элемент справочника с адресом ФО

Этот шаг один для обоих способов запуска.

  1. В тестовой МО откройте раздел Администрирование, справочник Внешние информационные базы.
  2. Создайте новый элемент. Наименование, например: AVC_PP_RETAIL_FO.
  3. Заполните поля строго так, как в таблице. Полный адрес с ?wsdl в поле адреса не пишите.
  4. Запишите элемент.
  5. Откройте получившийся адрес в браузере с сервера 1С, где работает тестовая МО. Должен открыться XML веб-сервиса avancore_ws.
Поле элементаЧто вписать
Адрес web-сервиса http://smsk02mg138u/AVC_PP_RETAIL_FO
Имя web-сервиса avancore_ws
Имя пользователя пусто
Пароль пусто

Из этих двух полей обработка получает адрес:

http://smsk02mg138u/AVC_PP_RETAIL_FO/ws/avancore_ws.1cws?wsdl
Логин и пароль оставьте пустыми: публикация PP Retail принимает учетную запись Windows сервера 1С. Если WSDL в браузере с сервера открывается, а из обработки нет, значит у сеанса сервера 1С нет прав на эту публикацию.

2. Ручной запуск

Форма обработки при открытии адрес из узла обмена не подставляет. Элемент справочника нужно выбрать на форме перед каждой выгрузкой.

Где

Файл, Открыть, обработка Выгрузка остатков МО ФО (внВыгрузкаОстатковМО_ФО), версия в заголовке формы: v.1.42.

Либо раздел дополнительных обработок, команда Выгрузка остатков МО ФО (открытие формы, не команда «в фоне»).

Что заполнить

  1. Поле Адрес WS: элемент AVC_PP_RETAIL_FO, созданный в шаге 1. Не вставляйте сюда текст URL.
  2. Дата позиции: дата, за которую нужны остатки. Для пробы возьмите предыдущий рабочий день.
  3. Количество портфелей в пакете: для первой пробы 1.
  4. В отборе мандатов оставьте один тестовый мандат. Без отбора уйдут все остатки тестовой МО.
  5. Нажмите Заполнить. Этот шаг только читает МО и в ФО не ходит. На форме должны появиться строки остатков.
  6. Нажмите Опубликовать. Только эта кнопка вызывает веб-сервис ФО.
После публикации сообщение начинается с «Загрузка произведена по адресу». Там будет наименование элемента справочника, а не URL. Сверьте, что это AVC_PP_RETAIL_FO, и еще раз откройте карточку элемента: в адресе web-сервиса должен быть smsk02mg138u/AVC_PP_RETAIL_FO.

3. Запуск через регламент

Регламент форму не открывает. Адрес он берет из настроек узла плана обмена, которые записываются вместе с узлом. Пока узел не записан после кнопки «Установить», задание продолжает использовать старый адрес.

Где

Обмен данными, Инфраструктура, план обмена Источники обмена, узел ВыгрузкаОстатков_ФОРозн.

Что сделать

  1. Откройте узел. Снимите флажок Регламентное задание разрешено. Запишите узел.
  2. Проверьте поле Внешняя обработка: обработка «Выгрузка остатков МО ФО».
  3. Проверьте поле Имя метода: точно ФоноваяВыгрузка, без пробелов. Другое имя метод версии 1.42 не выполняет.
  4. Если узел изменен и еще не записан, форма настроек не откроется. Сначала запишите узел.
  5. Нажмите гиперссылку под полем «Имя метода». Это команда Настройка внешней обработки. Если настройки уже есть, на ссылке их краткое описание, иначе текст «настройки не установлены».
  6. В открывшейся форме в поле Адрес WS выберите элемент AVC_PP_RETAIL_FO. Остальные поля узла (узлы регистрации ненайденных, УК, почта) не меняйте.
  7. Нажмите Установить.
  8. Вернитесь на узел и запишите его. Без этой записи новый адрес в задание не попадет.
  9. Для проверки запустите обмен вручную кнопкой Старт на узле, с одним тестовым мандатом в настройках, если отбор уже задан. Флажок регламента пока не включайте.
  10. Когда в протоколе адрес — элемент PP Retail, верните флажок Регламентное задание разрешено и запишите узел. Расписание кнопкой Настройка расписания не меняйте, если оно уже настроено на тестовом контуре.

# Диагностика блокировок ДС в МО розница на Т-1

Обработка `ДиагностикаБлокировокМО.epf` (версия 1 от 28.10.2026) только читает данные: ничего не записывает,
не проводит и не отправляет в ФО. Результат - текстовый лог, его нужно прислать обратно.

Зачем: с 21.10 выгрузка остатков МО - ФО в розницу отправляет около 19,4 тыс. поручений-блокировок (по одному на
мандат с остатком в регистре "Денежные средства заблокированные"), каждое отдельным вызовом. Лог должен показать,
когда, каким документом и какой обработкой появились эти блокировки.

## Запуск

1. Открыть МО розница на Т-1 (тонкий клиент) пользователем с полными правами: нужны права на регламентные задания.
2. Файл - Открыть - `ДиагностикаБлокировокМО.epf`. Если платформа спросит про защиту от опасных действий - разрешить.
3. Поле "Дней истории" - 30.
4. "Собрать лог", затем "Сохранить в файл (txt)" и прислать файл.

## Что в логе

| Раздел | Зачем |
|---|---|
| 1.1 | Замеры обработки выгрузки по дням и ключам: время шагов и вес замера `Блокировки_Сервер` (число строк блокировок, отправляемых в ФО) |
| 2.1 | Движения блокировок по дням: вид движения, объект блокировки, тип документа, записи, мандаты, сумма |
| 2.2 | Остатки блокировок на конец каждого из последних 15 дней по объекту блокировки: мандаты, строки, сумма |
| 2.3 | Остатки на текущий момент по типу мандата и объекту блокировки |
| 3.1 | Документы "Блокировка/разблокировка ДС" по дням: вид операции, объект блокировки, проведен, пометка удаления, основание |
| 4.1 | Обработки создания и обнуления блокировок, выгрузки и сверки: версия, публикация, команды и их регламентные задания |

## Что скрыто

Имена мандатов и клиентов в лог не выводятся, только количества и суммы. Основание документа выводится текстом
(до 100 символов). На Т-1 последний запуск регламентных заданий - собственный, самой Т-1, а не ПРОД.

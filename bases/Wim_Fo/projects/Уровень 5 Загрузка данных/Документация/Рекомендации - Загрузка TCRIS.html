Рекомендации по доработке: Загрузка TCRIS

По итогам нагрузочного тестирования 14.11.2026. Три главных предложения в порядке приоритета.

1. Писать только изменившиеся значения

Перед циклом одним запросом прочитать текущие значения TCRIS всех сопоставленных контрагентов и записывать только тех, у кого значение изменилось.

Ожидаемый эффект: Практически весь шаг записи: секунды вместо 31-33 с в каждой базе в обычный день.
Сложность: Низкая

2. Искать свойство по имени и писать наборами

Свойство TCRIS находить по имени, а не по наименованию, и записывать изменившиеся значения набором записей, а не менеджером по одному.

Ожидаемый эффект: Устойчивость к переименованию и меньше транзакций на остаток записей.
Сложность: Низкая

3. Убрать учетные данные базы рейтингов из кода

Пароль подключения к базе рейтингов хранится в тексте обработки. Перенести в безопасное хранилище и при доработке не тиражировать прежний вариант.

Ожидаемый эффект: Снятие риска утечки учетных данных.
Сложность: Низкая

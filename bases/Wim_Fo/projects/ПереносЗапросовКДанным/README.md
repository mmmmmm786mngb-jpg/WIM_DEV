# Перенос запросов к данным (JSON)

Проект на базе **Wim_Fo** (Аванкор: Фронт-офис, конфигурация RQW).

## Задача

Внешняя обработка, подключаемая через справочник «Дополнительные отчёты и обработки» (БСП). Обработка должна:

- выгружать в JSON данные выбранного на форме элемента справочника **ЗапросыКДанным** основной конфигурации;
- загружать эти данные из JSON обратно в справочник.

## Статус

Реализовано, версия 1.0. EPF собран, логика выгрузки и загрузки проверена автоматическими
проверками через COM (44 проверки, все пройдены). Документация — в
[Документация/index.html](./Документация/index.html).

Осталось проверить форму в интерфейсе на живой базе (headless-компиляция модуля формы
недоступна — `1cv8.exe /Execute` не возвращает ошибки компиляции).

## Структура проекта

| Папка | Назначение |
|-------|------------|
| `Документация/` | HTML: оглавление, установка и эксплуатация, формат обмена, анализ и постановка |
| `Обработка/` | XML-исходники внешней обработки (`src/`) и собранный EPF (`build/`) |
| `Тестирование/` | Проверки через COM, отчёты в `reports/` |
| `Скрипты/` | Сборка EPF, вспомогательная автоматизация |

## Исходники базы

Корень каталога базы — в файле `../../source-path.txt`. Основная конфигурация: `{source-path}\SRC\CF\`.
Справочник задачи: `SRC\CF\Catalogs\ЗапросыКДанным.xml`.

Базовая конфигурация в рамках проекта **не изменяется** — поставка идёт отдельным файлом EPF.

## Тестовая база

Файловая база, каталог из `../../source-path.txt`. Пользователь `admin`, пароль `1`.
Для проверок через COM пользователю должно быть разрешено внешнее соединение.

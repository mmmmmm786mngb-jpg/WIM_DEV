Перенос запросов к данным

Обработка выгружает элементы справочника Запросы к данным в файл JSON и загружает их в другую базу той же конфигурации. Подключается через Дополнительные отчеты и обработки.

На форме две вкладки — Выгрузка в JSON и Загрузка из JSON — и общее поле Протокол в нижней части окна.

Выгрузка в файл

Выгрузка только читает данные и ничего в базе не меняет.

  1. Откройте вкладку Выгрузка в JSON.
  2. Выберите элементы одним из способов:
    • один элемент — в поле Запрос к данным над таблицей;
    • несколько элементов — флажки в колонке Выгружать (кнопки Отметить все и Снять отметки).
  3. Нажмите Выгрузить в JSON и сохраните файл через диалог.

Кнопка Обновить список перечитывает справочник, если элементы меняли в другом окне. Уже расставленные отметки при этом сохраняются.

В файл попадают: код, наименование, код запроса, текст запроса, пометка удаления, уникальный идентификатор элемента и все строки параметров вместе с их значениями.

Загрузка из файла

Загрузка меняет данные справочника. Сначала показывается, что изменится, запись выполняется только после подтверждения.

  1. Откройте вкладку Загрузка из JSON, выберите файл в поле Файл. Файл читается сразу после выбора.
  2. Просмотрите таблицу Изменения, которые будут внесены:
    • Создание — элемента в базе нет, он будет создан;
    • Обновление — элемент найден, перечисленные поля будут изменены;
    • Без изменений — элемент найден и совпадает с файлом.
  3. Нажмите Записать изменения и подтвердите запись. В протоколе появится итог вида «создано ..., обновлено ..., ошибок ...».

Кнопка Прочитать файл нужна, если файл уже указан и его требуется перечитать (например, файл на диске изменился).

Как находится элемент в базе

  1. по уникальному идентификатору из файла;
  2. если не найден — по коду запроса;
  3. если не найден ни так, ни так — создаётся новый элемент с идентификатором и кодом из файла.

Повторная загрузка одного и того же файла безопасна: дубли не появляются, элементы приводятся к состоянию из файла.

Существующий элемент обновляется целиком: табличная часть параметров заменяется на ту, что в файле. Строки, которых в файле нет, будут удалены.

Протокол

Поле Протокол накапливает сообщения за весь сеанс — и по выгрузке, и по загрузке.

Сообщение Что делать
Файл выгружен из конфигурации «...», текущая конфигурация — «...» Файл из другой конфигурации. Текст запроса и состав параметров перенесутся, значения ссылочных параметров — нет. Проверьте такие параметры вручную.
Объект, на который ссылается значение, в базе не найден Значение записано, но запрос не будет работать, пока объект не появится в базе-приёмнике. Создайте или заполните параметр вручную.
Значение не читается текущей конфигурацией Заполните параметр вручную в карточке запроса после загрузки.
Ошибка записи элемента Чаще всего нехватка прав или занятость элемента другим сеансом. Остальные элементы файла при этом обрабатываются.
Файл не является выгрузкой запросов к данным Укажите файл, сформированный этой же обработкой.
Без расширения работы с файлами сохранить файл невозможно В веб-клиенте установите расширение работы с файлами либо выполните выгрузку из тонкого клиента.

Важные ограничения

  • Перенос рассчитан на базы с одной и той же конфигурацией (тест, препрод и пром одного релиза).
  • Если параметр ссылается на объект, которого в базе-приёмнике нет, платформа не выдаст ошибку — значение будет выглядеть заполненным. Обработка проверяет это сама и пишет предупреждение в протокол.
  • В веб-клиенте для выбора и сохранения файла нужно расширение работы с файлами.

Типовые проблемы

Симптом Решение
Таблица элементов пустая Справочник пуст либо нет прав на чтение. Нажмите Обновить список и проверьте права.
Кнопка «Выгрузить в JSON» ничего не делает Не отмечен ни один элемент. Отметьте флажками или выберите элемент в поле Запрос к данным.
«Записать изменения» просит прочитать файл Файл не был прочитан или уже записан. Выберите файл заново.
После загрузки всё «Без изменений» Данные в базе уже совпадают с файлом — нормальный результат повторной загрузки.

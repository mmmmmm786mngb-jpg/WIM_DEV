# Тестирование

Проверки выполняются через COM-соединение с файловой тестовой базой.

## Подключение

- Каталог базы — из `../../../source-path.txt` (сейчас `C:\1c\Cursor_1c\WORK\WIM_Fo`)
- Пользователь `admin`, пароль `1`
- Пользователю должно быть разрешено внешнее соединение, иначе платформа вернёт
  «Внешнее соединение не разрешено для указанного пользователя 1С:Предприятия»
- Строка соединения: `File='<каталог>';Usr='admin';Pwd='1';App='PyCOM';Locale=ru_RU;`

## Скрипты

| Скрипт | Назначение |
|--------|------------|
| `test_com_connect.py` | Подключение, чтение справочника ЗапросыКДанным вместе с табличной частью, состав справочника ДополнительныеОтчетыИОбработки |
| `test_com_probe2.py` | Признак использования дополнительных обработок, форматы внутренней сериализации значений, чтение UUID |

Отчёты сохраняются в `reports/` в формате JSON (UTF-8).

## Запуск

```powershell
[Console]::OutputEncoding = [System.Text.Encoding]::UTF8
$env:PYTHONIOENCODING = "utf-8"
python "Тестирование\test_com_connect.py"
```

## Известные особенности COM-доступа

- `conn.Строка(...)` недоступен — использовать `conn.String(...)`
- UUID и ссылки возвращаются как COM-объекты, приводить к строке через `conn.String(...)`
- Свойство `ПредопределенныеЗначения` у объекта метаданных через COM недоступно

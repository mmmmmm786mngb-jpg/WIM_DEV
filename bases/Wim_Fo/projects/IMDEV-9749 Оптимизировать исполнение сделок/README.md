Сборка 1.4.10.2: константа `КоличествоПотоковИсполненияСделок` (Число 2,0) живет в расширении. Пусто, 0 и 1 - проведение в одном сеансе (с одним пересчетом в конце), 2 и больше - столько фоновых потоков. После установки задать 6: "Функции для технического специалиста" - Константы - "Количество потоков исполнения сделок" (нужны "Полные права"; роль конфигурации дает права на константу расширения, заимствовать роль не нужно). Поля на панели "Общие настройки учета" в расширении нет: заимствованная форма панели при загрузке молча отключает модуль обработки расширения. Поле добавляется при переносе в cf.

Установка: безопасный режим расширения выключить (иначе перехват не применяется). Расширение 1.4.10.2 меняет структуру данных (своя константа).

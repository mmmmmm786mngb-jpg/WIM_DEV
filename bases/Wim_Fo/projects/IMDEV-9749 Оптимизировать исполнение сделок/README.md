# IMDEV-9749. Оптимизировать операцию "Исполнение сделок"

Строка 15 списка ключевых операций ФО: регламентное задание `АванкорИсполнениеСделок` в 23:55, `ГрупповоеИсполнениеСделок.СоздатьДокументыИсполнения` - документ `ИсполнениеПоСделке` на каждую строку плановой позиции, проведение по одному. Задача выделена из анализа ключевых операций ФО (папка `Анализ групп 3-15 и 9-13`), материалы скопированы оттуда 31.10.2026, включая проверку на стенде от 31.10.2026.

Итог проверки 31.10 (тестовая серверная база ФО, конфигурация не менялась, тестовые документы удалены): в проведении 58% времени - пересчет поручения `ОбновитьДанныеИсполнения` (медиана 92 мс на документ с пересчетом, 38 мс без него). Предлагаемое изменение (резерв 15.1): в цикле `ДополнительныеСвойства.ОбновитьДанныеИсполнения = Ложь`, после цикла один вызов `РасширенияПоручений.ОбновитьДанныеИсполнения` по всем поручениям. Один пересчет после всех проведений дает тот же финал, что поштучный; пересчет до проведений оставляет старый статус. Переписывание текстов запросов выигрыша не дает. Оценка на 18 886 документов - около 29 мин сейчас и около 12 мин после (арифметика стенда, не замер ПРОД). Изменение в конфигурацию не вносилось.

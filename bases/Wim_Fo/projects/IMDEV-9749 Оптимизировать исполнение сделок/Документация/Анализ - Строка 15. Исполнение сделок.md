# IMDEV-9749. Анализ: Строка 15. Исполнение сделок

Выдержка из анализа ключевых операций ФО от 28.10.2026 (папка `Анализ групп 3-15 и 9-13`, файлы
`Анализ групп 1 и 2.md` и `Объекты 1С по строкам.md`). Номера пунктов (15.1, 15.2, ...) - как в исходном анализе.

## Строка 15. Исполнение сделок, 23:55

**Как работает.** Регламентное задание `АванкорИсполнениеСделок` -> `АванкорВыполнениеРегламентныхЗаданий.ИсполнениеСделок`
-> `ГрупповоеИсполнениеСделок.СоздатьДокументыИсполнения(Истина)`:

1. `ЗаполнитьТаблицуСделок`: `ПлановаяПозиция.Остатки(КонецДня, ИСТИНА)` - остатки плановой позиции по ВСЕМ
   портфелям во временную таблицу, затем соединение с `Документ.Сделка` по `ДатаПоставки = &Дата`
   (реквизит `ДатаПоставки` не индексирован) и разыменование `Сделки.Поручение.Биржа.Внебиржевая`.
2. Цикл по строкам (строка = остаток плановой позиции по сделке: бумага или деньги, на сделку минимум 2 строки):
   создание и проведение `ИсполнениеПоСделке`. Проведение каждого документа:
   - очистка движений `ПлановаяПозиция` и запрос остатка по сделке;
   - движения `ПлановаяПозиция`, `ЗадолженностьПоБумаге`/`ЗадолженностьПоВалюте`, `СделкиДляОбмена` (с текстом XDTO);
   - `ОбновитьДанныеИсполнения`: `Движения.Записать()` + `РасширенияПоручений.ОбновитьДанныеИсполнения(поручение)`
     с `СтатусыПоручений.ОбработатьРасчетныеСтатусыРасш` - **на каждый документ**, то есть по одному поручению
     2 и более раз за ночь.
3. Один поток, без `Попытка` вокруг проведения.

**Замеры.** На ПРОД данных нет. В 1.4.9.5 замера нет, FO_KeyOpsPerf на ПРОД не установлен (ключей
FO_KeyOpsPerf нет в выгрузках 16-20.10). В 1.4.10.0 вендор включил замеры в базовый код (см. сводку, п. 2).

**Резервы (все - на стороне вендора, Аванкор).**

| # | Что | Эффект |
|---|---|---|
| 15.1 | Пересчет расширений и статусов поручений один раз в конце: в цикле передавать `ДополнительныеСвойства.ОбновитьДанныеИсполнения = Ложь` (точка уже есть в `ПередЗаписью`), после цикла один вызов `РасширенияПоручений.ОбновитьДанныеИсполнения(<все поручения>)` | Убирает 2+ пересчета на поручение; вероятно самый крупный резерв проведения |
| 15.2 | Отбор сделок по дате поставки - в параметры виртуальной таблицы (`Сделка В (ВЫБРАТЬ ... ГДЕ ДатаПоставки = &Дата)`), индекс по `Сделка.ДатаПоставки` | Не читать остатки по всем портфелям |
| 15.3 | Параллельное проведение по портфелям в фоновых заданиях (как в постконтроле) | Строки разных портфелей независимы |

**Дефект надежности.** Исключение при проведении одного `ИсполнениеПоСделке` (например, конфликт блокировок с
ночными заданиями) прерывает цикл: остальные сделки дня остаются неисполненными до ручного запуска.
Предложение вендору: `Попытка` на документ, запись в ЖР, продолжение цикла.

**Что сделать сейчас.** До 1.4.10.0 длительность можно оценить по ЖР ПРОД: событие "Аванкор. Исполнение сделок"
(старт) и последнее проведение `ИсполнениеПоСделке` в ту же ночь; объем - число документов за дату.

## Объекты 1С: Строка 15. Исполнение сделок

**Запуск**

| Шаг | Объект 1С | Что делает |
|---|---|---|
| 1 | РЗ `АванкорИсполнениеСделок` ("Исполнение сделок"), предопределенное | Расписание хранится в базе (по таблице ключевых операций - 23:55) |
| 2 | ОМ `АванкорВыполнениеРегламентныхЗаданий.ИсполнениеСделок` | Дата запуска со смещением фактической позиции, событие ЖР "Аванкор. Исполнение сделок", создание обработки с `НаДату` |
| 3 | Обработка `ГрупповоеИсполнениеСделок.СоздатьДокументыИсполнения(Истина)` | `ЗаполнитьТаблицуСделок` (без отбора по портфелям), затем цикл создания документов |
| - | Форма обработки `ГрупповоеИсполнениеСделок` (подсистема `ЗаявкиИСделки`) | Ручной запуск: "Заполнить" (отбор по портфелям и группам портфелей), "Создать документы" (`СоздатьДокументыИсполнения(Ложь, ...)`), "Настроить расписание" |

**Читает:** РН `ПлановаяПозиция` (виртуальная таблица остатков на конец дня), документ `Сделка` (`ДатаПоставки`,
`ВидОперации`, `Внебиржевая`, `Поручение.Биржа.Внебиржевая`), справочник `Активы`.

**Создает и меняет**

| Объект 1С | Что пишется |
|---|---|
| Документ `ИсполнениеПоСделке` | Документ на каждую строку остатка (бумага или деньги по сделке), `Дата = НаДату`, проведение |
| РН `ПлановаяПозиция` | Расход остатка плановой позиции по сделке |
| РН `ЗадолженностьПоБумаге` / `ЗадолженностьПоВалюте` | Расход задолженности по поручению сделки (если поручение есть) |
| РС `СделкиДляОбмена` | Запись с текстом XDTO для обмена (при включенной опции API `GetListOfDeals`) |
| РС `РасширенияПоручений` | Пересчет данных исполнения поручения сделки (`ОбновитьДанныеИсполнения`), на каждый документ |
| РС `СтатусыПоручений` | Расчетные статусы поручения (`ОбработатьРасчетныеСтатусыРасш`) |
| Журнал регистрации | Событие "Аванкор. Исполнение сделок" при старте |
| РС `ЗамерыВремени` | Ключи `ИсполнениеСделок*` - в 1.4.10.0 базовым кодом, в 1.4.9.5 только с FO_KeyOpsPerf |

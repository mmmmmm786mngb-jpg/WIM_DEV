Расширение FO_PositionLoadOpt
Пропуск неизменившихся флагов и кэш пакета при загрузке дополнительных сведений из МО

Расширение-исправление с одним перехватчиком: процедура ОбработатьДанные_ДополнительныеСведения модуля обработки ОбменДаннымиБэкОфис. Собственных объектов, ролей и данных нет. Отключение расширения полностью возвращает штатное поведение.

2. Что меняется

Изменения поведения

1
Флаг с тем же значением не перезаписывается
Если значение строки пакета булево, а в регистре ДополнительныеСведения у объекта уже есть запись этого свойства с тем же значением, запись пропускается. Текущие значения объекта читаются одним запросом на пакет при первой булевой строке объекта и дальше обновляются после каждой выполненной записи.
основной эффект
2
Поиск свойства и приведение значения один раз на пакет
Свойство ищется по наименованию один раз на наименование. Результат штатной функции ПреобразоватьЗначениеДополнительногоСведения запоминается для пары "свойство - значение из пакета", если значение из пакета примитивного типа.
минус 2 запроса на строку
Ошибки обмена ("Не найден объект типа", "Не найдено свойство с наименованием") записываются по каждой строке, как в штатном коде. Небулевы значения записываются всегда.

На пакет из 45 портфелей МО делает пять обращений: шаг 1 - флаг до позиции, шаг 2 - позиция, шаг 3 - снятие блокировок, шаг 4 - флаги после позиции, шаг 5 - запуск перерасчета РСА. Расширение затрагивает шаги 1 и 4, где приходят флаги лимитов. В замерах МО эти шаги обозначались номерами строк кода 754 и 872.

На каждую выполненную запись по-прежнему срабатывают обработчики регистра: версия объекта (история изменений) в ПередЗаписью набора записей, подписка УК_ПодпискаНаСобытиеПриЗаписиДополнительныхСведений расширения ВТБ_Прод, подписки управления доступом. Для пропущенной записи они не вызываются, так как записи нет.

// Находит свойство (дополнительный реквизит или сведение) по точному наименованию так же, как штатная загрузка,
// но обращается к базе один раз на наименование в пределах пакета. Ненайденное свойство (пустая ссылка) тоже
// запоминается: ошибка обмена по каждой строке с ним записывается вызывающим кодом, как и без кэша.
//
// Параметры:
//  Наименование - Строка - ключ строки пакета (наименование свойства)
//  КэшСвойств - Соответствие - кэш пакета: свойства по наименованию
//
// Возвращаемое значение:
//  ПланВидовХарактеристикСсылка.ДополнительныеРеквизитыИСведения - найденное свойство или пустая ссылка
//
Функция СвойствоПоНаименованию(Наименование, КэшСвойств)

	Если ТипЗнч(Наименование) <> Тип("Строка") Тогда
		Возврат ПланыВидовХарактеристик.ДополнительныеРеквизитыИСведения.НайтиПоНаименованию(Наименование, Истина);
	КонецЕсли;

	Свойство = КэшСвойств.Получить(Наименование);
	Если Свойство = Неопределено Тогда
		Свойство = ПланыВидовХарактеристик.ДополнительныеРеквизитыИСведения.НайтиПоНаименованию(Наименование, Истина);
		КэшСвойств.Вставить(Наименование, Свойство);
	КонецЕсли;

	Возврат Свойство;

// Преобразует значение строки пакета к типу свойства штатной функцией ПреобразоватьЗначениеДополнительногоСведения
// и запоминает результат для пары "свойство - значение из пакета". Штатная функция на каждую строку читает тип
// значения свойства запросом, а для ссылочных типов еще ищет значение по наименованию; в пакете флагов пары
// повторяются на каждом портфеле. Запоминаются только значения примитивных типов из пакета, остальные
// преобразуются без кэша.
//
// Параметры:
//  ЗначениеXDTO - Произвольный - значение строки пакета
//  Свойство - ПланВидовХарактеристикСсылка.ДополнительныеРеквизитыИСведения - свойство строки
//  КэшЗначений - Соответствие - кэш пакета: ключ - свойство, значение - Соответствие, где ключ - значение
//                из пакета, значение - Структура с полем Значение (преобразованное значение)
//
// Возвращаемое значение:
//  Произвольный - значение для записи в регистр, как его вернула бы ПреобразоватьЗначениеДополнительногоСведения
//
Функция ПреобразованноеЗначениеСведения(ЗначениеXDTO, Свойство, КэшЗначений)

	Если ПолучитьМассивПримитивныхТипов().Найти(ТипЗнч(ЗначениеXDTO)) = Неопределено Тогда
		Возврат ПреобразоватьЗначениеДополнительногоСведения(ЗначениеXDTO, Свойство);
	КонецЕсли;

	ЗначенияСвойства = КэшЗначений.Получить(Свойство);
	Если ЗначенияСвойства = Неопределено Тогда
		ЗначенияСвойства = Новый Соответствие;
		КэшЗначений.Вставить(Свойство, ЗначенияСвойства);
	КонецЕсли;

	// Результат хранится в структуре: преобразованное значение может быть Неопределено.
	Преобразованное = ЗначенияСвойства.Получить(ЗначениеXDTO);
	Если Преобразованное = Неопределено Тогда
		Преобразованное = Новый Структура("Значение",
			ПреобразоватьЗначениеДополнительногоСведения(ЗначениеXDTO, Свойство));
		ЗначенияСвойства.Вставить(ЗначениеXDTO, Преобразованное);
	КонецЕсли;

	Возврат Преобразованное.Значение;

КонецФункции

// Определяет, что запись флага можно пропустить: значение булево и в регистре у объекта уже есть запись этого
// свойства с тем же значением, то есть после записи регистр не изменился бы. Пропуск только для булевых значений:
// флаги лимитов булевы, а на запись небулевых свойств в конфигурации есть подписки с действиями (например,
// распространение правил при записи эталонного портфеля), которые должны срабатывать на каждую запись.
// Текущие значения объекта читаются один раз на пакет при первой булевой строке объекта и дальше
// поддерживаются процедурой ЗапомнитьЗаписанноеЗначение.
//
// Параметры:
//  ОбъектСсылка - ЛюбаяСсылка - объект строки (портфель, актив, место хранения, контрагент)
//  Свойство - ПланВидовХарактеристикСсылка.ДополнительныеРеквизитыИСведения - свойство строки
//  Значение - Произвольный - значение для записи
//  ТекущиеЗначения - Соответствие - кэш пакета: ключ - объект, значение - Соответствие из
//                    ТекущиеЗначенияСведенийОбъекта
//
// Возвращаемое значение:
//  Булево - Истина, если запись не изменит регистр и ее можно не выполнять
//
Функция ФлагУжеИмеетЗначение(ОбъектСсылка, Свойство, Значение, ТекущиеЗначения)

	Если ТипЗнч(Значение) <> Тип("Булево") Тогда
		Возврат Ложь;
	КонецЕсли;

	ЗначенияОбъекта = ТекущиеЗначения.Получить(ОбъектСсылка);
	Если ЗначенияОбъекта = Неопределено Тогда
		ЗначенияОбъекта = ТекущиеЗначенияСведенийОбъекта(ОбъектСсылка);
		ТекущиеЗначения.Вставить(ОбъектСсылка, ЗначенияОбъекта);
	КонецЕсли;

	ТекущаяЗапись = ЗначенияОбъекта.Получить(Свойство);
	Если ТекущаяЗапись = Неопределено Тогда
		Возврат Ложь;
	КонецЕсли;

	Возврат ТекущаяЗапись.Значение = Значение;

// Читает записи регистра ДополнительныеСведения объекта.
//
// Параметры:
//  ОбъектСсылка - ЛюбаяСсылка - объект, значения свойств которого нужны
//
// Возвращаемое значение:
//  Соответствие - ключ - свойство, значение - Структура с полем Значение (значение записи регистра).
//                 Свойства без записи в соответствии нет
//
Функция ТекущиеЗначенияСведенийОбъекта(ОбъектСсылка)

	Запрос = Новый Запрос;
	Запрос.Текст =
	"ВЫБРАТЬ РАЗРЕШЕННЫЕ
	|	ДополнительныеСведения.Свойство КАК Свойство,
	|	ДополнительныеСведения.Значение КАК Значение
	|ИЗ
	|	РегистрСведений.ДополнительныеСведения КАК ДополнительныеСведения
	|ГДЕ
	|	ДополнительныеСведения.Объект = &Объект";
	Запрос.УстановитьПараметр("Объект", ОбъектСсылка);

	ЗначенияОбъекта = Новый Соответствие;
	РезультатЗапроса = Запрос.Выполнить();
	Выборка = РезультатЗапроса.Выбрать();
	Пока Выборка.Следующий() Цикл
		ЗначенияОбъекта.Вставить(Выборка.Свойство, Новый Структура("Значение", Выборка.Значение));
	КонецЦикла;

	Возврат ЗначенияОбъекта;

7. Установка

Подключение в ФО

  1. Администрирование - Печатные формы, отчеты и обработки - Расширения. Команда "Добавить из файла", файл FO_PositionLoadOpt.cfe.
  2. В карточке расширения снять флажок "Безопасный режим" и отключить предупреждение защиты от опасных действий. В безопасном режиме платформа не применяет изменение модуля обработки обмена: в журнале регистрации появляется событие _$Session$_.ConfigExtensionApplyError с текстом "расширение модуля запрещено из-за того, что расширение подключено в безопасном режиме", а загрузка идет по штатному коду.
  3. Убедиться, что расширение активно и проверка применимости не выдает ошибок.
  4. Перезапуск сервера не нужен: вызовы веб-сервиса открывают новые сеансы и подхватывают расширение сразу.
8. Перенос в конфигурацию

Инструкция для переноса в базовую конфигурацию

  1. В модуле объекта обработки ОбменДаннымиБэкОфис в процедуре ОбработатьДанные_ДополнительныеСведения выполнить изменения по маркерам перехватчика: блоки #Вставка добавить, строки из блоков #Удаление заменить на следующий за ними блок #Вставка.
  2. Скопировать в тот же модуль пять функций области ЗаписьДополнительныхСведенийПакета без изменений. Имена проверены на отсутствие совпадений с методами модуля.
  3. После обновления конфигурации отключить и удалить расширение: иначе перехватчик перестанет применяться из-за изменения контролируемой процедуры.
9. Эксплуатация

Контроль, откат, совместимость

Как убедиться, что работает

Нет событий ConfigExtensionApplyError по FO_PositionLoadOpt. Число новых версий портфеля за утреннюю выгрузку уменьшается на 2. Шаг 4 пакета (флаги после позиции) в журнале обмена заметно короче.

Откат

Снять флажок "Активно" или удалить расширение. Следующие вызовы веб-сервиса идут по штатному коду. Данных у расширения нет, восстанавливать нечего.

Совместимость

ВТБ_Прод, VTB и FO_LimitCheckOpt не перехватывают обработку обмена. Если Аванкор изменит исходную процедуру, расширение не применится и сообщит об этом в журнале регистрации; перехватчик нужно будет актуализировать.

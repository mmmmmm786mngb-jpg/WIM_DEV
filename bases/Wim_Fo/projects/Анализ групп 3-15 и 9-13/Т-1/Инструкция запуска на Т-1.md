# Диагностика операций 3, 9, 13, 15 на Т-1

Обработка `ДиагностикаОперацийФО.epf` только читает данные: ничего не записывает, не проводит и не отправляет.
Результат - текстовый лог, его нужно прислать обратно.

## Запуск

1. Открыть Т-1 (тонкий клиент) пользователем с полными правами: нужны права на журнал регистрации и регламентные
   задания, иначе эти разделы лога покажут ошибку доступа (остальное соберется).
2. Файл - Открыть - `ДиагностикаОперацийФО.epf`. Если платформа спросит про защиту от опасных действий - разрешить.
3. Поле "Дней истории" - 30 (можно 60, если нужно больше истории замеров и пересчетов).
4. "Собрать лог". На dev сбор занял 2 с; на Т-1 запросы идут по большим регистрам, может занять минуты.
5. "Сохранить в файл (txt)" и прислать файл `Диагностика_ФО_<дата>_<время>.txt`.

Если есть Т-1 обычного ФО - повторить там же и прислать оба файла (по замерам ПРОД депозиты и распространение правил
в двух базах ведут себя по-разному).

## Что попадает в лог

| Раздел | Содержимое |
|---|---|
| 0 | Версия конфигурации, расширения, константы замеров и классов лимитов, опция версионирования |
| 1 | Регистр ЗамерыВремени по ключам строк 3, 9, 13, 15: итоги, по дням, 40 самых долгих запусков с комментарием |
| 2 | Регламентное задание исполнения сделок (включено, расписание, последний запуск); по каждой обработке строк - версия, команды, их регламентные задания, настройки |
| 3 | Строка 3: установки лимитов по дням, классам и часам, число лимитов, пороги, версии лимитов, временные XLS сервера |
| 4 | Строка 15: документы исполнения по дням и часам, сделки по дате поставки, неисполненные остатки, время запроса заполнения за сегодня и вчера |
| 5 | Строка 9: регистр депозитов ФО, данные сопоставления, время запросов сопоставления, запуски пересчета РСА, портфели с признаком перерасчета |
| 6 | Строка 13: поручения обработки по дням и часам, их статусы, портфели по статусам, время двух запросов обработки |
| 7 | Журнал регистрации: события операций по дням и ошибки с ключевыми словами операций |

Скрыто: пароли, логины, адреса веб-сервисов и почты, списки рассылки, код брокерского счета (в логе только
"задано" или "пусто"). Имена портфелей и клиентов в агрегатах не выводятся. В разделе 7 тексты ошибок журнала
выводятся как есть (до 300 символов) - в них могут встретиться коды портфелей.

На Т-1 журнал регистрации и состояние регламентных заданий - собственные, самой Т-1, а не ПРОД: копия базы переносит
данные, но не журнал. Данные регистров и документов - копия ПРОД на дату снимка.

## Разделы лога

0. Общие сведения: версия диагностики, дата, конфигурация, база, ДатаЗапроса, валюта регл; итоги регистра:
   ПолучитьИспользованиеИтогов, ПолучитьИспользованиеТекущихИтогов, Мин/МаксПериодРассчитанныхИтогов,
   ПолучитьРежимРазделенияИтогов.
1. Пользователь сервиса: есть ли роль РаботаСWS, роли с RLS из списка выше; все пользователи с РаботаСWS
   (имя только для svc/ws/fo, остальные "<пользователь>").
2. Объем (дешево): первая дата регистра (ПЕРВЫЕ 1 по Период), депозитные счета: всего, действующих, без
   ДатаОткрытия, без НоминалДепозита, мин/макс ДатаОткрытия, по годам открытия; записей АлгоритмыРасчетаПроцентов.
3. Исходный запрос по частям (прогон 1, холодный): СтрРазделить по ";", общий МенеджерВременныхТаблиц, мс и
   число строк каждой ВТ, выгрузка итога; время сборки ответа как в getDeposits (цикл с name).
4. Кандидат оптимизации по частям в своем менеджере ВТ (порядок: после прогона 1):
   - К_Остатки = часть 1 + Валюта ЕСТЬNULL(Валюта, &ВалютаРегл), ДатаОткрытия, НоминалДепозита;
   - НачалоИстории = мин ДатаОткрытия действующих; если у кого-то пусто - мин ДатыВыдачи из прогона 1
     (пометить "только для замера, в коде нужен источник");
   - К_Проценты, К_ПроцентыЗаДень: Обороты с началом периода, группировка, соединение по ссылке валюты;
   - К_ДвиженияВыдачи: ДвиженияССубконто один раз с НачалоИстории; К_ДатыВыдачи (мин), К_ПервоначальныеСуммы
     (без группировки, как в оригинале);
   - К_Алгоритмы: СрезПоследних с отбором Объект В (К_Остатки), ВТ с индексом;
   - итог; построчное сравнение с итогом прогона 1 по ключу счет+currency по всем полям, примеры расхождений
     (счет маскировать: номер по порядку и последние 4 цифры).
5. Реквизиты счета против вычисленного: ДатаОткрытия vs ДатаВыдачи и datestart, НоминалДепозита vs initialvalue
   (пусто / совпадает / отличается, распределение разницы в днях, примеры).
6. Вопросы по смыслу: дубли ключей в каждой ВТ и итоге; повторное использование счетов (движения до своей
   ДатаОткрытия, число дней выдачи на счет); пустой datestart; начисленные проценты (часть 2) против остатка
   76.20.2 (Остатки, субконто искать по типу БанковскиеСчетаСсылка, вывести виды субконто счета 76.20.2).
7. Повтор исходного (прогон 2, теплый кэш) + сверка с прогоном 1.
8. Подсчет проводок (флажок): по годам всего регистра; ДвиженияССубконто депозитов без начала и с НачалоИстории.
9. Сводка замеров: прогон 1, кандидат, прогон 2 по частям, ожидаемая экономия.

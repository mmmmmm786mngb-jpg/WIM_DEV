# Wim_Fo

Базовая конфигурация **Аванкор: Фронт-офис** (метаданные `RQW`). Исходники не копируются в репозиторий.

## Путь к исходникам

Файл **source-path.txt** — путь к каталогу с реальной базой в WORK.

Текущий путь: `C:\1c\Cursor_1c\WORK\WIM_Fo`

> Регистр папки в WORK: **WIM_Fo** (не `Wim_Fo`). В репозитории папка базы: **Wim_Fo** — по аналогии с Wim_Mo, Wim_Du.

## Состав выгрузки в WORK

```
WIM_Fo/
  SRC/
    CF/                    # Основная конфигурация RQW (Фронт-офис)
    CFE/
      ВТБ_Прод/            # Расширение конфигурации (продуктивные доработки)
```

| Каталог | Назначение |
|---------|------------|
| `SRC\CF\` | Основная конфигурация: **RQW**, синоним «Аванкор: Фронт-офис, редакция 1.3», вендор Аванкор |
| `SRC\CFE\ВТБ_Прод\` | Расширение: лимиты, фактические позиции депозитов, статусы портфелей и др. |

Перед правками уточняйте, с каким слоем работаете: **CF** (типовая/вендор) или **CFE** (доработки).

## Ключевые объекты для интеграции с МО

Прием позиций из мидл-офиса (обработка `внВыгрузкаОстатковМО_ФО` в Wim_Mo):

| Объект | Путь в CF |
|--------|-----------|
| Веб-сервис **Avancore** | `SRC\CF\WebServices\Avancore.xml` |
| Модуль WS (прием пакетов) | `SRC\CF\WebServices\Avancore\Ext\Module.bsl` |
| Операция **DownloadPosition** | прием XDTO-пакета позиции |
| Операция **DownloadOrders** | прием поручений/блокировок |
| Публикация IIS | `.../ws/avancore_ws.1cws` (например `PROD_AVC_RETAIL_FO-DL`) |
| Пространство имен XDTO | `http://avancore.ru/xsd` |

Смежные операции того же WS: `GetPosition`, `GetDataOnRequest`, `DownloadCompressedPosition`.

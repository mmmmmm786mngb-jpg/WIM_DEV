# Расширения

Доработки конфигурации Wim_Do - только через расширения. Исходники базы не изменяются.

По IMAPPS-39047 штатный сценарий - **замена файла шаблона в ИБ**. Расширение понадобится только если:

- потребуется выбирать шаблон анкеты по дате (до/после 31.08.2026) в коде;
- правила автозаполнения нельзя восстановить данными и нужен программный обход.

# Обработки

Внешние обработки (EPF) для базы Wim_Do.

## внВосстановлениеРеквизитаПоВерсиям

Поиск изменений значения реквизита по истории версий (`РегистрСведений.ВерсииОбъектов`) за период и точечное восстановление старого значения.

**Исходники:** `внВосстановлениеРеквизитаПоВерсиям_epf/` (XML), главный файл `внВосстановлениеРеквизитаПоВерсиям.xml`.

### Назначение

Для инцидента синхронизации НСИ: найти контрагентов, у которых доп. реквизит **КДУ_ИД** изменился 03.06.2026 в окне 09:00–09:30, и вернуть прежнее значение из предыдущей версии.

### Параметры формы

| Поле | Назначение |
|------|------------|
| С / По | Период по `ДатаВерсии` (с точностью до секунд) |
| Тип объекта | Полное имя, напр. `Справочник.Контрагенты`. Пусто = все типы |
| Реквизит | Имя реквизита или доп. реквизита, напр. `КДУ_ИД` |
| Автор версии | Фильтр по автору (напр. `svc_avancore`), необязательно |

### Логика

1. **Найти изменения** — версии типа «Изменено пользователем» за период; для каждой определяется предыдущая версия; значение реквизита сравнивается. В таблицу попадают только отличающиеся: колонка «Старое значение (до изменения)» = предыдущая версия, «Новое значение (текущее)» = версия в периоде.
2. **Восстановить отмеченные** — для отмеченных строк значение заново считывается из предыдущей версии (типизированно) и записывается в объект.

Поддерживаются обычные реквизиты и дополнительные реквизиты (ТЧ `ДополнительныеРеквизиты`, строки Свойство/Значение).

### Ограничения

- Колонка результата `Объект` типизирована как `СправочникСсылка.Контрагенты`. Для другого типа объектов измените тип колонки `ТаблицаИзменений.Объект` в форме (или сделайте составным).
- Требуется роль чтения версий (`ЧтениеВерсийОбъектов`) и право изменения объекта; запись идёт в привилегированном режиме.
- Восстановление перезаписывает объект целиком (меняется только указанный реквизит).
- Версии должны сохраниться (учитывать регламент очистки устаревших версий).

### Сборка

```
/epf-build внВосстановлениеРеквизитаПоВерсиям
```
Сборку выполнять против базы Wim_Do (нужны `Справочник.Контрагенты`, `Справочник.Пользователи`).

# Bug_sinhro

Проект на базе **Wim_Do** (1С:Документооборот): разбор и устранение последствий ошибочного запуска синхронизации НСИ с ДУ.

## Источник кода базы

Путь к каталогу с исходниками базовой конфигурации — в файле **../../source-path.txt** (относительно папки проекта).  
Скрипты и инструменты должны читать путь оттуда.

Текущий путь: `C:\1c\Cursor_1c\WORK\Wim_Do`

## Контекст

- Инцидент: запуск **Синхронизация НСИ с ДО** из тестовой ДУ при подключении к ПРОД-ДО (03.06.2026, около 09:00–09:30).
- Пострадавшее поле в ДО: доп. реквизит контрагента **КДУ_ИД** (и при необходимости **Дата синхронизации с ДУ**).
- Связанная обработка синхронизации (ДУ): проект `bases/Wim_Du/projects/IMDEV-8927`, обработка `внСинхронизацияНСИ`.

## Задачи проекта

1. Поиск изменений **КДУ_ИД** по версиям объектов (`РегистрСведений.ВерсииОбъектов`) за заданный интервал.
2. Восстановление значений из предыдущей версии (точечно, без полного отката объекта).
3. Сверка с эталоном ПРОД-ДУ и документирование пострадавших контрагентов.

## Структура проекта

- **Расширения/** — доработки конфигурации ДО (если потребуется)
- **Обработки/** — внешние обработки (поиск/восстановление КДУ_ИД по версиям)
- **Документация/** — описание инцидента, алгоритмы, отчёты сверки
- **Тестирование/** — сценарии проверки, отчёты (reports/), Python COM
- **Скрипты/** — автоматизация выгрузки, сверки, отчётов

## Требования

- Платформа 1С:Предприятие не ниже 8.3.21
- Подсистема БСП «Версионирование объектов» включена в ДО
- Права на чтение версий и изменение справочника Контрагенты

Стиль кода 1С — по правилам репозитория (`.cursor/rules/`, `.cursor/skills/`).

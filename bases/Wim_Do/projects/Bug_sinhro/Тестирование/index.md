# Тестирование

Сценарии проверки восстановления **КДУ_ИД** в Wim_Do.

- Отчёты — в подпапке `reports/`
- Проверка через Python COM — скрипты в `../Скрипты/` (при необходимости)

## Контрольные проверки

1. Выборочная сверка: значение **КДУ_ИД** в ДО = **ВнешнийIDДляЛК** в ПРОД-ДУ для того же контрагента.
2. Повторный прогон обработки поиска — пустой список изменений в целевом интервале после восстановления.

    - ФоновоеВыполнение (формирование п/п на перевод ДС на биржу, РЗ 07:02 / 120 с)
      Ключевая операция замера: ДУ.СинхронизацияНСИ.ФоновоеВыполнение (IMDEV-8927, п.07)
    - версия: 0.68 -> 0.69

  Цепочка вызовов (контур «поручение по ДС -> п/п» для РДУ):
    РЗ «Синхронизация НСИ с ДО (фоновое выполнение)»
      -> ВыполнитьКоманду("ФоновоеВыполнение")
        -> ВыполнитьСинхронизациюНСИ
          -> СоздатьНСИ (для ТипДУ = "Розничное")
            -> ЗаполнитьАналитикуПоДоговоруДУ
              -> СоздатьПоручение (ВидОперации = Перевод)   [новый договор]
              -> СоздатьПлатежноеПоручение                   [новый договор, рабочее время]
          -> ПлатежныеПорученияРозничногоДУ                  [рабочее время, «хвост» без п/п]
            -> СоздатьПлатежноеПоручение

  Целевые процедуры для оптимизации:
    - ПлатежныеПорученияРозничногоДУ
    - СоздатьПлатежноеПоручение
    - СоздатьПоручение (при необходимости)

  Вне scope (другой контур той же EPF):
    - ФоновоеВыполнениеПоручения / «Загрузка поручений из ДО» (РЗ 09:30 / 300 с)
      ВыводИзДУ из ДО, п/п на биржу не формирует

ОПИСАНИЕ ЗАДАЧИ
---------------
  Проанализировать и оптимизировать контур перевода денежных средств
  на биржу (формирование п/п) датой Т для розничных договоров (РДУ).

  По Катунину: «Синхронизация НСИ с ДО тут создаётся поручение по ДС» —
  это Документ.Поручение (ВидОперации = Перевод), основание для п/п.

  Оптимизировать процесс под большое количество платежных поручений
  (массовое создание/проведение ПлатежноеПоручение по пулу РДУ).

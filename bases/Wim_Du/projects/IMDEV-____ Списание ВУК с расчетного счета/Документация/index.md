# Списание ВУК с расчетного счета

Номер задачи пока не присвоен. Связано с IMDEV-9202 (потоки на «Поступлениях на перевод»).

## Запрос

Письмо заказчика: `Запрос от бизнеса_14102026_ДУ.docx`.

В обработке «Поступления на расчетный счет: Розничное ДУ» добавлен блок «Списание с расчетного счета ВУК». Оплата ВУК приходит одной суммой из банковской выписки, затем раскладывается на договоры розничного ДУ. Нужна оценка быстродействия.

## Обработка

Версия 1.18, файл `внПоступленияНаРасчетныйСчет_РозничноеДУ_1_18.epf` (каталог `Обработки`). В релизном каталоге внешних обработок этой версии нет: там поступления 1.10.

## Сравнение полного контура P2

Файл: `внТестСравнениеПолныйКонтурP2.epf` (v1.5)  
Исходники: `внТестСравнениеПолныйКонтурP2_epf/`

Два прогона полного контура (как v2.2: РЗ + обработка + рассылки, внешние отключены, откат):

| Режим | |
|-------|--|
| БЫЛО | `ИспользоватьПакетныйКэшP2 = Ложь` |
| СТАЛО | `ИспользоватьПакетныйКэшP2 = Истина` |

Регресс: ключи ТЧ (суммы/статусы/факт наличия ПП) + поля ПП (`СчетДоговораДУ`, `ТекстПлательщика`, …).  
Скорость: мс всего контура было/стало (пишется даже при ошибке прогона).

Если «Конфликт блокировок» на `УстановитьДатуРасторжения`:
1. Закрыть другие сеансы 1С на этой базе (Консоль кластера / Администрирование).
2. Не держать карточки ДоговорДУ открытыми на запись.
3. Сначала прогнать с N=5, затем увеличить.
4. Перезагрузить EPF v1.1 (retry записи даты + оба прогона независимо).

## Полный контур (рекомендуется для замеров)

Файл: `внТестРасторжениеРДУ_ПолныйКонтур.epf`  
Исходники: `внТестРасторжениеРДУ_ПолныйКонтур_epf/`

Что выполняется (код из боевой `внРасторжениеДоговоровРозничногоДУ` v1.17):

1. **`ДОДоговорыДУКРасторжению`** — полный цикл РЗ; вход `GetClosingRetailAgreements` заменён имитацией из ДУ (N договоров пула).
2. **`ОбработкаДоговоровКРасторжению`** — полный цикл формы, включая боевой **`ДанныеПоРасторжению()`** (~500 строк), СЧА, поручения, ПП, вознаграждение, закрытие в ДУ.
3. **`ДанныеДляРассылки` x4** — только чтение/подготовка (без почты и FO).

Что отключено жёстко (`ОтключитьВнешниеСистемы = Истина`):

- WS 1С:ДО: `GetClosingRetailAgreements`, `SetRetailAgreementClosed`
- Finance: `ДанныеНДФЛИзФИН`, `ОтправитьМатВыгодуФИН`
- FO: `СоздатьАвтоматическийВыводДСпоРасторжениямДляРДУ`
- Почта: `СформироватьИОтправитьПисьмо` (тело рассылки меряется отдельно через `ДанныеДляРассылки`)
- Любой `ПолучитьСервис` / WSПрокси — исключение при попытке вызова

Дерево замеров в табличном документе (полный контур):

```
0. ИТОГО
1. ДОДоговорыДУКРасторжению (РЗ)
    1.0 Имитация GetClosing (из ДУ)
    1.1 ДоговорПоНомеру
    1.2 АналитическийСчет
    1.3 УстановитьДатуРасторжения
    1.4 БанковскийСчетКлиента
    1.5 ДоговорКонтрагента (брокер)
    1.6 ПорученияДС (вывод)
2. ОбработкаДоговоровКРасторжению
    2.1 ДанныеНДФЛИзФИН (заглушка)
    2.2 ДанныеПоРасторжению (полный запрос)
    2.3 Цикл: ПолучитьСуммыРСА_СЧА
    2.4 Цикл: УдалитьПереводНаБиржу
    2.5 Цикл: ЗакрытьДоговор
    2.6 Цикл: прочая логика (вознагр./поручения/ПП)
    2.7 НачислитьВознаграждение
3. ДанныеДляРассылки x4
    3.1..3.4 по видам (Перевод/Вывод/Ввод/МатВыгода)
```

## Укороченный тест (legacy)

Обработка: `внТестРасторжениеДоговоровРДУ.epf`

Имитирует получение данных о расторжении для **указанного количества существующих** договоров пула «Розничное ДУ», проходит основные шаги контура РЗ / закрытия и выводит **замеры в табличный документ**.

**Не вызываются:** WS 1С:ДО, Finance, FO, почта, `SetRetailAgreementClosed`.  
**Упрощено относительно боя:** укороченный `ДанныеПоРасторжению`, поиск счёта без создания, поручение через `Запись` (не проведение).

# Тест расторжения договоров РДУ (без ДО) — IMDEV-9104

Обработка: `внТестРасторжениеДоговоровРДУ.epf`

Полный план тестирования и сравнение с боевым контуром (HTML):
[`../Документация/test_plan_and_processing_overview.html`](../Документация/test_plan_and_processing_overview.html)

## Назначение

Имитирует получение данных о расторжении для **указанного количества существующих** договоров пула «Розничное ДУ» (как будто пришли из `GetClosingRetailAgreements`), проходит основные шаги контура РЗ / закрытия и выводит **замеры в табличный документ**.

**Не вызываются:** WS 1С:ДО, Finance, FO, почта, `SetRetailAgreementClosed`.

## Как пользоваться

1. Собрать EPF (см. ниже) и открыть в базе ДУ.
2. Параметры:
   - **Количество договоров** — сколько существующих РДУ взять
   - **Пул** — по умолчанию «Розничное ДУ»
   - **Только чтение** — по умолчанию Нет (выполняются 2.5/2.6 запись даты и поручения)
   - **Откатывать транзакцию** — по умолчанию Да (запись в ДУ откатывается)
   - **Мерить ДанныеПоРасторжению** / **Мерить РасчетСЧА_РСА** — по умолчанию Да
3. Нажать **«Запустить тест (замеры)»**.
4. Смотреть табличный документ: блоки отсортированы по времени (убывание), плюс журнал регистрации `IMDEV-9104.Замер`.

## Блоки замеров

| Блок | Что входит |
|------|------------|
| 1. Имитация GetClosingRetailAgreements | отбор N договоров РДУ + реквизиты «как из ДО» |
| 2. Цикл РЗ | путь как `ДОДоговорыДУКРасторжению` без WS |
| 2.1–2.4 | ДоговорПоНомеру, АналитическийСчет, БанковскийСчет (поиск), ДоговорКонтрагента |
| 2.5–2.6 | запись даты / поручение на вывод (только если не «Только чтение», потом откат) |
| 3. ДанныеПоРасторжению | укороченный пакетный запрос по отобранным договорам |
| 4. РасчетСЧА_РСА | `ПолучитьСуммыРСА_СЧА` по каждому договору |
| 0. ИТОГО | полное время прогона |

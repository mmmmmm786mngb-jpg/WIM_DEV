Зачем вызывается

При создании ПП по основаниям НачислениеЗадолженности (НДФЛ) и НачислениеВознаграждения (вознаграждение / комиссия / регулярное) нужно подобрать банковский счёт УК с достаточной платёжной позицией.

Для ПП на вывод клиенту (основание = Поручение) этот путь не используется.

Зачем вызывается

При ИнициироватьВознаграждение создаётся/проводится НачислениеВознаграждения. В проведении вызывается алгоритм договора контрагента (АлгоритмДоговора из справочника доп. обработок) — внешняя обработка MF_РасчетВознаграждения_РозничноеДУ. Для договоров с датой уведомления о расторжении идёт ветка РазмерВознагражденияПриРасторжении.

В отладчике модуль без имени: e1cib/tempstorage/...d9bbdfb8c2?seanceId=... (обработка подгружена во временное хранилище сеанса).

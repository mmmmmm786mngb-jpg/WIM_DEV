IMDEV-9096 (v2.0): параллельная фоновая загрузка по кнопке «Разобрать отмеченные»

Версия ТЗ: 2.0 | Дата: 27.06.2026 | База: Wim_Du | EPF: внЗагрузкаВыписокДУ | Форма: Форма (команда МассоваяЗагрузка)

Итог проверки: подход из ТЗ 1.0 (фоновые задания БСП с пулом не более N, единица работы - группа выписок по паре (БанковскийСчет, ДоговорДУ)) подходит и совместим с конфигурацией Wim_Du. В v2.0 он упрощён в двух местах и исправлен в одном, чтобы логика и сообщения остались в точности как в синхронном режиме.

1. Цель и принципы

Ускорить массовое создание документов по отмеченным выпискам за счёт параллельных фоновых заданий БСП, запускаемых пулом не более N одновременно. При этом:

  • Логика не меняется - внутри фона выполняется тот же код КлиентБанк, что и сейчас.
  • Сообщения не теряются - после каждой завершённой группы переносятся в очередь сеанса (Сообщить), как в синхронном режиме.
  • Лог тот же - колонки Выписки.Лог, ПлатежныеДокументы.Загружен и окно ПоказатьЛогВыписки(ОбщийЛог) формируются в том же формате.
  • Откат на синхрон - если фон недоступен (нет ссылки, файловая ИБ, выключено флагом).

2. Три изменения относительно ТЗ 1.0

2.1. УПРОЩЕНИЕ-1: проверка завершения через ОперацияВыполнена

В ТЗ 1.0 предлагался ручной поиск ФоновыеЗадания.НайтиПоУникальномуИдентификатору + сравнение состояний и отдельная СформироватьРезультатОшибкиГруппы. В CF Wim_Du уже есть готовая функция ДлительныеОперации.ОперацияВыполнена(ИдентификаторЗадания, Ложь), которая:

  • возвращает структуру со Статус = "Выполняется" / "Выполнено" / "Ошибка" / "Отменено";
  • не выбрасывает исключение при аварии (в отличие от ЗаданиеВыполнено);
  • сразу отдаёт КраткоеПредставлениеОшибки / ПодробноеПредставлениеОшибки.

Это убирает ручную работу с менеджером заданий и отдельную сборку ошибки - оркестратор становится короче и безопаснее.

Запрет (подтверждён кодом, стр. 440-446): ДлительныеОперации.ЗаданиеВыполнено при ЗавершеноАварийно/Отменено делает ВызватьИсключение и оборвёт весь пул. В оркестраторе использовать только ОперацияВыполнена(ид, Ложь).

2.2. ИСПРАВЛЕНИЕ: КлиентБанк создаётся на каждую выписку (сохранение логики)

В ТЗ 1.0 (приложение B.4) один ОбработкаКлиентБанк переиспользовался на всю группу и не переустанавливал остатки (НачальныйОстаток, ВсегоПоступило, ВсегоСписано, КонечныйОстаток) по каждой выписке. В текущем коде (стр. 674-680) КлиентБанк создаётся на каждую выписку и остатки берутся из выписки. Чтобы логика и итоговые документы не изменились, в v2.0 КлиентБанк создаётся на каждую выписку внутри группы.

Группа по (Счёт, Договор) остаётся - но только как единица параллелизма (одно фоновое задание на группу), чтобы две задачи не писали одновременно документы по одному счёту/договору. Внутри задания выписки обрабатываются последовательно, каждая - со своим свежим КлиентБанк, точь-в-точь как сейчас.

2.3. УПРОЩЕНИЕ-2: оркестратор - один серверный вызов, без клиентских обработчиков ожидания

Кнопка как и сейчас вызывает один серверный метод МассоваяЗагрузкаНаСервере(ОбщийЛог) и затем ПоказатьЛогВыписки(ОбщийЛог). Весь пул крутится внутри серверного вызова: запуск до N заданий, ожидание через короткий ОжидатьЗавершения(timeout), опрос ОперацияВыполнена. Клиентские ПодключитьОбработчикОжидания не нужны - UX (один клик -> лог) сохраняется.

3. Архитектура (v2.0)

[Клиент] МассоваяЗагрузка(Команда)              // без изменений
   -> Состояние("Выполняется загрузка выписок.")
   -> МассоваяЗагрузкаНаСервере(ОбщийЛог)        // маршрутизация
   -> ПоказатьЛогВыписки(ОбщийЛог)               // без изменений

[Сервер] МассоваяЗагрузкаНаСервере(ОбщийЛог)
   |- можно фон? (флаг И N>1 И есть ДопСсылка И не файловая ИБ)
   |     -> МассоваяЗагрузкаПуломГруппНаСервере(ОбщийЛог, N)
   |          - ОчередьГрупп = СгруппироватьОтмеченныеВыписки()   // по (Счёт, Договор)
   |          - пока есть очередь или активные:
   |               запуск до N: ЗапуститьГруппуВыписокВФоне(...)
   |               ожидание: ОжидатьЗавершения(0.5) на первом активном
   |               для завершённых (ОперацияВыполнена <> "Выполняется"):
   |                  1) результат из ПолучитьИзВременногоХранилища -> РаспаковатьДанныеИзXML
   |                  2) ВывестиСообщенияФоновогоЗадания(ид)        // Сообщить()
   |                  3) ПрименитьРезультатГруппыКДаннымФормы -> ОбщийЛог
   |          - замер IMDEV-8927 (+ Групп, + Параллельность)
   |- иначе -> МассоваяЗагрузкаСинхронноНаСервере(ОбщийЛог)        // текущий код

[Фон] ВыполнитьПроцедуруМодуляОбъектаОбработки
   -> ЗагрузитьГруппуВыписокВФоне(ПакетXML, АдресРезультата)

        - на каждую выписку группы: новый КлиентБанк (как в синхроне)
        - ПоместитьВоВременноеХранилище(УпаковатьДанныеВXML(РезультатГруппы), Адрес)

A.2. ЗагрузитьОднуВыпискуКлиентБанк - общий код синхрона и фона

Точная копия логики из формы (стр. 658-722), но без обращения к данным формы - работает по структуре ДанныеВыписки. Создаёт свой КлиентБанк (как в текущем коде).
// IMDEV-9096 ++
// Описание: Загружает одну выписку через КлиентБанк (та же логика, что в синхронном режиме).
//   КлиентБанк создаётся на каждую выписку - остатки берутся из выписки.
//
// Параметры:
//  БанковскийСчет - СправочникСсылка.БанковскиеСчета
//  ДоговорДУ      - СправочникСсылка.ДоговорДУ
//  ДанныеВыписки  - Структура - реквизиты выписки + массив Платежи
//
// Возвращаемое значение:
//  Структура - КлючВыписки, Загружена, Лог, Платежи (массив обновлений флага Загружен)
//
Функция ЗагрузитьОднуВыпискуКлиентБанк(БанковскийСчет, ДоговорДУ, ДанныеВыписки) Экспорт

    Импорт_РасчетныеСчета = СформироватьИмпортРасчетныеСчета();

    ОбработкаКлиентБанк = Обработки.КлиентБанк.Создать();
    ОбработкаКлиентБанк.БанковскийСчет = БанковскийСчет;
    ОбработкаКлиентБанк.ДоговорДУ      = ДоговорДУ;
    ЗаполнитьЗначенияСвойств(ОбработкаКлиентБанк, ДанныеВыписки,
        "НачальныйОстаток, ВсегоПоступило, ВсегоСписано, КонечныйОстаток");

    ОбработкаКлиентБанк.НачПериода = ДанныеВыписки.ДатаСоздания;
    ОбработкаКлиентБанк.КонПериода = ДанныеВыписки.ДатаСоздания;

    Для Каждого СтрокаПлатежки Из ДанныеВыписки.Платежи Цикл
        НоваяСтрока_ДокументыКИмпорту = ОбработкаКлиентБанк.ДокументыКИмпорту.Добавить();
        ЗаполнитьЗначенияСвойств(НоваяСтрока_ДокументыКИмпорту, СтрокаПлатежки, , "Лог,Загружен");
        НоваяСтрока_ПлатежныеДокументы = ОбработкаКлиентБанк.ПлатежныеДокументы.Добавить();
        ЗаполнитьЗначенияСвойств(НоваяСтрока_ПлатежныеДокументы, СтрокаПлатежки);
    КонецЦикла;

    Обработки.КлиентБанк.РазобратьДанныеИмпорта(
        ОбработкаКлиентБанк.ДоговорДУ, ОбработкаКлиентБанк.БанковскийСчет,
        ОбработкаКлиентБанк.ДокументыКИмпорту, Неопределено);
    Обработки.КлиентБанк.ПроверитьЗаполнениеТаблицыДокументов(
        ОбработкаКлиентБанк, ОбработкаКлиентБанк.ПлатежныеДокументы);
    Обработки.КлиентБанк.Загрузить(
        ОбработкаКлиентБанк.ДокументыКИмпорту, Неопределено, Неопределено,
        ОбработкаКлиентБанк.ДоговорДУ, Импорт_РасчетныеСчета,
        ОбработкаКлиентБанк.ИспользоватьГраницуОбработки,
        ОбработкаКлиентБанк.ДатаГраницыОбработки,
        ОбработкаКлиентБанк.БанковскийСчет);
    Обработки.КлиентБанк.ПослеЗагрузкиВыписки(ОбработкаКлиентБанк);

    РезультатВыписки = Новый Структура("КлючВыписки, Загружена, Лог, Платежи",
        ДанныеВыписки.КлючВыписки, Истина, "", Новый Массив);
    ОбщийЛогПоВыписке = "";

    Для Каждого СтрокаПлатежки Из ДанныеВыписки.Платежи Цикл
        НайденнаяСтрока = ОбработкаКлиентБанк.ДокументыКИмпорту.Найти(СтрокаПлатежки.КлючДокумента, "КлючДокумента");
        Загружен = Ложь;
        Если НайденнаяСтрока <> Неопределено Тогда
            Загружен = НайденнаяСтрока.Загружен;
            ОбщийЛогПоВыписке = ОбщийЛогПоВыписке + Символы.ПС
                + ПредставлениеПП(НайденнаяСтрока) + Символы.ПС + СокрЛП(НайденнаяСтрока.Лог);
        КонецЕсли;
        Если Не Загружен Тогда
            РезультатВыписки.Загружена = Ложь;
        КонецЕсли;
        РезультатВыписки.Платежи.Добавить(Новый Структура("КлючВыписки, КлючДокумента, Загружен",
            ДанныеВыписки.КлючВыписки, СтрокаПлатежки.КлючДокумента, Загружен));
    КонецЦикла;

    Если РезультатВыписки.Загружена Тогда
        РезультатВыписки.Лог = ПредставлениеВыпискиПоДанным(ДанныеВыписки, БанковскийСчет, ДоговорДУ)
            + Символы.ПС + СокрЛП(ОбщийЛогПоВыписке);
    КонецЕсли;

    Возврат РезультатВыписки;

КонецФункции
// IMDEV-9096 --
ПредставлениеПП и ПредставлениеВыписки в форме объявлены как &НаКлиентеНаСервереБезКонтекста (стр. 271-283). Для фона нужны их копии в ObjectModule: ПредставлениеПП (та же строка) и ПредставлениеВыпискиПоДанным(ДанныеВыписки, Счёт, Договор), собирающая ту же строку "Выписка: дата + договор + счёт".

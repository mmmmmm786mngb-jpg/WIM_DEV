h2. IMDEV-9182 — Краткое ТЗ: конвертация XBRL ОРТИКОН в Excel

{panel:title=Суть|borderStyle=solid|borderColor=#42526E|titleBGColor=#EBECF0|bgColor=#FAFBFC}
*Проблема:* XBRL-пакеты ОРТИКОН уже ~500 МБ; внешний XBRL-конвертер выгружает формы частями (>1 часа, возможны сбои); портал Аванкор XBRL — >8 часов. Нужен инструмент визуализации данных в Excel для контроля качества отчётности.
*Цель:* внешней обработкой 1С выгружать *все формы/таблицы* XBRL-пакета в multi-sheet Excel *одним запуском*, *полностью*, за *вменяемое время* и *без сбоев*.
Форма 0420431 в исходной постановке — пример «тяжёлой» формы, *не* ограничение скоупа: выгружается весь entry point.
{panel}

{panel:title=Артефакт|borderStyle=solid|borderColor=#0052CC|titleBGColor=#DEEBFF|bgColor=#F5F9FF}
*Обработка:* {{внВыгрузкаXBRLОртиконВXLSX}} (EPF, БСП «Дополнительные отчеты и обработки»)
*Контур:* AvancoreDU / Wim_Du
*Платформа:* не ниже *8.3.12*
*Таксономия:* ЦБ XBRL *7.1* (вшивается в макет обработки)
*БезопасныйРежим:* *Ложь* (крупные файлы + запись XLSX)
*Полное ТЗ (HTML):* {{Документация/tz_xbrl_orticon_to_excel.html}}
{panel}

h3. Вход / выход
* *Вход:* файл {{.xbrl}} или {{.zip}} (instance ОРТИКОН / НСО ПУРЦБ)
* *Выход:* одна книга {{.xlsx}} (TOC + листы по таблицам пакета)
* *Режимы:* основной — с таксономией ЦБ (русские подписи); дополнительно — быстрый без таксономии
* *Только платформа 1С* (без Excel COM / Python на сервере)

h3. Ключевые требования
# Выгрузка *всех* форм entry point одним проходом (не частями)
# Пустые таблицы EP — как заглушки в книге (как в эталоне ЦБ), не ошибка
# Устойчивость на пакетах ~сотни МБ; без «тихого» обрезанного Excel
# Время — существенно лучше конвертера (>1 ч) и портала (>8 ч); ориентир: минуты / десятки минут
# Русские подписи таксономии; корректные числа / дроби количества ЦБ; члены осей (роль контрагента, ОКАТО)
# Особые layout (по эталону): пивот 0420415 (Taxis→строки); прочие формы — плоская раскладка

h3. Критерии приемки
# Весь пакет (все формы) в Excel одним запуском
# Без сбоев на крупном пакете
# Вменяемое время vs текущий конвертер/портал
# Объёмы ключевых блоков сопоставимы с эталоном ЦБ на том же ZIP
# Пригоден для визуальной проверки качества данных Back-Office Settle

h3. Вне скоупа
* Доработка чужого XBRL-конвертера / портала Аванкор
* Pixel-perfect UI конвертера ЦБ
* Замена штатной выгрузки XML/XBRL в ЦБ (обработка только *читает* instance)

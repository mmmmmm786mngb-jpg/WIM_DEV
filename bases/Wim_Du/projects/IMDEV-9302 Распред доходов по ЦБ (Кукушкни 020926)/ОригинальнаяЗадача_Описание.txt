Description
Необходимо создать в Аванкор ДУ обработку по распределению доходов по ЦБ, полученных единой суммой на ЕБС или ЕРС: на единые счета без необходимости самим формировать в экселе распределение по клиентам.

Идея следующая: на какой либо из Единых счетов ( брокерский, банковский - реквизиты их известны) приходит сумма дивидендов или купона, эта сумма должна быть отнесена на нескольких клиентов в корреспонденции с общей суммой полученного дохода на 51 или 55 счета: 

пользователь вводит Дату среза к выплате ( решения ) и Выпуск ЦБ, если это облигация,  то информация о НКД есть в купонном расписании
система определяет список договоров ДУ ( можно использовать код отчета Портфель по инструменту)
происходит расчет суммы для зачисления на счет клиента
формируются проводки по зачислению рассчитанной доли дохода каждому клиенту, с 51/55 списывается соответствующая часть суммы
округление согласно Методике распределения
Проверка полного списания пришедшей общей суммы против распределенных частей на клиентов
Желательно сделать обработку унифицированной: и для дивидендов и для купонов

 

Из Методики Распределения:

"Распределение доходов, полученных по ценным бумагам, осуществляется согласно списку Учредителей управления, которые имели право собственности на эти ценные бумаги на дату  решения (объявления) о выплате/перечислении таких доходов"

"Если в результате округления возникает расхождение в сотых, то корректировка относится на аналитический счет учета денежных средств Учредителя управления с наибольшим номером договора доверительного управления, участвовавшего в сделке"

// =============================================================================
// Консоль запросов 1С (база Wim_Du, конфигурация ДУ)
// =============================================================================
// Назначение:
//   По дням за период - сколько различных договоров ДУ встречается
//   в документах "Регламентные операции (ДУ)" (ПланРегламентныхОперацийДУ),
//   у которых договор относится к пулу "Розничное ДУ".
//
// Параметры (вкладка "Параметры" консоли запросов):
//   &НачалоПериода  - Дата, например '20250101'
//   &КонецПериода    - Дата, например '20250527' (включительно, конец дня)
//   &ПулРозницаДУ    - СправочникСсылка.Пул
//
// Значение &ПулРозницаДУ (выполнить в окне "Параметры" или перед запросом):
//   Справочники.Пул.НайтиПоНаименованию("Розничное ДУ")
// Если в вашей базе элемент пула называется иначе - подставьте нужную ссылку.
//
// Примечания:
//   - Один договор в один день считается один раз, даже если создано несколько планов
//     (разные группы операций и т.п.).
//   - Строка "КоличествоПланов" - дополнительно: число документов-планов за день.
//   - При необходимости раскомментируйте отбор только по проведенным документам.
// =============================================================================

ВЫБРАТЬ
    НАЧАЛОПЕРИОДА(План.Дата, ДЕНЬ) КАК День,
    КОЛИЧЕСТВО(РАЗЛИЧНЫЕ План.ДоговорДУ) КАК КоличествоРазличныхДоговоровДУ,
    КОЛИЧЕСТВО(РАЗЛИЧНЫЕ План.Ссылка) КАК КоличествоПланов
ИЗ
    Документ.ПланРегламентныхОперацийДУ КАК План
ГДЕ
    План.Дата МЕЖДУ &НачалоПериода И &КонецПериода
    И План.ДоговорДУ.Пул = &ПулРозницаДУ
    И НЕ План.ПометкаУдаления
    // И План.Проведен
СГРУППИРОВАТЬ ПО
    НАЧАЛОПЕРИОДА(План.Дата, ДЕНЬ)
УПОРЯДОЧИТЬ ПО
    День

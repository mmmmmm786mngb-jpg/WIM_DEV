## zob — IMDEV-9095 оптимизация переоценки (п.3)

Каталог: `Расширения/zob/`

Заимствован общий модуль `УчетДоходовРасходовСервер`. Перехват `&ИзменениеИКонтроль`:

- `ПодготовитьТаблицуВалютныхОстатковПоДокументу` — полная копия типового тела; точка доработки кеша (цикл `Запрос.Выполнить()`, baseline стр. 1219).

Сборка и загрузка: выгрузить XML в `.cfe` и подключить к базе `WIM_DU`.

```powershell
# База без авторизации: Srvr="localhost";Ref="WIM_DU";
db-load-xml ... -InfoBaseServer localhost -InfoBaseRef WIM_DU -Extension zob -UpdateDB
# без -UserName / -Password
```

Артефакт: `Расширения/zob.cfe`

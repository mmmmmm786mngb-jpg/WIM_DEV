ТЗ: кнопка «Отмена» — ждать доработку порций
Расширение IM86632, задача 1 (новая редакция)

Это новое ТЗ. Файлы prompt_im86632_cancel_and_evening_link.html и changes_task1_cancel_portions.html — старые (OLD), не править и не исполнять по ним отмену.

Поведение для пользователя. «Отмена» закрывает окно расчёта (родительское задание гасится — штат БСП). Сразу открывается второе окно: «Новые порции не запускаются. Ждём окончания уже запущенных потоков. Осталось порций: N». Обычно N около 12. Пока это окно висит, форма периода заблокирована (LockOwnerWindow) — «Создать» нажать нельзя. Порции не убиваем: текущий чанк дописывает договоры целиком.
Не делать.
  • Не вызывать Отменить() у дочерних ФЗ с ключом IM8663_.
  • Не вставлять ожидание / отмену в «Создать». Кнопка «Создать» не меняется.
  • Не заимствовать ФоновыеЗаданияСервер и не трогать общую форму ДлительнаяОперация.
  • Не звать типовой ОтменитьАктивныеЗадания.
  • Не объявлять Перем в модуле менеджера.
  • Не вызывать ПослеУспешногоЗавершенияГруппы после окна ожидания порций (иначе уедет автозапуск группы 3).

Как это стыкуется со штатом

ШагЧто происходит
Расчёт идёт Родитель ДТО + дочерние порции IM8663_дата_пачка_чанк_группа (скользящее окно, обычно 12).
Отмена первого окна БСП гасит только родителя. Новых чанков не будет. Уже запущенные 12 живут.
Второе окно Наше ФЗ только ждёт эти 12 (без Отменить) и показывает, сколько ещё активно.
Окно закрылось само Порций с ключом IM8663_ за дату больше нет. Можно жать «Создать».
Если на втором окне снова нажать «Отмена», БСП закроет и его — форма периода снова доступна, а чанки могут ещё писать. Это не страхуем: окно как раз для того, чтобы не запускать «Создать» раньше времени. Обработчик второго окна при отмене не открывает третье окно (иначе цикл).

1. Добавить: менеджер, ожидание порций

// Описание: Ждет окончания активных порций диспетчера за дату. Сами порции не отменяет.
// Ключ порции начинается с IM8663_ + yyyyMMdd. Свое ФЗ ожидания этот префикс не использует.
//
// Параметры:
//  ПараметрыПроцедуры - Структура - ключ ДатаПериода (Дата)
//  АдресРезультата - Строка - адрес временного хранилища для структуры с Успешно
//
Процедура ОжидатьЗавершенияПорцийРегламентаЗаДату(ПараметрыПроцедуры, АдресРезультата) Экспорт

    Результат = Новый Структура("Успешно, Сообщение", Истина, "");
    ДатаПериода = Неопределено;
    ПараметрыПроцедуры.Свойство("ДатаПериода", ДатаПериода);

    Если Не ЗначениеЗаполнено(ДатаПериода) Тогда
        ПоместитьВоВременноеХранилище(Результат, АдресРезультата);
        Возврат;
    КонецЕсли;

    ПрефиксКлюча = "IM8663_" + Формат(ДатаПериода, "ДФ=yyyyMMdd");
    ВсегоНаСтарте = 0;

    Пока Истина Цикл

        Отбор = Новый Структура;
        Отбор.Вставить("Состояние", СостояниеФоновогоЗадания.Активно);
        НайденныеЗадания = ФоновыеЗадания.ПолучитьФоновыеЗадания(Отбор);

        Порции = Новый Массив;
        Для Каждого ТекЗадание Из НайденныеЗадания Цикл
            Если СтрНачинаетсяС(ТекЗадание.Ключ, ПрефиксКлюча) Тогда
                Порции.Добавить(ТекЗадание);
            КонецЕсли;
        КонецЦикла;

        Если ВсегоНаСтарте = 0 Тогда
            ВсегоНаСтарте = Макс(Порции.Количество(), 1);
        КонецЕсли;

        Если Порции.Количество() = 0 Тогда
            ДлительныеОперации.СообщитьПрогресс(100, НСтр("ru='Запущенные порции завершены'"));
            Прервать;
        КонецЕсли;

        Осталось = Порции.Количество();
        Процент = Цел(100 * (ВсегоНаСтарте - Осталось) / ВсегоНаСтарте);
        ДлительныеОперации.СообщитьПрогресс(
            Процент,
            СтрШаблон(НСтр("ru='Новые порции не запускаются. Осталось потоков: %1'"), Осталось));

        ФоновыеЗадания.ОжидатьЗавершенияВыполнения(Порции, 5);

    КонецЦикла;

    ПоместитьВоВременноеХранилище(Результат, АдресРезультата);

КонецПроцедуры

Только ОжидатьЗавершенияВыполнения, не ОжидатьЗавершения (иначе аварийное завершение порции даст исключение).

Проверка

СценарийОжидание
Группа 2, 12 потоков, «Отмена» в середине Первое окно закрылось. Сразу второе: «ждём потоки», счётчик падает 12 → 0. Форма периода недоступна. В журнале ФЗ дети с IM8663_ доходят до конца, не «Отменено».
Второе окно само закрылось, затем «Создать» Нет пачки «два документа в один день» из-за живых порций прошлого запуска. «Создать» работает как сейчас, без нового ожидания.
0 потоков / порций уже нет Второе окно либо не появляется, либо сразу «Выполнено» — без зависания.
Автозапуск группы 3 после успешного расчёта Не срабатывает от окна ожидания порций. Только от штатного успеха группы 2.

Вендор: Аванкор (AvancoreDU). Вложение к задаче: расширение IM86632.cfe, версия 1.0.0.4. Этот файл — инструкция, что взять из CFE в базовую конфигурацию ДУ по двум доработкам ниже. Остальной код в том же CFE к этой задаче не относится. Директивы расширения (&ИзменениеИКонтроль, &После, #Вставка, #Удаление) в CF не копировать — влить тело в типовые процедуры. Дерево изменений IM86632 1.0.0.4 → базовая CF

Только две доработки: (1) отмена расчёта — ждать живые порции; (2) группа 3 считает только договоры с проведенным планом группы 2 и пишет ссылку ПланВечернихОпераций. Целевая CF уже содержит диспетчер порций 8663.1 и предыдущий перенос IM86632 (разделение групп + пакет 1000).

Что внести сейчас

  • Реквизит документа ПланРегламентныхОперацийДУ.ПланВечернихОпераций (ссылка на этот же документ, синоним «План вечерних операций»).
  • Поле только просмотр на форме плана — после ГруппаОперацийПользователя.
  • Реквизит формы (не документа) РасчетСЧА_РСА + поле только просмотр после ДокументОснование.
  • Модуль менеджера РегламентныеПериоды: 3 новых метода связи + 2 метода отмены + 1 служебный.
  • Форма РегламентныйПериод: 5 новых процедур отмены, 1 функция отбора группы 3, две точечные вставки в уже перенесённые методы.
  • Модуль объекта плана: код после ПередЗаписью.
  • Общий модуль ФоновыеЗаданияСервер: вставка до Записать в СоздатьПланРегламентныхОперацийДУ.
  • Две точечные вставки в уже существующие ОбработатьПачкуДиспетчером и СформироватьДокументыЗакрытияПериода.
  • Сигнатуры двух процедур пакета 1000 — в типовой CF параметров нет, дописать в заголовок (см. красный блок ниже).

Чего не делать

  • Не переносить заново пакет 1000, константу, флажок автозапуска, роль ПраваНаРегламентыСЧА_РСА — это предыдущее дерево avancor_changes_tree_im86632.html. Исключение: если в CF ещё нет двух параметров ниже — их вставить обязательно.
  • Не создавать в CF объекты, которые в CFE только заимствованы (список в таблице ниже, серые строки).
  • Не писать вечерний план в РасчетСЧА_РСА.ДокументОснование.
  • Не удалять поле «Комментарий» с типовой формы плана — в CFE его нет только из-за ограничения расширения.
  • Не добавлять ключ СоответствиеДоговорВечернийПлан в ОчиститьПакетныеДанныеПараметрыСохранения.
  • Не вызывать Отменить() у порций с ключом IM8663_.
  • Не менять кнопку «Создать», пулы, пакет 1000, «с учетом выполненных», ПослеУспешногоЗавершенияГруппы.
  • Не подменять модули целиком. Не копировать Configuration.xml, язык, картинки, префикс расширения.

Не забыть: параметры в 2 процедурах — в базовой CF их нет

Как переносить перехват

  • Открыть метод в CFE (имя с IM86632_) и тот же метод без префикса в CF.
  • Взять только содержимое #Вставка … #КонецВставки (или тело &После) и вставить в типовой метод в то же место.
  • Маркеры #Вставка / #Удаление / директивы &После в CF не оставлять.
  • Новые процедуры копировать как есть, без префикса (в CFE они уже без него).
  • Если в CFE у метода больше параметров, чем в типовой CF — сначала дописать параметры в заголовок типовой процедуры, потом тело. Сейчас так у ПолучитьСуммыРСАСЧА и Операция_1000_РасчетРСА_СЧА.

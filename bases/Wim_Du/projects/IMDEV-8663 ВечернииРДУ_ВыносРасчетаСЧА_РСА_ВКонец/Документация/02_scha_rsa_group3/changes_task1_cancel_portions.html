Задача 1. Отмена порций
Расширение IM86632, что меняем

Цель: кнопка «Отмена» и повторное «Создать» гасят дочерние ФЗ с ключом IM8663_ за дату формы и ждут остановки. Снимок планов — только после этого. Базовую CF не трогать. Ничего не удаляем.

Суть. Окно длительной операции отменяет только родителя. Дети с ключом IM8663_дата_пачка_чанк_группа продолжают проводить планы. Новый «Создать» снимает снимок без этих планов и падает на уникальности.

1. Добавить: модуль менеджера

// Описание: Отменяет активные порции диспетчера регламента за указанную дату
// и ждет их остановки. Ключ порции: IM8663_ + yyyyMMdd + ...
//
// Параметры:
//  ДатаПериода - Дата - дата регламентного периода
//
Процедура ОтменитьПорцииРегламентаЗаДату(ДатаПериода) Экспорт

    Если Не ЗначениеЗаполнено(ДатаПериода) Тогда
        Возврат;
    КонецЕсли;

    ПрефиксКлюча = "IM8663_" + Формат(ДатаПериода, "ДФ=yyyyMMdd");

    Отбор = Новый Структура;
    Отбор.Вставить("Состояние", СостояниеФоновогоЗадания.Активно);
    НайденныеЗадания = ФоновыеЗадания.ПолучитьФоновыеЗадания(Отбор);

    ЗаданияКОжиданию = Новый Массив;
    Для Каждого ТекЗадание Из НайденныеЗадания Цикл
        Если СтрНачинаетсяС(ТекЗадание.Ключ, ПрефиксКлюча) Тогда
            ТекЗадание.Отменить();
            ЗаданияКОжиданию.Добавить(ТекЗадание);
        КонецЕсли;
    КонецЦикла;

    Пока ЗаданияКОжиданию.Количество() > 0 Цикл
        ЗаданияКОжиданию = ФоновыеЗадания.ОжидатьЗавершенияВыполнения(ЗаданияКОжиданию, 5);
        ОсталисьАктивные = Новый Массив;
        Для Каждого ТекЗадание Из ЗаданияКОжиданию Цикл
            Если ТекЗадание.Состояние = СостояниеФоновогоЗадания.Активно Тогда
                ОсталисьАктивные.Добавить(ТекЗадание);
            КонецЕсли;
        КонецЦикла;
        ЗаданияКОжиданию = ОсталисьАктивные;
    КонецЦикла;

КонецПроцедуры

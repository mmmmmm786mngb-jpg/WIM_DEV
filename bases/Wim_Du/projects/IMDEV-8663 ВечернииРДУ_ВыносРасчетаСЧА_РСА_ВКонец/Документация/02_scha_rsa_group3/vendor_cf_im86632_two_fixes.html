IMDEV-8663.2. Две правки в релизе ДУ 1.5.30.3

Для Аванкор. Остальной перенос IM86632 1.0.0.4 в релизе уже есть. Ниже только то, что расходится.

07.10.2026. Эталон: расширение IM86632 1.0.0.4. Полная сверка: vendor_cf_im86632_comparison.html

Красный: так сейчас в 1.5.30.3 Зеленый: так надо Белый: строка уже верная, не трогать

1. Форма периода. Три вызова не вставлены

Справочник РегламентныеПериоды, форма РегламентныйПериод, процедура ОбработатьРезультатЗадания.

Процедуры ЗапуститьОжиданиеПорцийПослеОтмены и ПослеУспешногоЗавершенияГруппы в модуле уже есть. Их надо вызвать. Заново не создавать.

1.1. Отмена пользователем. Результат = Неопределено

Сейчас в 1.5.30.3

Если Результат = Неопределено Тогда
Состояние(НСтр("ru='Задание отменено пользователем'"));
// вызова нет, сразу выход
Возврат;
КонецЕсли;

Как надо

Если Результат = Неопределено Тогда
Состояние(НСтр("ru='Задание отменено пользователем'"));
ЗапуститьОжиданиеПорцийПослеОтмены();
Возврат;
КонецЕсли;

1.2. Успех. Сразу после обновления формы

Сейчас в 1.5.30.3

Если Данные.Успешно Тогда
Состояние(
НСтр("ru='Регламентные операции успешно сформированы'"),
100, ,
БиблиотекаКартинок.ЗапуститьОтдельныйСеансДляВыполненияРегламентныхЗаданий);
ЗавершитьОбработкуПослеУспехаНаКлиенте();
// автозапуск группы 3 не вызывается
Иначе

Как надо

Если Данные.Успешно Тогда
Состояние(
НСтр("ru='Регламентные операции успешно сформированы'"),
100, ,
БиблиотекаКартинок.ЗапуститьОтдельныйСеансДляВыполненияРегламентныхЗаданий);
ЗавершитьОбработкуПослеУспехаНаКлиенте();
ПослеУспешногоЗавершенияГруппы();
Иначе

Без зеленой строки флажок на форме ничего не запускает: после вечерних группа 3 сама не стартует. ЗавершитьОбработкуПослеУспехаНаКлиенте только обновляет дерево и чистит временное хранилище.

1.3. Статус «Отменено»

Сейчас в 1.5.30.3

ИначеЕсли Результат.Статус = "Отменено" Тогда
Состояние(НСтр("ru='Задание отменено'"));
// вызова нет
КонецЕсли;

Как надо

ИначеЕсли Результат.Статус = "Отменено" Тогда
Состояние(НСтр("ru='Задание отменено'"));
ЗапуститьОжиданиеПорцийПослеОтмены();
КонецЕсли;

Зеленая строка открывает окно «Новые порции не запускаются» и ждет уже запущенные порции с ключом IM8663_. Ключ ожидания IM86632_Wait_ внутри процедуры менять не нужно.

2. ПередЗаписью плана. Возврат стоит слишком высоко

Документ ПланРегламентныхОперацийДУ, модуль объекта, процедура ПередЗаписью.

В расширении это дописка после штатной процедуры. В релизе тот же текст стоит до проверки закрытого периода и пометки подчиненных. Красный Возврат выходит из всей процедуры, белый хвост ниже него не выполняется.

Сейчас в 1.5.30.3

Красный блок надо убрать из начала и поставить зеленым в конец, после пометки подчиненных. Тогда Возврат уже не пропускает штатный код.

Что из-за красного Возврат сейчас не делается:

  1. План не группы 3 (вечерние и остальные): при пометке удаления подчиненные документы не помечаются.
  2. План группы 3, у которого связь уже заполнена фоновым заданием: не проверяется закрытый период.

Поиск вечернего плана и текст отказа для ручной записи плана группы 3 уже есть. Их переносить по смыслу, не писать второй раз. Другие вызовы ПометитьНаУдалениеПодчиненныеДокументы (выполнение операций, пересчет) этот хвост не заменяют.

Задача 2. Отбор группы 3 и связь
Расширение IM86632, что меняем

Цель: группа 3 берёт только договоры с проведённым планом группы 2 за дату. На плане группы 3 — реквизит ПланВечернихОпераций. ДокументОснование расчёта СЧА не трогать. Ничего не удаляем.

Заполнение реквизита. Один запрос на пачку → СоответствиеДоговорВечернийПлан → срез чанка → ключ в СоответствиеОперацияТаблица → до Записать в СоздатьПланРегламентныхОперацийДУ. Не запрос в ПередЗаписью на каждый договор. Не Перем в модуле менеджера.

2. Добавить: менеджер, фильтр запуска

// Описание: Возвращает договоры, у которых за дату есть проведенный план группы 2.
//
Функция ДоговорыСПроведеннымВечернимПланом(ДатаПериода, СписокДоговоровДУ) Экспорт

    Результат = Новый Массив;
    Если СписокДоговоровДУ = Неопределено Или СписокДоговоровДУ.Количество() = 0 Тогда
        Возврат Результат;
    КонецЕсли;

    СоответствиеПланов = СоответствиеВечернихПланов(ДатаПериода, СписокДоговоровДУ);
    Для Каждого ТекДоговор Из СписокДоговоровДУ Цикл
        Если СоответствиеПланов.Получить(ТекДоговор) <> Неопределено Тогда
            Результат.Добавить(ТекДоговор);
        КонецЕсли;
    КонецЦикла;

    Возврат Результат;

КонецФункции

3. Добавить: менеджер, кэш пачки

Процедура ЗаполнитьСоответствиеВечернихПлановПачки(ПараметрыСохранения, СписокДоговоровДУ, ДатаПериода)

    ПараметрыСохранения.Удалить("СоответствиеДоговорВечернийПлан");
    ПараметрыСохранения.Вставить(
        "СоответствиеДоговорВечернийПлан",
        СоответствиеВечернихПланов(ДатаПериода, СписокДоговоровДУ));

КонецПроцедуры

Функция НайтиПроведенныйВечернийПлан(ДатаПериода, ДоговорДУ) Экспорт

    Список = Новый Массив;
    Список.Добавить(ДоговорДУ);
    СоответствиеПланов = СоответствиеВечернихПланов(ДатаПериода, Список);

    Возврат СоответствиеПланов.Получить(ДоговорДУ);

КонецФункции

СоответствиеВечернихПланов — общая выборка по тексту запроса выше (не экспорт). Вызов кэша пачки — из уже существующей ЗаполнитьПараметрыСохраненияПакетнымиДаннымиГруппыСЧА.

&НаСервере
Функция ОтобратьДоговорыДляЗапускаНаСервере(СписокДоговоровДУ)

    Результат = Новый Структура("СписокДоговоровДУ, Отказано, ТекстОшибки",
        СписокДоговоровДУ, Ложь, "");

    КодТекущей = "";
    Если ЗначениеЗаполнено(ГруппаРегламентныхОпераций) Тогда

    Если Не ЗначениеЗаполнено(КодГруппыСЧА) Или КодТекущей <> КодГруппыСЧА Тогда

    КонецЕсли;

    Результат.СписокДоговоровДУ = Справочники.РегламентныеПериоды.ДоговорыСПроведеннымВечернимПланом(
        ДатаПериода,
        СписокДоговоровДУ);

    Если Результат.СписокДоговоровДУ.Количество() = 0 Тогда

            |Группа «3. Расчет СЧА/РСА» не запущена.'");
    КонецЕсли;

    Возврат Результат;

Вендор: Аванкор (AvancoreDU). Источник пилота — расширение IM8663 (CFE). Ниже — дерево того, что нужно внести в базовую конфигурацию ДУ, и как это соотносится с файлами расширения. Префикс процедур IM8663_ в базовой CF можно оставить (трассировка) или переименовать по стандарту вендора — важно сохранить логику и экспорт воркера порции.

Дерево изменений для переноса IM8663 → базовая CF

IMDEV-8663.1 — диспетчер порций договоров + исправления CR по фоновым заданиям регламента. База: Wim_Du / Доверительное управление. Артефакт пилота: Расширения/IM8663.cfe.

Что переносим (кратко)

  • 2 константы (имена уже без префикса расширения — копировать как есть).
  • 1 модуль менеджера справочника РегламентныеПериоды: правки двух типовых процедур + 5 новых методов.
  • Общий модуль ФоновыеЗаданияСервер не трогать (типовой вызов ФоновыеЗаданияРазрешены / СоздатьПланРегламентныхОперацийДУ остаётся).
  • Формы / роли / другие объекты — не менять.

Как читать дерево

  • ДОБАВИТЬ — новый объект/метод в базовой CF.
  • ИЗМЕНИТЬ — правки внутри существующего типового метода.
  • УБРАТЬ — удалить/заменить старый фрагмент типового кода.
  • в CF — целевое место в базовой конфигурации.
  • из CFE — откуда взять код в расширении.
  • этап A / этап B — маркеры IMDEV-8663.1.

Порядок работ для вендора (пошагово)

Целевой объект почти везде один: Справочник.РегламентныеПериоды → модуль менеджера (Catalogs/РегламентныеПериоды/Ext/ManagerModule.bsl в выгрузке). Источник пилота: расширение IM8663 / файл IM8663.cfe. Директивы расширения (&ИзменениеИКонтроль, #Вставка, #Удаление) в базовую CF не копировать — переносить только тело кода.

Что не копировать и не менять

  • Не копировать в CF строки &ИзменениеИКонтроль(...), #Вставка / #Удаление / #Конец….
  • Не заимствовать и не менять ОбщийМодуль.ФоновыеЗаданияСервер и ОбщегоНазначения.ВыполнитьБПБезопасно — только вызовы.
  • Не трогать форму РегламентныйПериод и процедуры пакетной предподготовки (ЗаполнитьПараметрыСохраненияПакетнымиДанными…) — меняется только размер пачки.
  • Не переносить пустые модули констант (Constants/…/Ext/ManagerModule.bsl) — не нужны.

Главное для вендора.
  • В CFE модуль менеджера содержит полные копии двух типовых процедур с &ИзменениеИКонтроль — это нужно только расширению. В базовую CF не подставлять файл целиком: влить 5 новых методов + точечные блоки из #Вставка/#Удаление в уже существующие процедуры CF.

Обязательно поправить и строку запуска ФЗ: "Справочники.РегламентныеПериоды.СоздатьПланыРегламентныхОперацийПоЧанку". Имена двух констант уже без префикса — их не менять.

5. Справочник РегламентныеПериоды, МодульМенеджера

Файл пилота: Catalogs/РегламентныеПериоды/Ext/ManagerModule.bsl. В CFE — перехваты &ИзменениеИКонтроль и блоки #Вставка/#Удаление. В базовую CF директивы расширения не копировать — вливать только тело.

4.1 ИЗМЕНЕНИЕ СформироватьРегламентныеОперации

4.1.1 Init после проверки ПараметрыСохранения

ВСТАВИТЬ сразу после Если ПараметрыСохранения = Неопределено … Возврат; КонецЕсли;:

  • ФоновыеЗаданияДоступны (потоки > 0 и ФоновыеЗаданияСервер.ФоновыеЗаданияРазрешены());
  • счётчики УспешныхЗаданий / ОшибокЗаданий, ПроблемныеДоговоры;
  • РазмерЧанкаПоУИД, таймер IM8663_НачалоРасчетаМС;
  • РазмерЧанка из константы порции.

Маркеры: // IMDEV-8663.1.A, // IMDEV-8663.1.B.

4.1.2 Размер пачки

УДАЛИТЬ РазмерПачки = 3000; // IMDEV-8926
ВСТАВИТЬ чтение константы пачки + защита < 1.

4.1.3 Цикл по договорам пачки (после предподготовки)

УДАЛИТЬ безусловный цикл Для Каждого ТекДоговор Из СписокПачки → СформироватьДокументыЗакрытияПериода.

ВСТАВИТЬ:

  • если ФоновыеЗаданияДоступны → IM8663_ОбработатьПачкуДиспетчером(...);
  • иначе → прежний последовательный цикл;
  • затем IM8663_ЗавершитьФоновыеЗаданияПорции (барьер пачки).

4.1.4 Финал успешного завершения

ВСТАВИТЬ перед СообщитьПрогресс(100, …завершено): финальное ожидание, сводка, время.
ЗАМЕНИТЬ Результат.Сообщение = "" → Результат.Сообщение = ТекстСводки.

4.1.5 Ветка Исключение

ВСТАВИТЬ в начале: IM8663_ОтменитьАктивныеЗадания(ПараметрыСохранения).

4.2 ИЗМЕНЕНИЕ СформироватьДокументыЗакрытияПериода

Где: внутри Если ТаблицаОпераций.Количество() > 0 — блок Если КоличествоПотоков > 0 И ФоновыеЗаданияСервер.ФоновыеЗаданияРазрешены().

УДАЛИТЬ целиком ветку запуска ФоновыеЗадания.Выполнить("ФоновыеЗаданияСервер.СоздатьПланРегламентныхОперацийДУ", …) и вложенное ожидание/разбор порции.

ВСТАВИТЬ вместо If/Else один синхронный вызов (как типовой Иначе):

ФоновыеЗаданияСервер.СоздатьПланРегламентныхОперацийДУ(
    ДатаПериода, ДоговорДУ, ТаблицаОпераций, ТекПлан,
    ТекГруппаОперацийПользователя, УчитыватьВыполненные,
    СоответствиеОперацияТаблица);
Параллельность больше не здесь. Диспетчер вызывает эту процедуру с КоличествоПотоков = 0 / ФоновыеЗаданияДоступны = Ложь.

8. Правила переноса и чеклист

  1. Создать 2 константы (имена как в п. 4; пустые Ext/*.bsl не копировать).
  2. Добавить 5 новых методов в модуль менеджера РегламентныеПериоды (воркер — Экспорт; ВсеЗаданияЗавершены не создавать).
  3. Влить правки в СформироватьРегламентныеОперации (6 точек) и СформироватьДокументыЗакрытияПериода (1 замена) без директив расширения и без подмены файла целиком.
  4. Проверить совпадение имени воркера в строке запуска ФЗ.
  5. После переноса на ИБ снять расширение IM8663 (иначе двойные перехваты) — зона внедрения.
Не копировать в CF: &ИзменениеИКонтроль(...), #Вставка / #Удаление / #Конец…, пустые модули констант Constants/…/Ext/*.bsl, язык расширения, заимствование справочника как «новый объект», общий модуль-заглушку для ФЗ, правки ФоновыеЗаданияСервер / ОчиститьПакетныеДанные… / формы / группу 3 СЧА (8663.2).

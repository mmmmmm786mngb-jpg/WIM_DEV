# Расширение IM86632

Доработка IMDEV-8663.2: вынос расчета СЧА/РСА в группу `3. "Расчет СЧА/РСА"`.

На этом шаге (этап 2) расширение дает только UX разделения запуска. Пакетные запросы, ключи диспетчера и 7-й параметр операции 1000 не подключаются.

## Состав этапа 2

- Константа `IM86632_ИспользоватьПредварительныеЗапросыДляРегламентовСЧА_РСА` (Булево, по умолчанию Ложь).
- Форма `РегламентныеПериоды.РегламентныйПериод`: флажок «После вечерних операций запускать расчет СЧА/РСА».
- Предупреждение при перезапуске вечерних, если планы группы 3 уже есть.
- После успешного завершения группы 2: либо сообщение пересчитать группу 3, либо вторая длительная операция группы 3 (если флажок включен).

Группу 3 в справочнике создает обработка поддержки `ПереносОперацийСЧА_РСАВГруппу3`. Без нее флажок скрыт, форма не падает.

## Порядок внедрения

1. Прогнать обработку поддержки на информационной базе.
2. Подключить расширение IM86632 (константа выключена).
3. Позже включить пакетный расчет (этапы 3-4).

Старое расширение IM8663 на базу не подключать.

# Расширение IM86632T1

Копия IM86632 для тестовой базы Т-1, где доступно только динамическое обновление: новую константу в метаданные добавить нельзя.

Префикс перехватов тот же: `IM86632_`. IM86632 не менять и на Т-1 не подключать вместе с этой копией.

## Отличия от IM86632

- Нет константы `ИспользоватьПредварительныеЗапросыДляРегламентовСЧА_РСА`.
- Нет роли `ПраваНаРегламентыСЧА_РСА`.
- Пакет группы 3 включается функцией `ПакетныйРасчетСЧА_РСАВключен()`: если константы нет в метаданных — всегда Истина; если константа появится в CF — читается её значение.

Остальной код (форма, пакетный расчет, операция 1000) совпадает с IM86632.

## На Т-1

1. Обработка `ПереносОперацийСЧА_РСАВГруппу3.epf` — создать группу 3.
2. Подключить IM86632T1 как небезопасное расширение (перехваты модулей).
3. Константу не включать: её нет, пакет уже включен.

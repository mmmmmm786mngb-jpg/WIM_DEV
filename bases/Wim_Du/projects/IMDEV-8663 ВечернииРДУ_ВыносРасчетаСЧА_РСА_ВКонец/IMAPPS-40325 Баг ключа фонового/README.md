# IMAPPS-40325. Ошибка ключа фонового задания при параллельном запуске вечерних

Обращение: при создании вечерних регламентных операций одновременно несколькими пользователями
возникает ошибка "Задание с таким значением ключа уже выполняется", операции не создаются
(`40325_Skip to main contentSkip to sidebar.docx` - выгрузка обращения из Jira).

Причина: ключ фонового задания порции (доработка IMDEV-8663) составлялся из даты, номера пачки,
номера порции и группы - одинаково у всех запусков за дату. Исправление: идентификатор запуска в
ключе порции; ожидание после отмены ищет только порции своего запуска.

# Сверка документов операций СЧА/РСА

Тестовая внешняя обработка (только EPF). Нужна для A/B проверки: документы
операций 1000/1010/1020/1030 по договорам ДУ совпадают до и после доработки.

## Назначение

1. После расчета дня "по-старому" сохранить снимок документов в JSON.
2. Пометить на удаление все `ПланРегламентныхОперацийДУ` за этот день
   (параллельные потоки; подчиненные документы помечает типовой `ПередЗаписью` плана).
3. После установки нового расширения и повторного расчета того же дня
   сохранить второй снимок.
4. Сверить два файла и увидеть, есть ли расхождения и какие именно.

## Что попадает в снимок

Документы за выбранный день без пометки удаления:

- `РасчетСЧА_РСА` (шапка + ТЧ `РасчетСЧА` и `РасчетРСА`)
- `РасчетДоходностиПортфеля`
- `КонтрольУменьшенияСтоимостиПортфеля`
- `КонтрольДопустимогоУровняРиска`

Ключ строки: тип документа + UID договора ДУ. Код договора пишется только
для отображения.

Не сохраняются: номер документа, дата документа, ссылка, документ-основание,
номер строки ТЧ, хранилище `СправкаРасчет`.

Ссылки в показателях канонизируются как `ПолноеИмяМетаданных:UID`.

## Регистрация в БСП (обязательно для ФЗ)

Пометку планов фоновые задания берут объект обработки только из справочника
`Дополнительные отчеты и обработки` (`ДополнительнаяОбработкаСсылка`).
Подключение через Файл - Открыть для ФЗ недостаточно.

1. Администрирование - Печатные формы, отчеты и обработки - Дополнительные отчеты и обработки.
2. Создать, загрузить `СверкаДокументовОперацийСЧА_РСА.epf`.
3. Публикация: Используется. Безопасный режим выключен (так задано в сведениях).
4. Открывать команду из дополнительных обработок (тогда форма получает ссылку справочника).

Снимок JSON и сверка двух файлов работают и без регистрации. Кнопка
"Пометить планы за день" без элемента справочника не стартует ФЗ.

## Как пользоваться

1. Открыть обработку из справочника дополнительных отчетов и обработок.
2. Указать день расчета. Метка снимка: например `etalon`, затем `after`.
3. "Сохранить снимок в файл" - выбрать JSON.
4. "Пометить планы за день" - подтвердить. Число потоков берется из
   константы `МаксимальноеКоличествоПараллельныхПотоков`.
5. Поставить расширение, снова посчитать тот же день.
6. Сменить метку на `after`, снова сохранить снимок.
7. "Файл эталона" / "Файл после" (если пути не подставились сами) и "Сверить два файла".

Если в метке есть `after` или `после`, путь последнего снимка попадает в
"Файл после", иначе - в "Файл эталона".

## Сборка

```
/epf-build СверкаДокументовОперацийСЧА_РСА
```

Исходники в этой папке, собранный файл: `build/СверкаДокументовОперацийСЧА_РСА.epf`.

# Перенос операций СЧА/РСА в группу 3

Внешняя обработка для отдела поддержки (только EPF, без расширения).

## Назначение

Создает группу `3. "Расчет СЧА/РСА"` и переносит в нее пять видов операций:

- РасчетРСА_БУ
- РасчетСЧА_БУ
- РасчетДоходностиПортфеля_БУ
- КонтрольУменьшенияСтоимостиПортфеля_УУ
- КонтрольПревышенияУровняРисков_УУ

Время группы копируется с `2. "Вечерние" операции`. Есть возврат тех же операций в вечерние. Группа 3 при возврате не удаляется.

## Как работает

1. "Проверить" - только чтение, заполняет таблицу плана и протокол.
2. "Выполнить перенос" - запись после подтверждения. Идемпотентно.
3. "Вернуть в вечерние" - доступна, если хотя бы одна из пяти операций в группе 3 и найдена группа вечерних.

```

```

## Запуск

Файл -> Открыть -> выбрать `.epf` -> "Проверить" -> "Выполнить перенос" или "Вернуть в вечерние".
Можно подключить через "Дополнительные отчеты и обработки".

# Пометка удаления планов регл. операций за день

Внешняя обработка (только EPF, без расширения).

## Назначение

Для A/B сравнения: после прогона «по-старому» пометить на удаление все
`ПланРегламентныхОперацийДУ` за выбранный день (без отбора договоров).
Типовой `ПередЗаписью` плана также пометит подчиненные документы
(`ПометитьНаУдалениеПодчиненныеДокументы`).

## Как работает

1. Отбор: все планы за день с `ПометкаУдаления = Ложь`.
2. Число потоков: `Константы.МаксимальноеКоличествоПараллельныхПотоков` (если 0 → 1).
3. Планы раскладываются по порциям; каждая порция — фоновое задание через
   `ДлительныеОперации.ВыполнитьПроцедуруМодуляОбъектаОбработки` (метод модуля
   объекта этой же обработки).

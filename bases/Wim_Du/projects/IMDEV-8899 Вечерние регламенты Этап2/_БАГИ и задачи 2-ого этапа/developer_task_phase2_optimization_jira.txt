{panel:title=IMDEV-8899 / постановка для разработчика|borderStyle=solid|borderColor=#2b6cb0|titleBGColor=#2b6cb0|bgColor=#EBF4FF}

*Материалы:*
* «Тест по замеру отладчиком новой конфигурации.docx»

{panel}

----

h2. 1. Контекст и цель

{info:title=Контекст}
Отдельная подзадача на *исследование и оптимизацию* участков, выявленных после устранения основного узкого места по [IMAPPS-35992|https://jira/browse/IMAPPS-35992] (индексация + потоки — отдельное согласование с бизнесом).

*Цель:* сократить время полного вечернего расчета (~17 тыс. договоров ДУ) за счет оптимизации запросов, отсечения «пустых» договоров и устранения коллизий номеров документов.
{info}

----

h2. 2. Оценка времени полного расчета (базовая линия)

При длительности *~2 часа* на 17 тыс. договоров ДУ (5 потоков, после индексации IMAPPS-35992):

|| Блок || Оценка ||
| ПланРегламентныхОперацийДУ + внутренние алгоритмы (параметры договоров и т.п.) | ~30 мин |
| РСА + СЧА | ~30 мин |
| Переоценка активов + НКД | ~40 мин |
| Прочие расчеты (без движений: Переоценка ДС, дефолтные, контроль уменьшения стоимости и т.п.) | ~20 мин |

h2. 5. Дополнительные доработки

{warning:title=+1 | Документ РасчетСЧА_РСА — коллизия номера при записи}
При параллельной записи возможен дубль номера документа. Реализовать по аналогии с МО (IMDEV-8665):

# Перед записью: {{УстановитьНовыйНомер()}}
# До *30 попыток* записи/проведения
# При ошибке с текстом «*не уникально*» (регистронезависимо) — повторить
# Иначе — пробросить исключение с информативным сообщением

_Эталон:_ Wim_Mo, обработка {{внРасчетMVиWAP}}, процедура {{СоздатьИПровестиОдинДокументРасчета}} (строки ~1644-1662).
{warning}

{warning:title=+2 | Предварительный отсев договоров ДУ без расчета}
Для видов расчетов, которые *как правило не формируют документов* (прочие расчеты без движений: переоценка ДС, дефолтные, контроль уменьшения стоимости портфеля и т.п. — ~20 мин в общей оценке):

# Разработать предварительные запросы, отсекающие договоры ДУ, по которым расчет заведомо не нужен
# Не запускать полный цикл регламентных процедур для отсеченных договоров
# Зафиксировать критерии отсечения по каждому виду операции (таблица в описании задачи)
# Замер: сокращение времени блока «прочие расчеты» и общего времени расчета
{warning}

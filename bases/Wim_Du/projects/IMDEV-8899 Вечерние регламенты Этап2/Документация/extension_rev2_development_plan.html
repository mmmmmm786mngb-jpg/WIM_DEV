3. Целевая архитектура (кратко)

  1. Форма РегламентныйПериод строит СписокОпераций (как в базе).
  2. Перед СписокОпераций.Индексы.Добавить("ДоговорДУ") — вызов ОтфильтроватьСписокОперацийЗакрытия(...) при включенной константе и только если все договоры из отбора формы (СписокДоговоровДУ) имеют ДоговорДУ.Пул с наименованием Розничное ДУ.
  3. Модуль менеджера РС по видам из регистра снимает Выполнять = Ложь там, где пакетный отбор показывает отсутствие оснований для расчета.
  4. Дальше базовая логика: план создается только для строк с Выполнять = Истина.

Эталон: RduPF (WIM_FIn, IMDEV-8641) — однородность пула перед отсевом; разрез ДоговорДУ (реквизит Пул, не портфель). В отборе формы по замерам: пул «Розничное ДУ».

Ручной запуск: «Начисление вознаграждения за управление: Розничное ДУ»

Источник: ОРИГИНАЛ/внНачислениеВознаграждения_РозничноеДУ_epf, версия 1.09.
Команда БСП: НачислениеВознагражденияЗаУправлениеРозничноеДУ (тип ОткрытиеФормы).

Этот документ — только про ручную команду (открытие формы и кнопки на форме). Фоновая команда расторжения (23:45) сюда не входит.

1. Как пользователь запускает

  1. Дополнительные отчеты и обработки → «Начисление вознаграждения за управление: Розничное ДУ».
  2. Открывается форма обработки.
  3. Подставляются сохранённые настройки (Пул, ставка, счета, каталоги).
  4. Пользователь указывает Дата начисления (и при необходимости список договоров / флаг расторжения).
  5. Кнопка «Выбрать» → отбор договоров в ТЧ.
  6. Кнопка «Начислить» → создание документов и справок.
Для сценария «обычное ВУК» флаг Режим расторжения должен быть выключен (значение по умолчанию при ручном начислении за управление).

3. Алгоритм кнопок

[Открытие формы]
   -> загрузка настроек из доп. обработки
   -> пользователь задаёт ДатуНачисления, Пул (и опционально список)

[Выбрать]  = ДоговорыКНачислению()
   -> очистка ТЧ ДоговорыДУКНачислению
   -> запрос отбора
   -> в ТЧ только строки с (СуммаВознаграждения + Удержание) > 0

[Начислить] = СоздатьНачисления()
   -> для каждой строки ТЧ:
        если СуммаВознаграждения > 0 -> создать НачислениеВознаграждения
        (ветка удержания при расторжении для обычного режима обычно не срабатывает)
        -> PDF справка
        -> удалить «сырые» обязательства ДС

4. Отбор договоров при РежимРасторжения = Ложь

Не все договоры пула РДУ. Нужно пройти все фильтры ниже.

4.1. Базовый отбор справочника ДоговорДУ

#УсловиеСмысл
1 Пул = &Пул или договор в списке ДоговорыДУ Пул из настроек либо ручной список
2 ДатаОкончания пустая или > ДатаРасчета Договор ещё действует на дату начисления
3 ДатаПолученияУведомленияОРасторженииДоговораДУ пустая Только договоры без уведомления о расторжении

Договор вознаграждения подтягивается ЛЕВЫМ соединением:

ДоговорыКонтрагентов.ДоговорДУ = ДоговорДУ
И РольДоговора = СоглашениеОВознаграждении

4.2. Обязательные соединения / доп. условия

#УсловиеЭффект
4 Есть активные вводы в ВводыВыводыДУ (Сумма > 0) Без ввода ДС договор отбрасывается (ВНУТРЕННЕЕ соединение)
5 Есть остаток ОбязательстваПоДС на дату (основание пустое) Без остатка обязательств договор не попадает (для обычного режима нужно НЕ СуммаВознаграждения... ЕСТЬ NULL)
6 Нет проведённого НачислениеВознаграждения с Розница и комментарием "Дополнительное вознаграждение" Защита от уже созданного «доп.» документа расторжения
7 После выборки: сумма > 0 В ТЧ только договоры с положительной суммой к начислению
Практический смысл: в список попадают договоры РДУ выбранного пула, по которым уже «накоплено» обязательство ДС (типично после загрузки/расчёта обязательств), есть ввод средств, нет расторжения и есть чему начислять.

Сумма не считается MF-алгоритмом и не идёт через монитор 0060.

8. Ответ на вопрос «все ли договоры РДУ?»

Нет. При ручном запуске с пулом «Розничное ДУ» выбираются только договоры, которые одновременно:

  1. в указанном пуле (или в ручном списке);
  2. ещё не окончены на дату начисления;
  3. без уведомления о расторжении;
  4. с вводом ДС;
  5. с ненулевым остатком обязательств ДС без основания.
Если обязательств по договору ещё нет — он не появится в ТЧ после «Выбрать», даже если это действующий договор РДУ.

ТЗ: ускорение создания и записи PDF справок на сетевой диск

Задача: IMDEV-9153. База: Wim_Du.
Контур: начисление ВУК Розничное ДУ — справка-расчёт PDF в каталог на диске и в каталог кабинета клиента.
Дата: 22.07.2026. Статус: вариант оптимизации (согласовать с инфраструктурой до реализации).

Связь с этапами.
Этап 1 (очистка обязательств) — не блокирует.
Этап 2 (многопоточность + регламент) — основной потребитель: при десятках тысяч PDF запись сразу на UNC из каждого потока — узкое место.
Вариант можно включить в этап 2 или вынести отдельным подэтапом после замера.

1. Проблема

При регламентном начислении (~20 000 договоров) на каждый договор формируется PDF и сохраняется:

  • в каталог регламентных справок (КаталогСохранения\РЕГЛАМЕНТНЫЕ\год\N кв\);
  • при заполненном пути — ещё раз в каталог кабинета (КаталогСохраненияКабинетаДУ).

Много мелких записей на UNC из сеансов 1С дают высокую долю накладных (шара, антивирус, сеть). Генерация табличного документа часто быстрее, чем запись на шару.

2. Идея решения

Схема: в рабочем потоке писать PDF только на локальный диск сервера 1С → после пачки (или в конце прогона) одним вызовом robocopy скопировать папку на сетевой каталог регламента и отдельно на каталог кабинета.
  1. Ускорить этап сохранения справок при большом объёме.
  2. Не менять содержимое PDF и правила имён файлов.
  3. Сохранить два целевых места (регламент + кабинет).
  4. Сделать копирование на шару управляемым и наблюдаемым в сводке.

3. AS-IS

  1. Собрать макет справки.
  2. ТабличныйДокумент.Записать сразу в путь на шаре (регламент).
  3. При необходимости — второй Записать сразу в каталог кабинета.

Имя файла по договору/клиенту — уникально, коллизий между договорами нет.

4. TO-BE

4.1. Режимы

РежимПоведение
Классический PDF сразу в сетевые каталоги (fallback, малые прогоны).
Ускоренный PDF в локальный staging; на сеть — robocopy папкой.

Переключение флагом. До согласования инфры по умолчанию — классический.

4.2. Локальный staging

  • База: например D:\1C_Temp\VUK_RDU_PDF\<ИдПрогона>\.
  • Внутри — зеркало структуры приёмника (регламент / кабинет отдельными деревьями).
  • Ид прогона: UID задания / дата-время + номер пачки — параллельные пачки не пересекаются.
Момент копирования: настройка ПослеПачки (быстрее видно в кабинете) или ВКонцеПрогона (меньше одновременных robocopy на шару). Выбор после замера.

4.3. Алгоритм ускоренного режима

  1. Создать локальный staging пачки/прогона.
  2. При формировании справки писать PDF только локально (регламент + при необходимости кабинет-staging).
  3. После пачки или в конце:
    • robocopy staging-регламент → UNC регламента;
    • robocopy staging-кабинет → UNC кабинета (если задан).
  4. При успехе — удалить локальный staging.
  5. При ошибке robocopy — staging не удалять; путь указать в сводке для ручного докопирования.

4.4. Что не меняется

  • Содержимое справки, имя файла.
  • Справка после начисления (как в основном алгоритме).
  • Учёт успеха/ошибки PDF в сводке (письмо + ЖР).

5. Почему это быстрее

ФакторПояснение
Локальная записьПотоки 1С пишут на локальный диск без UNC на каждый файл.
Пакетный robocopyОдин процесс, меньше накладных, опция /MT.
Меньше конкуренцииВместо N потоков на шару — контролируемые вызовы robocopy.
Выигрыш в схеме «локально + пачка на сеть», а не в «магии» robocopy. Потолок — канал и диск шары. Нужен замер.

7. Инфраструктура

  1. Локальный диск на сервере(ах) кластера с запасом места.
  2. Учётка агента 1С: запись в staging и на обе шары; запуск robocopy.
  3. Разрешён COM WScript.Shell (или согласованный аналог) на сервере.
  4. Антивирус: по возможности исключения на staging/приёмник на время регламента.
  5. Staging только на том сервере, где крутится пачка; не на общий UNC.

8. Отчётность

СобытиеУчёт
PDF записан локальноФакт «PDF сформирован»
Ошибка локальной записиОшибка PDF по договору
robocopy код 0..7Успех копирования папки
robocopy код >= 8Ошибка; staging сохранить; код и пути в сводку
Ошибка очистки stagingПредупреждение в ЖР; прогон не валить

Успех «файл в кабинете» = успешный robocopy на каталог кабинета, не только локальная запись. Сводка: письмо + ЖР.

9. Критерии приёмки

  1. В ускоренном режиме PDF сначала локально, после robocopy — в целевых каталогах с теми же именами.
  2. Содержимое PDF совпадает с классикой на контрольной выборке.
  3. Флаг выключен = поведение AS-IS.
  4. Ошибка robocopy видна в ЖР и письме; staging не удалён.
  5. Замер на стенде: N PDF классика vs локально+robocopy (N >= 1000 желательно).
  6. После успеха staging пачки удалён.

A.1. Выбор пути сохранения

// IMDEV-9153: ускорение PDF — в ускоренном режиме писать только в локальный staging.
Процедура СохранитьСправкуРасчетПоРежиму(СправкаРасчет, Расторжение)

	Если УскоренноеСохранениеPDF Тогда

		СохранитьНаДиск(СправкаРасчет, ПолучитьЛокальныйПутьРегламент(Расторжение));

		Если Не ПустаяСтрока(КаталогСохраненияКабинетаДУ) Тогда
			СохранитьНаДиск(СправкаРасчет, ПолучитьЛокальныйПутьКабинет());
		КонецЕсли;

	Иначе

		ПутьСохранения = ПутьСохранения(Расторжение, КаталогСохранения);
		Если ПутьСохранения <> Неопределено Тогда
			СохранитьНаДиск(СправкаРасчет, ПутьСохранения);
		КонецЕсли;

		Если Не ПустаяСтрока(КаталогСохраненияКабинетаДУ) Тогда
			СохранитьНаДиск(СправкаРасчет, КаталогСохраненияКабинетаДУ + "\");
		КонецЕсли;

	КонецЕсли;

A.2. Robocopy папки

// IMDEV-9153: ускорение PDF — копирование staging на сеть через robocopy.
// Коды возврата robocopy: 0..7 — успех, >= 8 — ошибка.
Процедура СкопироватьПапкуБыстро(КаталогИсточник, КаталогПриемник, ЧислоПотоковMT = 8) Экспорт

	Если ПустаяСтрока(КаталогИсточник) Или ПустаяСтрока(КаталогПриемник) Тогда
		ВызватьИсключение "IMDEV-9153: не задан каталог источника или приемника для robocopy";
	КонецЕсли;

	СоздатьКаталог(КаталогПриемник);

	ОпцияMT = "";
	Если ЧислоПотоковMT > 0 Тогда
		ОпцияMT = СтрШаблон(" /MT:%1", Формат(ЧислоПотоковMT, "ЧГ=0"));
	КонецЕсли;

	Команда = СтрШаблон(
		"cmd /c robocopy ""%1"" ""%2"" /E /R:2 /W:2 /NFL /NDL /NJH /NJS /NP%3 & exit /b %ERRORLEVEL%",
		КаталогИсточник,
		КаталогПриемник,
		ОпцияMT);

	WshShell = Новый COMОбъект("WScript.Shell");
	КодВозврата = WshShell.Run(Команда, 0, Истина);

	Если КодВозврата > 7 Тогда
		ВызватьИсключение СтрШаблон(
			"IMDEV-9153: robocopy error, code=%1; src=%2; dst=%3",
			КодВозврата, КаталогИсточник, КаталогПриемник);
	КонецЕсли;

  1. Классика: 1000 договоров, флаг = Ложь — время блока PDF.
  2. Ускорение: те же 1000, флаг = Истина, /MT:8 — локальная запись + robocopy.
  3. Сравнить число файлов и выборочно размер PDF на шаре.
  4. Результат — в отчёт тестирования IMDEV-9153.
Итог: локальная генерация PDF в потоках + пакетная выгрузка на сетевые каталоги через robocopy, с fallback на классическую запись и явной диагностикой копирования.

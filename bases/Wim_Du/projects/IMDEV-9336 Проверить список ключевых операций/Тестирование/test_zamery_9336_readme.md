# Тест замеров IMDEV-9336

## внТестЗамеров9336.epf

Проверяет замеры **без доработки тестовых методов** в самих обработках.

Тест подключает элементы справочника `ДополнительныеОтчетыИОбработки` и вызывает **штатные** методы:

- Сверка ЦБ: `ВыполнитьСверку()` (как с формы)
- Отрицательные остатки: `СформироватьОтчет(Дата)` (как с формы)

Фоновую команду `ВыполнитьКоманду("ФоновоеВыполнение")` тест **не вызывает**, чтобы не создавать задачу интеграции и не слать рассылку.

### Как запустить

1. Загрузить EPF из `ЗАМЕРЫ/` в справочник доп. обработок (ИмяОбъекта: `СверкаЦБ`, `ОтрицательныеОстаткиНаАналитическомСчете`).
2. Открыть `Обработки/внТестЗамеров9336.epf`.
3. Проверить ссылки на две доп. обработки (автопоиск по ИмяОбъекта).
4. Нажать **Запустить тест**.

### Ожидаемые КО (контур Ручной)

| Обработка | Штатный метод | Имя КО |
|-----------|---------------|--------|
| СверкаЦБ | `ВыполнитьСверку()` | `ДУ.СверкаЦБ.Сверка.Ручной` |
| Отрицательные остатки | `СформироватьОтчет()` | `ДУ.Сверка.ОтрицательныеОстаткиНаРС.ФормированиеОтчета.Ручной` |

Вес берется из записи `РС.ЗамерыВремени` (число строк сверки / минусовых остатков).

Статус **WARN** — метод отработал, но запись в РС не найдена (часто выключены замеры БСП).

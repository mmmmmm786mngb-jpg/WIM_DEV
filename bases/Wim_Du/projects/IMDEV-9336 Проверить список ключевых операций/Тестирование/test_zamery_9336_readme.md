# Тест замеров IMDEV-9336

## внТестЗамеров9336.epf

Проверяет работу замеров в двух доработанных обработках с **нагрузочными данными из БД** (без ADODB/внешних ИБ).

Доработанные обработки в базе WIM_DU хранятся в **справочнике «Дополнительные отчеты и обработки»** (БСП).

### Как работает

1. На форме указываются элементы справочника `ДополнительныеОтчетыИОбработки` (автопоиск по `ИмяОбъекта`).
2. Параметр **Мин. строк нагрузки** (по умолчанию 50) передается в `ТестЗамераПроизводительности()`.
3. Подключение через `ДополнительныеОтчетыИОбработки.ПолучитьОбъектВнешнейОбработки(Ссылка)`.
4. Внутри замера выполняется реальная бизнес-логика:
   - **СверкаЦБ:** `ПодготовитьТаблицу()` (запрос к регистрам) + `ЗаполнитьМакет()`; при нехватке строк — дополнение образцом из БД.
   - **Отрицательные остатки:** `ПолучитьДанныеОСВ()`; при нехватке строк — формирование отчета на образце аналитических счетов из БД.
5. Вес замера = фактическое число строк нагрузки.
6. Проверяются имя КО, вес >= минимума, комментарий и запись в `РС.ЗамерыВремени`.

### ИмяОбъекта в справочнике

| Обработка | ИмяОбъекта |
|-----------|------------|
| Сверка ЦБ | `СверкаЦБ` |
| Отрицательные остатки на РС | `ОтрицательныеОстаткиНаАналитическомСчете` |

### Запуск

1. Загрузить доработанные EPF в справочник доп. обработок.
2. Открыть `внТестЗамеров9336.epf` в базе WIM_DU.
3. Проверить ссылки на доп. обработки и при необходимости изменить **Мин. строк нагрузки**.
4. Нажать **Запустить тест**.

### Ожидаемые ключевые операции (контур Ручной)

| Обработка | Имя КО | Вес |
|-----------|--------|-----|
| СверкаЦБ | `ДУ.СверкаЦБ.Сверка.Ручной` | >= мин. строк (обычно 50+) |
| ОтрицательныеОстатки... | `ДУ.Сверка.ОтрицательныеОстаткиНаРС.ФормированиеОтчета.Ручной` | >= мин. строк (обычно 50+) |

Тестовый прогон пишет замер в те же КО, что и ручной запуск с формы (без отдельного контура `Тест9336`). В комментарии замера остается маркер `Нагрузка=БД`.

Статус **WARN** — код замера отработал, но запись в РС не найдена (замеры отключены в настройках БСП).

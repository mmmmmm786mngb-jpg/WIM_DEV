# Тест замеров IMDEV-9336

## внТестЗамеров9336.epf

Проверяет работу замеров в двух доработанных обработках **без внешних соединений** (ADODB/SQL/запрос ОСВ).

Доработанные обработки в базе WIM_DU хранятся в **справочнике «Дополнительные отчеты и обработки»** (БСП), а не как файлы на диске.

### Как работает

1. На форме указываются элементы справочника `ДополнительныеОтчетыИОбработки` (при открытии подставляются автоматически по `ИмяОбъекта`).
2. Подключение через `ДополнительныеОтчетыИОбработки.ПолучитьОбъектВнешнейОбработки(Ссылка)` — так же, как при штатном запуске из справочника.
3. Вызывается экспортный метод `ТестЗамераПроизводительности()` в каждой обработке.
4. Метод выполняет только `НачатьЗамерВремени` / `ЗакончитьЗамерВремени` с имитацией веса (контур `Тест9336`).
5. Проверяются имя КО, вес, комментарий и при возможности запись в `РС.ЗамерыВремени`.

### ИмяОбъекта в справочнике

| Обработка | ИмяОбъекта |
|-----------|------------|
| Сверка ЦБ | `СверкаЦБ` |
| Отрицательные остатки на РС | `ОтрицательныеОстаткиНаАналитическомСчете` |

### Запуск

1. Загрузить доработанные EPF в справочник доп. обработок (или обновить существующие записи).
2. Зарегистрировать/открыть `внТестЗамеров9336.epf` в базе WIM_DU.
3. Убедиться, что на форме заполнены ссылки на обе доп. обработки (автопоиск по `ИмяОбъекта`).
4. Нажать **Запустить тест**.

### Ожидаемые ключевые операции (контур Тест9336)

| Обработка | Имя КО | Вес |
|-----------|--------|-----|
| СверкаЦБ | `ДУ.СверкаЦБ.Сверка.Тест9336` | 5 |
| ОтрицательныеОстатки... | `ДУ.Сверка.ОтрицательныеОстаткиНаРС.ФормированиеОтчета.Тест9336` | 3 |

Статус **WARN** — код замера отработал, но запись в РС не найдена (замеры отключены в настройках БСП).

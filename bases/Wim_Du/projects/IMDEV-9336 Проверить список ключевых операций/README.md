# Проект IMDEV-9336

Проверить список ключевых операций на потребность в оптимизации (сверки).

База: **Wim_Du** (AvancoreDU). Эпик: IMDEV-8633 (Оптимизация производительности систем, Розничное ДУ).

## Три объекта проверки

1. Сверка с отчетом брокера — EPF `внСверкаCделокДУСОтчетомБрокера`
2. Сверка остатков ЦБ с депозитарием — EPF `внСверкаЦБ` (только ИДУ)
3. Сверка отриц. остатков на р/с (пул РДУ) — EPF `внОтрицательныеОстаткиНаАналитическомСчете` (IMDEV-8274; в списке 9336 ошибочно как «API сигнал vs Реестры платежей»)

Краткое описание: `Документация/imdev_9336_three_objects_overview.html`

## Источник кода базы

Путь к каталогу с исходниками базовой конфигурации (не изменять) — в файле **../../source-path.txt** (относительно папки проекта).
Скрипты и инструменты должны читать путь оттуда.

## Структура проекта

- **Расширения/** — доработки: расширения конфигурации
- **Обработки/** — EPF для анализа и доработки (внешние обработки)
- **Документация/** — ТЗ, спецификации, описание объектов
- **Тестирование/** — сценарии тестов, отчёты (reports/), Python COM
- **Скрипты/** — выгрузка/загрузка, анализ замеров, утилиты

## Требования

- Платформа 1С:Предприятие не ниже 8.3.21

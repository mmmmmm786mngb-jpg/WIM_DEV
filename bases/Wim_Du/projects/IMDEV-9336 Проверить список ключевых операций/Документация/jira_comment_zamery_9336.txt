h2. Как читать цифры (простыми словами)

{panel:title=Вес замера|borderStyle=solid|borderColor=#17a2b8|titleBGColor=#d1ecf1|bgColor=#ffffff}
*Вес* — сколько «единиц работы» было в запуске.

* Сверка с брокером: вес = *число сделок из SQL* (обычно 6–11 тыс.)
* Сверка ЦБ: вес всегда *1* (замер не учитывает объем портфеля — это ограничение, см. ниже)

*Удельная скорость* = время / вес. Позволяет сравнивать запуски с разным объемом:
* *с/сделку* — сколько секунд на одну сделку
* *сделок/с* — сколько сделок обрабатывается за секунду (чем больше — тем лучше)

*Порог из IMDEV-8927:* 1800 с (30 мин) на ключевую операцию.
{panel}

h3. Замечание: ФоновоеПроведение (вне scope 9336)

{panel:title=Что это за команда|borderStyle=solid|borderColor=#ffc107|titleBGColor=#fff3cd|bgColor=#fffef5}
*Команда:* {{ФоновоеПроведение}} (ключ {{ДУ.Сверка.СделокСОтчетомБрокера.ФоновоеПроведение}})
*Что делает:* для каждой расхождения вызывает {{ПолучитьОбъект()}} + {{Записать(Проведение)}} — массовая запись и перепроведение документов 1С.
*Почему медленно:* узкое место — запись в базу 1С, а не SQL-сверка.
*Медиана:* ~14 мин (~851 с) при ~8 400 сделок (~9 сделок/с).
*Выброс:* 30.07.2026 — 46 мин при 10 210 сделок (0,27 с/сделку).

{status:colour=Yellow|title=КАНДИДАТ НА ОПТИМИЗАЦИЮ} только если включать эту команду в задачу. В регламент 9336 не входит.
{panel}

h2. Предложения по улучшению замеров

{panel:title=1. Сверка остатков ЦБ — добавить вес замера|borderStyle=solid|borderColor=#17a2b8|titleBGColor=#d1ecf1|bgColor=#ffffff}
*EPF:* {{внСверкаЦБ}}
*Где менять:* функция {{ВыполнитьСверку()}}, модуль объекта — сейчас {{ВесЗамераСверки = 1}} (строка ~23).

*Предлагаемый вес:* {{ТЗ.Количество()}} после {{ПодготовитьТаблицу()}}.
*Откуда берется {{ТЗ}}:* результат свертки внутренних остатков 1С и данных депозитария по ключу *ДоговорДУ + ЦБ* (функция {{ПодготовитьТаблицу}}, свертка {{тзВнутренние.Свернуть("ДоговорДУ, ТипКлиентаДУ, ЦБ", ...)}}).
Каждая строка {{ТЗ}} — одна позиция сверки (договор + ценная бумага).

*Формула:*
{code}
ВесЗамераСверки = ?(ТЗ <> Неопределено И ТЗ.Количество() > 0, ТЗ.Количество(), 1);
{code}

*В комментарий замера дополнительно* (как у сверки с брокером):
* {{СтрокСверки=}} + {{ТЗ.Количество()}}
* {{СтрокСРасхождениями=}} + число строк, где {{Разница = "Есть расхождения"}}
* {{УдельныйВес=... об/с}} — через существующую функцию {{ДополнениеКомментарияУдельныйВес}}

*Ключевая операция* (уже есть, менять не нужно): {{ДУ.СверкаЦБ.Сверка.ФоновоеВыполнение}}
{panel}

{panel:title=2. Отрицательные остатки на р/с (IMDEV-8274) — вставить замеры|borderStyle=solid|borderColor=#17a2b8|titleBGColor=#d1ecf1|bgColor=#ffffff}
*EPF:* {{внОтрицательныеОстаткиНаАналитическомСчете}}
*Текущее состояние:* замеров нет; только {{СформироватьОтчет(ДатаОтчета)}} и {{ПолучитьДанныеОСВ(Дата)}}; фоновой команды {{ФоновоеВыполнение}} пока нет (нужна по IMDEV-8274 для РЗ и рассылки).

*Куда вставить замер (по аналогии с {{внСверкаЦБ}}):*

# *Точка замера:* функция {{СформироватьОтчет(ДатаОтчета)}} в модуле объекта — обернуть вызов {{ПолучитьДанныеОСВ()}} парой {{НачатьЗамерВремени}} / {{ЗакончитьЗамерВремени}}.
# *При добавлении {{ФоновоеВыполнение}}:* вынести логику в общую функцию (как {{ВыполнитьСверку}} у {{внСверкаЦБ}}), чтобы замер работал и при ручном запуске с формы, и при фоновом РЗ.
# *Переменная контура:* {{ИдентификаторКомандыДляЗамера}} = {{ФоновоеВыполнение}} или {{Ручной}} (как в {{внСверкаЦБ}} / {{внСверкаCделокДУСОтчетомБрокера}}).

*Предлагаемое имя ключевой операции:*
{{ДУ.Сверка.ОтрицательныеОстаткиНаРС.ФормированиеОтчета.ФоновоеВыполнение}}
(для ручного запуска — суффикс {{Ручной}} по тому же шаблону, что в {{внСверкаЦБ}})

*Предлагаемый вес:* число строк результата запроса ОСВ с отрицательным остатком.
*Откуда брать:* в {{ПолучитьДанныеОСВ(Дата)}} после {{Запрос.Выполнить()}}:
{code}
ТаблицаМинусов = Запрос.Выполнить().Выгрузить();
ВесЗамера = ТаблицаМинусов.Количество();
{code}
Каждая строка — одна комбинация *АналитическийСчет + ДоговорДУ + Валюта* с {{СуммаОстатокДт < 0}} (запрос к {{РегистрБухгалтерии.Хозрасчетный.Остатки}}, отбор {{ДоговорДУ.Пул = Розничное ДУ}}).

*В комментарий замера:*
* {{СтрокМинусов=}} + {{ТаблицаМинусов.Количество()}}
* {{Договоров=}} + число уникальных {{ДоговорДУ}} в результате (опционально, для контекста)
* {{FAIL=}} / {{WARN=}} — по наличию найденных минусов
* {{УдельныйВес=... об/с}}

{panel}

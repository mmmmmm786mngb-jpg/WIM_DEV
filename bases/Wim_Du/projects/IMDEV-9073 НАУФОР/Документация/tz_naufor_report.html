Отчет НАУФОР (камеральная проверка)

Краткое техническое задание по задаче IMDEV-9073

IMDEV-9073 Реализация v1.14 RegReporting

Назначение

Внешний отчет для предоставления данных в НАУФОР в рамках внеплановой камеральной проверки управляющей компании.

Формирует таблицу из 14 колонок по действующим договорам ДУ на выбранную отчетную дату.

Артефакт

Имя: внОтчетНАУФОР_КамеральнаяПроверка

Тип: дополнительный отчет (БСП)

Файл: build/внОтчетНАУФОР_КамеральнаяПроверка.erf

Выгрузка

  • Табличный документ 1С на форме отчета
  • Excel (.xlsx)
  • Word (.docx)

Ориентация: альбомная. Закрепление шапки: 3 строки (заголовок, названия колонок, номера 1-14).

Параметры формы отчета

Параметр Обязательность Описание
Отчетная дата Да Дата среза данных. По умолчанию - текущая дата сеанса.
Управляющая компания Да Отбор договоров ДУ и квалификации инвестора по выбранной УК.
Тип клиента ДУ Нет Дополнительный фильтр по одному значению перечисления ТипыКлиентовДУ.
Лицензия ПУРЦБ Нет Ограничивает выборку типами клиентов для лицензии ПУРЦБ (см. список ниже).
Лицензия НПФ Нет Ограничивает выборку типами клиентов для лицензии НПФ (см. список ниже).

Отбор договоров ДУ

В выгрузку попадают договоры из справочника ДоговорДУ, для которых одновременно выполняются условия:

  • не помечен на удаление;
  • Дата окончания не заполнена или позже отчетной даты (договор действует на отчетную дату; например, окончание 02.06.2026 при отчете на 01.06.2026 - включается);
  • Дата заключения (ДатаНачала) не позже отчетной даты - договоры, заключенные после отчетной даты, не включаются;
  • Управляющая компания совпадает с параметром отчета;
  • при заполненном параметре Тип клиента ДУ - совпадение типа клиента;
  • при выборе лицензии - тип клиента входит в список допустимых для ПУРЦБ и/или НПФ;
  • исключение по флагу Только лицензия ПУРЦБ и Дате репортинга ПУРЦБ (см. ниже).
Исключение «Только лицензия ПУРЦБ» (всегда включено). На форме отчета отдельного флага для этого правила нет: фильтр применяется постоянно, как обязательное требование ТЗ для выгрузки в НАУФОР. Аналог в конфигурации: регл. отчет 042001 (Информация о видах и суммах операций) с флагом «Без клиентов "Только лицензия ПУРЦБ"» — здесь то же правило, но без возможности отключить.
  • договор исключается, если ТолькоЛицензияПУРЦБ = Истина, заполнена ДатаРепортингаПУРЦБ и отчетная дата строго позже этой даты;
  • договор включается, если флаг не установлен, дата репортинга не заполнена или отчетная дата совпадает с датой репортинга (в день репортинга договор еще в выгрузке);
  • пример: Дата репортинга ПУРЦБ = 01.06.2026, отчет на 01.06.2026 — договор включается; отчет на 02.06.2026 и позже — исключается.
Если лицензии не выбраны и тип клиента не задан, в отчет попадают все действующие договоры выбранной УК.

Типы клиентов по лицензиям

Лицензия НПФ

  • Пенсионные резервы НПФ
  • Пенсионные накопления граждан (через НПФ)
  • Пенсионные накопления граждан (ПФР)
  • Военная ипотека
  • Собственные средства НПФ
  • Саморегулируемые организации
  • Фонд целевого капитала

Лицензия ПУРЦБ

  • Физические лица
  • Юридические лица
  • Фонд целевого капитала
  • Саморегулируемые организации
  • Страховые компании
  • Собственные средства СК

Колонки отчета (1-14)

No Наименование колонки Правило заполнения Источник данных
1 Наименование организации / ФИО Клиент по договору ДУ из колонки 2 ДоговорДУ.Клиент
2 Договор ДУ (номер, дата заключения) Код договора + дата начала в формате dd.MM.yyyy ДоговорДУ.Код, ДатаНачала
3 Дата последней пролонгации Расчет по правилам файла «Даты пролонгации.xlsx»: шаг = срок x 365 дней (если срок <= 100), учет флагов Пролонгация и Действует до ДоговорДУ + алгоритм
4 Стратегия индивидуальная Константа «Индивидуальная» для всех строк ТЗ
5 Стратегия стандартная Не заполняется -
6 Физическое лицо «Физическое лицо», если ТипКлиентаДУ = ФизическиеЛица ДоговорДУ.ТипКлиентаДУ
7 Коммерческая организация Для коммерческих типов клиента (ЮЛ, НПФ, СК, гарантийные фонды и др.) ДоговорДУ.ТипКлиентаДУ
8 Некоммерческая организация «Некоммерческая организация» для ФЦК и СРО ДоговорДУ.ТипКлиентаДУ
9 Квалифицированный инвестор «квалифицированный», если клиент включен в реестр на отчетную дату РС ДействующиеКвалИнвесторы
10 Неквалифицированный инвестор «неквалифицированный» во всех остальных случаях РС ДействующиеКвалИнвесторы
11 Дата последнего профилирования Максимальная дата проведенного документа ИнвестиционныйПрофиль с датой <= отчетной Док. ИнвестиционныйПрофиль
12 Пересмотр инвестиционного профиля «Да» - если 2 и более записей профиля с разными датами; иначе «Нет» Док. ИнвестиционныйПрофиль
13 Дата ввода средств в ДУ Значение реквизита договора без пересчета ДоговорДУ.ДатаВводаСредствВДУ
14 Дата последней сделки MAX дата сделок купли/продажи до отчетной даты по T0, T+ и ПФИ Сделка, ВнебиржеваяСделка, СделкаНаСрочномРынке

Детали по ключевым блокам

Колонки 9-10 (квалификация)

Используется срез последних записей регистра ДействующиеКвалИнвесторы на отчетную дату с отбором по контрагенту и управляющей компании.

  • если ВключенВРеестр = Истина - колонка 9;
  • иначе - колонка 10.
Согласовано с комментарием комплаенса: журнал квал. инвесторов / реестр действующих квалифицированных инвесторов.

Колонки 11-12 (профилирование)

По каждому договору анализируются проведенные документы ИнвестиционныйПрофиль с датой не позже отчетной.

  • колонка 11 - дата последнего документа (не тип профиля);
  • колонка 12 - признак пересмотра: «Да» / «Нет» по числу различных дат профилирования.

Колонка 14 (сделки)

Учитываются сделки купли/продажи из источников:

  • T0 - документ Сделка (перерегистрация), поле Дата;
  • T+ - бизнес-процесс ВнебиржеваяСделка, поле СрокПеререгистрации;
  • ПФИ - документ СделкаНаСрочномРынке, поле Дата.

Берется максимальная дата среди всех найденных сделок по договору.

Оформление табличного документа

  • строка 1 - заголовок «Отчет НАУФОР (камеральная проверка) на dd.MM.yyyy»;
  • строка 2 - наименования 14 колонок;
  • строка 3 - номера колонок 1-14;
  • данные - с 4-й строки;
  • рамки ячеек - сплошная линия по всей таблице;
  • сортировка строк - по наименованию клиента, затем по номеру договора.

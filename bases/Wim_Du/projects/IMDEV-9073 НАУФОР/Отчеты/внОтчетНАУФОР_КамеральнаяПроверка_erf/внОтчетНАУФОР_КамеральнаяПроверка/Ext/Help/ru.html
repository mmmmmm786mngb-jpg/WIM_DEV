Анкета УК для НАУФОР _Камеральная проверка формат

Задача IMDEV-9073. Версия отчета: 1.36.

Назначение

Внешний отчет для предоставления данных в НАУФОР в рамках внеплановой камеральной проверки управляющей компании.

Формирует таблицу из 14 нумерованных колонок (17 физических: «Тип клиента», «СЧА» и «Код клиента» без номера в шапке) по действующим договорам ДУ на выбранную отчетную дату.

Результат доступен на форме отчета, а также может быть сохранен в Excel (.xlsx) или Word (.docx). Ориентация печати: альбомная.

Отбор договоров ДУ

В выгрузку попадают договоры справочника ДоговорДУ, для которых одновременно выполняются условия:

  • договор не помечен на удаление;
  • Дата окончания не заполнена или позже отчетной даты;
  • Дата заключения (ДатаНачала) не позже отчетной даты;
  • Управляющая компания совпадает с параметром отчета;
  • при заполненном параметре Тип клиента ДУ - совпадение типа клиента;
  • при выборе лицензии - тип клиента входит в список допустимых для ПУРЦБ и/или НПФ.

Исключение «Только лицензия ПУРЦБ»

Правило применяется только при включенном на форме флаге Лицензия НПФ (требование ТЗ для выгрузки по лицензии НПФ).

  • если флаг Лицензия НПФ выключен - договоры с «Только лицензия ПУРЦБ» не отсекаются этим правилом;
  • если флаг включен - договор исключается, когда ТолькоЛицензияПУРЦБ = Истина, заполнена ДатаРепортингаПУРЦБ и отчетная дата строго позже этой даты;
  • в день даты репортинга договор еще включается.

Исключение по уведомлению о расторжении

Реквизит: ДатаПолученияУведомленияОРасторженииДоговораДУ («Дата получения уведомления о расторжении договора ДУ»).

  • договор исключается, если дата заполнена и меньше или равна отчетной дате (по календарному дню);
  • договор включается, если дата не заполнена или позже отчетной даты.

Типы клиентов по лицензиям

Лицензия НПФ: пенсионные резервы НПФ; пенсионные накопления граждан (через НПФ и ПФР); военная ипотека; собственные средства НПФ; СРО; фонд целевого капитала.

Лицензия ПУРЦБ: физические лица; юридические лица; фонд целевого капитала; СРО; страховые компании; собственные средства СК.

Для документа Сделка пустой бизнес-процесс проверяется как БизнесПроцесс = НЕОПРЕДЕЛЕНО. Если сделок нет - колонки 13 и 14 пустые.

Оформление табличного документа

  • строка 1 - заголовок «Анкета УК для НАУФОР _Камеральная проверка формат на dd.MM.yyyy»;
  • строка 2 - наименования 17 колонок;
  • строка 3 - номера 1-6, пустая ячейка (кол. «Тип клиента»), затем 7-14, пустая ячейка (кол. «СЧА»), пустая ячейка (кол. «Код клиента»);
  • данные - с 4-й строки;
  • рамки ячеек - сплошная линия;
  • сортировка - по наименованию клиента, затем по номеру договора.

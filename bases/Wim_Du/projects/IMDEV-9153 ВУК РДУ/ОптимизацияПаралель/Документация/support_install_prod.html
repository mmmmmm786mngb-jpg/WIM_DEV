IMDEV-9153. Установка обработки начисления ВУК РДУ на прод

Для поддержки. База: ДУ (прод).
Файл: внНачислениеВознаграждения_РозничноеДУ.epf
Справочник: Дополнительные отчеты и обработки.

Важно. Это обновление уже существующей обработки «Начисление вознаграждения за управление: Розничное ДУ», а не новая карточка. После загрузки файла появится новая команда для регламента — её нужно отдельно включить и настроить расписание. Старую команду расторжения не трогать без необходимости.

1. Что делает обработка

  • Начисляет вознаграждение за управление по договорам розничного ДУ.
  • Формирует справки-расчеты (PDF) в указанные каталоги.
  • Удаляет обязательства по ДС (документ «Операция» / регистр обязательств).
  • По регламенту может запускаться автоматически 4 раза в год и отправлять письмо об итогах.

2. Установка / обновление файла

  1. Открыть справочник Дополнительные отчеты и обработки.
  2. Найти элемент «Начисление вознаграждения за управление: Розничное ДУ» (имя объекта обработки обычно НачислениеВознаграждения_РозничноеДУ).
  3. Загрузить / заменить файл обработки внНачислениеВознаграждения_РозничноеДУ.epf (кнопка загрузки из файла / обновление, как принято у вас на проде).
  4. Записать элемент.
  5. Убедиться, что в списке команд есть три команды (см. таблицу ниже).
  6. Раздел размещения оставить как было: Доверительное управление (Подсистема).

4. Настройка регламентной команды и задания (обязательно)

После обновления файла в карточке доп. обработки в табличной части Команды должна быть строка:

  • представление: Начисление ВУК: Розничное ДУ (регламентное фоновое);
  • идентификатор: НачислениеВУКРегламентноеФоновое (тип — вызов серверного метода).

В табличной части «Команды»

Здесь задаётся только расписание (поля пользователя и ключа в ТЧ нет).

  • запуск 4 раза в год: 1 января, 1 апреля, 1 июля, 1 октября;
  • время старта: 00:15.
Как задать в форме расписания 1С (типовой вариант):
  • месяцы: январь, апрель, июль, октябрь (1, 4, 7, 10);
  • день месяца: 1;
  • время начала: 00:15:00;
  • повтор в течение дня не нужен.

В самом регламентном задании

Пользователь и ключ настраиваются не в ТЧ «Команды», а в карточке регламентного задания, связанного с этой командой:

Параметр Значение
Использование Да (задание включено)
Пользователь svc_avancore
Ключ Начисление ВУК: Розничное ДУ (регламентное)
Ключ должен быть уникальным среди регламентных заданий. Не использовать ключ от задания расторжения.
Если после загрузки EPF регламентное задание для новой команды ещё не создано — создайте / привяжите его к команде НачислениеВУКРегламентноеФоновое стандартным способом БСП, укажите расписание в ТЧ «Команды», а пользователя и ключ — в регламентном задании.
Логика даты внутри обработки (для понимания, не настройка):
Пример при старте регламента 01.10 (в т.ч. в 00:15): сначала берется НачалоДня → 01.10 00:00:00.
1) в коде: ДатаНачисления = ДатаЗапуска - 1 секунда → 30.09 23:59:59;
2) реквизит обработки ДатаНачисления имеет тип Дата (без времени), поэтому в реквизите сохраняется 30.09.2026 00:00:00;
3) дата документа начисления = ДатаНачисления + 86100 секунд → 30.09.2026 23:55:00.
Важно: без НачалоДня при старте 01.10 00:15 минус 1 секунда дает 01.10 00:14:59 и документы ошибочно уходят на 01.10 23:55.
В письме: «дата старта расчета» — момент запуска регламента; «дата документов начисления» — дата документов в базе (без времени в письме).

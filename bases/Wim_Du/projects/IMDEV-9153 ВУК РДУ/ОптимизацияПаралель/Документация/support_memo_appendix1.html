Приложение 1. Краткая памятка для поддержки

После загрузки файла обработки в справочник «Дополнительные отчеты и обработки» сотрудник поддержки делает следующее.

1. Дополнительные настройки обработки

Форма настроек, затем записать карточку:

  • Отправлять письмо об итогах — Да.
  • Почтовый логин — учетная запись электронной почты для отправки (системная или рабочая учетка, принятая на проде ДУ).
  • Макс. строк в теле письма — 200 (если пусто — обработка подставит 200 сама).
  • Игнорировать проверку регламентной даты — Нет на проде. (Да — только для тестового запуска не в 01.01 / 01.04 / 01.07 / 01.10.)
  • Список рассылки — добавить получателей итогового письма. Колонки: Отправлять, Почтовый ящик, Представление. Если ни у кого не стоит «Отправлять» — письмо уйдет всем с заполненным ящиком. Если хотя бы у одной строки стоит «Отправлять» — только помеченным. По умолчанию в коде при пустом списке используется IMAppSupport@wiminvest.ru — на проде лучше явно заполнить нужных получателей.

2. Команды

  • Убедиться, что появилась третья команда: «Начисление ВУК: Розничное ДУ (регламентное фоновое)».
  • Для этой команды установить флаг использования расписания и задать расписание в ТЧ «Команды»:
  • месяцы — январь, апрель, июль, октябрь;
  • день месяца — 1;
  • время начала — 00:15:00;
  • повтор в течение дня не нужен.

3. Регламентное задание

  • Найти в списке регламентных заданий задание, связанное с этой командой.
  • Указать Пользователь: svc_avancore.
  • Указать Ключ: Начисление ВУК: Розничное ДУ (регламентное) (уникальный, не как у задания расторжения).
  • Убедиться, что задание включено (использование — Да).

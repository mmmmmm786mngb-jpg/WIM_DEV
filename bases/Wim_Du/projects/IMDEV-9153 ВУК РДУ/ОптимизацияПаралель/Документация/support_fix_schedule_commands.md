# Починка регламентных команд ВУК РДУ (IMDEV-9153)

Внешняя обработка для поддержки: развязывает общий `РегламентноеЗаданиеGUID`
у команд расторжения и квартального начисления после загрузки EPF через кнопку «Загрузить».

## Файл

- Исходники: `внПочинкаРегламентныхКомандВУК_epf/`
- Сборка: `внПочинкаРегламентныхКомандВУКРДУ.epf` (рядом после build)

## Как пользоваться

1. Открыть файл EPF в 1С (Файл - Открыть) или подключить как доп. обработку.
2. В шапке выбрать элемент справочника **Дополнительные отчеты и обработки**
   («Начисление вознаграждения за управление: Розничное ДУ»).
3. При необходимости указать:
   - пользователь заданий: `svc_avancore`
   - ключ квартального задания: `Начисление ВУК: Розничное ДУ (регламентное)`
   - ключ расторжения: оставить пустым, если не нужно менять
4. **Проверить** — только протокол, без записи.
5. **Починить** — запись в справочник + создание/правка регламентных заданий.

## Что делает «Починить»

- Находит команды:
  - `НачислениеВознагражденияПриРасторженииРозничноеДУФоновое`
  - `НачислениеВУКРегламентноеФоновое`
- Если GUID общий — оставляет его у **расторжения**, сбрасывает у **ВУК**.
- Расторжение: сохраняет существующее задание и его расписание; обновляет параметры/пользователя.
- ВУК: создаёт **отдельное** задание с расписанием 1/4/7/10 в 00:15, ключом и пользователем.
- Записывает элемент справочника.

## После починки

Откройте карточку доп. обработки: у третьей команды должно быть своё расписание;
в «Регламентные и фоновые задания» — два задания по этой обработке.

h2. (*) План доработки IMDEV-9202

{panel:title=Цель|borderStyle=solid|borderColor=#1f3c88|titleBGColor=#1f3c88|titleColor=#ffffff|bgColor=#f4f7fb}
Ускорить массовое создание поступлений на р/с *Розничное ДУ* и обеспечить корректную обработку *двух платежек «Перевод»* в одном дне выписки при запуске из *«Зачисления на р/с Розничного ДУ»*.
{panel}

----

h2. (i) 1. Загрузка выписок ДУ

{panel:title=Обработка · версия 6.04|borderStyle=solid|borderColor=#0f6e8c|titleBGColor=#0f6e8c|titleColor=#ffffff|bgColor=#e8f4fc}
Изменения в сценарии *«Зачисления на р/с Розничного ДУ»* (кнопка из банковской выписки).
{panel}

* Если сумма поручений *Перевод* не совпадает с суммой первой платежки — отобрать группу поручений по комментарию *«Перевод ДС при расторжении»* (или комплементарную группу под сумму платежки).
* Создать поступления по первой платежке; затем по *остатку* поручений найти *вторую* платежку того же дня / счета и создать поступления по ней.
* Диагностика — только *краткие* сообщения (несовпадение сумм / вторая платежка не найдена).
* Запуск внешней обработки поступлений: {{ВнешниеОбработки.Создать(..., Ложь)}} (без безопасного режима), чтобы работал параллельный режим.

{quote}
*Не меняем:* маски поиска платежек, состав реквизитов поступления, прочий функционал загрузки выписки.
{quote}

----

h2. (/) 2. Создание поступлений на р/с Розничное ДУ

{panel:title=Обработка · версия 1.09|borderStyle=solid|borderColor=#1a7a32|titleBGColor=#1a7a32|titleColor=#ffffff|bgColor=#eaf7ec}
Ускорение массового *«Создать»* без изменения бизнес-правил заполнения документа.
{panel}

* Параллельное создание/проведение через *БСП ДлительныеОперации*: порции по *50*, до *5* фоновых потоков.
* При безопасном режиме или сбое фона — *последовательный* fallback по порциям (создание не останавливается).
* Исправление отбора поручений: JOIN к *НачислениеЗадолженности* только для *ВводВДУ*; для *Перевод* начисление не размножает строки; итог — {{ВЫБРАТЬ РАЗЛИЧНЫЕ}} (устранение дублей сумм в ТЧ).
* Замеры и сводка в сообщениях пользователю (режим, потоки, порции, док/с, время, ошибки).

{quote}
*Не меняем:* состав и заполнение реквизитов поступления, проведение внутри создания документа, смысл отбора поручений (кроме устранения ложных дублей).
{quote}

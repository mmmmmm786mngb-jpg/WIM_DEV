IMDEV-9202. Блок Создать: Было/Стало

Диаграммы показывают изменение только диспетчеризации создания/проведения документов Поступление: последовательная очередь (Было) -> параллельные воркеры по порциям (Стало).

Было (последовательно)

flowchart TD; A["СоздатьПоступленияДС"] --> B["ПорученияПоДС: получить ТЧ"]; B --> C["Цикл по строкам порций/ТЧ"]; C --> D{Есть следующая строка}; D -- Да --> E{Поступление пусто}; E -- Да --> F["Вызвать Поступление(...)"]; F --> G["Записать(Проведение)"]; E -- Нет --> H["Пропустить создание"]; G --> I["Следующая строка"]; H --> I["Следующая строка"]; I --> D; D -- Нет --> J["Готово"];

Стало (параллельно по порциям)

flowchart TD; A["СоздатьПоступленияДС"] --> B["Поделить на порции (РазмерПачки)"]; B --> C["Запустить воркеры параллельно (КоличествоПотоков)"]; C --> W1["Воркер 1: цикл по строкам порции"]; C --> WN["Воркер N: цикл по строкам порции"]; W1 --> X{Поступление пусто}; WN --> X; X -- Да --> Y["Создать реквизиты Поступления"]; Y --> Z["Записать(Проведение)"]; X -- Нет --> AA["Пропустить создание"]; Z --> AB["Завершить воркер"]; AA --> AB["Завершить воркер"]; AB --> E["Дождаться всех воркеров"]; E --> F["Готово"];

Дерево изменений (IMDEV-9202)

Объект: внЗагрузкаВыписокДУ (EPF), версия 6.03 (было 6.00 / IMDEV-9096, затем 6.01 safe mode)
Правки: (1) создание обработки поступлений без безопасного режима; (2) две платежки Перевод в одной выписке: группа комментария Перевод ДС при расторжении и остаток поручений, порядок строк не важен; одна платежка на всю сумму работает как раньше.
  • Уровень 1 (обработка): внЗагрузкаВыписокДУ
    • Уровень 2 (модуль): Ext/ObjectModule.bsl
      • Уровень 3 (измененные процедуры):
        • Изменена: Функция СведенияОВнешнейОбработке() Экспорт
          Версия 6.03. Комментарий в коде: расторжение может быть любой из двух платежек Перевод.
        • Изменена: Функция ЗачисленияНаРСРозничногоДУ() Экспорт
          Создание внешней обработки поступлений без безопасного режима (фон наследует его). Поиск двух строк выписки и цикл по ним не менялись: первая строка (брокер 30601..., субсчет 13W6XW) — вид Перевод; вторая (компенсация) — по-прежнему ВводВДУ.
          
Было:
НоваяОбработка = ВнешниеОбработки.Создать(ИмяФайла);

Стало:
// IMDEV-9202: при старте из выписки фоновый режим наследует безопасный режим
НоваяОбработка = ВнешниеОбработки.Создать(ИмяФайла, Ложь);
        • Изменена: Процедура СоздатьДокументы_РозничноеДУ(...)
          Для Перевод: если итог начитанных поручений не равен сумме найденной платежки, вызывается отбор по комментарию Перевод ДС при расторжении (если сумма группы = платежка — оставляем группу; если платежка = остаток без этой группы — оставляем остаток). При совпадении сумм создаётся первая пачка, затем СоздатьОстатокПереводаПоВторойПлатежке. Для ВводВДУ логика сверки и создания без изменений. Пользователь по-прежнему один раз открывает форму поступлений: в ТЧ обе пачки, в шапке вх. номер последней созданной платежки. 
          
Если ВидОперации = Перевод Тогда
    Если Итог(СуммаДС) <> СуммаПлатежки Тогда
        ОтобратьПорученияПодСуммуПлатежки(..., "Перевод ДС при расторжении");
    КонецЕсли;
КонецЕсли;
// сверка и СоздатьПоступленияДС как раньше
Если ВидОперации = Перевод Тогда
    СоздатьОстатокПереводаПоВторойПлатежке(...);
КонецЕсли;
      • Уровень 3 (добавленные процедуры):
        • Добавлена: Процедура ОтобратьПорученияПодСуммуПлатежки(ТабличнаяЧасть, СуммаПлатежки, ПодстрокаКомментария)
          Читает Документ.Поручение.Комментарий. Считает сумму строк с подстрокой. Если она равна платежке — в ТЧ остаются только они. Если платежке равен итог минус эта сумма — остаются строки без этой подстроки. Иначе ТЧ не меняет (одна платежка на всю сумму или суммы не бьются). Порядок строк выписки не используется.
        • Добавлена: Процедура СоздатьОстатокПереводаПоВторойПлатежке(ПерваяСтрока, НоваяОбработка)
          Повторный ПорученияПоДС(Перевод): уже проведённые поступления в запрос не попадают. Если остаток 0 — выход (случай одной платежки). Иначе ищет в ТЧ выписки другую входящую на тот же ПолучательСчет с суммой остатка и другим номером, создаёт вторую пачку с её вх. номером и назначением. Строки дописываются в ПорученияПоДС_РДУ, форма открывается один раз с обеими пачками.

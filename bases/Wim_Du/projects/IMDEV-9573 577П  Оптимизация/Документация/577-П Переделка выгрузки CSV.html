Выгрузка отчета 577-П в CSV: как было и как станет

Внешняя обработка «Выгрузка отчетности XBRL-CSV для PB» (СформироватьВыгрузкуCSV), версия 1.02 → 2.00. Цель: выгрузка месяца (9,7 млн строк) без чтения документа целиком, без табличного документа и без передачи файлов через клиента.

1. Поток выгрузки: было и стало

Было (1.02)

  1. Клиент: каталог выгрузки задан жестко на диске клиента, иначе диалог выбора.
  2. Клиент: цикл по 11 разделам, на каждый раздел отдельный серверный вызов. 11 вызовов, каждый с контекстом формы
  3. Сервер: раздел берется через ссылку на документ ДокументОтчета[ИмяРаздела]. читается весь документ со всеми разделами, 9,7 млн строк на месяце
  4. Сервер: построитель отчета выводит раздел в табличный документ. раздел 7 за месяц: около 79 млн ячеек в памяти
  5. Сервер: табличный документ сохраняется в xlsx. xlsx не больше 1 048 576 строк: разделы 7 и 9 за месяц невозможны
  6. Сервер: поиск символов табуляции по всем ячейкам, сохранение в текст, чтение всего текста в строку, две замены. несколько копий текста размером порядка гигабайта
  7. Сервер → клиент: файлы через временное хранилище, клиент пишет их на диск. гигабайты через клиентское соединение
  8. Сопроводительная информация: реквизиты и 11 проверок РазделN.Количество() через ссылку. еще раз чтение всего документа

Станет (2.00)

  1. Клиент: каталог выгрузки в сетевой папке, доступной серверу; проверка доступности на сервере.
  2. Клиент: один запуск фонового задания на всю выгрузку, окно ожидания с прогрессом по разделам. клиент не держит соединение часами
  3. Сервер: каждый раздел читается запросом с отбором по документу, по порядку строк. документ целиком не загружается
  4. Сервер: выборка обходится строка за строкой, каждая строка сразу пишется в файл. память не зависит от числа строк
  5. Сервер: форматирование значений по правилам колонок (те же, что давал построитель).
  6. Сервер: string_num формируется счетчиком, uuid пустой, разделитель «|».
  7. Сервер: файлы пишутся прямо в сетевую папку, клиенту возвращается только список файлов.
  8. Сопроводительная информация: реквизиты одним запросом, признаки «данные переданы» запросом наличия строк.

4. На что опираемся (проверено)

  • Фоновое задание из внешней обработки. В конфигурации ДУ (БСП) есть процедура ДлительныеОперации.ВыполнитьПроцедуруМодуляОбъектаОбработки(Параметры, АдресХранилища): по параметрам ИмяОбработки, ИмяМетода, ЭтоВнешняяОбработка, ДополнительнаяОбработкаСсылка она создает обработку на сервере и вызывает ее экспортный метод с сигнатурой (ПараметрыВыполнения, АдресХранилища). Запуск через ДлительныеОперации.ВыполнитьВФоне, ожидание на клиенте через ДлительныеОперацииКлиент.ОжидатьЗавершение со стандартным окном ожидания. Этот же прием уже применялся в наших доработках других задач.
  • Сообщения из фонового задания. В версии БСП конфигурации ДУ сообщения фонового задания до формы не доходят (проверено на расширении «Заполнить и закрыть»). Поэтому итог (список файлов, ошибки) возвращается через временное хранилище и выводится клиентом.
  • Потоковая запись файла. Платформа: ЗаписьТекста (кодировка UTF-8) и ЗаписатьСтроку, каждая строка пишется сразу в файл, без накопления текста в памяти.
  • Чтение раздела без загрузки документа. Запрос к табличной части документа с отбором по ссылке и обход выборки (Выбрать(), без Выгрузить()): в памяти одна строка выборки.
  • Безопасный режим. Регистрация обработки уже с выключенным безопасным режимом, это нужно для записи файлов на сервере.

5. Что не меняется для пользователя и для Банка России

  • те же 11 файлов разделов и файл сопроводительной информации, те же имена (R1-R11, sr_sved_purcb);
  • те же колонки, их порядок и коды, разделитель «|», кодировка UTF-8;
  • те же правила форматирования чисел, дат и времени, та же сквозная нумерация string_num;
  • команда «Выгрузить CSV» вызывается из документа так же.

xlsx: для разделов 7 и 9 за месяц невозможен (лимит строк листа). Для остальных разделов оставить или отказаться решает бизнес; в схеме выше xlsx не формируется.

6. Проверка

  • документ за 1 день: по каждому разделу строки и значения в файлах новой и старой версии совпадают (после приведения переводов строк к одному виду); оформление файла (заголовок, кодировка, разделители) проверяется отдельно;
  • документ за месяц на DR: выгрузка проходит, память фонового задания не растет с числом строк, время фиксируется;
  • после перехода разделов 5, 6, 7, 9 на регистры: новый документ читается из регистров, ранее заполненный документ выгружается из табличных частей, документ с признаком «заполнение не завершено» не выгружается.

Вызов функции снаружи тот же: СписокЦБ как массив/список. В запрос больше не отдаём его через В (&СписокЦБ) — каждый элемент становился отдельным параметром SQL. Кладём в таблицу значений и передаём одним параметром &ТаблицаАктивов. Приём уже есть в этом же модуле для приоритета бирж (&ПриоритетБирж).

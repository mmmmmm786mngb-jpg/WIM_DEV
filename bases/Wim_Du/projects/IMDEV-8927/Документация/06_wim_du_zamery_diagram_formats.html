Схема записи в РС ЗамерыВремени - выбор формата

Упрощенная фактическая схема Wim_Du (БСП 2.1). Запись через УстановитьПривилегированныйРежим, без УстановитьОтключениеБезопасногоРежима.

1. Mermaid (flowchart)

Популярен в GitHub, GitLab, Notion, VS Code. Рендер в браузере через CDN.

flowchart TB
    U(["Инициатор: пользователь / EPF / серверный код"])
    CTX{"Контекст выполнения"}
    U --> CTX

    CTX -->|"Безопасный режим EPF"| SM["БезопасныйРежим = Истина"]
    SM --> XDU["Wim_Du: журнал, ВЫХОД без записи"]
    SM --> XMO["Wim_Mo 8.3.6: ошибка,
обработка падает"]

    CTX -->|"Серверный замер"| S["НачатьЗамерВремени →
ЗакончитьЗамерВремени"]
    CTX -->|"Клиентский замер"| C["Буфер на клиенте
ЗафиксироватьДлительностьКлючевыхОпераций"]

    S --> P["УстановитьПривилегированныйРежим(Истина)"]
    C --> P
    P --> R[("РС ЗамерыВремени")]

    classDef stop fill:#fff3cd,stroke:#ffc107,color:#856404
    classDef danger fill:#f8d7da,stroke:#dc3545,color:#721c24
    classDef ok fill:#d4edda,stroke:#28a745,color:#155724
    class XDU stop
    class XMO danger
    class R ok
Плюсы: живой код в репозитории, легко править. Минусы: нужен интернет для CDN (или локальный mermaid.js).

3. Flipchart / Miro (имитация стиля)

Atlassian Flipchart и Miro: карточки на серой сетке, цветные полоски, стикеры. Ниже - CSS-макет, как это выглядит на доске.

В реальном Flipchart: перетаскиваемые карточки, стрелки-коннекторы, комментарии команды. Экспорт: PNG / PDF / SVG.

Плюсы: удобно для обсуждения с командой, коллаборация. Минусы: не хранится в git как код (только экспорт картинки).

4. PlantUML

Стандарт в Java/Spring и многих техдоках. Рендер через Kroki.io (нужен интернет).

Загрузка диаграммы...
@startuml
skinparam backgroundColor #fafbfc
skinparam activityBackgroundColor #ffffff
skinparam activityBorderColor #6c757d

start
:Пользователь / внешняя обработка EPF;
if (Контекст выполнения?) then (безопасный режим)
  #FFF3CD:Журнал - не поддерживается;
  stop
elseif (клиентский замер) then
  :Буфер + ЗафиксироватьДлительностьКлючевыхОпераций;
else (обычный сеанс)
  :ЗакончитьЗамерВремени;
endif
:УстановитьПривилегированныйРежим(Истина);
#D4EDDA:(РС ЗамерыВремени);
stop
@enduml
Kroki недоступен - используйте исходник выше на plantuml.com или плагин PlantUML в IDE.
Плюсы: текстовый формат, IDE-плагины. Минусы: activity-диаграммы менее гибки для ветвлений.

5. Graphviz (DOT)

Классика для архитектурных схем. Используется в Doxygen, Structurizr, многих CI-отчетах.

digraph WimDuZamery {
  graph [bgcolor="#fafbfc" rankdir=TB splines=ortho nodesep=0.5]
  node [shape=box style="rounded,filled" fontname="Segoe UI" fontsize=11]
  edge [color="#6c757d" fontname="Segoe UI" fontsize=10]

  U [label="Пользователь / EPF" fillcolor="#f3effa" color="#6f42c1"]
  CTX [label="Контекст выполнения?" shape=diamond fillcolor="#e7f1ff" color="#0d6efd"]

  SM [label="БезопасныйРежим = Истина" fillcolor="#fff3cd" color="#ffc107"]
  X  [label="ВЫХОД без записи" fillcolor="#fff3cd" color="#ffc107"]

  S  [label="ЗакончитьЗамерВремени"]
  CL [label="Буфер +\nЗафиксироватьДлительность..."]
  P  [label="УстановитьПривилегированныйРежим(Истина)" fillcolor="#e8daef" color="#6f42c1"]
  R  [label="РС ЗамерыВремени" shape=cylinder fillcolor="#d4edda" color="#28a745"]

  U -> CTX
  CTX -> SM [label="безоп. режим"]
  SM -> X
  CTX -> S  [label="обычный сеанс"]
  CTX -> CL [label="клиент"]
  S -> P
  CL -> P
  P -> R
}
Плюсы: точная авто-раскладка, CLI dot -Tsvg. Минусы: синтаксис DOT нужно учить.

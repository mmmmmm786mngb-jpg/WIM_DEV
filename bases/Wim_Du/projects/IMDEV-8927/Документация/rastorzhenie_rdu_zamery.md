# Замеры: Расторжение договоров розничного ДУ (IMDEV-8927)

Операция Excel **№14**: **Процесс расторжения РДУ**.

## Обработка

| Параметр | Значение |
|----------|----------|
| EPF | `внРасторжениеДоговоровРозничногоДУ` |
| Команда РЗ | **`ФоновоеДоговорыИзДОКРасторжению`** |
| РЗ | 07:00-23:00, каждые **600 с** |
| Модуль | `Замеры_2/.../Ext/ObjectModule.bsl` |

## Замер (один, в целом)

| Параметр | Значение |
|----------|----------|
| Процедура | `ВыполнитьКоманду` при `ФоновоеДоговорыИзДОКРасторжению` |
| Ключевая операция | `ДУ.РасторжениеДоговоровРДУ.ФоновоеДоговорыИзДОКРасторжению` |
| Вес | `ДоговорыКРасторжениюИзДО.Количество()` (минимум 1) |
| Отказ | `Ложь` (этап до рассылок) |

В замер входит только `ДОДоговорыДУКРасторжению()` (загрузка из ДО). Рассылки выполняются после закрытия замера.

## Не замеряется (по задаче)

- `ФоновоеРасчетМатериальнойВыгодыПриРасторженииРозничногоДУ` — другая команда
- `ОбработкаДоговоровКРасторжению` — только кнопка на форме, не РЗ
- `РасторжениеДоговоровРозничногоДУ` (`ОткрытиеФормы`)

# Замеры: Распределение доходов по ценным бумагам (IMDEV-8927)

Операция Excel №03 (контур **РДУ**): **Обработка отчетов брокера за T-1** — распределение доходов по ЦБ.

## Обработка

| Параметр | Значение |
|----------|----------|
| EPF | `внРаспределениеДоходовПоЦеннымБумагам` |
| Команда БСП | `внРаспределениеДоходовПоЦеннымБумагам` (`ОткрытиеФормы`) |
| РЗ | нет |
| Модуль замера | `Forms/Форма/Ext/Form/Module.bsl` |

## Замер (упрощенный вариант)

| Параметр | Значение |
|----------|----------|
| Процедура | `СоздатьВсёНаСервере` (кнопка «Создать всё») |
| Ключевая операция | `ДУ.РаспределениеДоходов.СозданиеОпераций.внРаспределениеДоходовПоЦеннымБумагам` |
| Вес | сумма строк с `Отм = Истина` в ТЧ Купон, Погашение, Дивиденды (минимум 1) |
| Отказ | в `МассивСообщений` есть сообщения, отличные от «Создана операция…» |

**Не замеряется:** «Заполнить всё», создание по отдельным вкладкам (НКД / Погашение / Дивиденды), «Отметить/Снять».

# Форма 431, нехватка памяти

Номер задачи не назначен. Обработка заполнения 0420431 (по договорам ДУ, таксономия 7.1): исходная версия 1.07, новая 1.08.

## Состав

- **ОРИГИНАЛ** - выгрузка обработки 1.07 без изменений и собранный файл `..._1.07.epf`.
- **ОПТИМИЗИРОВАНО** - версия 1.08 и собранный файл `..._1.08.epf`. В модуле объекта вызов TWR по стратегии заменен на пачки по 500 мандатов со сверткой до одной строки на мандат. Правки помечены маркером `// Форма431_Память ++ / --`.
- **Письмо** - разбор и сравнение кода «было/стало».
- **Тестирование** - проверка 1.08 на dev-базах: компиляция и сверка доходности с 1.07, результаты в `Тестирование\index.md`.
- **Скрипты** - скрипты стенда и сверки.

На dev-стенде доходность 1.08 совпала с 1.07 на 451 и на 2003 мандатах. На 2000 мандатах 1.08 расходует 0,95 ГБ против 3,65 ГБ у 1.07 и считается быстрее. На копии Т-1 вариант не загружался, память на объемах PROD не проверена.

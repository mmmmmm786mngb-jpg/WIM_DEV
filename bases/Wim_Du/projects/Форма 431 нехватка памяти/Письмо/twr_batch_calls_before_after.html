0420431. Разбить вызовы TWR по пачкам мандатов

Процедура СформироватьВТ_ДанныеПоСтратегиям. Меняется только ветка, где на стратегию уходит один вызов TWR со всем массивом мандатов. Сбор массива, период НачалоПериодаTWR, группировка MANDATE и индекс ДоходностьПоМандатам ниже остаются прежними.

Красные строки - один вызов на всю стратегию. Зеленые строки - цикл порций. Серые строки - контекст, его не трогаем. В копии обработки из IMDEV-9005 вызов стоит на строках 768-772. В модуле со снимка (внКонтроль) тот же вызов на строке 1060.

Было один вызов на стратегию

Если НЕ МассивМандатов.Количество() = 0 Тогда
Группировка = "MANDATE";
ДанныеДоходности = Соединение.ВТБ_РасчетДоходностиСервер.TWR(НачалоПериодаTWR, ОтчетОбъект.КонецПериода,
Соединение.Справочники.Валюты.RUB, ВознаграждениеКакПассив, ?(ТипУчета = "Плановый", Истина, Ложь),
МассивМандатов, ТекущаяСтрока.Стратегия, Группировка, КоммисияКакПассив, НДФЛКакПассив,);
Иначе
ДанныеДоходности = Неопределено;
КонецЕсли;
ДоходностьПоМандатам = Соединение.NewObject("Соответствие");

В TWR уходит весь МассивМандатов стратегии. Рыночная стоимость и вводы-выводы за период с 31.12 прошлого года собираются внутри этого одного вызова МО.

Стало пачки по 500 мандатов

Если НЕ МассивМандатов.Количество() = 0 Тогда
Группировка = "MANDATE";
ДанныеДоходности = Неопределено;
РазмерПорции = 500;
КоличествоМандатов = МассивМандатов.Количество();
ИндексМандата = 0;
Пока ИндексМандата < КоличествоМандатов Цикл
ПорцияМандатов = Соединение.NewObject("Массив");
КонецПорции = Мин(ИндексМандата + РазмерПорции, КоличествоМандатов);
Пока ИндексМандата < КонецПорции Цикл
ПорцияМандатов.Добавить(МассивМандатов.Получить(ИндексМандата));
ИндексМандата = ИндексМандата + 1;
КонецЦикла;
ПорцияДоходности = Соединение.ВТБ_РасчетДоходностиСервер.TWR(НачалоПериодаTWR, ОтчетОбъект.КонецПериода,
Соединение.Справочники.Валюты.RUB, ВознаграждениеКакПассив, ?(ТипУчета = "Плановый", Истина, Ложь),
ПорцияМандатов, ТекущаяСтрока.Стратегия, Группировка, КоммисияКакПассив, НДФЛКакПассив,);

Продолжить;
КонецЕсли;
Если ДанныеДоходности = Неопределено Тогда
ДанныеДоходности = ПорцияДоходности;
Иначе
Для Каждого СтрокаПорции Из ПорцияДоходности Цикл
ЗаполнитьЗначенияСвойств(ДанныеДоходности.Добавить(), СтрокаПорции);
КонецЦикла;
КонецЕсли;
КонецЦикла;
Иначе
ДанныеДоходности = Неопределено;
КонецЕсли;
ДоходностьПоМандатам = Соединение.NewObject("Соответствие");

Каждая пачка - отдельный вызов МО. Счетчик памяти вызова после возврата обнуляется. В ДанныеДоходности склеиваются только короткие строки результата, индекс ниже читает их как раньше.

  • РазмерПорции = 500 - стартовое значение. На т-1 его стоит уменьшить, если самая большая стратегия снова упрется в лимит, и увеличить, если пачки проходят с запасом.
  • Группировка остается MANDATE: доходность мандата не зависит от соседей в том же вызове.
  • Период НачалоПериодаTWR не меняется. Это по-прежнему 31.12 предыдущего года .. конец отчета.
  • Вызовы пачек идут последовательно. Параллельный запуск снова сложит память в одном рабочем процессе МО.

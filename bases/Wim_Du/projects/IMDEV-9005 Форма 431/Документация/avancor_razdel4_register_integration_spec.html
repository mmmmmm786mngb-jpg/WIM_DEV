Раздел4 формы 0420431 — доработка EPF (перенос в регистр)

Обработка: внЗаполнениеРеглОтчетаПоДоговорамДУ_0420431_71  |  Документ: РО_XBRL7_1_0420431_СведенияОДеятельностиПоУправлениюЦБ_7119У  |  IMDEV-9005 / IMAPPS-37477

Проблема: в Раздел4 >99 999 строк — ошибка при Записать() (лимит платформы). Решение EPF: заполняем Раздел4 как сейчас; перед Записать() при активном режиме — Выгрузить() в ТЗ, записать в регистр CF, Раздел4.Очистить().

1. Точка вставки

Файл: NEW_Оптимизация/.../Ext/ObjectModule.bsl, процедура ВыполнитьКоманду. Одна строка между дозаполнением и записью:
ЗаполнитьРазделыОтчета(ОбъектНазначения); РегламентированнаяОтчетность.ДозаполнениеПустыхЗначенийПоОтчетамПрофучастника(ОбъектНазначения); ПеренестиРаздел4ВРегистрПриНеобходимости(ОбъектНазначения); // НОВОЕ ОбъектНазначения.Записать();

ЗаполнитьРаздел_4 и остальные разделы не меняются.

2.2. НужноХранитьРаздел4ВРегистре

Проверка режима: все три условия одновременно. На старых CF без новых метаданных — Ложь. 
// Возвращаемое значение: Булево
Функция НужноХранитьРаздел4ВРегистре(ОтчетОбъект)

    ИмяДокумента = ОтчетОбъект.Метаданные().Имя;
    МетаДок = Метаданные.Документы[ИмяДокумента];

    Если МетаДок.Реквизиты.Найти(ИмяФлагаХраненияРаздел4ВРегистре()) = Неопределено Тогда
        Возврат Ложь;
    КонецЕсли;

    Если Метаданные.РегистрыСведений.Найти(ИмяРегистраРаздел4()) = Неопределено Тогда
        Возврат Ложь;
    КонецЕсли;

    // Q3: флаг должен быть Истина до вызова EPF (или EPF выставляет сама — уточнить)
    Возврат ОбщегоНазначения.ЗначениеРеквизитаОбъекта(
        ОтчетОбъект, ИмяФлагаХраненияРаздел4ВРегистре()) = Истина;

КонецФункции

2.3. ПеренестиРаздел4ВРегистрПриНеобходимости

Процедура ПеренестиРаздел4ВРегистрПриНеобходимости(ОтчетОбъект)

    Если НЕ НужноХранитьРаздел4ВРегистре(ОтчетОбъект) Тогда
        Возврат;
    КонецЕсли;

    Если НЕ ЗначениеЗаполнено(ОтчетОбъект.Ссылка) Тогда
        ВызватьИсключение "Документ должен быть записан в ИБ перед переносом Раздел4 в регистр.";
    КонецЕсли;

    Если ОтчетОбъект.Раздел4.Количество() = 0 Тогда
        // Q4: пустой регистр или не трогать
        ОчиститьРегистрРаздел4(ОтчетОбъект.Ссылка);
        Возврат;
    КонецЕсли;

    ТаблицаРаздел4 = ОтчетОбъект.Раздел4.Выгрузить();
    ЗаписатьРаздел4ВРегистр(ОтчетОбъект.Ссылка, ТаблицаРаздел4);
    ОтчетОбъект.Раздел4.Очистить();

КонецПроцедуры

2.4. ЗаписатьРаздел4ВРегистр / ОчиститьРегистрРаздел4

Модель: одна запись регистра на документ, ресурс = ХранилищеЗначений(ТаблицаРаздел4) (Q2). 
Процедура ЗаписатьРаздел4ВРегистр(Регистратор, ТаблицаРаздел4)

    // Q5: сжатие или без
    Хранилище = Новый ХранилищеЗначения(ТаблицаРаздел4);

    НаборЗаписей = РегистрыСведений[ИмяРегистраРаздел4()].СоздатьНаборЗаписей();
    НаборЗаписей.Отбор.Регистратор.Установить(Регистратор);

    Запись = НаборЗаписей.Добавить();
    Запись.Регистратор = Регистратор;
    Запись[ИмяРесурсаХранилищаРаздел4()] = Хранилище;

    НаборЗаписей.Записать(Истина);

КонецПроцедуры

Процедура ОчиститьРегистрРаздел4(Регистратор)

    НаборЗаписей = РегистрыСведений[ИмяРегистраРаздел4()].СоздатьНаборЗаписей();
    НаборЗаписей.Отбор.Регистратор.Установить(Регистратор);
    НаборЗаписей.Записать(Истина);

КонецПроцедуры

3. Данные в регистре

Содержимое ХранилищеЗначений = результат ОтчетОбъект.Раздел4.Выгрузить() (все реквизиты ТЧ + НомерСтроки). EPF заполняет те же поля, что и сейчас; отличий в расчёте нет.

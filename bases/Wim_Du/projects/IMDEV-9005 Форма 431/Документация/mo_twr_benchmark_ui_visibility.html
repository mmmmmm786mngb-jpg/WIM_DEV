TWR_Бенчмарк в отчете МО: расчет есть, колонки на экране нет

Объект: Отчет.VTBAM_MWR_TWR  |  База: Wim_Mo  |  Контекст: IMDEV-9005, замечание аналитика (Chukhachov, Alexander)

Введение

Аналитик отметил: в коде отчета доходности МО есть расчет и TWR, и TWR_Бенчмарк, но конечный пользователь на экране видит только колонку TWR. Колонка TWR_Бенчмарк в интерфейсе отчета отсутствует.

Это замечание корректно. Расхождение объясняется не ошибкой запуска отчета, а разделением двух уровней: расчет в модуле объекта и вывод в макете печатной формы.

Краткий вывод

Да
TWR_Бенчмарк считается в РасчетTWR
Нет
Колонки TWR_Бенчмарк в макете VTBAM нет
Частично
На экране виден только дневной Rn_Бенчмарк

Что видит пользователь в режиме TWR

Отчет VTBAM_MWR_TWR формирует табличный документ через макет Результат, область СтрокаTWR. В заголовке и строках данных для режима TWR присутствуют следующие колонки, связанные с бенчмарком и доходностью:

Заголовок на экране Параметр макета Поле в таблице расчета Тип показателя
Rn Rn Rn Дневная доходность портфеля
Rn Бенчмарк Rn_Бенчмарк Rn_Бенчмарк Дневная доходность бенчмарка
TWR Доходность Доходность Накопленный TWR портфеля за период
— отсутствует — TWR_Бенчмарк TWR_Бенчмарк Накопленный TWR бенчмарка — не выводится

Важно: заголовок последней видимой колонки — «TWR», а не «TWR Бенчмарк». Пользователь видит накопленную доходность портфеля, а не накопленный бенчмарк.

Где считается TWR_Бенчмарк

Модуль объекта отчета

Файл: Wim_Mo/SRC/CF/Reports/VTBAM_MWR_TWR/Ext/ObjectModule.bsl
Функция: РасчетTWR(MV, ВводыВыводы), строки ~2212–2302

В возвращаемую таблицу MV добавляются колонки:

  • Доходность — накопленный TWR портфеля;
  • TWR_Бенчмарк — накопленный TWR бенчмарка.
// Шаг 1: дневные коэффициенты (разные формулы)
ТекСтрока.Rn           = (MVn - IO) / MVn_1;   // портфель
ТекСтрока.Rn_Бенчмарк  = MVn / MVn_1;          // бенчмарк

// Шаг 2: накопление за период
Rn_Накопленный         = Rn_Накопленный * ТекСтрока.Rn;
Rn_НакопленныйБенчмарк = Rn_НакопленныйБенчмарк * ТекСтрока.Rn;  // см. примечание ниже

ТекСтрока.Доходность   = Rn_Накопленный - 1;
ТекСтрока.TWR_Бенчмарк = Rn_НакопленныйБенчмарк - 1;
Примечание (отдельная тема, не про видимость колонки): в накоплении бенчмарка умножается ТекСтрока.Rn, а не ТекСтрока.Rn_Бенчмарк. Из-за этого значение TWR_Бенчмарк в данных может совпадать с Доходность. Подробный числовой пример — в документе mo_twr_benchmark_calculation_example.html.

Почему колонка не попадает на экран

Цепочка вывода отчета

РасчетTWR()  =>  таблица MV (есть TWR_Бенчмарк)
  |
ОтчетПоДоходности(ТЗ)  =>  цикл по строкам
  |
Строка = Макет.ПолучитьОбласть("СтрокаTWR")
ЗаполнитьЗначенияСвойств(Строка.Параметры, ТекСтрока)
  |
В макет попадают только поля, для которых объявлен параметр области

Функция ОтчетПоДоходности (строки ~100–144) копирует свойства строки расчета в параметры макета через ЗаполнитьЗначенияСвойств. Если в области СтрокаTWR нет параметра TWR_Бенчмарк, значение из таблицы расчета игнорируется при выводе.

Файл макета: Wim_Mo/SRC/CF/Reports/VTBAM_MWR_TWR/Templates/Результат/Ext/Template.xml
Область: СтрокаTWR — параметры Rn_Бенчмарк и Доходность (заголовок «TWR»). Параметра TWR_Бенчмарк нет.

Сравнение VTBAM_MWR_TWR и старого MWR_TWR

Показатель Отчет MWR_TWR (старый) Отчет VTBAM_MWR_TWR (текущий)
Дневной Rn_Бенчмарк на экране Да Да
Накопленный TWR_Бенчмарк на экране Да (параметр TWR_Бенчмарк в макете) Нет
Накопленный TWR портфеля на экране Да (TWR) Да (Доходность, заголовок «TWR»)
MWR_Бенчмарк на экране (режим MWR) Да Нет (считается в коде, но не в макете)

Вывод: при переходе на VTBAM_MWR_TWR накопленные показатели бенчмарка (TWR_Бенчмарк, MWR_Бенчмарк) из пользовательского интерфейса убраны. Осталась только дневная колонка Rn_Бенчмарк в режиме TWR.

Где TWR_Бенчмарк используется вне экрана отчета

Поле TWR_Бенчмарк остается в таблице, которую возвращает расчет TWR. Его читают интеграции и внешние потребители, а не пользователь отчета в МО.

Отдельный API бенчмарка ДоходностьБенчмарка(), ДоходностьБенчмаркаСтратегииМандата() Другой путь: расчет по регистру ДанныеБенчмарка, не колонка отчета TWR

Для формы 431 важно различать: пользователь МО не видит TWR_Бенчмарк в отчете, но ДУ может получать это поле программно через COM при заполнении регламентированного отчета.

Схема: расчет vs отображение vs интеграция

Слой TWR портфеля Rn_Бенчмарк (дневной) TWR_Бенчмарк (накопленный)
Расчет в РасчетTWR Да (Доходность) Да Да
Макет VTBAM (экран пользователя) Да (колонка «TWR») Да Нет
COM / форма 0420431 Косвенно Косвенно Да (читается из таблицы)

Формулировка для ответа аналитику

  1. Замечание верное: в отчете VTBAM_MWR_TWR колонки TWR_Бенчмарк для конечного пользователя нет.
  2. Код расчета существует: поле заполняется в функции РасчетTWR и присутствует в возвращаемой таблице.
  3. Причина невидимости: в макете Результат (область СтрокаTWR) не объявлен параметр TWR_Бенчмарк; вывод идет только в Доходность (заголовок «TWR») и Rn_Бенчмарк.
  4. Это не сбой отчета, а следствие состава макета текущей версии отчета. В старом MWR_TWR колонка на экране была.
  5. Для интеграций (в т.ч. 0420431) поле по-прежнему доступно через API, хотя пользователь МО его не видит.

Если нужно вернуть колонку на экран

Минимальные шаги (только макет, без изменения расчета):

  1. В Templates/Результат/Ext/Template.xml добавить в область ЗаголовокТаблицыTWR заголовок «TWR Бенчмарк».
  2. В область СтрокаTWR добавить параметр TWR_Бенчмарк (по аналогии со старым отчетом MWR_TWR).
  3. Проверить, что ЗаполнитьЗначенияСвойств подхватывает поле из таблицы (имена должны совпадать).

Отдельно от видимости: перед публикацией стоит подтвердить бизнес-логику накопления (Rn vs Rn_Бенчмарк в цикле) — см. связанный документ с примером.

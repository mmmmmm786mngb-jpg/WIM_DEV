h3. Выполненные доработки



{panel:title=ДУ-1: стр. 801 — индекс доходности по мандату|borderStyle=solid|borderColor=#6554C0|titleBGColor=#EAE6FF|bgColor=#F8F6FF}

*Проблема:* после каждого TWR — полный перебор {{ДанныеДоходности}} для каждого мандата (25 729 x {{НайтиСтроки}}).

*Решение:* один проход по результату TWR, построение COM-{{Соответствие}} {{ДоходностьПоМандатам}} (ключ — ссылка мандата из МО).

*Важно:* {{Соединение.NewObject("Соответствие")}}, не {{Новый Соответствие}} — иначе COM-ключи не сопоставляются.

*Замер:* 2 355 сек -> *~34 сек* (стр. 781 {{ДоходностьПоМандатам.Получить}}).

{panel}



{panel:title=ДУ-2: стр. 2470/2471 — раздел 1.2|borderStyle=solid|borderColor=#6554C0|titleBGColor=#EAE6FF|bgColor=#F8F6FF}

*Проблема:* для каждой строки раздела 1.2 — два {{НайтиСтроки}} по {{СведенияПоДоговорам}} (44 932 вызова, 491 сек).

*Решение:*

* {{ИндексСтрокПоГруппе}} — {{Соответствие}} «ключ группы -> Массив строк» (ключ из 10 полей, {{КлючГруппыРаздел1_2()}});

* {{ОбработанныеГруппы}} — кэш уже обработанных групп вместо второго {{НайтиСтроки}}.

*Замер:* {{ЗаполнитьРаздел_1}} — 510 сек -> *51 сек* (-90%).

{panel}



{panel:title=МО-1: стр. 2275 — исправление индекса MV|borderStyle=solid|borderColor=#FF991F|titleBGColor=#FFF0E0|bgColor=#FFFAF5}

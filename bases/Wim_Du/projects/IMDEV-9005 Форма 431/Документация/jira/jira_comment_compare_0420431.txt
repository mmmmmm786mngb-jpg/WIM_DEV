h2. Внешняя обработка {{внСравнение0420431}} — сравнение документов формы 0420431 (XBRL 7.1)

*Цель:* регрессионное тестирование.



{panel:title=Назначение|borderStyle=solid|borderColor=#0052CC|titleBGColor=#DEEBFF|bgColor=#FAFBFC}

*Обработка:* {{внСравнение0420431.epf}}

*Документ:* {{РО_XBRL7_1_0420431_СведенияОДеятельностиПоУправлениюЦБ_7119У}}



Сравнивает *два заполненных документа* регл. отчета 0420431 за *один и тот же период* и показывает расхождения по шапке и всем табличным частям. Используется при проверке оптимизаций заполнения, объединенных отчетов и регрессии данных.

{panel}



h3. Как работает



# Укажите *Документ 1* и *Документ 2* (оба — документы 0420431).

# Нажмите *Сравнить*.

# В поле *Итог сравнения* — краткий результат (идентичны / число расхождений).

# В таблице ниже — детализация по каждому расхождению.



{panel:title=Что сравнивается|borderStyle=solid|borderColor=#00875A|titleBGColor=#E3FCEF|bgColor=#F3FFF5}

*Шапка:* все реквизиты, включая {{НачалоПериода}} и {{КонецПериода}}.

*Исключено из сравнения:* {{Номер}}, {{Дата}}, {{Проведен}}, {{ПометкаУдаления}}, {{НомерСтроки}}.



*Табличные части (11 разделов):*

* {{Раздел1_Подраздел1_1}}, {{Раздел1_Подраздел1_2}}, {{Раздел1_Подраздел1_3}}

* {{Раздел2}} … {{Раздел7}}, {{Раздел10}}

* {{РеестрЦенныхБумаг}}



Строки ТЧ сравниваются как *мультимножество* (порядок строк не важен, дубликаты учитываются).

Для чисел допуск: *0.01*.

{panel}



h3. Элементы формы



||Элемент||Описание||

|*Документ 1 / Документ 2*|Ссылки на сравниваемые документы|

|*Только расхождения*|Если включено (по умолчанию) — в таблице только отличия; если выключено — добавляются строки «Совпадает» по разделам без расхождений|

|*Итог сравнения*|Многострочное поле с текстовым итогом; *очищается при смене любого из документов*|

|*Таблица расхождений*|Область, поле/ключ строки, значения в док.1 и док.2, тип расхождения|



h3. Типы расхождений в таблице



* *Реквизит* — различие в шапке документа

* *Количество* — разное число строк в табличной части

* *Только в док.1* / *Только в док.2* — строка есть только в одном документе

* *Количество вхождений* — одинаковая строка, но разное число повторов

* *Совпадает* — раздел без расхождений (при выключенном флаге «Только расхождения»)



h3. Как открыть



# Файл {{внСравнение0420431.epf}} — *Файл → Открыть* в 1С:Предприятие.

# Либо подключить через подсистему дополнительных обработок (при необходимости).



{panel:title=Типовой сценарий (IMDEV-9005)|borderStyle=solid|borderColor=#6554C0|titleBGColor=#EAE6FF|bgColor=#F8F6FF}

Сформировать два документа 0420431 за один период разными способами (полный прогон / объединение половинок / старая и новая версия заполнения) и убедиться, что обработка показывает *«Документы идентичны»* или вывести список расхождений для анализа.

{panel}

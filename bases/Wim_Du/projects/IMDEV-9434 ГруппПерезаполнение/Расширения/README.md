# Расширения

Доработки конфигурации — только через расширения. Исходники базы не изменяются.

## IM9434_Риск 1.0.0.10 (06.11.2026)

`IM9434_Риск.cfe`, исходники `IM9434_Риск\`. Назначение - исправление, префикс `IM9434Риск_`, совместимость 8.3.27.
Описание: `..\Документация\im9434_risk_fix.md`.

Одно заимствование - форма обработки `ГрупповоеПерезаполнениеДокументов`, модуль менеджера не заимствуется.

- `&ИзменениеИКонтроль` на `ПолучитьМассивДокументовДляПерепроведения`: тело типовой функции без изменений, в начале
  `#Вставка` - для макета `КонтрольДопустимогоУровняРиска` всегда пустой массив (без сообщения пользователю); документы
  риска фоновое задание берет по договорам и дням отобранных СЧА (`ТаблицаРискаПоДокументамСЧА`). При обновлении CF
  проверять дрейф тела (`cfe-patch-method -Check`).
- Отбор списка по видам документа: `&Перед`/`&После` на `ПриСозданииНаСервере` и `ВидДокументаОбработкаВыбораНаСервере`,
  свой обработчик `ПриЗакрытии` (событие OnClose в Form.xml расширения), запись в системном хранилище под ключом
  `<Форма>.СписокДокументов/IM9434РискОтборПоВиду`, ключ настроек - вид документа без пробелов, "/" -> "_".
  Автосохранение настроек списка выключено. Строки с полями чужого вида при загрузке убираются только из копии (1.0.0.9).

История: 1.0.0.1 `&Вместо` -> `&ИзменениеИКонтроль` по решению 06.11; 1.0.0.7 вставка без проверки полей;
1.0.0.6-1.0.0.8 отбор по видам; 1.0.0.9 исправлена потеря отбора со строками разных видов, правки ревью;
1.0.0.10 убран перехват всего `ВыполнитьГрупповоеПерезаполнение` в модуле менеджера (менялся только текст сообщения,
а контроль 450 строк ломал бы применение расширения при любой правке вендора).

ПОДКЛЮЧАТЬ БЕЗ БЕЗОПАСНОГО РЕЖИМА. В безопасном режиме платформа не применяет расширение к модулю формы обработки
(журнал регистрации: `_$Session$_.ConfigExtensionApplyError` "расширение модуля запрещено ... подключено в безопасном
режиме"), исправление молча не работает. Проверено на dev WIM_DU.

Дерево изменений для переноса IM9434 -> базовая CF

IMDEV-9434: ускорение обработки «Групповое перезаполнение документов» - параллельные пачки по договорам ДУ, окно процента БСП, подтверждение периода, замер длительной операции. Артефакт: IM9434.cfe.

Что внести в CF

  • Обработка ГрупповоеПерезаполнениеДокументов: создать модуль менеджера (в типовой его нет) - 8 методов из CFE (диспетчер, воркер, прогресс, заполнение одного документа, подбор таблиц по массиву ссылок).
  • Форма ГрупповоеПерезаполнениеДокументов.Форма: 4 вставки в типовую Перезаполнить + 6 новых методов + клиентская переменная модуля.
  • Ключ замера ДУ.ГрупповоеПерезаполнениеДокументов (при первом прогоне создастся сам; при необходимости завести в ключевых операциях).

Как читать

  • ДОБАВИТЬ - новый модуль / метод / переменная.
  • ИЗМЕНИТЬ - вставка в существующий типовой метод.
  • в CF - куда вносить.
  • из CFE - откуда взять код.
  • Форму, реквизиты, макеты СКД, команду открытия, справку не менять.
  • Новых констант и общих модулей нет.

Поведение (чтобы понимать, что переносится)

Вид документа После переноса
Установка котировок ц/б (по пулам) Как сейчас: клиентский цикл ПереполнитьДокументы + замер ДУ.ГрупповоеПерезаполнениеДокументов. Договора ДУ в шапке нет, в параллель не переводим.
Остальные 10 видов обработки Подтверждение периода -> форма только типовой СКД (ПолучитьМассивДокументовДляПерепроведения) и запуск ФЗ -> окно БСП -> диспетчер ВыполнитьГрупповоеПерезаполнение подбирает Ссылка+ДоговорДУ запросом Выгрузить (не цикл с Таблица.Найти) -> пачки целых ДоговорДУ (размер из МаксимальныйРазмерПорцииДоговоровВПотокеРегл, по умолчанию 50) -> скользящее окно воркеров ОбработатьПачкуДокументов (число из МаксимальноеКоличествоПараллельныхПотоков). Если потоков 0 или ФЗ запрещены - пачки последовательно внутри диспетчера, окно процента остаётся.
Расчет СЧА/РСА + флаг риска Риск в диспетчере: дни отобранных СЧА во временную таблицу, соединение с контролем риска по ДоговорДУ и интервалу даты дня (не НАЧАЛОПЕРИОДА на обеих сторонах JOIN). Дубли при доборе из СКД риска - через Соответствие, не Таблица.Найти. В воркере по договору: сначала СЧА, затем риск. Ошибка СЧА - риск этого договора не запускать.

Сначала модуль менеджера (иначе форма не скомпилируется), затем методы формы, затем вставки в Перезаполнить. Форму визуально не трогать.

Куда вставлять в типовую Перезаполнить

Типовая процедура начинается с ОчиститьСообщения();, затем выбор макета по Объект.ВидДокумента, затем ПолучитьМассивДокументовДляПерепроведения и клиентский цикл. Четыре вставки:

Вставка Место в типовой Суть кода (взять тело из CFE между #Вставка и #КонецВставки)
1 Сразу после ОчиститьСообщения(); Если клиентская переменная ещё не «да после вопроса»: проверить оба края периода; если нет - ПоказатьПредупреждение и Возврат. Иначе ПоказатьВопрос (Да/Нет, по умолчанию Нет) и Возврат. Если уже подтверждено - сбросить флаг и идти дальше.
2 После КонецЕсли; выбора вида (после ветки «по пулам»), до ПолучитьМассивДокументовДляПерепроведения Если вид не «Установка котировок ц/б (по пулам)»: ЗапуститьПерезаполнениеНаСервере, ДлительныеОперацииКлиент.ОжидатьЗавершение (окно ожидания, прогресс, сообщения) и Возврат. Типовой клиентский цикл для этих видов больше не выполняется.
3 После проверки, что массив документов - Массив; до КартинкаИндикатора = ... Только путь «по пулам»: ОписаниеЗамера = НачатьЗамерПерезаполненияНаСервере();
4 После сообщения «Перезаполнение документов завершено...», перед КонецПроцедуры Только путь «по пулам»: закончить замер с весом = число обработанных документов, комментарий Вид / Договоров=0 / Документов / Риск=Нет / Потоков=1.

Не делать

  • Не создавать константы, общий модуль, элементы формы, поля периода в шапке.
  • Не подменять ПереполнитьДокументы и макеты СКД.
  • Не копировать маркеры #Вставка / #КонецВставки в CF.
  • Не оставлять имя IM9434_Перезаполнить в CF - править Перезаполнить.
  • Не рвать один ДоговорДУ на два потока.
  • Не писать процент во втором параметре СообщитьПрогресс (его рисует окно БСП из первого параметра).
  • Не собирать таблицы документов циклом с Таблица.Найти(Ссылка) без индекса: на тысячах строк это квадратичный поиск, форма зависает до окна БСП. Только Выгрузить() / Соответствие.
  • Не переносить подбор ДоговорДУ обратно на форму: после СКД сразу ФЗ, подбор - в диспетчере (пользователь уже видит окно процента).

# ПросмотрНастроекСписков.epf

Внешняя обработка для разбора жалобы "после деплоя слетели отборы" (письмо Кукушкина 05.11.2026).
Только читает стандартные хранилища настроек, ничего не записывает.

Файл: `build\ПросмотрНастроекСписков.epf`. Исходники: `src\`, описание формы: `form.json`.
Проверена на dev WIM_DU (1.5.30.9, платформа 8.3.27.2214) 06.11.2026: форма открывается, вывод по одному
пользователю, по всем пользователям и с расшифровкой отбора работает.

## Что показывает

Записи пяти хранилищ: настройки динамических списков, системные настройки, настройки данных форм, общие
настройки, пользовательские настройки отчетов. Для каждой записи: пользователь, дата изменения, ключ объекта,
ключ настроек, тип значения, расшифровка отборов (с идентификаторами `userSettingID`) и полный XML.

Текущие отборы динамических списков платформа хранит в СИСТЕМНЫХ настройках под ключом
`<Форма>.<ИмяТаблицы>/ТекущиеПользовательскиеНастройки`. Для обработки группового перезаполнения:
`Обработка.ГрупповоеПерезаполнениеДокументов.Форма.Форма.СписокДокументов/ТекущиеПользовательскиеНастройки`.
В хранилище настроек динамических списков лежат только варианты, сохраненные командой "Сохранить настройки".

"(нет даты)" в колонке даты - запись сохранена платформой, которая дату не записывала (режим совместимости
8.3.18 и ниже). Такие записи читаются и сейчас.

## Запуск на Т-1

1. Войти в базу Т-1 пользователем с правом "Администрирование" (без него видны только свои настройки).
2. Файл - Открыть - `ПросмотрНастроекСписков.epf`, подтвердить предупреждение безопасности.
3. "Пользователь ИБ" - выбрать Кукушкина из списка (в списке имя и полное имя).
4. Прогон 1: "Ключ объекта содержит" = `ГрупповоеПерезаполнениеДокументов`, "Показать настройки".
5. Прогон 2: очистить "Ключ объекта содержит", "Показать настройки" - все записи пользователя.
6. После каждого прогона сохранить результат: на закладке "Сводка" - Еще - Сохранить как (xlsx), на закладке
   "Полный текст (XML)" - выделить все, скопировать в txt.

Флажок "Все пользователи" работает только с подстрокой ключа; по всем ключам всех пользователей прогон долгий.

## Как читать результат

- Записи Кукушкина с датой до деплоя или "(нет даты)" есть, а отборы в форме пустые - настройки не удалены,
  платформа их не применила (сравнить поля и `userSettingID` в XML с формой).
- Все записи с датой не раньше деплоя - старые записи были удалены или перезаписаны при деплое или при первом
  открытии форм после него.
- Запись `...СписокДокументов/ТекущиеПользовательскиеНастройки` от 05.11.2026 без строки
  `Ссылка.РасчетСЧА.Показатель` - отбор по полю расчета СЧА потерялся уже при закрытии формы.

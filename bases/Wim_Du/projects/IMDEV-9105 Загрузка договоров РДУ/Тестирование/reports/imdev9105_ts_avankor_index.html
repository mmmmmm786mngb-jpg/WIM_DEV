Основание Замеры производительности (PFF), 14.07.2026

1. Суть задачи

При загрузке/синхронизации договоров РДУ (путь как в обработке СинхронизацияНСИ: создание договора ДУ, аналитика, связанные договоры контрагентов, поручение на перевод) на каждый договор многократно выполняется поиск существующих элементов справочника ДоговорыКонтрагентов по комбинации Владелец + ДоговорДУ + РольДоговора.

Реквизиты ДоговорДУ и РольДоговора сейчас не индексируются (DontIndex), из-за чего запрос при массовой загрузке выполняется медленно. Требуется включить индексацию.

3. Почему нужно изменение

  • Один и тот же запрос вызывается из двух мест кода при создании связанных договоров контрагентов (~500 раз на пакет 100 договоров РДУ).
  • Без индекса СУБД выполняет дорогой поиск по таблице ДоговорыКонтрагентов (отбор по неидентифицированным реквизитам ДоговорДУ / РольДоговора).
  • По замерам PFF две call-site этого запроса занимали 55,7% времени всего сценария (172 с из ~309 с).
  • После включения индексации в тестовой базе время тех же строк сократилось до 1,2 с — ускорение порядка ×140 (−99%).
  • Общее время сценария загрузки 100 договоров сократилось с 311,5 с до 132,4 с (−58%, ×2,35).

4. Что сделать (объём работ)

  1. Для реквизита Справочник.ДоговорыКонтрагентов.ДоговорДУ установить индексирование: Index.
  2. Для реквизита Справочник.ДоговорыКонтрагентов.РольДоговора установить индексирование: Index.
  3. Программный код не изменять.
  4. Выполнить обновление конфигурации базы данных (реструктуризация индекса).
  5. Передать патч/релиз с описанием изменения в метаданных.

5. Критерии приемки

  • В метаданных: ДоговорДУ.Indexing = Index и РольДоговора.Indexing = Index.
  • Функциональность создания/поиска договоров контрагентов при загрузке РДУ не нарушена.
  • На тестовой базе время выполнения горячего Запрос.Выполнить() по ДоговорыКонтрагентов при загрузке 100 договоров — порядка секунд, а не сотен секунд.

7. Ограничения

  • Изменяются только метаданные указанных реквизитов.
  • Программный код модулей конфигурации и внешние обработки не затрагиваются.

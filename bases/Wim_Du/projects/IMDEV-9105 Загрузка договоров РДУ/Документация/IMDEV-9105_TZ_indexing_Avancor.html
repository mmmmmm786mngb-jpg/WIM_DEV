Техническое задание для Аванкор

Тема Включить индексацию реквизитов ДоговорДУ и РольДоговора справочника ДоговорыКонтрагентов
Заявка IMDEV-9105
Конфигурация 1С:Доверительное управление
Тип изменения Только метаданные (код не менять)
Основание Замеры производительности (PFF), 14.07.2026

1. Суть

При загрузке договоров РДУ многократно выполняется поиск в Справочник.ДоговорыКонтрагентов по связке Владелец + ДоговорДУ + РольДоговора.

У реквизитов ДоговорДУ и РольДоговора индексирование выключено (DontIndex) — поиск медленный. Нужно включить индекс.

2. Что сделать

Параметр Значение
Объект метаданных Справочник.ДоговорыКонтрагентов
Реквизиты ДоговорДУ, РольДоговора
Файл XML Catalogs/ДоговорыКонтрагентов.xml
Сейчас <Indexing>DontIndex</Indexing>
Нужно <Indexing>Index</Indexing>
  1. Для ДоговорДУ и РольДоговора установить индексирование: Индексировать (Index).
  2. Программный код не изменять.
  3. Обновить конфигурацию БД (реструктуризация индексов).
  4. Передать изменение в релизе/патче.

3. Запрос, который должен ускориться

ВЫБРАТЬ
    ДоговорыКонтрагентов.Ссылка
ИЗ
    Справочник.ДоговорыКонтрагентов КАК ДоговорыКонтрагентов
ГДЕ
    ДоговорыКонтрагентов.Владелец = &Владелец
    И ДоговорыКонтрагентов.ДоговорДУ = &ДоговорДУ
    И ДоговорыКонтрагентов.РольДоговора = &РольДоговора

Контекст: создание связанных договоров контрагентов при загрузке РДУ (поиск перед созданием).

4. Эффект (подтверждено на тест-базе)

Сценарий: загрузка 100 договоров РДУ.

Показатель До После Изменение
SELECT по ДоговорыКонтрагентов (~500 вызовов) 172 с (55,7%) 1,2 с (~0,4%) -99%
Итого загрузка 100 договоров 311,5 с 132,4 с -58%

5. Критерии приемки

  • У ДоговорДУ и РольДоговора установлено индексирование Index.
  • Поиск/создание договоров контрагентов при загрузке РДУ работает без регресса.
  • Код конфигурации не изменен.
Резюме: ДоговорДУ и РольДоговора — DontIndex → Index. Код не трогать. Эффект: критичный SELECT ×140 быстрее, загрузка 100 договоров −58%.

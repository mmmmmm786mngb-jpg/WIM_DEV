Файл кода:
  C:\1c\Cursor_1c\WORK\Wim_Du\SRC\epf\внСинхронизацияНСИ_epf\внСинхронизацияНСИ\Ext\ObjectModule.bsl

Команда запуска:
  ВыполнитьКоманду("ФоновоеВыполнение")
    -> ВыполнитьСинхронизациюНСИ()

Принцип для замеров/теста:
  ЧИТАЕМ из ДО -> СОЗДАЕМ НСИ в ДУ -> НЕ ПИШЕМ в ДО, НЕ завершаем задачи ДО.


================================================================================
  1. ПРОЦЕДУРЫ, КОТОРЫЕ НУЖНЫ ДЛЯ НОВОГО ДОГОВОРА В ДУ (ОСТАВИТЬ)
================================================================================

Цепочка вызовов (порядок важен):

  A. Подключение и отбор
     УстановитьСоединениеДО()              стр. ~920
     КонтрагентыСОшибкамиДО()              стр. ~194  (чтение из ДО)
     СписокОбъектовИзОткрытыхЗадач()       стр. ~210  (запрос к ДО: открытые задачи)
     ПрочитатьДанныеДО()                   стр. ~227  (запрос к ДО -> ТЧ обработки)

  B. Транзакция создания НСИ в ДУ
     СоздатьКЕШ()                          стр. ~245
     СоздатьНСИ()                          стр. ~253
       |
       |-- цикл СписокКонтрагентов (стр. ~2961):
       |     создание/запись Справочник.Контрагенты
       |     регистр ДокументыФизическихЛиц (паспорт)
       |     ДобавитьСвязь(..., "DMCorrespondent", ...)  - только регистр ДУ, не запись в ДО
       |
       |-- цикл Договоры (стр. ~3300), если ТипДУ = "Розничное":
       |     создание Справочник.ДоговорДУ, ДоговорОбъект.Записать()
       |     ДобавитьСвязь(..., "DMInternalDocument", ...) - только регистр ДУ
       |     ЗаписатьДополнительноеСведение() (Reporting, ЛК)
       |     ЗаполнитьАналитикуПоДоговоруДУ()  стр. ~3440
       |       ЗаполнитьУчетнаяПолитка()
       |       ЗаполнитьНастройкиОтчетности()
       |       ЗаполнитьНастройкиВознаграждения()
       |       ЗаполнитьАналитическиеСчета()
       |       ДоговорКонтрагента()
       |       СоздатьПоручение() / СоздатьПлатежноеПоручение() - документы ДУ
       |     ЗаписатьСтратегию()               при наличии стратегии
       |     СоздатьИнвестпрофиль()            для нового договора с UID инвестпрофиля
       |
       |-- цикл БанковскиеСчета (если есть в выборке)

     УстановитьМенеджераКлиента()          стр. ~270  (запись только в ДУ)
     ЗафиксироватьТранзакцию()             стр. ~293

  C. После транзакции - только чтение из ДО / запись в ДУ (можно оставить)
     СинхронизацияМенеджеров()             стр. ~286  (читает ДО, пишет ДУ)
     СинхронизацияДатыПодписанияДоговоров_в_ДУ()  стр. ~319  (читает ДО, пишет ДУ)

  D. Опционально для полного сценария розничного ДУ (только ДУ, не ДО)
     ПлатежныеПорученияРозничногоДУ()      стр. ~315  (документы ДУ)


================================================================================
  2. ЧТО ЗАКОММЕНТИРОВАТЬ (ЗАПИСЬ / ОТПРАВКА В ДО)
================================================================================

Минимальный набор (4 места). Без этого на PROD уйдут письма «Новые договоры»
и изменятся задачи/реквизиты в ДО.

----------------------------------------------------------------------
  МЕСТО 1. ВыполнитьСинхронизациюНСИ(), стр. 297-312
----------------------------------------------------------------------
  Закомментировать весь блок:

    //Если НЕ Отказ Тогда
    //    Попытка
    //        ИсполнитьЗадачиДО();
    //    Исключение
    //        ...
    //    КонецПопытки;
    //КонецЕсли;

  Что отключается:
    - ИсполнитьЗадачиДО()
    - ЗавершитьЗадачиПоУспешнымДоговорамДУ() -> Задача.ExecuteTask()
      (триггер письма {OK} ДОК и вложения Новые договоры.xlsx)
    - ДополнительныеРеквизитыДО() -> ТекДок.Записать() в ДО
    - СоздатьОповещениеАдмина() -> БП Ознакомление в ДО

----------------------------------------------------------------------
  МЕСТО 2. СоздатьНСИ(), стр. 3169-3238
----------------------------------------------------------------------
  Закомментировать блок от комментария до КонецЕсли:

    // Установка допсвойства в ДО
    // ... весь блок с ДополнительныйРеквизитДО_ДатаСинхронизации,
    //     ДополнительныйРеквизитДО_КДУ_ИД, ВнешОбъект.Записать()

  Что отключается:
    - запись КДУ_ИД и «Дата синхронизации с ДУ» в контрагент 1С:ДО

----------------------------------------------------------------------
  МЕСТО 3. ВыполнитьСинхронизациюНСИ(), стр. 320
----------------------------------------------------------------------
  Закомментировать строку:

    //СинхронизацияДатыРасторженияДоговоров_в_ДО();

  Что отключается:
    - ВнешОбъект.Записать() договора в ДО (дата расторжения, НеДействует)

----------------------------------------------------------------------
  МЕСТО 4. ВыполнитьКоманду(), стр. 95-97
----------------------------------------------------------------------
  Закомментировать блок:

    //Если ПлатежныеПорученияСледующийРабочий.Количество() > 0 Тогда
    //    УстановкаПризнакаОтправкиНаБрокерскийСчет();
    //КонецЕсли;

  Что отключается:
    - вызов WS DMService.SetRetailSentToBroker в 1С:ДО


================================================================================
  3. ДОПОЛНИТЕЛЬНО (НЕ ДО, НО ЛУЧШЕ ОТКЛЮЧИТЬ ПРИ ЗАМЕРАХ)
================================================================================

  ВыполнитьКоманду(), стр. 91-93:
    СформироватьИОтправитьПисьмо() - письмо ДУ по платежным поручениям (не ДО)

  ВыполнитьСинхронизациюНСИ(), стр. 314-316:
    ПлатежныеПорученияРозничногоДУ() - создает документы в ДУ (не ДО);
    для чистого замера только чтения+создания договора можно тоже закомментировать


================================================================================
  4. СХЕМА ПОТОКА (КОММЕНТИРОВАННЫЙ РЕЖИМ)
================================================================================

  [ДО] открытая задача (ВнутренниеДокументы)
    |
    v  только SELECT (СписокОбъектовИзОткрытыхЗадач, ПрочитатьДанныеДО)
  [ДУ] СоздатьНСИ
    |    контрагент + договор + аналитика
    |    БЕЗ ВнешОбъект.Записать() в ДО
    v
  [ДУ] транзакция зафиксирована
    |
    X  ИсполнитьЗадачиДО()           <- ЗАКОММЕНТИРОВАНО
    X  ExecuteTask / письмо ДО      <- не вызывается
    X  SetRetailSentToBroker         <- ЗАКОММЕНТИРОВАНО


================================================================================
  5. ПРОВЕРКА ПОСЛЕ ЗАПУСКА
================================================================================

  OK:
    - в ДУ появились контрагент и ДоговорДУ (розничный)
    - заполнена аналитика (УП, счета, поручение - если не отключали п.3)
    - в ДО задачи по договору остались НЕ выполненными
    - письмо «Новые договоры» НЕ пришло

  Если письмо пришло - не закомментирован МЕСТО 1 (ИсполнитьЗадачиДО).

  Внимание: на боевой базе ДУ создаются реальные объекты. Для замеров
  использовать копию базы или откат транзакции/тестовый контур.

# N баз ДУ 1.5: обслуживание 1 млн договоров РДУ

Презентация для обсуждения архитектуры масштабирования Розничного доверительного управления.

## Файл презентации

Откройте `n_bases_du15_presentation.html` в браузере.

- Слайды на весь экран, формат 16:9
- Листание: стрелки клавиатуры, пробел, колесо мыши, клик по краям
- Печать / PDF: Ctrl+P, альбомная ориентация
- На слайде с калькулятором можно менять размер шарда и сразу видеть число баз

## О чём документ

Планируется порядка **1 млн договоров РДУ**. Одна информационная база ДУ 1.5 по замерам ключевых операций не выдерживает даже целевые 250 тыс. Предложение: **N копий одной конфигурации ДУ 1.5**. Новые клиенты открываются в следующей базе, когда текущая достигает порога (ориентир 200 тыс.).

Аналог уже есть: мидл-офис и фронт-офис разделены на обычный контур и контур РДУ. Тот же приём — отдельная информационная база / отдельный узел обмена — применяется внутри РДУ сколько раз, сколько нужно по объёму.

## Источники цифр в презентации

- Сводка ключевых операций Розничного ДУ (IMDEV-9393): замеры ПРОД, окно 28.07–02.09.2026
- Нагрузочные прогоны регламентов и СЧА/РСА на полном отборе РДУ (порядка 22 тыс. договоров)
- Штатный механизм узлов плана обмена «Источники обмена» (уже два контура ФО: корпоративный и розничный)
- Документация платформы 1С:Предприятие: кластер обслуживает несколько информационных баз, процессы можно изолировать по базам

# Проект tax-ndfl-config (shared)

Проект для разработки новой конфигурации 1С по требованиям налогового блока из файла `Требования от налогов.xlsx`.

## Назначение

- Реализовать движок расчета НДФЛ для операций клиентов.
- Реализовать правила сальдирования убытков.
- Автоматически формировать `6-НДФЛ`, `Приложение 1` и справку для клиента.
- Обеспечить проверку расчетов по контрольным кейсам из требований.

## Структура

- `bases.txt` - список баз, в которых потребуется интеграция.
- `Расширения/` - расширения и доработки конфигураций.
- `Документация/` - ТЗ, спецификации, правила расчета.
- `Тестирование/` - сценарии и отчеты тестирования.
- `Скрипты/` - утилиты и автоматизация.

## Основной документ

# Требования

Свод требований и проектное ТЗ для разработки налогового контура.

## Документы

- `tz_ndfl_engine.html` — техническое задание на разработку конфигурации 1С «Налоговый движок НДФЛ» (HTML, итоговая версия для согласования).
- `comparison_nalogoplatelshchik_vs_bsp.html` — сравнительный анализ: `1С Налогоплательщик 8` против разработки отдельной конфигурации на базе БСП.
- `ndfl_tax_engine_tz.md` — рабочий черновик ТЗ (использован как вход для финальной версии).

## Источник требований

- `bases/shared/projects/tax-ndfl-config/Требования от налогов.xlsx` — бизнес-требования налогового блока (8 листов).

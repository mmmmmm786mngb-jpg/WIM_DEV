# Документация: OpenAdditionalProcessingSettings

## Содержание

1. [Доработка VTB_Devops: ФормаНастроек без EPF](vtb_devops_settings_form_extension.md) — **основная спецификация**  
   Как в расширении `VTB_Devops` добавить открытие / редактирование / сохранение `ФормаНастроек` по аналогии с гиперссылкой «Настройки» в ДУ (AVANCORE), без отдельной внешней обработки.

## Кратко о задаче

В ФИН (ДУ ред. 2) реквизит `ХранилищеНастроек` и передача настроек в команды (`ПараметрыДополнительнойОбработки`) уже есть.  
На карточке справочника `ДополнительныеОтчетыИОбработки` нет UI для редактирования настроек (в ДУ — гиперссылка AVANCORE / SROS-14).

Рекомендуемый путь: доработать уже заимствованные формы в `VTB_Devops` (кнопка или гиперссылка + запись в `ХранилищеНастроек`).

## Запасные варианты (не целевые)

- Отдельная EPF `ОткрытиеНастроекДопОбработок` — автономный инструмент, если расширение временно нельзя менять.
- Расширение определяемого типа `ОбъектСДополнительнымиКомандами` для подменю БСП «Заполнение...» — в режиме совместимости расширения `8.3.12` практически неработоспособен.

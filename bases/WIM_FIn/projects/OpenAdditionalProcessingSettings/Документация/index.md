# Открытие настроек дополнительных обработок

## Назначение

В ФИН (ДУ ред. 2) с формы элемента справочника `ДополнительныеОтчетыИОбработки` пропала аванкоровская гиперссылка «Настройки». Реквизит `ХранилищеНастроек` и передача настроек в команды (`ПараметрыДополнительнойОбработки`) остались.

Обработка `ОткрытиеНастроекДопОбработок` восстанавливает сценарий редактирования без правки типовой формы:

1. Выбор элемента справочника.
2. Подключение внешней обработки/отчета через БСП.
3. Открытие формы `ФормаНастроек` с параметром `НастройкиАлгоритма`.
4. При возврате структуры (`ОповеститьОВыборе` или `Закрыть(Структура)`) — запись в `ХранилищеНастроек`.

## Требования к целевой обработке

- В метаданных внешней обработки/отчета должна быть форма с именем **`ФормаНастроек`**.
- Форма должна принимать `Параметры.НастройкиАлгоритма`.
- Для сохранения через эту утилиту форма должна вернуть **Структуру** (`ОповеститьОВыборе(Структура)` или `Закрыть(Структура)`).
- Строка вроде `"ЗаписьНастроек"` намеренно игнорируется (такие формы пишут настройки сами в другие места).

## Как запускать

1. `Файл` → `Открыть` → `ОткрытиеНастроекДопОбработок.epf`
2. Либо добавить в `Дополнительные отчеты и обработки` (вид: дополнительная обработка, команда открытия формы).

## Ограничения

- Не заменяет полноценное восстановление гиперссылки в карточке.
- Не подходит для встроенных обработок конфигурации без формы `ФормаНастроек`.
- Нужны права на запись элемента справочника.

## Несовместимость УстановитьПользовательскиеНастройки

У части внешних обработок (пример: `внПакетныйОтчетБрокераДУ`) форма `ФормаНастроек` вызывает:

`ТекОбъект.УстановитьПользовательскиеНастройки(Настройки);`

а в модуле объекта метод без параметров или с другой сигнатурой → ошибка «Слишком много фактических параметров».

Обработка-утилита:

1. Проверяет вызов `УстановитьПользовательскиеНастройки(Настройки)` на экземпляре объекта.
2. Если сигнатура не подходит — открывает форму **без** `НастройкиАлгоритма` (форма откроется, но сохраненные настройки не подставятся).
3. Если ошибка всё же возникла при открытии — повторяет открытие без настроек.

Корневое исправление таких обработок: привести сигнатуру метода в модуле объекта к виду  
`УстановитьПользовательскиеНастройки(Настройки, ПредставлениеНастроек = "")`.

# Сценарии проверки

1. Открыть EPF в базе ФИН.
2. Выбрать дополнительную обработку **с** формой `ФормаНастроек`.
3. Убедиться, что в «Текущие настройки» видно представление или «настройки не установлены».
4. Открыть форму настроек, изменить параметры, подтвердить.
5. Проверить оповещение «Настройки сохранены».
6. Повторно открыть — значения должны подтянуться из `ХранилищеНастроек`.
7. Выбрать обработку **без** `ФормаНастроек` — должно быть сообщение об отсутствии формы.
8. Отмена в форме настроек — элемент справочника не должен меняться.

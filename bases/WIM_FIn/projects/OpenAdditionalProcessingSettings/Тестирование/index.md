# Сценарии проверки (вариант 1)

1. Загрузить расширение `Расширения/VTB_Devops` в WIM_FIN (или обновить существующее).
2. Обновить EPF `ОткрытиеНастроекДопОбработок` в справочнике из `epf/build/`.
3. В карточке утилиты: публикация «Используется», назначение на справочник, «для формы объекта».
4. Открыть любой элемент `ДополнительныеОтчетыИОбработки`.
5. В командной панели должно быть **Заполнение...** → **Открыть форму настроек**.
6. Должна открыться форма настроек целевой обработки (или утилита с уже выбранным элементом и автозапуском).
7. Сохранить настройки — проверить запись в `ХранилищеНастроек`.
8. Обработка без `ФормаНастроек` — понятное сообщение.
9. Ручной запуск EPF через Файл → Открыть по-прежнему работает.

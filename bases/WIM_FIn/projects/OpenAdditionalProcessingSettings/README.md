# Проект OpenAdditionalProcessingSettings

Восстановление сценария редактирования `ФормаНастроек` для элементов справочника **Дополнительные отчеты и обработки** в базе WIM_FIn.

## Документация

Основной документ:

- [`Документация/vtb_devops_settings_form_extension.md`](Документация/vtb_devops_settings_form_extension.md) — техническая спецификация доработки расширения **VTB_Devops** (без отдельной EPF), по аналогии с гиперссылкой «Настройки» в ДУ.

Оглавление: [`Документация/index.md`](Документация/index.md).

## Структура проекта

- **Документация/** — спецификации
- **Расширения/VTB_Devops/** — копия/исходники расширения (точка доработки)
- **epf/** — запасная EPF-утилита (не целевой путь)
- **Скрипты/build.ps1** — сборка EPF на `localhost/WIM_FIN`
- **Тестирование/** — сценарии проверки

## Целевой подход

Доработать `VTB_Devops`: на форме элемента справочника открывать `ФормаНастроек` внешней обработки, принимать структуру и сохранять в `ХранилищеНастроек`. Отдельная обработка в справочнике не нужна.

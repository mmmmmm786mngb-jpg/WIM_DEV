# Проект OpenAdditionalProcessingSettings

Универсальная внешняя обработка для открытия `ФормаНастроек` элементов справочника **Дополнительные отчеты и обработки** и записи результата в `ХранилищеНастроек`.

Обход отсутствия гиперссылки «Настройки» в карточке справочника ФИН (ДУ ред. 2) после обновления БСП.

## Источник кода базы

Путь: **../../source-path.txt** → `C:\1c\Cursor_1c\WORK\WIM_FIn` (конфигурация `cf`).

## Структура

- **epf/src/** — XML-исходники обработки `ОткрытиеНастроекДопОбработок`
- **epf/build/** — собранный EPF
- **Документация/** — описание использования
- **Тестирование/** — сценарии проверки
- **Скрипты/** — сборка
- **Расширения/** — не используется (решение через EPF)

## Сборка

```powershell
powershell.exe -NoProfile -File ".\Скрипты\build.ps1"
```

Или вручную через skill `/epf-build` (при отсутствии базы ФИН в `.v8-project.json` используется временная база со заглушками).

## Использование

1. Файл → Открыть → `epf/build/ОткрытиеНастроекДопОбработок.epf`  
   либо зарегистрировать в справочнике доп. отчетов и обработок.
2. Выбрать элемент справочника.
3. Нажать **Открыть форму настроек**.
4. В форме настроек подтвердить (обычно «Установить» / «ОК» через `ОповеститьОВыборе`).
5. Настройки запишутся в `ХранилищеНастроек` выбранного элемента.

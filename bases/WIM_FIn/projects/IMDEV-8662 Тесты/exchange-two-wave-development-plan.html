  • Пакетные потоки: только БизнесПроцессСсылка.СделкиTn по пулам.

  • Общий пакет: исключить Сделка.
  • Пакетные потоки: только ДокументСсылка.Сделка по пулам.
Перед стартом волны 2 обязательно дождаться завершения всех фоновых заданий волны 1.

// Описание: Настраивает таблицу правил выгрузки для общего пакета и пакетных волн.
//
// Параметры:
// ОбработкаОбмена - ОбработкаОбъект
// ПулСделок - Массив - ссылки БП СделкиTn
// ЭтоПакетСделокTn - Булево - текущий пакет СделкиTn
//
Процедура ПолучениеДанныеXMLПоПравиламКонвертации(ОбработкаОбмена, ПулСделок = Неопределено, ЭтоПакетСделокTn)

    ЭтоПакетСделка = ?(ОбработкаОбмена.Параметры.Свойство("ЭтоПакетСделка"), ОбработкаОбмена.Параметры.ЭтоПакетСделка, Ложь);
    ПулСделка = ?(ОбработкаОбмена.Параметры.Свойство("ПулСделка"), ОбработкаОбмена.Параметры.ПулСделка, Неопределено);

    СтрПравилСделкиTn = НайтиПравилоВыгрузки(ОбработкаОбмена, "СделкиTn", "БизнесПроцессСсылка.СделкиTn");
    СтрПравилСделкаДок = НайтиПравилоВыгрузки(ОбработкаОбмена, "Сделка", "ДокументСсылка.Сделка");

    // Общий пакет: исключаем целевые тяжелые объекты

        Если СтрПравилСделкиTn <> Неопределено Тогда

        Если СтрПравилСделкаДок <> Неопределено Тогда

        КонецЕсли;

        Для Каждого Строка Из ОбработкаОбмена.ТаблицаПравилВыгрузки.Строки Цикл

// Описание: Устанавливает отбор "Ссылка В Списке" для выбранного правила.

Где:
  внешняя обработка внОбменДУ-Финансы3.0(потоки), макет правил;
  общий модуль VTB_ОбщийМодуль, процедура ВыполнитьОбменДУ_Финансы

Что:

При обмене постоянно происходят события вида: операция не может быть выполнена из-за несоответствия версии или отсутствия записи базы данных (возможно, запись была изменена или удалена). Это сильно замедляет обмен.

В FIN очень медленно идет обработка после загрузки из информационной базы. Дублируются объекты при обработке после обменов по бизнес-процессу СделкиTn.

При выгрузке по потокам объекты разделяются некорректно. В потоке 1 дублируются СделкиTn, в потоках 2-7 дублируются прочие объекты: вместо ссылки выгружаются как объекты. При параллельной загрузке потоков возникают указанные ошибки; при обработке проявляется дублирование.

Способ решения: два изменения в макете правил и одно в VTB_ОбщийМодуль.

1) Макет правил: в правиле конвертации СделкиTn добавить (или проверить) теги:

<НеВыгружатьОбъектыСвойствПоСсылкам>true</НеВыгружатьОбъектыСвойствПоСсылкам>

<СинхронизироватьПоИдентификатору>true</СинхронизироватьПоИдентификатору>

<ПродолжитьПоискПоПолямПоискаЕслиПоИдентификаторуНеНашли>true</ПродолжитьПоискПоПолямПоискаЕслиПоИдентификаторуНеНашли>

<Источник>БизнесПроцессСсылка.СделкиTn</Источник>

<Приемник>БизнесПроцессСсылка.СделкиTn</Приемник>

2) Макет правил: в обработчике <ПередВыгрузкой> для СделкиTn после блока AVANCORE (15.02.2017) вставить строку:

ТолькоПолучитьУзелСсылки = Параметры.Свойство("ЭтоОбщийПакет") И Параметры.ЭтоОбщийПакет; // IMAPPS - 32010

(контекст: перед закрывающим тегом </ПередВыгрузкой>, рядом с комментарием // AVANCORE  - 15.02.2017 })

3) Модуль VTB_ОбщийМодуль, процедура ВыполнитьОбменДУ_Финансы: при подготовке параметров для обмена добавить передачу в ОбработкаXML.Параметры, в частности:

ОбработкаXML.Параметры.Вставить("ДатаНачалаРегистрации", ДатаНачалаРегистрации);

ОбработкаXML.Параметры.Вставить("СписокДоговоров", СписокДоговоров);

ОбработкаXML.Параметры.Вставить("ОбменРГС", ОбменРГС);

ОбработкаXML.Параметры.Вставить("ЭтоОбщийПакет", Не ЭтоПакетСделокTn);

(при необходимости оставить закомментированной отладочную запись журнала регистрации по обмену)

УстановитьУзелОбменаСтрокиДерева(ОбработкаXML.ТаблицаПравилВыгрузки.Строки, УзелОбмена);

В обработчике <ПриЗагрузке> для того же правила вызывается:

Выполнить(Алгоритмы.ПроверкаДатыЗапретаИзмененияДанных_Загрузка); // VTB-Borisov - 05.05.2017

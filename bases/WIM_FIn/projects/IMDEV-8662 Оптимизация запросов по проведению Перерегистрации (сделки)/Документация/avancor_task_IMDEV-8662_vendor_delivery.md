# IMDEV-8662: что перенести в продуктовую конфигурацию (Аванкор)

Задача по оптимизации проведения перерегистрации (сделки). В теле профиля замеров выделены пять «тяжелых» строк; по ним нужны правки в типовой конфигурации. Отдельно - доработка паузы на сервере.

Номера строк в таблице замеров (для трассировки в переписке и комментариях в коде): **137, 1160, 1769, 2485, 2551** и отдельно **пауза** в общем модуле **АванкорСервер**. Для номеров **1160, 1769, 2485, 2551** контекст замера - **модуль объекта документа Сделка**; номер **137** относится к **общему модулю параметров портфеля** (см. раздел 1), не к модулю Сделки.

Рекомендуемый маркер в комментариях к измененным участкам: `// IMDEV-8662, стр. N` (для паузы: `// IMDEV-8662, стр. Пауза`).

---

## 1) Строка замера 137

**Суть:** в модуле параметров портфеля при заполнении служебных параметров учета не вызывать для каждой строки тяжелый `ПривестиЗначение()` типа - вынести получение «пустого» значения параметра в отдельную функцию и вызывать ее из цикла.

**Объект:** общий модуль `УправлениеПараметрамиПортфеляПовтИспНаВремяСеанса`, процедура/функция контекста `СлужебныеПараметрыУчета` (не модуль документа «Сделка»).

---

## 2) Строка замера 1160

**Суть:** в текстах запросов блока БУ/НКД по продажам убрать небезопасное обращение к полю `.Дата` у полиморфных ссылок: через конструкции вида `ВЫБОР` + `ТИПЗНАЧЕНИЯ` + `ВЫРАЗИТЬ` получать дату там, где это нужно, и подставлять в текст запроса (в т.ч. через `СтрЗаменить`), чтобы платформа не строила лишние планы и не падает на типах.

**Объект:** модуль объекта документа `Сделка` (тексты запросов «таблицы по продажам БУ» и НКД).

---

## 3) Строка замера 1769

**Суть:** не вызывать `ПолучитьСуммуОНВ` заранее на каждом проведении; вызывать только в той ветке кода, где таблица ОНВ реально используется, с проверкой перед обращением к итогам.

**Объект:** модуль объекта документа `Сделка` (параметры проведения и формирование движений по реализации).

---

## 4) Строка замера 2485

**Суть:** упростить получение таблиц аванса: для основной таблицы не разносить пакет по номерам таблиц, а выполнить один запрос и выгрузить результат; остальную специфику (отдельная таблица по документам авансов) сохранить по смыслу.

**Объект:** модуль объекта документа `Сделка`, функциональность `ТаблицыАванса`.

---

## 5) Строка замера 2551

**Суть:** в цепочке «получить авансы» убрать неиспользуемую ветку по НУ: из текста запроса убрать поле/расчеты `СуммаНУ`, из пустой таблицы остатков - колонку `СуммаНУ`, из дозаполнения зачтенных авансов - расчет коэффициента курса НУ.

**Объект:** модуль объекта документа `Сделка` (текст запроса получения авансов и связанные вспомогательные процедуры).

---

## 6) Пауза (не номер строки профиля, отдельная доработка)

**Суть:** процедура паузы на сервере должна корректно работать и в фоне (прямой вызов платформенной паузы по миллисекундам), и при клиент-серверном вызове (чтобы не блокировать сеанс неправильно) - в т.ч. через вынесение ожидания в фоновое задание.

**Объект:** общий модуль `АванкорСервер`, метод `Пауза` (при необходимости - вспомогательная экспортная обертка для вызова из других контекстов).

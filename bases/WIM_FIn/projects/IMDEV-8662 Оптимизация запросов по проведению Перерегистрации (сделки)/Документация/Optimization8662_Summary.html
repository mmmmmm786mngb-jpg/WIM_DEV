Детальная разбивка доработок FonProv на 5 групп

Ниже расширенная версия с контекстом, файлами, конкретными изменениями и стандартным маркером комментариев.

1) Оптимизация стр. 137

Контекст: общий модуль параметров портфеля, не Документ.Сделка.

Файл:
Расширения/FonProv/CommonModules/УправлениеПараметрамиПортфеляПовтИспНаВремяСеанса/Ext/Module.bsl

Изменения:

  • добавлена функция ПустоеЗначениеПараметраПортфеля(Параметр);
  • перехвачен метод СлужебныеПараметрыУчета через &ИзменениеИКонтроль;
  • в цикле замена: было СтрокаТЗ.Параметр.ТипЗначения.ПривестиЗначение(), стало вызов УправлениеПараметрамиПортфеляПовтИспНаВремяСеанса.ПустоеЗначениеПараметраПортфеля(...).

Маркер-комментарий группы: // IMDEV-8662, стр. 137

2) Оптимизация стр. 1160

Контекст: типобезопасное получение .Дата в тяжелом пакете БУ/НКД.

Файл:
Расширения/FonProv/Documents/Сделка/Ext/ObjectModule.bsl

Изменения:

  • FonProv_ТекстЗапросаТаблицыПоПродажамБУ_БезНКД (&ИзменениеИКонтроль): добавлены блоки ТекстДатаПоСубконто2 и ТекстДатаПоПартии (ВЫБОР + ТИПЗНАЧЕНИЯ + ВЫРАЗИТЬ); добавлены СтрЗаменить для замены прямых .Дата.
  • FonProv_ТекстЗапросаНКД (&ИзменениеИКонтроль): добавлен ТекстДатаПоПартииНКД; замена ВТ_ОстаткиТело.Партия.Дата через СтрЗаменить.

Маркер-комментарий группы: // IMDEV-8662, стр. 1160

3) Оптимизация стр. 1769

Контекст: ленивый вызов ПолучитьСуммуОНВ (не трогаем текст запроса, меняем callsite).

Файл:
Расширения/FonProv/Documents/Сделка/Ext/ObjectModule.bsl

Изменения:

  • FonProv_УстановкаДополнительныхПараметровПроведения (&ИзменениеИКонтроль): удален ранний вызов ТаблицаОНВ = ПолучитьСуммуОНВ();, вместо этого ТаблицаОНВ = Неопределено.
  • FonProv_СформироватьДвиженияРеализация (&ИзменениеИКонтроль): добавлен ленивый вызов ПолучитьСуммуОНВ() только в нужной ветке; добавлена безопасная проверка перед Итог("СуммаОНВ").

Маркер-комментарий группы: // IMDEV-8662, стр. 1769

4) Оптимизация стр. 2485

Контекст: ТаблицыАванса - упрощение выполнения запроса.

Файл:
Расширения/FonProv/Documents/Сделка/Ext/ObjectModule.bsl

Изменения:

  • FonProv_ТаблицыАванса (&Вместо("ТаблицыАванса")):
  • отказ от пакетного сценария с НомераТаблиц;
  • результат основной таблицы формируется через Запрос.Выполнить().Выгрузить();
  • отдельная логика таблицы документов авансов сохранена.

Маркер-комментарий группы: // IMDEV-8662, стр. 2485

5) Оптимизация стр. 2551

Контекст: удаление неиспользуемой ветки СуммаНУ в цепочке авансов.

Файл:
Расширения/FonProv/Documents/Сделка/Ext/ObjectModule.bsl

Изменения:

  • FonProv_ТекстЗапроса_ПолучитьАвансы (&Вместо): из текста запроса убраны поля/расчеты СуммаНУ.
  • FonProv_ПустаяТаблицаОстаткиАвансов (&ИзменениеИКонтроль): удалена колонка СуммаНУ.
  • FonProv_ДобавитьСтрокиЗачтенныхАвансов (&ИзменениеИКонтроль): удален расчет КоэффициентКурсаАвансаНУ.

Маркер-комментарий группы: // IMDEV-8662, стр. 2551

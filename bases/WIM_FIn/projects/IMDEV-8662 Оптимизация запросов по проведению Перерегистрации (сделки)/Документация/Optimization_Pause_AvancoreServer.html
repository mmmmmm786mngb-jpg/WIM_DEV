Оптимизация блока паузы в АванкорСервер

Контекст: задача IMDEV-8662, расширение FonProv, общий модуль АванкорСервер, перехват процедуры Пауза.

Файл доработки: Расширения/FonProv/CommonModules/АванкорСервер/Ext/Module.bsl. Тип перехвата: &Вместо("Пауза"). Дополнительно добавлена процедура ПаузаБСП(Секунд) по аналогии с IMAPPS-31419.

Что было

В базовой реализации пауза выполнялась через внешнюю компоненту ASL, а при ее недоступности использовался fallback через платформенный механизм паузы в секундах.

Это давало зависимость от доступности ВК и не использовало встроенный платформенный механизм ВызватьПаузу для фонового контекста.

Что изменено в расширении

  • Перехвачена процедура Пауза(КолМС) в АванкорСервер через &Вместо.
  • В фоновом контексте используется прямой вызов ВызватьПаузу(КолМС).
  • В клиент-серверном вызове пауза делегируется в ПаузаБСП(Секунд).
  • Добавлена процедура ПаузаБСП(Секунд) с запуском фонового задания и ожиданием завершения.
  • Добавлена нормализация времени: перевод Секунд * 1000 в целое и минимум 1 мс для фонового вызова.

Ключевая идея оптимизации

Сделать поведение паузы стабильным и платформенным:

  • если код уже выполняется в фоне - сразу использовать встроенный ВызватьПаузу;
  • если вызов пришел из клиент-серверного сценария - выполнять паузу через фоновое задание, чтобы избежать ограничений прямого вызова ВызватьПаузу в этом контексте.

Реализация: перехват Пауза

&Вместо("Пауза")
Процедура FonProv_Пауза(КолМС) Экспорт

    ТекущийСеансИнформационнойБазы = ПолучитьТекущийСеансИнформационнойБазы();
    ФоновоеЗадание = ТекущийСеансИнформационнойБазы.ПолучитьФоновоеЗадание();

    Если Не ФоновоеЗадание = Неопределено Тогда
        ВызватьПаузу(КолМС);
    Иначе
        Секунд = Цел(КолМС / 1000);
        Если Секунд <= 0 Тогда
            Секунд = 1;
        КонецЕсли;
        ПаузаБСП(Секунд);
    КонецЕсли;

КонецПроцедуры

Реализация: ПаузаБСП

Процедура ПаузаБСП(Секунд) Экспорт

    ТекущийСеансИнформационнойБазы = ПолучитьТекущийСеансИнформационнойБазы();
    ФоновоеЗадание = ТекущийСеансИнформационнойБазы.ПолучитьФоновоеЗадание();

    Если ФоновоеЗадание = Неопределено Тогда
        Параметры = Новый Массив;
        КолМСДляФона = Цел(Секунд * 1000);
        Если КолМСДляФона <= 0 Тогда
            КолМСДляФона = 1;
        КонецЕсли;
        Параметры.Добавить(КолМСДляФона);

        ФоновоеЗадание = ФоновыеЗадания.Выполнить("АванкорСервер.Пауза", Параметры);
    КонецЕсли;

    Попытка
        ФоновоеЗадание.ОжидатьЗавершенияВыполнения(Секунд);
    Исключение
        Возврат;
    КонецПопытки;

КонецПроцедуры
Важно: доработка выполнена в расширении и не меняет сигнатуру внешнего вызова Пауза(КолМС). Логика перераспределена между перехваченной процедурой и новой ПаузаБСП для безопасной работы в разных режимах выполнения.

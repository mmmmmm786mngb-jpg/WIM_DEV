Как сейчас в базовой конфигурации

Запрос выполняется одним пакетом из трёх частей:

  1. ПОМЕСТИТЬ ВТ_ОстаткиТело — остатки РегистрБухгалтерии.Хозрасчетный.Остатки по счету ПланСчетов.Хозрасчетный.ОблигацииТело, отбор Портфель = &Портфель и Субконто1 = &Облигация.
  2. ПОМЕСТИТЬ ВТ_ОстаткиОНВ — остатки по счету ПланСчетов.Хозрасчетный.ОНВ с теми же отборами.
  3. Итоговый ВЫБРАТЬ: из ВТ_ОстаткиОНВ левое соединение с ВТ_ОстаткиТело, расчет СуммаОНВ * &Количество / ЕСТЬNULL(ВТ_ОстаткиТело.КоличествоОстатокДт, 1).

Зачем менять

По практике учета по облигациям остатков на счете ОНВ чаще всего нет: вторая временная таблица и чтение остатков ОНВ в типовом сценарии дают пустой набор, при этом первая часть пакета всё равно каждый раз материализует ВТ_ОстаткиТело (отдельное обращение к виртуальной таблице остатков по телу).

Цель доработки: не держать отдельную ВТ по телу в пакете, а получить количество по телу только в контексте строк остатка ОНВ — через вложенный запрос в правой части ЛЕВОЕ СОЕДИНЕНИЕ к основной выборке по ОНВ. Тогда при отсутствии строк по ОНВ платформа не строит соединение с «телом» для итоговой выборки (ожидаемое сокращение работы при пустом ОНВ).

Проверка на тестовой базе: план выполнения и фактическое сокращение времени нужно подтвердить замером (технологический журнал / ПВХ) на реальных данных: поведение СУБД может отличаться от идеальной «короткой схемы».

Предлагаемый вариант запроса (одна итоговая выборка)

Идея: одна часть запроса — выборка из Хозрасчетный.Остатки(..., ОНВ, ...); к ней ЛЕВОЕ СОЕДИНЕНИЕ с подзапросом, который один в один повторяет бывшее наполнение ВТ_ОстаткиТело (тот же период, счет ОблигацииТело, те же параметры). Связь по Субконто1 (облигация). Формула в ВЫБРАТЬ та же.

ВЫБРАТЬ
	ОстаткиОНВ.СуммаОНВ * &Количество / ЕСТЬNULL(ОстаткиТелоВложенный.КоличествоОстатокДт, 1) КАК СуммаОНВ
ИЗ

		ХозрасчетныйОстаткиОНВ.СуммаОстатокДт КАК СуммаОНВ
	ИЗ
		РегистрБухгалтерии.Хозрасчетный.Остатки(
			&Период,
			Счет = ЗНАЧЕНИЕ(ПланСчетов.Хозрасчетный.ОНВ),
			&ВидыСубконто,

				И Субконто1 = &Облигация) КАК ХозрасчетныйОстаткиОНВ

		ЛЕВОЕ СОЕДИНЕНИЕ
		(
		ВЫБРАТЬ
			ХозрасчетныйОстаткиТело.КоличествоОстатокДт КАК КоличествоОстатокДт,
			ХозрасчетныйОстаткиТело.Субконто1 КАК Субконто1
		ИЗ
			РегистрБухгалтерии.Хозрасчетный.Остатки(
				&Период,
				Счет = ЗНАЧЕНИЕ(ПланСчетов.Хозрасчетный.ОблигацииТело),
				&ВидыСубконто,
				Портфель = &Портфель
					И Субконто1 = &Облигация) КАК ХозрасчетныйОстаткиТело
		) КАК ОстаткиТелоВложенный
		ПО ОстаткиОНВ.Субконто1 = ОстаткиТелоВложенный.Субконто1
Семантика результата: при непустых остатках ОНВ строки и расчет СуммаОНВ совпадают с текущим третьим запросом. При пустых остатках ОНВ результат запроса пустой — как сейчас при пустой ВТ_ОстаткиОНВ; далее в коде по-прежнему используется Результат.Пустой() и ТаблицаОНВ.Итог("СуммаОНВ") в местах проведения.

Смысл строк в базовой конфигурации (документ «Сделка»)

Строки 1–4 таблицы относятся к Документ.Сделка.МодульОбъекта (подготовка данных к проведению по БУ и зачету авансов). При продаже/выбытии актива последовательно вызываются подготовка таблиц продажи по бухучету, расчет сумм по облигациям и блок авансов — в плане это четыре запроса к оптимизации. Строка 5 — отдельный общий модуль, см. ниже.

  • Строка 1160 — ТаблицыПоПродажам_БУ (область ПОДГОТОВКА_ДАННЫХ / БУ). Функция собирает большой пакет запросов к регистру бухгалтерии: остатки по счетам актива, переоценке, дисконту, при необходимости дополнительным счетам (облигации, векселя). Текст начинается с ТекстЗапросаТаблицыПоПродажамБУ_БезНКД; для облигаций к пакету добавляются запросы по НКД (и при необходимости по НУ индексируемых облигаций), для векселей — проценты. Результат ВыполнитьПакет() раскладывается по номерам временных таблиц и дальше используется при списании активов и движениях по реализации (см. ветку проведения, где вызывается ТаблицыПоПродажам_БУ).
  • Строка 1769 — ПолучитьСуммуОНВ. Выполняется при включенном БУ. Запрос обращается к остаткам «Хозрасчетный» по счету тела облигаций и по счету ОНВ, затем вычисляется доля суммы ОНВ на количество в текущей сделке (пропорционально остатку тела). Возвращается таблица значений с суммой ОНВ для последующих проводок.
  • Строка 2551 — ПолучитьАвансы. Если зачет авансов не отключен, подбираются счета авансов, формируется текст ТекстЗапроса_ПолучитьАвансы (с учетом субконто «документы расчетов» при необходимости). Выполняется запрос Выполнить(), в результате получается таблица остатков авансов по портфелю, контрагенту и договору для зачета в сделке; при большом числе строк добавляется индекс для ускорения последующей обработки.
  • Строка 2485 — ТаблицыАванса. Готовит структуру данных для зачета авансов: пакет запросов строит временные таблицы по суммам и НКД документа, дополнительным расходам, строкам взаиморасчетов с контрагентом. Результат пакета используется в СформироватьДвиженияЗачетАвансов вместе с таблицей из ПолучитьАвансы.
  • Строка 137 — УправлениеПараметрамиПортфеляПовтИспНаВремяСеанса, функция СлужебныеПараметрыУчета. После запроса к регистру ЗначенияПараметровПортфеля и соединения с ПВХ ПараметрыПортфеля для строк без значения в срезе выполняется цикл: СтрокаТЗ.Значение = СтрокаТЗ.Параметр.ТипЗначения.ПривестиЗначение() — подстановка пустого значения по описанию типа реквизита параметра. В замере по перепроведению накопилось много вызовов (десятки тысяч на пакет сделок); по доле времени точка второстепенна по сравнению с запросом на строке 1160, но даёт заметный вклад при массовом проведении.

Порядок вызовов при проведении (БУ)

Схема отражает цепочку в ОбработкаПроведения и внутри СформироватьДвиженияБУ: сначала подготовка параметров и ОНВ, затем движения по бухучету с ветвлением по виду операции. Связь между четырьмя точками замера в модуле «Сделка» (строки 1–4 таблицы): ПолучитьСуммуОНВ выполняется отдельно и раньше блока зачёта авансов; ТаблицыПоПродажам_БУ при выбытии идёт перед зачётом авансов и не передаёт данные напрямую в ТаблицыАванса / ПолучитьАвансы. ТаблицыАванса и ПолучитьАвансы вызываются подряд внутри СформироватьДвиженияЗачетАвансов и вместе питают ПодготовитьТаблицуВзаиморасчетовЗачетАвансов. Строка 5 таблицы (УправлениеПараметрамиПортфеляПовтИспНаВремяСеанса, строка 137) на схеме не показана: это другой модуль, вызовы при проведении не укладываются в ту же линейную цепочку БУ.

Узлы «Поступление» / «Выбытие» — взаимоисключающие ветки из СформироватьДвиженияБУ (ObjectModule.bsl, строки около 5380–5470). Диаграмма строится Mermaid; при отключённом интернете откройте текстовый вариант ниже.

Текстовая последовательность
  1. ОбработкаПроведения вызывает УстановкаДополнительныхПараметровПроведения, внутри — ПолучитьСуммуОНВ.
  2. Затем СформироватьДвиженияБУ: при поступлении сразу СформироватьДвиженияЗачетАвансов; при выбытии сначала ТаблицыПоПродажам_БУ, затем СформироватьДвиженияЗачетАвансов.
  3. Внутри зачёта авансов: сначала ТаблицыАванса (пакет по данным документа), затем ПолучитьАвансы (остатки из учёта), затем подготовка таблицы взаиморасчётов и проводки.

# Тестирование IMAPPS-39438

Внешняя обработка сравнения двух отсевов пар клиент+УК после заполнения как в обработке «Формирование начислений НДФЛ», вариант 2.

## Файл

`IMAPPS39438_CompareTurnoverFilter.epf` — открыть как внешнюю обработку в ФИН20.

## Что делает

1. Набирает исходный список тем же методом, что кнопка Заполнить обычного варианта: `ЗаполнитьДокументамиНаДату` (вариант 2). На форме те же отборы, что в типовой обработке: период, **управляющая компания** (обязательна), клиент, «по закрытым портфелям», «по закрытым с поступлением НКД», схема выплаты. Оба флажка закрытых портфелей по умолчанию включены.
2. Для каждой пары клиент+УК смотрит обороты Хозрасчетного за год даты окончания периода.
3. Отсев по постановке: нет оборота по счетам `90.01, 91.01.02, 91.01.03, 91.01.04, 91.01.09, 91.01.99`.
4. Отсев по широкому списку: нет оборота по счетам Общих оборотов без 68.01 (`90.01, 90.02, 91.01.02, 91.01.09, 91.02.*, 91.03, 91.04`).
5. В таблицу попадают только отличия двух отсевов. Пары без оборотов по обоим спискам в таблицу не входят (они в счетчике «Оба отсекают»).

## Виды строк в таблице

- «Отсекает только постановка (Jira)» — оборот есть по широкому списку (комиссии, себестоимость, 91.03 и т.п.), по счетам постановки оборота нет.
- «Отсекает только широкий список» — оборот есть по счетам постановки, которых нет в Общих оборотах (91.01.03, 91.01.04, 91.01.99).

Списки счетов на форме можно править перед сравнением.

# IMAPPS39438_EmptyTurnover

Расширение IMAPPS-39438 к обработке `ФормированиеНачисленийНДФЛ`. Назначение: Customization.

После штатного `ЗаполнитьДатыДокументов` в ТЧ остаются пары клиент+УК: сначала по выбранному пулу (если флажок включён), затем по оборотам доходов. Оба флажка по умолчанию выключены. Умолчание счетов: `90.01, 91.01, 91.03`. Умолчание пула: константа `ПулРозницаДУ` (или элемент «Розничное ДУ»).

Модуль объекта: перехват `&После` и две процедуры отбора в области `IMAPPS39438`. Модуль менеджера не заимствован. Заимствован справочник `Пул` как тип реквизита.

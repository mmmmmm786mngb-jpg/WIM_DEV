# IMAPPS39438_EmptyTurnover

Расширение IMAPPS-39438 к обработке `ФормированиеНачисленийНДФЛ`. Назначение: Customization.

После штатного `ЗаполнитьДатыДокументов` в ТЧ остаются пары клиент+УК с оборотами по счетам доходов. Флажок по умолчанию выключен. Умолчание счетов: `90.01, 91.01, 91.03`.

Модуль объекта: перехват `&После` и одна процедура отбора в области `IMAPPS39438`. Модуль менеджера не заимствован.

# IMAPPS-39438 Доработка обработки Формирование начислений НДФЛ

База: WIM_FIn (ФИН20). Обработка: `ФормированиеНачисленийНДФЛ`.

Задача Jira: флажок не создавать начисление, если у пары клиент+УК нет оборотов по счетам доходов. На форме умолчание `90.01, 91.01, 91.03` (префикс раскрывает субсчета). Старые пустые документы не удалять.

Продолжение IMDEV-7330 (скорость и параллельные пачки той же обработки).

## Папки

- `IMAPPS-39438.doc` - выгрузка постановки Jira.
- `Документация/` - анализ для разработки.
- `Расширения/` - расширение `IMAPPS39438_EmptyTurnover`.
- `Тестирование/` - внешняя обработка сравнения листьев Jira vs умолчания `90.01, 91.01, 91.03`; клиенты из постановки и регресс флага.
- `Скрипты/` - служебные скрипты при появлении расширения.

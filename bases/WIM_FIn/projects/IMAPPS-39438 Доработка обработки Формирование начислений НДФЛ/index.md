# IMAPPS-39438 Доработка обработки Формирование начислений НДФЛ

База: WIM_FIn (ФИН20). Обработка: `ФормированиеНачисленийНДФЛ`.

Задача Jira: флажок не создавать начисление, если у пары клиент+УК нет оборотов по счетам доходов из постановки (90.01, 91.01.02, 91.01.03, 91.01.04, 91.01.09, 91.01.99). Старые пустые документы не удалять.

Продолжение IMDEV-7330 (скорость и параллельные пачки той же обработки).

## Папки

- `IMAPPS-39438.doc` - выгрузка постановки Jira.
- `Документация/` - анализ для разработки.
- `Расширения/` - расширение `IMAPPS39438_EmptyTurnover` (после согласования анализа).
- `Тестирование/` - внешняя обработка сравнения отсева Jira vs Общие обороты; клиенты из постановки и регресс флага.
- `Скрипты/` - служебные скрипты при появлении расширения.

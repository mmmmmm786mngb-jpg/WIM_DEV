# IMAPPS-39438 - документация

Отбор клиентов без оборотов по счетам доходов при заполнении обработки "Формирование начислений НДФЛ". Это логика отбора, не ускорение расчета (ускорение и пачки - проект IMDEV-7330).

## Постановка

- `../IMAPPS-39438.doc` - выгрузка Jira (16.09.2026). Флаг, список счетов, зерно "клиент / все портфели", примеры Абайдулина / Абайдулова / Абакарова.

## Для разработки

- [imapps39438_analysis_empty_turnover_filter.html](imapps39438_analysis_empty_turnover_filter.html) - технический анализ: хранение счетов, точка встройки в Заполнить, запрос оборотов, перехваты расширения `IMAPPS39438_EmptyTurnover`, риски и тесты.
- Тестовая обработка `IMAPPS39438_CompareTurnoverFilter` - сверка отсева по счетам постановки и по широкому списку доходов (постановка плюс остальные счета доходов, без расходов 91.02) на списке Заполнить варианта 2.

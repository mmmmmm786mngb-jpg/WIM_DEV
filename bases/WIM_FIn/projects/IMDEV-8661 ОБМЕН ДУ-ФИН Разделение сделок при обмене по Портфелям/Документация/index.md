# IMDEV-8661 - Документация по обмену ДУ-ФИН

## Состав документов

- `../ТЗ - одноволновой обмен ДУ-ФИН.html` - **ТЗ для разработки**: смысл, схема работы, приложение с кодом.
- `../Двухволновой обмен - кратко.html` - кратко простыми словами (пример с расчетом времени; вариант с двумя волнами).
- `current-exchange-algorithm.md` - как сейчас работает многопоточный обмен в обработке `внОбменДУ-Финансы3.0(потоки)`.
- `implementation-options.md` - варианты реализации идеи двухволнового обмена для разделения `СделкиTn` и `Документ.Сделка`.
- `../exchange-two-wave-implementation-guide.html` - полное руководство и код изменений (Приложение 1).

// q01_array: То же, что q01_plan_reg_oper_du_day_by_pool_or_portfolio_list.txt, но список портфелей
//            задаётся массивом &МассивПортфелей, а не таблицей значений.
//
// Параметры:
//   &ДатаНач, &ДатаКон     - границы периода по дате плана
//   &ТолькоПул             - Булево: Истина = все непомеченные портфели пула &Пул; Ложь = режим массива
//   &Пул                   - СправочникСсылка.Пул
//   &МассивПортфелей       - Массив из СправочникСсылка.Портфели (при &ТолькоПул = Ложь). При &ТолькоПул = Истина
//                            допустим пустой массив — вторая ветка ОБЪЕДИНИТЬ не даст строк
//   &ФильтрПулВСписке      - Булево: при &ТолькоПул = Ложь и Истина — из массива остаются только портфели с Пул = &Пул
//
// Отбор: портфели и планы без пометки удаления.

////////////////////////////////////////////////////////////////////////////////

// Временная таблица портфелей отбора

////////////////////////////////////////////////////////////////////////////////



ВЫБРАТЬ

	П.Ссылка КАК Портфель

ПОМЕСТИТЬ ВТ_ПортфелиОтбора

ИЗ

	Справочник.Портфели КАК П

ГДЕ

	&ТолькоПул

	И НЕ П.ПометкаУдаления

	И П.Пул = &Пул



ОБЪЕДИНИТЬ ВСЕ



ВЫБРАТЬ

	П.Ссылка КАК Портфель

ИЗ

	Справочник.Портфели КАК П

ГДЕ

	НЕ &ТолькоПул

	И НЕ П.ПометкаУдаления

	И П.Ссылка В (&МассивПортфелей)

	И (НЕ &ФильтрПулВСписке ИЛИ П.Пул = &Пул)

;



////////////////////////////////////////////////////////////////////////////////

// Планы за период по отбору портфелей

////////////////////////////////////////////////////////////////////////////////



ВЫБРАТЬ

	План.Ссылка КАК ПланСсылка,

	План.Дата КАК Дата,

	План.Номер КАК Номер,

	План.Портфель КАК Портфель,

	План.Проведен КАК Проведен,

	План.ГруппаОперацийПользователя КАК ГруппаОперацийПользователя

ИЗ

	Документ.ПланРегламентныхОперацийДУ КАК План

		ВНУТРЕННЕЕ СОЕДИНЕНИЕ ВТ_ПортфелиОтбора КАК Отбор

		ПО План.Портфель = Отбор.Портфель

ГДЕ

	План.Дата МЕЖДУ &ДатаНач И &ДатаКон

	И НЕ План.ПометкаУдаления



УПОРЯДОЧИТЬ ПО

	План.Портфель,

	План.Дата,

	План.Номер

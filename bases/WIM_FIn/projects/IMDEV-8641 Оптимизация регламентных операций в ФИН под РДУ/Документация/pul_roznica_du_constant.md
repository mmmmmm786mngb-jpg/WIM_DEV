# Константа ПулРозницаДУ (IMDEV-8641)

## Назначение

Эталон пула «розница ДУ» для шага 1 фильтра плана регламентных операций: алгоритм срабатывает только если константа **заполнена** и все портфели в таблице плана на день имеют `Справочник.Портфели.Пул`, равный значению константы.

## Метаданные (типовая конфигурация)

Константа **`ПулРозницаДУ`** входит в **основную** конфигурацию WIM_FIn (Аванкор ДУ), не зависит от расширения RduPF.

| Проверка | Результат (выгрузка `WORK/WIM_FIn/src/cf`, 2.8.5.x) |
|----------|------------------------------------------------------|
| Объект | `Constants/ПулРозницаДУ.xml` |
| Состав | `Configuration.xml` → `<Constant>ПулРозницаДУ</Constant>` |
| Тип | `СправочникСсылка.Пул` |
| Синоним | Пул розницы ДУ |
| Права | `Roles/БазовыеПрава` — `Constant.ПулРозницаДУ` |

Чтение в коде (EPF и черновик RduPF):

```bsl
ЗначениеКонстантыПулРозницаДУ = ОбщегоНазначенияДУПовтИсп.ПолучитьЗначениеКонстанты("ПулРозницаДУ");
```

Реализация: `ОбщегоНазначенияДУПовтИсп.ПолучитьЗначениеКонстанты` → `Константы[ИмяКонстанты].Получить()`.

Дубликат метаданных в черновике `Расширения/RduPF/Constants/ПулРозницаДУ.xml` при **отключённом** RduPF в ИБ не используется.

## Значение в информационной базе

Метаданные и **заполненность значения** — разные вещи.

- Пустая константа → ранний выход фильтра, таблица плана **не меняется** (шаг 1 не пройден).
- Перед тестом EPF в ИБ нужно указать элемент справочника **Пул** (розница ДУ) в настройках константы.

Проверка скриптом (COM, без авторизации):

```powershell
[Console]::OutputEncoding = [System.Text.Encoding]::UTF8
$env:PYTHONIOENCODING = "utf-8"
python "bases/WIM_FIn/projects/IMDEV-8641 .../Скрипты/check_pul_roznica_du_constant.py"
```

Ожидаемый вывод при корректной ИБ: `metadata_PulRoznicaDU: OK`; для рабочего теста фильтра — `value_filled: YES`.

Проверено на `Srvr=localhost; Ref=WIM_FIN` (03.06.2026): метаданные OK, значение не заполнено.

## Связь с внедрением

| Компонент | Роль |
|-----------|------|
| Типовая CF | объект константы |

| RduPF (черновик, ИБ выкл.) | источник кода для переноса в EPF |

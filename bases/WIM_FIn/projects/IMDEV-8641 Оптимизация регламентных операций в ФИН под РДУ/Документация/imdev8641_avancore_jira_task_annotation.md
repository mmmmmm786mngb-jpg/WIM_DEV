## Тема задачи (Summary)

IMDEV-8641 — RduPF (WIM_FIn): оптимизация регламентного закрытия периода для пула «розница ДУ».

---

## Цели

* Сократить время массового закрытия при однородных портфелях пула «розница ДУ», не удаляя строки плана: автоматически снимать признак выполнения (**Выполнять**) там, где по учётным данным операция для портфеля не нужна.
* Не создавать лишний документ **ПланРегламентныхОперацийДУ** и не вызывать создание плана по группе, если для новой группы нет ни одной строки к выполнению и документа плана ещё не было; при этом обрабатывать **остальные группы** в том же вызове.

---

## Что меняем (смысл для исполнителя)

1. **Перед** помещением таблицы плана на день в соответствие по дням (**ПланРеглОперацийПоДням.Вставить**) в заимствованной обработке **ГрупповоеВыполнениеЗакрытияПериодов** вызывается процедура **ОтфильтроватьПланРеглОперацийНаДень** менеджера регистра **ВидыОптимизируемыхРегламентныхОперацийДУ**. Она может менять только колонку **Выполнять** (0/1), строки плана не удаляются.
2. Фильтр включается только если заполнена константа **ПулРозницаДУ** и все строки плана на день относятся к портфелям этого пула; иначе таблица не трогается (детали и алгоритм — в ТЗ, разделы 4 и 6).
3. По видам операций из регистра и результатам отбора портфелей пересчитывается **Выполнять**; для пяти поддерживаемых видов закрытия логика отбора — в модуле менеджера РС (раздел 8 ТЗ, таблица 8.1).
4. Во втором перехвате (**СформироватьРеглОперацииПоГруппе**) при «пустой» группе без существующего плана выполняется **Продолжить** по циклу групп — без создания документа плана и без вызова **СоздатьПланРегламентныхОперацийДУ** для этой группы.

## Объекты: какие новые, какие изменяемые

### Новые объекты (добавлены в расширении RduPF)

| Объект | Назначение |
|--------|------------|
| Константа **ПулРозницаДУ** | Ссылка на элемент справочника **Пул**; граница сценария «розница ДУ». Чтение в коде через **ОбщегоНазначенияДУПовтИсп.ПолучитьЗначениеКонстанты("ПулРозницаДУ")**. |
| Регистр сведений **ВидыОптимизируемыхРегламентныхОперацийДУ** | Непериодический, независимая запись; измерение **ВидОперации** (элементы **ВидыОперацийЗакрытияПериода**). Формы списка и записи. Модуль менеджера: отбор портфелей и **ОтфильтроватьПланРеглОперацийНаДень**. Модуль набора записей в выгрузке может быть пустым. |

### Изменяемые объекты (заимствования из базовой конфигурации, правки только в расширении)

| Объект | Что делается в RduPF |
|--------|----------------------|
| Справочники **ВидыОперацийЗакрытияПериода**, **Пул** | Заимствование для типов в метаданных; типовая логика справочников не переписывается. |
| Обработка **ГрупповоеВыполнениеЗакрытияПериодов** | В модуле объекта: перехват **ВыполнитьМногопоточноеЗакрытиеПериодовПортфелей** (вставка вызова фильтра плана); перехват **СформироватьРеглОперацииПоГруппе** (пропуск группы с **Продолжить** при условиях из ТЗ, раздел 9). |

### Данные (не код расширения)

Первичное заполнение регистра **ВидыОптимизируемыхРегламентныхОперацийДУ** по пяти видам из таблицы 8.1 ТЗ — задача сопровождения информационной базы по согласованию с владельцем метаданных и эксплуатацией.

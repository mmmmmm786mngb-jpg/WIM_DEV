Документация на разработку IMDEV-8772

Тема: устранение лишней отмены и повторного проведения документа Сделка при завершении БП после закрытия.
Система: расширение VTB_ExchangeDU (база WIM_FIn).
Задача: IMDEV-8772.
Основание: комментарий в коде по маркеру IMDEV-8772.

1. Цели задачи

  • Сократить время обработки обмена за счет исключения лишнего цикла проведение -> отмена проведения -> повторное проведение для документа Сделка.
  • Сохранить текущую бизнес-логику запуска и завершения шагов бизнес-процесса.
  • Сделать изменение локальным для сценария БП СделкиTn, без влияния на остальные типы БП.

2. Проблема до доработки

В событии Выполнение_ПроведениеДокументовПослеЗагрузки документ Сделка проводился. Затем событие Выполнение_ЗавершениеБППослеЗакрытия вызывало стандартную отмену шагов БП, где происходила отмена проведения документа. После этого шаги БП запускались повторно, и Сделка проводилась второй раз.

Негативный эффект: лишние операции записи и проведения увеличивали общее время обработки обмена.

3. Способ реализации

3.1 Изменение точки входа завершения БП

В модуле CommonModules/ExchDU_ОбработкаОбъектовПослеЗагрузки/Ext/Module.bsl в процедуре Выполнение_ЗавершениеБППослеЗакрытия добавлена развилка:

  • Для БП СделкиTn рассчитывается флаг БезОтменыПроведенияСделки.
  • При истинном флаге вызывается новая процедура с параметром запрета отмены проведения сделки.
  • Для остальных сценариев сохраняется старый вызов ОтменитьШагиБизнесПроцессаАвтоматически.
БезОтменыПроведенияСделки = ТипБП = "СделкиTn" И Не БПСсылка.ПометкаУдаления И Не Ошибки;
Если БезОтменыПроведенияСделки Тогда
    БизнесПроцессы[ТипБП].ExchDU_ОтменитьШагиБизнесПроцессаАвтоматически(БПСсылка, БезОтменыПроведенияСделки);
Иначе
    БизнесПроцессы[ТипБП].ОтменитьШагиБизнесПроцессаАвтоматически(БПСсылка);
КонецЕсли;

3.2 Новая процедура в менеджере БП СделкиTn

В модуле BusinessProcesses/СделкиTn/Ext/ManagerModule.bsl добавлена экспортная процедура:

Процедура ExchDU_ОтменитьШагиБизнесПроцессаАвтоматически(БизнесПроцесс, БезОтменыПроведенияСделки = Ложь) Экспорт

Она повторяет базовый алгоритм отмены шагов БП, но при обработке документов БП применяет условие:

Если БезОтменыПроведенияСделки И ТипЗнч(ТекДок) = Тип("ДокументСсылка.Сделка") Тогда
    Продолжить;
Иначе
    ДокОбъект = ТекДок.ПолучитьОбъект();
    ДокОбъект.Записать(РежимЗаписиДокумента.ОтменаПроведения);
КонецЕсли;

4. Детализация изменений по объектам

  • Общий модуль: ExchDU_ОбработкаОбъектовПослеЗагрузки - добавлен условный вызов специальной процедуры для СделкиTn.
  • Менеджер БП: СделкиTn - добавлена процедура отмены шагов с параметром управления отменой проведения.
  • Поведение: стандартная логика для других БП не изменена.

5. Ожидаемый результат

  • Документ Сделка не проходит лишний цикл отмены и повторного проведения в событии завершения БП после закрытия.
  • Сокращается суммарное время обработки обмена по сценарию БП СделкиTn.
  • Поведение обмена для остальных бизнес-процессов остается совместимым с прежней логикой.

Результат по задаче: устранен лишний технический цикл проведения для Сделки в сценарии IMDEV-8772.

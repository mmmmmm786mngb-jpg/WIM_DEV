# Источники данных по процедурам закрытия (таблица operation_closure_procedure_document_map)

Назначение: для каждой процедуры из [operation_closure_procedure_document_map.html](operation_closure_procedure_document_map.html) зафиксировать **основной источник строк табличных частей** (запросы к регистрам / документам / РС) и связь с **появлением проведенного документа**.

Источник кода: выгрузка конфигурации WIM_FIn, общий модуль `ИсполняемыеПроцедурыЗакрытияПериода`, модули объектов перечисленных документов.

---

## Общее правило записи (`ЗаписатьРегламентнуюОперацию`)

В модуле `ИсполняемыеПроцедурыЗакрытияПериода` процедура **ЗаписатьРегламентнуюОперацию** задаёт поведение:

| Условие | Поведение |
|---------|-----------|
| **ПризнакПроведения = Истина** | Проверка заполнения, запись, проведение (или запись без проведения при ошибке проверки). |
| **ПризнакПроведения = Ложь** и документ **уже существовал** (не новый) | Запись + **пометка на удаление**. |
| **ПризнакПроведения = Ложь** и документ **новый** | **Запись в ИБ не выполняется** (ветка отсутствует): в базе не появляется нового объекта. |

Поэтому формулировка «документ не будет делаться» в смысле **нет нового проведенного документа** верна, если пустые ТЧ дали **ПризнакПроведения = Ложь**. Для **повторного** запуска по тому же плану ранее созданный подчиненный документ может остаться **записанным с пометкой удаления**, а не исчезнуть физически сразу.

Ниже «пустой первичный отбор» означает: ключевой запрос или список из РС не дал строк для заполнения ТЧ, из которых дальше считается признак проведения.

## 1. Операция_0025_НачислениеПроцентовПоБанковскимСчетамПоГрафикуВыплат

**Документ:** `НачислениеПроцентовПоБанковскимСчетам`  
**Заполнение:** `Документ.ЗаполнитьТЧ()` (модуль объекта документа).

**Лог:** префикс вида «Предварительные данные (N договоров):» в сообщениях относится к **замерам** (охват/диагностика), а не к отдельной процедуре или документу; в сводной HTML-таблице операция описана одной строкой.

**Основные источники данных**

1. **Банковские счета (депозиты и МНО):** запрос к остаткам/оборотам **Хозрасчетный**, **ЕПС**, **ДенежныеСредстваУправленческий** по счетам расчетных/текущих/депозитных с отбором по портфелю и признаку `БанковскиеСчета.НачислениеПроцентов`. Результат: список `БанковскийСчет`. Если запрос **пустой**, дальнейшее заполнение списка начислений по счетам **не выполняется**.
2. **Фильтр по графику:** регистр сведений **ПараметрыРасчетаБанковскихПроцентов** — метод **СписокСчетовДляВыплатПоГрафику** (для `ПоГрафикуВыплат = Истина`). Если список **пустой**, строки в ТЧ **СписокНачислений** / **СписокНачисленийРасчетныеСчета** **не добавляются**.
3. **Депозитные сделки:** регистр сведений **ДепозитныеСделки** — **СписокДепозитныхСделокПоГрафику**. Пустой список — ТЧ **ДепозитныеСделки** не заполняется.

**Расчет сумм:** РС **ПараметрыРасчетаБанковскихПроцентов.РассчитатьНачисленнныеПроценты**, РС **ДепозитныеСделки.РассчитатьНачисленныеПроценты**, РС **ЗаключенныеМНО.РассчитатьНачисленнныеПроценты** (по уже отобранным строкам).

**Признак проведения (в процедуре 0025):** есть строки в **СписокНачислений** или **СписокНачисленийРасчетныеСчета** или **ДепозитныеСделки**.

**Дополнительно:** блок записи в `Операция_0025` выполняется только если в списке операций есть вид **НачислениеПроцентовПоБанковскимСчетамПоГрафику** (`ПоГрафикуВыплат = Истина`); иначе **ЗаписатьРегламентнуюОперацию не вызывается**.

## 2. Операция_0050_ПереводНКДВЗадолженностьЭмитента

**Документ:** `ПереводНКДВЗадолженностьЭмитента`  
**Заполнение:** `ЗаполнитьКупоннымиПериодами()`, при УУ — еще **ЗаполнитьКупоннымиПериодамиПоРЕПО**, **ЗаполнитьКупоннымиПериодамиПоОбратномуРЕПО**, плюс **ЗаполнитьСтруктурныеНоты**, **ЗаполнитьСтарыеКупоны**.

**Основной смысл источника:** сочетание **остатков по облигациям / РЕПО / ЕПС** (в зависимости от вида учета) на дату с **справочником КупонныеПериоды**, отобранным по условиям «окончание купонного периода совпадает с датой операции» (и аналогичные правила для незакрытых периодов). Плюс отдельные запросы по структурным нотам и «старым купонам».

**Признак проведения:** непустые ТЧ **Облигации** и/или (при УУ) **ОблигацииПоСделкамРЕПО**, и/или **СтруктурныеНоты**, и/или **ОблигацииПоСделкамОбратногоРЕПО**, и/или **СтарыеКупоныОблигаций**.

Если **все** перечисленные ТЧ пусты после заполнения — **ПризнакПроведения = Ложь** (документ не проводится; для нового — в ИБ не сохраняется).

## 3. Операция_0140_ОпределениеСделокСОтклонениемЦен

**Документ:** `ОтклонениеЦенСделок`  
**Заполнение:** `ЗаполнитьОтклонения()`.

**Основной источник:** **Документ.Сделка** за календарный день по портфелю (`Проведен`), далее сопоставление с **РС КотировкиЦБНаБирже** (срез) и **РС ЗафиксированныеКотировкиЦБ_НУ** (срез по портфелю) для выявления выхода цены сделки за коридор min/max.

Если **нет проведенных сделок за день** по портфелю (или нет цепочки до строк с отклонением), ТЧ **СделкиСОтклонением** остается пустой.

**Признак проведения:** **СделкиСОтклонением.Количество() > 0**.

## 4. Операция_0058_ПогашениеОблигаций_ДоПереоценки

**Документ:** `ПогашениеОблигаций` (флаги `ЕстьПогашениеОблигаций = Истина`, частичное погашение выключено).

**Предварительное условие в процедуре:** параметр портфеля **ПогашениеОблигацийПослеПереоценки** — если Истина, процедура **выходит без записи** (документ по этой ветке не формируется).

**Заполнение:** `ЗаполнитьСписокОблигаций()` после **ЗаполнитьПоВыбраннымАктивам**.

**Ключевой отбор:** функция справочника **Облигации.ЕстьОблигацииКПогашениюПоДате** для даты и портфеля — при **Ложь** дальнейшее заполнение **ЦенныеБумаги** не выполняется. Источник позиций — **остатки по портфелю** (методы вида **СписокАктивовПоОстаткам** и связанная логика в модуле документа), плюс данные амортизации из **Справочники.Облигации.ПолучитьДанныеАмортизации**.

**Признак проведения:** **ЦенныеБумаги** или **ЦенныеБумагиОбратноеРЕПО** (при ЕПС) с непустым составом.

## 5. Операция_0058_ЧастичноеПогашениеОблигаций

**Документ:** `ПогашениеОблигаций` (`ЕстьЧастичноеПогашение = Истина`).

**Заполнение:** та же **ЗаполнитьСписокОблигаций()**, ветки **ЗаполнитьЦенныеБумагиЧастичноеПогашение**, структурные ноты и обратное РЕПО.

**Тот же ранний фильтр:** **ЕстьОблигацииКПогашениюПоДате** — при отсутствии облигаций к погашению на дату основная часть ТЧ не заполняется.

**Признак проведения:** непустые **ЦенныеБумагиЧастичноеПогашение** и/или **ЦенныеБумагиЧастичноеПогашениеОбратноеРЕПО** и/или **СтруктурныеНоты** и/или **СтруктурныеНотыФиксация**.

## 6. Операция_0032_НачислениеПроцентовПоЗаймамПоГрафикуВыплат

**Документ:** `РасчетПроцентовПоЗаймам` (`ПоГрафикуВыплат = Истина`).

**Заполнение:** `ЗаполнитьНачисление()` (если включен хотя бы один из БУ/УУ/ЕПС в документе после копирования видов учета с портфеля).

**Первичный запрос:** текст **ЗаполнитьНачисление_ТекстЗапроса()** — остатки/обороты по счетам денежных требований (**Хозрасчетный** по строке плана счетов `58.13`, при ЕПС — счета ЕПС денежных требований) по портфелю на дату. Если **Результат.Пустой()** — процедура **сразу выходит**, ТЧ **СписокНачислений** пуста.

**Второй уровень:** регистр сведений **ПараметрыРасчетаПроцентовПоЗаймам** — **СписокЗакладныхДляВыплатПоГрафику**. Если список **пустой** — строки в ТЧ **не добавляются**.

**Признак проведения:** **СписокНачислений.Количество() > 0**.

**Дополнительно:** в `Операция_0032` запись вызывается только при `ПоГрафикуВыплат = Истина` в документе (наличие соответствующего вида операции в списке).

## 7. Операция_0033_НачислениеПроцентовПоЗаймам

**Документ:** `РасчетПроцентовПоЗаймам` (`ПоГрафикуВыплат = Ложь`).

**Начисление:** `ЗаполнитьНачисление()` — тот же **первый запрос по 58.13**; при **пустом результате** выход. Далее **СписокЗакладныхДляНачислениеПоПериодичностиУП** (и отсечение уже начисленных по графику).

**Погашение (если в плане есть операция погашения):** `ЗаполнитьПогашение()` — запрос **ЗаполнитьПогашение_ТекстЗапроса()** по остаткам 58.13; при **пустом** — выход; иначе **СписокЗакладныхДляПогашенияПоГрафику** из **ПараметрыРасчетаПроцентовПоЗаймам**.

**Признак проведения:** **СписокНачислений** или **СписокПогашений** не пусты.

## 8. Операция_0080_СписаниеПросроченныхОблигаций

**Документ:** один или несколько **ДефолтнаяОперация** (по **ВидСобытия**).

**Первичный источник набора видов событий:** менеджер документа **ДефолтноеСобытиеЭмитента.СтатусыЭмитентовПортфеля(Дата, Портфель)** — таблица свернутая по **ВидСобытия**. Если для портфеля **нет релевантных статусов/событий**, цикл по созданию документов **не создает новых** `ДефолтнаяОперация`.

Для каждого события вызывается **ЗаполнитьСписокДефолтныхОблигаций()**: запросы по **активам портфеля** и списку эмитентов из статусов (детали в модуле документа). Если **Облигации.Количество() = 0**, для **нового** документа запись проведения **не выполняется**; для существующего подчиненного — документ может быть **помечен на удаление** в общей логике процедуры 0080.

**Исключения из цикла:** виды событий **ПрекращениеРасчетаДефолтныхСуммПоОблигациям** / **ПоКупонам** в коде **пропускаются** (отдельные документы по ним в этом цикле не заполняются).

## Замечание для внешней обработки из ТЗ

Проверка «есть ли документ типа X среди **СвязанныеДокументы**» не эквивалентна «были непустые первичные запросы»: документ мог быть создан ранее и помечен на удаление, или существовать непроведенным при особых ветках. Для диагностики «почему нет документа» ориентир — таблица выше и факт **ПризнакПроведения** в коде процедур.

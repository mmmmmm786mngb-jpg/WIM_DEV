// q01d: Количество документов типов из белого списка обработки SubordinateDocsPlanRegOperCheck,
//       у которых ДокументОснование указывает на ПланРегламентныхОперацийДУ за период по тем же портфелям, что q01.
//
// Белый список (имена метаданных документов) синхронизирован с СоответствиеПроцедурИИменДокументов в ObjectModule.bsl EPF.
//
// ВАЖНО: внешняя обработка считает документы через КритерииОтбора.СвязанныеДокументы.Найти(План).
//        Здесь отбор по ДокументОснование = СсылкаПлана — совпадает с типичной связью регламентных документов,
//        но может расходиться с критерием, если платформа связывает дополнительные объекты.
//
// Параметры — как в q01: &ДатаНач, &ДатаКон, &ТолькоПул, &Пул, &ТЗПортфелей, &ФильтрПулВСписке
//
// Отбор: портфели и планы без пометки удаления; подчинённые документы белого списка — без пометки удаления.

////////////////////////////////////////////////////////////////////////////////
// ВТ портфелей (как в q01)
////////////////////////////////////////////////////////////////////////////////

ВЫБРАТЬ
	П.Ссылка КАК Портфель
ПОМЕСТИТЬ ВТ_ПортфелиОтбора
ИЗ
	Справочник.Портфели КАК П
ГДЕ
	&ТолькоПул
	И НЕ П.ПометкаУдаления
	И П.Пул = &Пул

ОБЪЕДИНИТЬ ВСЕ

ВЫБРАТЬ
	Т.Портфель КАК Портфель
ИЗ
	&ТЗПортфелей КАК Т
		ВНУТРЕННЕЕ СОЕДИНЕНИЕ Справочник.Портфели КАК П
		ПО Т.Портфель = П.Ссылка
ГДЕ
	НЕ &ТолькоПул
	И НЕ П.ПометкаУдаления
	И ЗначениеЗаполнено(Т.Портфель)
	И (НЕ &ФильтрПулВСписке ИЛИ П.Пул = &Пул)
;

////////////////////////////////////////////////////////////////////////////////
// Планы за период по отобранным портфелям
////////////////////////////////////////////////////////////////////////////////

ВЫБРАТЬ
	План.Ссылка КАК СсылкаПлана
ПОМЕСТИТЬ ВТ_ПланыОтбора
ИЗ
	Документ.ПланРегламентныхОперацийДУ КАК План
		ВНУТРЕННЕЕ СОЕДИНЕНИЕ ВТ_ПортфелиОтбора КАК Отбор
		ПО План.Портфель = Отбор.Портфель
ГДЕ
	План.Дата МЕЖДУ &ДатаНач И &ДатаКон
	И НЕ План.ПометкаУдаления
;

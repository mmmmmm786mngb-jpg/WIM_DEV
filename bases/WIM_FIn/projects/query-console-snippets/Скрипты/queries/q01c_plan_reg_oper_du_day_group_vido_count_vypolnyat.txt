// q01c: Строки ТЧ "Операции" планов за сутки с Выполнять = Истина: группировка по ГруппаОперацийПользователя и ВидОперации, количество строк
// Вариант с массивом портфелей: q01c_plan_reg_oper_du_day_group_vido_count_vypolnyat_array.txt
//
// Параметры — как в q01_plan_reg_oper_du_day_by_pool_or_portfolio_list.txt:
//   &ДатаНач, &ДатаКон, &ТолькоПул, &Пул, &ТЗПортфелей, &ФильтрПулВСписке
//
// Смысл количества:
//   КоличествоСтрок — число строк ТЧ Операций (с признаком Выполнять) по всем планам, попавшим в отбор;
//   при нескольких планах с одной группой и одним видом операции строки суммируются.
//   КоличествоПланов — число различных документов ПланРегламентныхОперацийДУ в группе (Группа + ВидОперации).
//
// Отбор: портфели и планы без пометки удаления.

////////////////////////////////////////////////////////////////////////////////
// Временная таблица портфелей отбора (как в q01)
////////////////////////////////////////////////////////////////////////////////

ВЫБРАТЬ
	П.Ссылка КАК Портфель
ПОМЕСТИТЬ ВТ_ПортфелиОтбора
ИЗ
	Справочник.Портфели КАК П
ГДЕ
	&ТолькоПул
	И НЕ П.ПометкаУдаления
	И П.Пул = &Пул

ОБЪЕДИНИТЬ ВСЕ

ВЫБРАТЬ
	Т.Портфель КАК Портфель
ИЗ
	&ТЗПортфелей КАК Т
		ВНУТРЕННЕЕ СОЕДИНЕНИЕ Справочник.Портфели КАК П
		ПО Т.Портфель = П.Ссылка
ГДЕ
	НЕ &ТолькоПул
	И НЕ П.ПометкаУдаления
	И ЗначениеЗаполнено(Т.Портфель)
	И (НЕ &ФильтрПулВСписке ИЛИ П.Пул = &Пул)
;

////////////////////////////////////////////////////////////////////////////////
// Агрегация по группе (шапка плана) и виду операции (ТЧ), только Выполнять = Истина
////////////////////////////////////////////////////////////////////////////////

ВЫБРАТЬ
	План.ГруппаОперацийПользователя КАК ГруппаОперацийПользователя,
	СтрОп.ВидОперации КАК ВидОперации,
	КОЛИЧЕСТВО(*) КАК КоличествоСтрок,
	КОЛИЧЕСТВО(РАЗЛИЧНЫЕ План.Ссылка) КАК КоличествоПланов
ИЗ
	Документ.ПланРегламентныхОперацийДУ КАК План
		ВНУТРЕННЕЕ СОЕДИНЕНИЕ ВТ_ПортфелиОтбора КАК Отбор
		ПО План.Портфель = Отбор.Портфель
		ВНУТРЕННЕЕ СОЕДИНЕНИЕ Документ.ПланРегламентныхОперацийДУ.Операции КАК СтрОп
		ПО План.Ссылка = СтрОп.Ссылка
ГДЕ
	План.Дата МЕЖДУ &ДатаНач И &ДатаКон
	И НЕ План.ПометкаУдаления
	И СтрОп.Выполнять

СГРУППИРОВАТЬ ПО
	План.ГруппаОперацийПользователя,
	СтрОп.ВидОперации

УПОРЯДОЧИТЬ ПО
	ГруппаОперацийПользователя,
	ВидОперации

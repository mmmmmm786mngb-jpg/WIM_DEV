# Project query-console-snippets

Project on WIM_FIn: query texts for the 1C query console (and related `.bsl` snippets under `Скрипты/queries/`).

## Base configuration path

Read **../../source-path.txt** relative to this project folder. Do not copy base sources into the repo.

## Layout

- **Расширения/** — configuration extensions (if needed)
- **Документация/** — specs and notes
- **Тестирование/** — tests; **reports/** for run outputs
- **Скрипты/queries/** — query text files (`.bsl` or plain snippets)

## Requirements

- 1C:Enterprise platform 8.3.21 or newer

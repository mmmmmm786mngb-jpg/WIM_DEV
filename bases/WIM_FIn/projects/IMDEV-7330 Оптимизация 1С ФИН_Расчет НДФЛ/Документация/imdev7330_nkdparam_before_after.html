IMDEV-7330. Было / стало: отказ от параметра сеанса

Расширение IMDEV7330_NkdParam. Массовый кэш расходов НКД больше не кладётся в ПараметрыСеанса.ОбщиеЗначения. Ссылка на то же Соответствие идёт аргументом до lookup.
В двух фразах Кэш как жил на обработке в Перем СтруктураКэшНКД, так и живёт. Меняется только доставка до РасходыПоНКДПоВидуОбращаемости: не через сеанс и ХранилищеЗначения, а параметром вызова (как обороты портфеля: Перем ВнешнийКэшОборотов).

1. Что ломалось

ПараметрыСеанса.ОбщиеЗначения - это не переменная модуля. Тип - ХранилищеЗначения. Платформа при каждом Получить() десериализует весь мешок общих значений сеанса, при каждом Установить сериализует его целиком обратно. Ключ "КэшНКД" сидел внутри этого мешка.

Замер PFF 6 потоков: около 43% собственного времени потока - сериализация/десериализация сеанса в модуле менеджера УК (УстановитьВнешнийКэшНКДРасходов ~0.88 с/вызов, ПолучитьВнешнийКэшНКДРасходов ~2.61 с/вызов). Это не SQL и не блокировки.

2. Где лежит кэш

Было сеанс

Обработка.Перем СтруктураКэшНКД
        |
        |  УстановитьВнешнийКэшНКДРасходов
        v
ПараметрыСеанса.ОбщиеЗначения     <- ХранилищеЗначения
        |   ключ "КэшНКД"
        |  ПолучитьВнешнийКэшНКДРасходов
        v
РасходыПоНКДПоВидуОбращаемости    lookup КлючКэшаНКД

На каждый документ УК: Get + Insert + новый ХранилищеЗначения. На каждый lookup расходов: снова Get всего мешка. Плюс три сброса Установить(Неопределено) в РассчитатьНДФЛ (Д-2), иначе ключ залипал до конца сеанса.

Стало ссылка

Обработка.Перем СтруктураКэшНКД
        |
        |  РассчитатьНДФЛ(СтруктураКэшНКД)
        v
Документ УК.Перем ВнешнийКэшНКД   <- только расширение
        |
        |  аргумент по стеку менеджера
        v
РасходыПоНКДПоВидуОбращаемости(...., ВнешнийКэшНКД)
        lookup КлючКэшаНКД, без сеанса

Один объект Соответствие в памяти обработки. Документ держит ссылку в Перем объекта (менеджер её не видит, поэтому дальше параметр). Сбрасывать сеанс нечего.

Почему две «переменные», а не одна Перем модуля объекта документа видна перехватам объекта (РассчитатьНДФЛ, РасчетНДФЛ_ИнвестиционныйВычет), но не видна модулю менеджера. Поэтому имя параметра в РассчитатьНДФЛ - ВнешнийКэшНКДПараметр (чтобы не совпасть с Перем), а по стеку менеджера - уже ВнешнийКэшНКД. Образец: портфель, ПараметрыРасчетаВнешн / ВнешнийКэшОборотов. В типовую CF переменную объекта не кладём заранее.

4. Три точки, где сеанс уходит

4.1. Обработка: больше не пишем в сеанс

Было - СоздатьНачислениеНДФЛПоУК

МенеджерНачисленияУК = Документы.НачислениеНДФЛПоУправляющейКомпании;
Если СтруктураКэшНКД <> Неопределено Тогда
    МенеджерНачисленияУК.УстановитьВнешнийКэшНКДРасходов(СтруктураКэшНКД);
КонецЕсли;
Попытка
    НачислениеНДФЛПоУК.РассчитатьНДФЛ();
Исключение
    Если СтруктураКэшНКД <> Неопределено Тогда
        МенеджерНачисленияУК.УстановитьВнешнийКэшНКДРасходов(Неопределено);
    КонецЕсли;
    ВызватьИсключение;
КонецПопытки;
Если СтруктураКэшНКД <> Неопределено Тогда
    МенеджерНачисленияУК.УстановитьВнешнийКэшНКДРасходов(Неопределено);
КонецЕсли;

Стало

// IMDEV-7330 Кэш НКД передаётся параметром,
// без ПараметрыСеанса.ОбщиеЗначения.
НачислениеНДФЛПоУК.РассчитатьНДФЛ(СтруктураКэшНКД);

Попытка вокруг расчёта жила только ради сброса сеанса при исключении. Кэш на обработке остаётся, следующий документ той же пачки получит ту же ссылку. Неопределено (пачка меньше порога 2) - штатный путь запроса.

4.2. Документ УК: больше не чистим сеанс

Было - три вызова Д-2 / конца процедуры

Процедура РассчитатьНДФЛ() Экспорт

    Если Не ПроверитьЗаполнениеУКИКлиента() Тогда
        Документы....УстановитьВнешнийКэшНКДРасходов(Неопределено);
        Возврат;
    КонецЕсли;
    ...
    Если СписокПортфелей.Количество() = 0 Тогда
        ...УстановитьВнешнийКэшНКДРасходов(Неопределено);
        Возврат;
    КонецЕсли;
    ...
    Документы....УстановитьВнешнийКэшНКДРасходов(Неопределено);

КонецПроцедуры

Стало

Перем ВнешнийКэшНКД;   // модуль объекта, только расширение

Процедура РассчитатьНДФЛ(ВнешнийКэшНКДПараметр = Неопределено) Экспорт

    ВнешнийКэшНКД = ВнешнийКэшНКДПараметр;

    Если Не ПроверитьЗаполнениеУКИКлиента() Тогда
        Возврат;
    КонецЕсли;
    ...

Ранние Возврат больше не трогают сеанс: чистить нечего. Следующий документ - новый объект, обработка снова передаёт СтруктураКэшНКД.

4.3. Lookup: читаем аргумент, не сеанс

Функция РасходыПоНКДПоВидуОбращаемости(ВидыОбращаемости, Клиент, Дата)

    ВнешнийКэш = ПолучитьВнешнийКэшНКДРасходов();
    Если ВнешнийКэш <> Неопределено Тогда
        КлючКД = КлючКэшаНКД(Клиент, Дата);
        ПоКД = ВнешнийКэш.Получить(КлючКД);
        Если ПоКД <> Неопределено Тогда
            Возврат ПоКД;
        КонецЕсли;
    КонецЕсли;

    Запрос = Новый Запрос;
    ...
Функция РасходыПоНКДПоВидуОбращаемости(
    ВидыОбращаемости, Клиент, Дата, ВнешнийКэшНКД = Неопределено)

    Если ВнешнийКэшНКД <> Неопределено Тогда
        КлючКД = КлючКэшаНКД(Клиент, Дата);
        ПоКД = ВнешнийКэшНКД.Получить(КлючКД);
        Если ПоКД <> Неопределено Тогда
            Возврат ПоКД;
        КонецЕсли;
    КонецЕсли;

    Запрос = Новый Запрос;
    ...  // тело запроса без изменений

Между ними - только проброс последнего аргумента: РасчетНДФЛ_ИнвестиционныйВычет берёт Перем объекта и отдаёт в РезультатРасчетаИнвестиционногоВычета, дальше ОтразитьУКДиНКДВИнвестВычете, ИнвестиционныйВычетУКД.

5. Что осталось как было

МестоПочему не трогаем
Перем СтруктураКэшНКД обработки, ИнициализироватьКэшНКДПоМассивуПар Сбор кэша один раз на пачку. Меняется только транспорт
КлючКэшаНКД, ПолучитьРасходыПоНКДПоКлиентам Lookup и построение кэша те же
Форма документа УК: РассчитатьНДФЛ() без аргумента Дефолт Неопределено - путь запроса, как раньше
Вызов из менеджера портфеля (пять аргументов) Шестой = Неопределено. Кэш обработки туда не несём
УстановитьВнешнийКэшНКДРасходов / ПолучитьВнешнийКэшНКДРасходов в типовой CF Расширение не умеет удалить процедуры типовой. На пути массового формирования они больше не вызываются. Удалить целиком - при вливе в типовую (см. ТЗ)
Расширение vs типовая Перехват &ИзменениеИКонтроль не может добавить параметр, которого нет в типовой. Пять сигнатур с последним необязательным = Неопределено уже в CF 2.8.7.5. Перем ВнешнийКэшНКД - только в расширении. Типовые Установить / Получить пока живут мёртвым кодом.

6. Зачем это быстрее

БылоСтало
Запись кэша на документ УК Deserialize всего ОбщиеЗначения + Insert + новый ХранилищеЗначения Присвоение ссылки в Перем
Чтение кэша в lookup Снова deserialize всего мешка сеанса Чтение аргумента / Перем
Сброс Обязателен (иначе ключ до конца сеанса). Три точки в РассчитатьНДФЛ + обработка Не нужен. Объект документа не таскает кэш в следующий сеанс
Исключение посреди расчёта Без Попытка ключ залипал в сеансе Сеанс не участвует

1. Проблема и цель

Массовый предрасчёт НКД (IMDEV-7330-4) уже строится один раз на пачку в обработке ФормированиеНачисленийНДФЛ (Перем СтруктураКэшНКД, ПолучитьРасходыПоНКДПоКлиентам). Для передачи в расчёт документа УК кэш кладётся в ПараметрыСеанса.ОбщиеЗначения. Платформа при каждом ХранилищеЗначения.Получить() десериализует весь мешок общих значений сеанса, а при Установить сериализует его целиком. Это не SQL и не межсеансовые блокировки.

Место (модуль менеджера УК) Код Сумма own, 6 потоков На поток Вызовов с / вызов
~стр. 3294 УстановитьВнешнийКэшНКДРасходов ОбщиеЗначения = ПараметрыСеанса.ОбщиеЗначения.Получить() 449 с~75 с5100.88
~стр. 3320 ПолучитьВнешнийКэшНКДРасходов то же Получить() 429 с~71 с1642.61
~стр. 3307 ПараметрыСеанса.ОбщиеЗначения = Новый ХранилищеЗначения(...) 137 с~23 с5130.27
~стр. 3301 ОбщиеЗначения.Удалить(КлючКэша) 118 с~20 с1710.69

Цель: кэш остаётся в памяти и передаётся ссылкой (без копирования таблиц ПоПартиям / ПоРегистраторам, как сейчас при попадании в кэш: Возврат ПоКД). Строки 3294 и 3320 из замера исчезают.

Запрещено Глобальная Перем в модуле менеджера документа. В 1С модуль менеджера не даёт экземплярной переменной для этого сценария. Слот в памяти — только Перем модуля объекта (как обороты портфеля) плюс параметр вызова.

Для УК делаем то же: необязательный параметр в типовой + Перем модуля объекта в расширении (в базовую CF переменную не класть). Дальше по стеку менеджера параметр обязателен, потому что менеджер не видит Перем объекта.

Не смешивать две функции с одним именем У документа портфеля в модуле объекта есть своя РасходыПоНКДПоВидуОбращаемости(ПараметрыРасчета, ВидыОбращаемости). Её не трогать. Меняется только функция модуля менеджера УК РасходыПоНКДПоВидуОбращаемости(ВидыОбращаемости, Клиент, Дата).

Имя формального параметра может быть ВнешнийКэшНКДПараметр, чтобы не совпадать с Перем (как у портфеля: параметр ПараметрыРасчетаВнешн, переменная ВнешнийКэшОборотов).

Ранние Возврат (пустой клиент/УК, пустой список портфелей) больше не чистят сеанс: кэш не в параметрах сеанса. Сброс Перем не нужен — объект документа после расчёта не переиспользуется как долгоживущий кэш-носитель для следующего клиента в том же смысле, что сеанс: следующий документ — новый объект, обработка передаёт тот же СтруктураКэшНКД заново.

Документирующий комментарий (экспорт): описать параметр ВнешнийКэшНКДПараметр — Соответствие или Неопределено, ключ КлючКэшаНКД(Клиент, Дата), значение структура ПоПартиям / ПоРегистраторам.

5.8. Удаление Установить / Получить

После п. 5.1, 5.2, 5.7 в типовой CF не должно остаться ссылок на УстановитьВнешнийКэшНКДРасходов и ПолучитьВнешнийКэшНКДРасходов (поиск по конфигурации обязателен: обработка формирования, три места в РассчитатьНДФЛ, lookup в РасходыПоНКДПоВидуОбращаемости). Процедуры удалить целиком, включая комментарии IMDEV-7330-4 про ОбщиеЗначения.

Пустые заглушки не оставлять: любой оставшийся вызов снова запишет кэш в хранилище.

8. Приёмка и регресс

Функционал

  1. Форма документа УК: кнопка расчёта без обработки формирования — суммы как до доработки (путь запроса, кэш не передаётся).
  2. Обработка «Формирование начислений НДФЛ», пачка из 1 строки (кэш не строится, порог 2) — документы УК считаются запросом, результат как раньше.
  3. Та же обработка, пачка заведомо больше порога: кэш строится один раз, каждый документ УК получает срез по своему КлючКэшаНКД. Суммы инвествычета / НКД совпадают с контрольным прогоном без кэша (или с эталоном до доработки) на одной и той же выборке.
  4. Исключение внутри РассчитатьНДФЛ не оставляет хвоста в ПараметрыСеанса.ОбщиеЗначения по ключу КэшНКД (ключа больше нет).
  5. Документ портфеля: расчёт инвествычета через менеджер УК без шестого аргумента компилируется и даёт прежний результат.

Производительность

  1. Повтор PFF 6 потоков на том же стенде: в модуле менеджера УК не должно быть горячих строк ПараметрыСеанса.ОбщиеЗначения.Получить() / Новый ХранилищеЗначения в контуре НКД.
  2. Ожидание: исчезновение ~189 с own на поток (сумма четырёх строк таблицы в разделе 1). Абсолютная цифра зависит от размера мешка сеанса и объёма кэша.

Техконтроль

  • Глобальный поиск по CF: нет УстановитьВнешнийКэшНКДРасходов, нет ПолучитьВнешнийКэшНКДРасходов, нет ключа "КэшНКД" в присвоении ОбщиеЗначения.
  • Нет Перем кэша НКД в модуле менеджера.
  • Ключевые слова 1С в стандартном регистре (Не, И, Или, Тогда).
  • Экспортные процедуры — документирующий комментарий по стандарту проекта.

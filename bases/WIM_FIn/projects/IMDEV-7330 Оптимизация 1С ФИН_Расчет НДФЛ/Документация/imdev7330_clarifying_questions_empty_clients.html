НДФЛ: счета для нового флажка

Кому: Анастасия Михайлова. IMDEV-7330 - ускорение. Дополнительно к нему нужна новая логика: не создавать расчет НДФЛ, если у клиента нет оборотов по счетам 90.

Решение уже принято. На форму обработки «Формирование начислений НДФЛ» добавим флажок: не создавать расчет НДФЛ, если у клиента нет оборотов по счетам 90.

Нужно уточнить только одно: по каким именно счетам смотреть обороты.

Счета, которые уже участвуют в расчете НДФЛ

План счетов «Хозрасчетный». Счета учета в табличной части «Общие обороты» документа «Начисление НДФЛ по портфелю». Документы ниже - типичные, которые делают проводку на этот счет.

Доработка типовой 1С ФИН 2.8.7.5: убрать кэш НКД из ПараметрыСеанса.ОбщиеЗначения / ХранилищеЗначения, передать ссылку на Соответствие последним необязательным параметром (как РассчитатьНДФЛ(ПараметрыРасчетаВнешн) у документа по портфелю). Полное ТЗ: Документация/imdev7330_tz_nkd_cache_pass_by_param.html. Этот файл — карта объектов и точные сигнатуры для переноса в типовую.

Дерево доработок: параметр внешнего кэша НКД

IMDEV-7330. As-is: типовая 2.8.7.5 после влива IMDEV7330_Fix. Новый параметр везде последний, тип Соответствие или Неопределено, значение по умолчанию Неопределено = текущий путь запроса. Существующие вызовы без аргумента остаются валидными (форма УК, портфель стр. 1622, тесты).

Что сделать в тестовой / типовой CF сначала

  • В типовую / тестовую CF — только параметр в 5 процедурах таблицы ниже. Тела пока можно не менять.
  • Перем ВнешнийКэшНКД в типовую не добавлять: новая переменная модуля объекта в расширении.
  • Не менять сигнатуры документа портфеля, регистра инвествычетов, формы УК.

Легенда

  • сигнатура добавить последний параметр с умолчанием
  • Перем только расширение (не типовая заранее)
  • вызов передать аргумент / убрать сеанс (тела, второй шаг)
  • удалить процедуры сеансового кэша после снятия вызовов
  • без изменений сигнатуру не трогать

Имя параметра у РассчитатьНДФЛ — ВнешнийКэшНКДПараметр, чтобы не совпасть с этой Перем (как у портфеля: параметр ПараметрыРасчетаВнешн, переменная ВнешнийКэшОборотов). В менеджере параметра модуля нет — имя ВнешнийКэшНКД.

Вендор: Аванкор. В рамках IMDEV-7330 доработки выполняются в расширении NDFL_RDU. Основной объем изменений локализован в перехватах расширения. Отдельно зафиксированы изменения сигнатур в базовой CF (см. карточку "Источник структуры").

Дерево изменяемых объектов и процедур расширения NDFL_RDU

Дерево собрано по материалам IMDEV-7330: таблица замеров и реализованные оптимизации расчета НДФЛ (массовый предрасчет, параллельные пачки, контроль пустых документов УК, исправление справки-расчета НДФЛ к удержанию при пустых строках удержаний).

Основные зоны оптимизации IMDEV-7330

Карта ниже показывает фактические точки изменения в расширении NDFL_RDU по объектам и перехватам, без сводного списка сценариев в этом блоке.

Легенда групп доработок

строка 1 массовый предрасчет и кэш ОбщиеОбороты по портфелям
строка 2 кэш расходов НКД по связке клиент-дата для УК
параллельные пачки оркестратор и фоновое выполнение по пачкам
оптимизация запросов замена тяжелых запросов на массовые/табличные параметры
контроль записи запрет записи пустых документов начисления по УК
баг: справка НДФЛ исправление падения в справке-расчёте к удержанию при пустых строках удержаний
баг яркая метка: исправление ошибки выполнения, не зона производительности.

План доработок
1) Подготовка входных данных в СоздатьДокументы
В Обработка.ФормированиеНачисленийНДФЛ.Процедура СоздатьДокументы добавить подготовительный этап до цикла Для каждого СтрокаДокументов Из ДатыДокументов Цикл.
На этом этапе:
собрать массив клиентов с учетом текущих отборов;
по клиентам собрать общий массив портфелей;
убрать дубли портфелей (через Соответствие или промежуточную ТаблицаЗначений).
Ввести флаг режима, например МногопортфельныйРасчет = Истина, если массив портфелей не пустой.
2) Изменение сценария создания документов
До внутреннего цикла по каждому портфелю:
создать один документ для даты через НайтиСоздатьДокументПоПортфелю(ПустойПортфель, СтрокаДокументов.Дата).
Важно: определить единый безопасный маркер ПустойПортфель (пустая ссылка нужного типа), чтобы не ломать логику поиска/создания документа.

Точки вставки кода
Ниже - конкретно куда вставляем и что именно.

Обработка.ФормированиеНачисленийНДФЛ, модуль объекта, процедура СоздатьДокументы

Куда вставка: перед основным циклом Для каждого СтрокаДокументов Из ДатыДокументов Цикл.
Что вставляем: подготовительный блок сбора уникальных клиентов по тем же отборам, что и основной цикл.
Результат блока: МассивКлиентов для дальнейшего получения портфелей.
Обработка.ФормированиеНачисленийНДФЛ, модуль объекта, функция СписокПортфелей (или новая СписокПортфелейПоКлиентам)

Куда вставка: в эту функцию (или рядом новая функция).
Что вставляем: поддержку входа не только из СтрокаДокументов, но и из МассивКлиентов.
Результат блока: единый МассивПортфелей по всем клиентам, без дублей.
Обработка.ФормированиеНачисленийНДФЛ, модуль объекта, процедура СоздатьДокументы

Куда вставка: после формирования МассивПортфелей, но до внутреннего портфельного цикла.
Что вставляем: вызов
ТехДок = НайтиСоздатьДокументПоПортфелю(ПустойПортфель, СтрокаДокументов.Дата); и затем вызов нового экспортного метода документа для массового расчета.
Результат блока: получаем кэш таблиц оборотов по всем портфелям.
Документ.НачислениеНДФЛПоПортфелю, модуль объекта (в вашем расширении NDFL_RDU)

Куда вставка: новая экспортная функция, например ПолучитьОбщиеОборотыПоПортфелям(МассивПортфелей) Экспорт.
Что вставляем: внутри создаем ЛокПараметры = ПараметрыРасчета();, добавляем Портфели, считаем:
ОбщиеОбороты(ЛокПараметры)
ОбщиеОбороты(ЛокПараметры, Истина) и раскладываем обе таблицы в Соответствие вида Портфель -> Таблица.
Результат блока: возврат структуры с двумя кэшами:
ОборотыПоПортфелю
ОборотыПрошлыйГодПоПортфелю
Документ.НачислениеНДФЛПоПортфелю, модуль объекта (в NDFL_RDU)

Куда вставка: новая служебная функция, например РазложитьТаблицуОборотовПоПортфелю(ТаблицаОборотов).
Что вставляем: универсальный алгоритм группировки строк по полю Портфель в отдельные ТаблицаЗначений.
Результат блока: переиспользуемая функция для текущего и прошлого года.
Обработка.ФормированиеНачисленийНДФЛ, модуль объекта, место где сейчас делается

ПараметрыРасчета.Вставить("ОбщиеОбороты", ОбщиеОбороты(...));
ПараметрыРасчета.Вставить("ОбщиеОборотыПрошлыйГод", ОбщиеОбороты(..., Истина));
Куда вставка: прямо в этом месте.
Что вставляем: заменяем прямые вызовы на чтение из подготовленного кэша:
Кэш.ОборотыПоПортфелю.Получить(ТекПортфель)
Кэш.ОборотыПрошлыйГодПоПортфелю.Получить(ТекПортфель)
Результат блока: без повторных тяжелых вызовов ОбщиеОбороты внутри цикла.
Обработка.ФормированиеНачисленийНДФЛ, модуль объекта, функция НайтиСоздатьДокументПоПортфелю

Куда вставка: точечная проверка логики поиска/создания для пустого портфеля.
Что вставляем: защита от дублей "технического" документа с пустым портфелем на ту же дату.
Результат блока: стабильный контейнер для массового предрасчета.
Если нужно, следующим сообщением дам это же в формате "чек-лист внедрения 1-2-3" для поэтапной реализации в NDFL_RDU без риска регрессии.

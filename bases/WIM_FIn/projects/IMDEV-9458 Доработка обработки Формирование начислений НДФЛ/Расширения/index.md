# IMDEV9458_EmptyTurnover

Расширение IMDEV-9458 к обработке `ФормированиеНачисленийНДФЛ`. Назначение: Customization.

После штатного `ЗаполнитьДатыДокументов` в ТЧ остаются пары клиент+УК: сначала по выбранному пулу (если флажок включён; «Розничное ДУ» - РДУ, пустое поле - не-РДУ), затем по оборотам доходов. Оба флажка по умолчанию выключены. Умолчание счетов: `90.01, 91.01, 91.03`. Пул не подставляется.

Модуль объекта: перехват `&После` и две процедуры отбора в области `IMDEV9458`. Модуль менеджера не заимствован. Заимствован справочник `Пул` как тип реквизита.

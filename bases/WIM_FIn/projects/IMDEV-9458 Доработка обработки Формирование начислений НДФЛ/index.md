# IMDEV-9458 Доработка обработки Формирование начислений НДФЛ

База: WIM_FIn (ФИН20). Обработка: `ФормированиеНачисленийНДФЛ`.

Задача перенесена из IMAPPS-39438 в проект IM Development: `IMDEV-9458`.

Задача Jira: флажок не создавать начисление, если у пары клиент+УК нет оборотов по счетам доходов. На форме умолчание `90.01, 91.01, 91.03` (префикс раскрывает субсчета). Дополнительно: флажок и выбор пула («Розничное ДУ» - РДУ, пустое поле - не-РДУ). Старые пустые документы не удалять.

Продолжение IMDEV-7330 (скорость и параллельные пачки той же обработки).

## Папки

- `IMDEV-9458.doc` - выгрузка постановки Jira.
- `Документация/` - анализ для разработки.
- `Расширения/` - расширение `IMDEV9458_EmptyTurnover`.
- `Тестирование/` - внешняя обработка сравнения листьев Jira vs умолчания `90.01, 91.01, 91.03`; клиенты из постановки и регресс флага.
- `Скрипты/` - служебные скрипты при появлении расширения.

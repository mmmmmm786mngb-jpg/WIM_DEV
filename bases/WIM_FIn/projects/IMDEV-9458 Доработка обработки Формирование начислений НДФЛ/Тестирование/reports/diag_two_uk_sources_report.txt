IMDEV-9458. Источники начисления документа УК
Дата документов: 30.12.2026 23:59:59

Схема РассчитатьНДФЛ документа УК (если константа НачислениеНДФЛПоПортфелю = Ложь):
  A. СведенияИзВнешнейСистемы -> регистр НДФЛСведенияОДоходахПоУправляющейКомпании
     (флаг СведенияИзВнешнейСистемы), любые коды
  B. Обращающиеся ЦБ -> Хозрасчетный, коды 1530 / 1544 (ИИС)
  C. Необращающиеся ЦБ -> Хозрасчетный, коды 1531 / 1545 (ИИС)
  D. Срочные контракты -> коды 1533, 1532/1546, 1535/1548
  E. Депозиты -> код 3020
  F. Погашенные купоны -> код 1011 либо 1530/1531 (если купон учитывают в 1530/1531)
  G. РЕПО -> коды 1537 / 1551 (ИИС)
  H. Операции с валютой -> код 2900
  I. Дивиденды -> код 1010 либо коды из ДоходыПоДивидендам_ПоКодамДохода
  J. Прочие доходы -> код 4800
  K. НачисленияИзСтороннихСистем -> регистр НДФЛСведенияОДоходах, Система <> своя

Если константа НачислениеНДФЛПоПортфелю = Истина:
  УК берет строки из регистра НДФЛСведенияОДоходах (движения документов по портфелю).
  Тогда ветки A-J на УК не вызываются, источник - портфельный документ / регистр доходов.

Константы, влияющие на ветку расчета:
  НачислениеНДФЛПоПортфелю = Нет
  ПогашенныйКупонныйДоходУчитыватьВКодахДохода1530и1531 = Нет
  ДоходПоПаямУчитыватьВКодахДохода1530и1531 = Нет
  НачислятьНДФЛПоУКПриПуловомПоступленииДивидендов = Нет

IMDEV-9458. Просим включить доработку в базовую конфигурацию обработки «Формирование начислений НДФЛ».

Суть. На форме два дополнительных отбора (оба по умолчанию выключены).

1. Флажок «В заполнение включать только клиентов с доходами» и поле счетов справа. Умолчание счетов: 90.01, 91.01, 91.03. Если флажок включён, после штатного заполнения в таблице остаются пары клиент + УК, у которых за период есть обороты по этим счетам или доход из сторонних систем (ПИФ и другие, регистр сведений о доходах НДФЛ). Без оборотов по счетам и без дохода ПИФ пара отсекается.

2. Флажок «Создавать начисления только по клиентам выбранного пула» и поле пула справа (видно только при включённом флажке). Пул выбирают вручную. «Розничное ДУ» - клиенты РДУ. Пустое поле - клиенты не-РДУ (портфели без заполненного пула). Само ничего не подставляется. После заполнения остаются пары клиент + УК, у которых есть хотя бы один портфель с выбранным (в том числе пустым) пулом. Признак - реквизит портфеля «Пул», не номер договора.

Расчёт НДФЛ и документ «Начисление НДФЛ по портфелю» не меняются.

Референс. Расширение IMDEV9458_EmptyTurnover (Customization). Просим перенести точечно в типовую и расширение снять. Аннотации &После в типовую не копировать. Комментарии IMDEV-9458 оставить.

Что трогать. Только обработка ФормированиеНачисленийНДФЛ: четыре реквизита объекта, форма «Форма», модуль объекта, модуль формы. Модуль менеджера и документ начисления не менять.

Как встраивать.
1. В конец штатной ЗаполнитьДатыДокументов: вызов ОставитьТолькоПарыСПулом(), затем ОставитьТолькоПарыСОборотами().
2. В модуль объекта скопировать две процедуры (в расширении с префиксом IMDEV9458_ - в типовой префикс снять). Область IMDEV9458.
3. В конец штатной УправлениеФормой: умолчание счетов и видимость поля счетов; видимость поля пула. Пул не подставлять. Отдельный перехват ПриСозданииНаСервере не нужен.
4. На форме в ГруппаОтборПраво две горизонтальные группы: флажок со счетами и флажок с пулом. У обоих флажков ПриИзменении - вызов УправлениеФормой.

Код и приёмка - во вложении imdev9458_avancor.html.

Приёмка. Оба флажка выключены - список как сейчас. Вариант заполнения 2, период по 01.09.2026: Абайдулина, Абайдулова, Абакарова в таблице нет. Тот же прогон по 02.09.2026: трое появляются (купон 91.01.02). Флажок доходов: нет оборотов по счетам, но есть доход ПИФ - пара остается. Флажок пула и «Розничное ДУ»: только РДУ. Флажок пула и пустое поле: только не-РДУ.

# IMDEV-9458 - документация

Отбор клиентов без оборотов по счетам доходов при заполнении обработки "Формирование начислений НДФЛ". При включенном флаге пара клиент + УК остается и тогда, когда дохода по счетам нет, но есть доход из сторонних систем (ПИФ). Это логика отбора, не ускорение расчета (ускорение и пачки - проект IMDEV-7330).

Задача передана из отдела поддержки приложений в разработку: прежний номер IMAPPS-39438, текущий IMDEV-9458.

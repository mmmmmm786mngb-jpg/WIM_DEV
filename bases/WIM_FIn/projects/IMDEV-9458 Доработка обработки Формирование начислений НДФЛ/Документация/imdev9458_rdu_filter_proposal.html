IMDEV-9458 · предложение

Отбор клиентов РДУ при заполнении начислений НДФЛ

Флаг из комментария к задаче оставляем. Рядом, когда он включен, выбирают пул. «Розничное ДУ» - клиенты РДУ. Пустое поле - клиенты не-РДУ. Само ничего не подставляется. Признак РДУ берем не из номера договора «МИИ», а из пула портфеля.

Что просят в задаче

Добавить флажок Создавать начисления только по клиентам РДУ. При включении в список должны попадать клиенты, у которых есть хотя бы один портфель РДУ.

В комментарии РДУ определили так: портфели, номер договора которых начинается с «МИИ». Это удобный визуальный ориентир в списке, но в ФИН это не основной признак.

Почему не номер «МИИ»

Тип клиента «физическое лицо» в ФИН общий: и розничное ДУ, и прочие договоры физлиц. Префикс в номере или наименовании портфеля — это представление договора в ДУ, а не классификатор в учете.

Основной признак уже есть в карточке портфеля: реквизит Пул. Для розницы это элемент справочника пулов Розничное ДУ. Этот признак передается из ДУ в ФИН и уже используется в задачах закрытия периода и отбора плановых операций (IMAPPS-36224, IMAPPS-36274, IMDEV-8641).

Как определять РДУ

РДУ В поле выбирают Розничное ДУ. Портфель относится к РДУ, если Портфели.Пул равен этому элементу (эталон также в константе «Пул розницы ДУ»).
Не-РДУ Поле пула оставляют пустым. Это клиенты не-РДУ: портфели, у которых пул не заполнен.
Не использовать Номер договора / наименование портфеля, начинающиеся с «МИИ». Тип клиента. Любой текстовый разбор кода. Автоподстановка «Розничное ДУ».

Как фильтровать при заполнении

  1. Новый флажок, по умолчанию выключен. Синоним: «Создавать начисления только по клиентам выбранного пула».
  2. Справа от флажка, только когда он включен, поле выбора пула. Для РДУ выбирают «Розничное ДУ». Пустое поле - клиенты не-РДУ (портфели без заполненного пула). Само ничего не подставляется.
  3. Штатное заполнение работает как сейчас: физлица, открытые портфели, выбранные УК и клиенты.
  4. Если флаг включен, из табличной части оставляем только пары клиент + УК, у которых есть хотя бы один неудаленный портфель с выбранным пулом. Срок жизни портфеля - тот же, что у заполнения (открыт на дату / период обработки).
  5. Если одновременно включен отбор по оборотам доходов, сначала сужаем список до выбранного пула, затем проверяем обороты по счетам.

Зерно «клиент + УК» совпадает с уже принятым отбором по оборотам и с документами начисления. Формулировка «хотя бы один портфель РДУ» из комментария сохраняется, но внутри пары, а не «любой УК клиента».

Пример

Клиент Есть портфель с пулом «Розничное ДУ» в УК «НВМ» и другой портфель физлица без этого пула в той же УК.
Флаг выключен Пара попадает в заполнение, если проходит остальные отборы.
Флаг включен Пара клиент + «НВМ» остается: есть хотя бы один портфель РДУ. Пара того же клиента с другой УК, где розничного пула нет, не остается.

Форма

Флажок в той же правой группе отборов, под отбором по оборотам. Справа от флажка - поле «Пул». Пока флажок выключен, поле скрыто. Пул выбирают вручную: «Розничное ДУ» для РДУ, пустое поле для не-РДУ.

По активным портфелям ИИС

Спасибо за комментарий и скрин карточки. Разобрали постановку и сверили с текущим кодом обработки «Формирование начислений НДФЛ».

Как мы поняли требование

Активные портфели ИИС не должны попадать в формирование начислений. По карточке портфеля:

  • «Тип клиента» = «Индивидуальные инвестиционные счета»;
  • «Дата окончания» не заполнена (договор ещё открыт).

Правило относится к кнопке «Создать» (набор портфелей и запись документов), а не к «Заполнить» (только список клиентов).

Дерево: когда ИИС берётся в документ по УК

Документ «Начисление НДФЛ по УК» собирает портфели так:

Создать → документ по УК (вид операции «Физическое лицо»)
│
├─ Дата документа = 31.12  и  уже включён «Итоговый расчёт»
│  └─ берём ВСЕ ИИС клиента по этой УК
│     (в т.ч. открытые, с пустой датой окончания)
│
└─ Иначе (обычный день / первый проход без итогового флага)
   └─ по каждому ИИС:
      ├─ дата окончания пустая?
      │  └─ НЕ берём  ← активный ИИС
      ├─ закрыт вне выбранного налогового года
      │  или позже даты документа?
      │  └─ НЕ берём
      ├─ срок владения для вычета уже выдержан?
      │  └─ НЕ берём
      └─ закрыт в выбранном году, срок не выдержан
         └─ берём  ← закрытие, не «активный»

Дерево: какой документ появляется

Портфель ИИС
│
├─ Начисление по портфелю
│  └─ никогда
│     (обработка берёт только тип «Физические лица»)
│
└─ Начисление по УК
   ├─ ИИС не попал в список портфелей
   │  └─ в документ не идёт
   │
   └─ ИИС попал в список
      ├─ есть суммы к начислению / удержанию
      │  └─ полноценный расчёт
      └─ сумм нет, но заполнены «Выводы» / «Общие расходы»
         └─ документ всё равно могут записать
            (пустым его не считают — ТЧ не пустые)
Примеры.
Только открытый ИИС, дата документа не 31.12 — начисление не создаём.
Обычное ДУ + открытый ИИС — считаем обычное ДУ, открытый ИИС не берём.
ИИС закрыли в выбранном году, срок не выдержан — может попасть в начисление по УК.
Период до 31.12.2026 (налоговый 2026): после первого расчёта у документа на 31.12 включается «Итоговый расчёт». При повторном «Создать» открытые ИИС уже могут попасть в ТЧ «Выводы» / «Общие расходы», даже без строк начисления налога.
Уточнение к формулировке «не создаётся». По активному ИИС отдельного начисления налога (строк «Начисления» / «Удержания») из этой обработки действительно нет, и начисление по портфелю не создаётся. Но на дату итогового расчёта (31.12) открытый ИИС всё же может оказаться внутри документа по УК в служебных табличных частях — документ при этом не отсекается как «пустой».
Вывод. Базовое правило «активный ИИС не должен давать начисление налога» в целом уже соблюдается. Отдельный флажок на форме для этого не нужен. Если требование жёстче — «открытый ИИС вообще не должен попадать ни в какие ТЧ документа по УК, в том числе на 31.12» — это уже доработка отбора портфелей при итоговом расчёте. Подтвердите, пожалуйста, какой вариант имелся в виду.

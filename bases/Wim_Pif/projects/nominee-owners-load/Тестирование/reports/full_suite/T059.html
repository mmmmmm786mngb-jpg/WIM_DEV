T059. Колонка ИНН есть

Введение

Отдельный отчет по виду теста из полного плана начитки списка владельцев номинального держателя. Проверка выполнена через COM-соединение с базой WIM_PIF и/или через веб-клиент Playwright.

Технология

COM (Component Object Model) — внешнее соединение 1С через pywin32 и объект V83.COMConnector. Это не HTTP: Python вызывает методы модуля объекта обработки внутри сеанса информационной базы.

Параметры строки соединения: Srvr (сервер), Ref (имя базы), Usr/Pwd (пользователь), App (имя приложения), Locale (язык сеанса).

Примеры подключения:

pythoncom.CoInitialize()
com = win32com.client.Dispatch("V83.COMConnector")
# 1) серверная база с пользователем admin
conn = com.Connect("Srvr='localhost';Ref='WIM_PIF';Usr='admin';Pwd='1';App='PyCOM';Locale=ru_RU;")
# 2) файловая база
conn = com.Connect("File='D:\\Bases\\Demo';Usr='admin';Pwd='1';App='PyCOM';Locale=ru_RU;")
# 3) попытка без пароля (после появления пользователей будет отказано)
conn = com.Connect("Srvr='localhost';Ref='WIM_PIF';App='PyCOM';Locale=ru_RU;")

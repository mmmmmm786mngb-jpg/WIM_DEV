WEB-тест обработки «Заполнение списка владельцев НД»

Введение

Проверка управляемой формы внешней обработки в веб-клиенте WIM_PIF после публикации на Apache и исправления отбора фондов. База разработческая, данные с префиксом WEBFIX_.

Технология

COM (Component Object Model, pywin32) готовит фонд, номинального держателя, пайщика и Excel. Затем Playwright открывает веб-клиент и проходит форму как пользователь.

Строка COM:

Srvr='localhost';Ref='WIM_PIF';App='PyCOM';Locale=ru_RU;

Примеры подключения:

Srvr='localhost';Ref='WIM_PIF';App='PyCOM';Locale=ru_RU;
Srvr='localhost';Ref='WIM_PIF';Usr='Admin';Pwd='';App='PyCOM';Locale=ru_RU;
File='C:\Bases\WIM_PIF';Usr='Admin';Pwd='';App='PyCOM';Locale=ru_RU;

Примеры запросов:

ВЫБРАТЬ Ссылка, Наименование, Используется
ИЗ Справочник.ПИФ
ГДЕ Наименование ПОДОБНО &П1 ИЛИ Наименование ПОДОБНО &П2
ВЫБРАТЬ ПЕРВЫЕ 1 Ссылка
ИЗ Справочник.ДополнительныеОтчетыИОбработки
ГДЕ ИмяОбъекта = &Имя

Примеры вызовов:

conn.ВнешниеОбработки.Создать(epf, False, protection)
proc.ОбеспечитьСвойствоНРДid()
tab_doc.Записать(xlsx_path, conn.ТипФайлаТабличногоДокумента.XLSX)

Обработка открывается в вебе через Файл / открыть EPF: кнопка «Список команд» справочника дополнительных обработок на веб-клиенте падает в БСП (ДополнительныеОтчетыИОбработкиКлиентСервер, переменная Перечисления).

Детали тестов

Запрос фондов, которые форма выбора скрывала:

ВЫБРАТЬ Ссылка, Наименование, Используется
ИЗ Справочник.ПИФ
ГДЕ Наименование ПОДОБНО &П1 ИЛИ Наименование ПОДОБНО &П2

параметры: П1="WEBFIX_%" П2="TEST_ND_%"

Причина, почему поиск фонда не находил карточку 
ФормаВыбора справочника ПИФ при открытии ставит отбор Используется = Истина.
Создание через COM шло с ОбменДанными.Загрузка = Истина, заполнение по умолчанию
(FillValue=true) не срабатывало, Используется оставался Ложь. Карточка в базе была,
в списке выбора ее не было.

Возможности

  • Форма тонкого/веб-клиента открывается, кнопки чтения и сопоставления на месте
  • Старый поиск по НРД id
  • Протокол «не найден»
  • Создание карточки и технических ЛС
  • Документ «Список владельцев номинального держателя»
  • COM-набор (шаг 2а, ФИО+ДР, ИНН, несколько карточек, Excel/XML) закрыт отдельным отчетом

Выводы

Тестовый фонд нужно создавать с Используется = Да, иначе форма выбора ПИФ его не показывает. После установки флага веб-сценарий проходит: файл, поиск по НРД id, протокол, создание, документ.

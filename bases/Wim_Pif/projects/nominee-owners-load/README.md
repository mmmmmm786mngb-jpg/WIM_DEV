# Начитка списка владельцев номинального держателя

Внешняя обработка тонкого клиента для базы WIM_PIF. Регистрируется в справочнике дополнительных отчетов и обработок.

## Что умеет

- Форматы файла: Гарант Excel, XML ВТБ СД, ЦДФ, Гарант Excel NEW
- Пакетный поиск: НРД id, ФИО + дата рождения, имя + отчество + ДР + адрес
- Юрлица по ИНН/ОГРН
- Протокол подмены клиента, замены НРД id, выбора из нескольких
- Создание недостающих карточек, технических ЛС и банковских счетов
- Документ «Список владельцев номинального держателя»
- Анкета найденной карточки не перезаписывается; на шаге 2а пишется новый НРД id

## Сборка и регистрация

Обработка собирается в `build/ЗаполнениеСпискаВладельцевНД.epf` (копия с ASCII-именем `NomineeOwnersLoad.epf` для COM).

В информационной базе элемент справочника дополнительных обработок создается тестом и доступен интерактивно.

## Тесты

COM: `Тестирование/test_nominee_owners_com.py`  
Отчет: `Тестирование/reports/com_web_test_report.html`

Префикс тестовых данных: `TEST_ND_`.

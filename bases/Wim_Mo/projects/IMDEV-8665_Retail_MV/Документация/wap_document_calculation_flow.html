Документ `РасчетСредневзвешеннойСтоимости`: что делает `ЗаполнитьДокумент()` и что пишет при проведении

Отчет описывает поведение "как сейчас" по базовой конфигурации `Wim_Mo`, модули: SRC/CF/Documents/РасчетСредневзвешеннойСтоимости/Ext/ObjectModule.bsl и SRC/CF/Documents/РасчетСредневзвешеннойСтоимости/Ext/ManagerModule.bsl.

1. Точка входа из `СформироватьWAP`

Внешняя обработка в цикле по датам и мандатам делает следующую последовательность:

Док = Документы.РасчетСредневзвешеннойСтоимости.СоздатьДокумент();
Док.Дата   = НачалоДня(ТекДата) + 23*60*60 + 59*60 + 59;
Док.Мандат = Выборка.Мандат;
Док.ЗаполнитьДокумент();
Док.Записать(РежимЗаписиДокумента.Проведение);
То есть вся расчетная логика WAP сосредоточена в документе: обработка только создает объект, задает шапку и инициирует заполнение/проведение.

2. Что делает `ЗаполнитьДокумент()`

2.1. Базовая подготовка

  1. Если `Дата` не заполнена, подставляет `ТекущаяДата()`.
  2. Инициализирует `СообщенияЗаполнения = ""`.
  3. Очищает табличную часть СписокАктивов.
  4. Создает кэш курсов валют (`Соответствие`) для повторных пересчетов.

2.2. Получение входных данных

Ключевой вызов:

СтруктураДанныхРасчета = Документы.РасчетСредневзвешеннойСтоимости.ПолучитьДанныеРасчета(Дата, Мандат);

Из структуры берутся:

  • ВалютыРасчета - список валют для расчета WAP.
  • ТаблицаКотировок - фиксированные котировки на дату (через `МандатДляКотировки`).
  • ЭтоНачалоОтчетногоПериода - флаг источника базы для WAP1.
  • ТаблицаПредыдущихСтоимостей - предыдущие WAP/количество из регистра `СредевзвешеннаяСтоимость`.
  • ТаблицаОпераций - операции дня по активам и счетам.
  • РезультатаЗапроса результат одного запроса из пакета ВыполнитьПакет() с итогами по активу (см. подробнее ниже).

2.2.1. Что именно такое `РезультатаЗапроса`

В модуле менеджера в структуру подставляется тот фрагмент пакета запросов, который в ПолучитьДанныеРасчета() присваивается как РезультатВыполнения[7] (из текста ПолучитьТекстЗапросаЗаполненияДокумента()). Это не «голая таблица», а иерархический результат запроса из-за конструкции ИТОГИ ПО Актив: сначала идут группы по активу, внутри каждой группы - строки по сочетанию актив + счет мандата.

Состав строк детальных записей (внутри группы по активу):

Поле Смысл
СчетМандата Ссылка на Справочник.СчетаМандатов; разрез позиции по счетам внутри мандата.
Актив Ценная бумага (актив) для расчета WAP по этому счету.
ОстатокНаНачало, ОстатокНаКонец Количество по регистру ЦенныеБумаги на начало и конец дня документа (ОстаткиИОбороты между границами дня из параметров запроса). При расчете в модуле объекта для строки документа используется в первую очередь ОстатокНаКонец как текущее количество после движений дня.
Порядок, Период Вспомогательные поля упорядочивания строк внутри группы актива: «хвост» из строк остатков дает порядок 0 и техническую дату; к ним добавляются строки-плейсхолдеры по операциям (нулевые остатки, но свой Порядок и минимальный Период среди операций), чтобы детальный обход следовал нужной последовательности обработки.

Как строки собираются в тексте запроса:

  • Одна часть набора строк приходит из виртуальной таблицы остатков регистра ЦенныеБумаги (ВТ_ТаблицаОстатков): реальные ОстатокНаНачало, ОстатокНаКонец.
  • Вторая часть добавляется из операций за день (ВТ_ТаблицаОпераций): по каждой паре актив + счет мандата + порядку подмешивается строка с нулевыми остатками, но с полями Порядок и минимальным временем операции (Период) для общей сортировки результатов перед итогами.
  • По объединенному набору выполняется свертка (СГРУППИРОВАТЬ ПО СчетМандата, Актив), затем УПОРЯДОЧИТЬ ПО Порядок, Период, затем ИТОГИ ПО Актив.

Как это использует `ЗаполнитьДокумент()`:

ВыборкаАктив = СтруктураДанныхРасчета.РезультатаЗапроса.Выбрать(ОбходРезультатаЗапроса.ПоГруппировкам);
Пока ВыборкаАктив.Следующий() Цикл
    ВыборкаСчета = ВыборкаАктив.Выбрать();
    Пока ВыборкаСчета.Следующий() Цикл
        ... расчет WAP для пары актив + счет, Количество = ВыборкаСчета.ОстатокНаКонец
    КонецЦикла;
КонецЦикла;
Имея в виду: ТаблицаОпераций и тот же пакет отдельно возвращает полный список операций дня для расчета сумм по сделкам, а РезультатаЗапроса задает «каркас» активы и счета с количественными итогами дня для внешнего цикла расчета.

2.3. Основной цикл расчета

  1. По каждой валюте расчета определяется курс к валюте документа расчета.
  2. По каждому активу и счету мандата:
    • читаются предыдущие значения WAP/количества;
    • подбираются операции за день;
    • для переводов между счетами используется кэш рассчитанных источников (`КэшОперацийИсточников`);
    • суммы операций приводятся к текущей валюте расчета.
  3. Для облигаций применяется коэффициент амортизации КоэффициентАмортизацииОблигации(...).
  4. Считаются промежуточные `P0` и `X0`, затем итоговые `WAP1` и `WAP2`.
  5. Если есть ненулевой остаток на конец или ненулевые WAP - добавляется строка в СписокАктивов.
Важная особенность: на начале отчетного периода база для `WAP1_X0` берется из текущей котировки, иначе - из предыдущего WAP1. Для `WAP2_X0` используется предыдущий WAP2.

4. Что пишет `ОбработкаПроведения()`

4.1. Контроль ручной корректировки

Сначала вызывается ПроведениеСервер.РучнаяКорректировкаОбработкаПроведения(...). Если механизм перехватывает проведение, запись движений не выполняется.

4.2. Основная запись движений

Для каждой строки табличной части СписокАктивов создается запись в один регистр сведений:

Регистр Измерения/ключи Ресурсы
РегистрСведений.СредевзвешеннаяСтоимость Период=Дата, Мандат, СчетМандата, Валюта, Актив WAP1, WAP2, Количество
В отличие от MV-документа, здесь нет дополнительного блока "дозануления" через выборку среза предыдущего дня: регистр заполняется только строками текущей табличной части документа.

5. Текстовая диаграмма процесса документа

Создан документ РасчетСредневзвешеннойСтоимости (из внешней обработки)
    -> ЗаполнитьДокумент()
        -> если Дата пустая: Дата = ТекущаяДата()
        -> очистка СписокАктивов
        -> ПолучитьДанныеРасчета(Дата, Мандат)
            -> ПолучитьВалютыРасчета(Дата)
            -> МандатДляКотировки = ВТБ_АлгоритмыРасчета.МандатРозничноеДУ(Мандат)
            -> ВыполнитьПакет() по операциям, остаткам, котировкам, предыдущему WAP
        -> цикл по ВалютыРасчета
            -> цикл по Актив/Счет из результата запроса
                -> сбор операций и предыдущих WAP
                -> пересчет сумм между валютами
                -> расчет WAP1/WAP2 (с учетом отчетного периода и амортизации)
                -> запись строки в СписокАктивов
    -> Записать(Проведение)
        -> ОбработкаПроведения()
            -> проверка ручной корректировки
            -> для каждой строки СписокАктивов запись движения в:
                -> РегистрСведений.СредевзвешеннаяСтоимость (Период, Мандат, СчетМандата, Валюта, Актив, WAP1, WAP2, Количество)

6. Вывод по блоку `СформироватьWAP`

При вызове из внешней обработки `СформироватьWAP` документ `РасчетСредневзвешеннойСтоимости` самодостаточно формирует `СписокАктивов` на основе операций/остатков/котировок/предыдущих WAP и затем пишет результат в регистр СредевзвешеннаяСтоимость.

Ветка проведения WAP технически проще MV: один целевой регистр записи и без отдельной логики зануления по "исчезнувшим" ключам.

6.1. Операционная схема расчета `WAP1/WAP2`

Шаблон на одну пару: (СчетМандата, Актив, ВалютаРасчета)

Вход:
    Предыдущее состояние:
        ПредыдущееКоличество, ПредыдущийWAP1, ПредыдущийWAP2
    Операции дня:
        Массив операций (Количество, Сумма, Валюта, СчетИсточник, ...)
    Котировка:
        КотировкаУУ + ВалютаУУ (если есть)
    Коэффициент амортизации:
        Для облигаций = ОстатокНоминала / НоминальнаяСтоимость, иначе 1

Шаг 1. Подготовка операций:
    Для каждой операции считается X = СуммаВВалютеРасчета / Количество
    Для переводов между счетами СуммаВВалютеРасчета берется из кэша источника (WAP1/WAP2 источника * Количество)

Шаг 2. Базовые веса:
    ЗнаменательWAP1 = ПредыдущееКоличество + Сумма(КоличествоОпераций)
    ЗнаменательWAP2 = ПредыдущееКоличество + Сумма(КоличествоОпераций)
    WAP1_P0 = ПредыдущееКоличество / ЗнаменательWAP1
    WAP2_P0 = ПредыдущееКоличество / ЗнаменательWAP2

Шаг 3. Начальная база X0:
    WAP2_X0 = ПредыдущийWAP2
    WAP1_X0:
        если ЭтоНачалоОтчетногоПериода = Истина:
            WAP1_X0 = котировка (с пересчетом в ВалютаРасчета при необходимости)
        иначе:
            WAP1_X0 = ПредыдущийWAP1
    После этого:
        WAP1_X0 = WAP1_X0 * КоэффициентАмортизации
        WAP2_X0 = WAP2_X0 * КоэффициентАмортизации

Шаг 4. Итог:
    WAP1 = WAP1_P0 * WAP1_X0 + Сумма( X_операции * (КоличествоОперации / ЗнаменательWAP1) )
    WAP2 = WAP2_P0 * WAP2_X0 + Сумма( X_операции * (КоличествоОперации / ЗнаменательWAP2) )

Выход:
    Строка ТЧ СписокАктивов:
        СчетМандата, Актив, ВалютаРасчета, Количество=ОстатокНаКонец, WAP1, WAP2

Разница сценариев: начало / не начало отчетного периода

Сценарий Источник для `WAP1_X0` Практический эффект
ЭтоНачалоОтчетногоПериода = Истина Текущая зафиксированная котировка актива (через `ТаблицаКотировок`, с конвертацией валюты при необходимости). `WAP1` начинает период от "рыночной базы" котировки, а затем корректируется операциями дня.
ЭтоНачалоОтчетногоПериода = Ложь Предыдущее значение `WAP1` из регистра `СредевзвешеннаяСтоимость`. `WAP1` продолжает предыдущую траекторию и обновляется только весами/операциями текущего дня.
`WAP2` в обоих сценариях стартует от предыдущего `WAP2`, но также проходит через коэффициент амортизации и операционные корректировки.

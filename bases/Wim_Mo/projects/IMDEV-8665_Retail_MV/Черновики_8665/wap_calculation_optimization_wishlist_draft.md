# Черновик: пожелания по оптимизации расчета WAP (много мандатов в одном запросе)

Статус: **черновик идей**, не реализовано. Цель: не потерять направление работ и при реализации сверить с кодом `Wim_Mo`.

База исходников документа:

- `SRC/CF/Documents/РасчетСредневзвешеннойСтоимости/Ext/ManagerModule.bsl` (`ПолучитьДанныеРасчета`, `ПолучитьТекстЗапросаЗаполненияДокумента`)
- `SRC/CF/Documents/РасчетСредневзвешеннойСтоимости/Ext/ObjectModule.bsl` (`ЗаполнитьДокумент`)

## Задумка в двух словах

Вынести фильтрацию по мандату/счетам в виртуальную таблицу **`ВТ_СчетаМандатов`** из параметра **`&ТаблицаСчетовМандатов`**, передавать **`&МассивМандатов`**, чтобы один пакет мог обслужить **несколько мандатов** (или подготовить базу для пакетной загрузки данных без повторного разбора текста запроса для каждого мандата).

Отдельно сохранить **`МандатДляКотировки`** через `ВТБ_АлгоритмыРасчета.МандатРозничноеДУ` там, где котировки по-прежнему должны быть привязаны к правилу розницы (для одного переданного `Мандат` в текущем документе это ок; при реальном массиве разных мандатов логику котировок нужно проектировать отдельно).

## Что нужно не забыть перед внедрением

1. **`ЭтоНачалоОтчетногоПериода`** сейчас строится из одного результата среза `ДействующиеФинПланы` по **одному** мандату. При **`Мандат В (&МассивМандатов)`** возможны **несколько строк** или неоднозначность: нужно явное правило (на актив, на мандат документа или отдельное поле в результате).
2. **Модуль объекта** `ЗаполнитьДокумент()` и проведение завязаны на **один** `Мандат` в шапке документа. Пакетный режим в менеджере **сам по себе** не даст «один документ на много мандатов» без доработки объекта, ТЧ и движений.
3. **Индексы результатов пакета** в `ПолучитьДанныеРасчета`: после изменения количества/порядка запросов перепроверить номера `РезультатВыполнения[N]` для `ТаблицаКотировок`, `ТаблицаОпераций`, `РезультатаЗапроса`, `ТаблицаПредыдущихСтоимостей`.
4. **Запрос 9 (срез предыдущих WAP)** в черновом тексте ниже: проверить корректность **синтаксиса** второго соединения с `ВТ_СчетаМандатов` (в 1С все соединения должны быть привязаны к одной цепочке `ИЗ ... СОЕДИНЕНИЕ ... СОЕДИНЕНИЕ` без «висячих» фрагментов).
5. **`ВТ_МаксПериод`** в полном пакете должен стоять **до** запроса котировок, если дальнейшие шаги от него зависят; в текущей функции порядок запросов фиксирован — при вставке не перепутать порядок с `РезультатВыполнения[...]`.

## 1. Черновик: `ПолучитьДанныеРасчета` (модуль менеджера)

Идея: собрать `МассивМандатов`, развернуть пары **Мандат + СчетМандата** в таблицу значений, передать в запрос как `ТаблицаСчетовМандатов` и `МассивМандатов`.

```bsl

    СтруктураВозврата = Новый Структура("ВалютыРасчета, ЭтоНачалоОтчетногоПериода, ТаблицаКотировок, ТаблицаПредыдущихСтоимостей, ТаблицаОпераций, РезультатаЗапроса",
        Новый Массив, Ложь, Новый ТаблицаЗначений, Новый ТаблицаЗначений, Новый ТаблицаЗначений, Неопределено);

    ВалютыРасчета = ПолучитьВалютыРасчета(Дата);
    СтруктураВозврата.ВалютыРасчета = ВалютыРасчета;

    МассивМандатов = Новый Массив;
    Если ЗначениеЗаполнено(Мандат) Тогда
        МассивМандатов.Добавить(Мандат);
    КонецЕсли;

    ТаблицаСчетов = Новый ТаблицаЗначений;
    ТаблицаСчетов.Колонки.Добавить("Мандат", Новый ОписаниеТипов("СправочникСсылка.Мандаты"));
    ТаблицаСчетов.Колонки.Добавить("СчетМандата", Новый ОписаниеТипов("СправочникСсылка.СчетаМандатов"));

    Для Каждого ТекМандат Из МассивМандатов Цикл
        Счета = СписокСчетовВыбранногоМандата(ТекМандат);
        Для Каждого Счет Из Счета Цикл
            стр = ТаблицаСчетов.Добавить();
            стр.Мандат = ТекМандат;
            стр.СчетМандата = Счет;
        КонецЦикла;
    КонецЦикла;

    Запрос = Новый Запрос(ПолучитьТекстЗапросаЗаполненияДокумента());
    Запрос.УстановитьПараметр("ДатаСреза", Дата);
    Запрос.УстановитьПараметр("ДатаНачала", Новый Граница(НачалоДня(Дата), ВидГраницы.Включая));
    Запрос.УстановитьПараметр("ДатаОкончания", Новый Граница(КонецДня(Дата), ВидГраницы.Включая));
    Запрос.УстановитьПараметр("МассивМандатов", МассивМандатов);
    Запрос.УстановитьПараметр("ТаблицаСчетовМандатов", ТаблицаСчетов);
    Запрос.УстановитьПараметр("МассивВалют", ВалютыРасчета);

    МандатДляКотировки = ВТБ_АлгоритмыРасчета.МандатРозничноеДУ(Мандат);
    Запрос.УстановитьПараметр("МандатДляКотировки", МандатДляКотировки);

    // Далее: ВыполнитьПакет(), разбор результатов по индексам, заполнение структуры.

    Возврат СтруктураВозврата;

КонецФункции
```

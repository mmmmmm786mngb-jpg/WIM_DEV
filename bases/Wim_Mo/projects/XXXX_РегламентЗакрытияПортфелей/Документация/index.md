# Документация — Регламент закрытия портфелей

## Точка входа

**Справочник** `РегламентныеПериоды` → **форма** `РегламентныйПериод` → команда «Сформировать регл. операции» → клиентская процедура:

```bsl
&НаКлиенте
Процедура СформироватьРегламентныеОперации()
```

## Содержание

- [ПереносWimParВОсновнуюКонфигурацию.md](./ПереносWimParВОсновнуюКонфигурацию.md) — пошаговая инструкция по переносу содержимого расширения `WimPar` (константа, общий модуль, команда и кнопка на форме `РегламентныйПериод`, код модуля формы) напрямую в основную конфигурацию `WIM_MO`, с таблицей замены имён и контрольным списком проверки.
- [ДеревоАлгоритмаЗакрытияПортфелей.html](./ДеревоАлгоритмаЗакрытияПортфелей.html) — полное дерево шагов алгоритма от клиентской процедуры `СформироватьРегламентныеОперации()` до тела фонового задания `ФоновыеЗаданияСервер.СоздатьПланРегламентныхОпераций`. Включает:
  - карту клиент/сервер-вызовов
  - подготовку временного хранилища (`ПолучитьАдресВременногоХранилища`)
  - разбиение на пачки по 5 мандатов (MID-153)
  - **разделение на фоновые задания** (`ФоновыеЗадания.Выполнить` / `ОжидатьЗавершения`) и текущую заглушку `КоличествоПотоков = 0` (RMC-52)
  - тело задания и связь с `ВыполнитьРегламентныеПроцедуры`
  - таблицу ключевых объектов и места, где разделение «ломается»

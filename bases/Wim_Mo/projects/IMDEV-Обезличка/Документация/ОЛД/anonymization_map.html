Карта обезличивания по выбранным объектам

Проект: IMDEV-Обезличка
База: Wim_Mo
Область: только объекты, указанные заказчиком

Введение

В документ включены только следующие объекты: СчетаМандатов, Мандаты, СчетаДЕПО, Контрагенты, История изменений контрагентов, Брокерские счета, Банковские счета. Для каждого объекта зафиксированы итоговые правила: какие реквизиты меняем, какие не меняем, и как именно выполняем замену.

Технология обезличивания

Применяется точечное обезличивание только согласованных реквизитов. Для Контрагентов используется отбор по условию Клиент = Истина. Для СчетаДЕПО выполняется замена только текста в круглых скобках Наименования. Для БрокерскиеСчета меняется только НомерБанковскогоСчета. Для истории изменений выполняется полная очистка регистра ВерсииОбъектов. Предопределенные элементы справочников не изменяются. Ссылочная целостность объектов сохраняется.

Возможные проблемы и как решать

  • Проблема: нарушение уникальности наименований после замены. Решение: добавлять числовой суффикс к шаблону наименования.
  • Проблема: потеря связности отчетов. Решение: ссылки на объекты не удалять, менять только согласованные реквизиты.
  • Проблема: утечки через историю. Решение: полная очистка регистра ВерсииОбъектов.
  • Проблема: утечки в дополнительных реквизитах Контрагентов. Решение: обрабатывать строковые значения в табличной части.

Выводы

Для текущей задачи достаточно обрабатывать только 7 указанных объектов. Ключевой порядок выполнения: Контрагенты (только Клиент = Истина) -> Мандаты и связанные счета -> полная очистка ВерсииОбъектов. Такой порядок снижает риск пропуска исходных данных.

Контроль после выполнения

1) В карточках контрагентов (только где Клиент = Истина) не должно быть реальных ИНН, телефонов, email и адресов.
2) В СчетаДЕПО должен быть обезличен только текст в круглых скобках Наименования.
3) В БрокерскиеСчета должен быть изменен только НомерБанковскогоСчета.
4) РегистрСведений.ВерсииОбъектов должен быть полностью очищен.
5) Все ссылки между объектами должны оставаться рабочими.

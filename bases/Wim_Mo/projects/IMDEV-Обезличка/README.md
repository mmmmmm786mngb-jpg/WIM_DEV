# IMDEV-Обезличка

Проект для подготовки и согласования карты обезличивания данных в базе `Wim_Mo`.

## Структура

- `Документация/` - описание области обезличивания, правила и контрольные шаги.

## Основной документ

- `Документация/anonymization_map.html` - карта обезличивания по объектам метаданных.

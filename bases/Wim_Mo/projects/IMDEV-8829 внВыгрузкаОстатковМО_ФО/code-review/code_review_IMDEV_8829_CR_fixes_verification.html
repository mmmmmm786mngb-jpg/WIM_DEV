C2. HIGH Временное хранилище между сеансами → Частично

Объект / модульвнВыгрузкаОстатковМО_ФО / ObjectModule.bsl
ПроцедурыФоноваяВыгрузкаПачками (создание/чтение), ВыполнитьКоманду (запись воркером)
Сейчасстр. 491-494, 132-134, 566-581
Было в CR: координатор создаёт адрес temp storage, воркер пишет, координатор читает. Между сеансами ФЗ это ненадёжно; рекомендовались файлы.
Сделано (по ОписаниеДоработок.txt): если из хранилища не пришла структура с КоличествоПортфелей - считаем ошибкой, дописываем ТекстАварии, затем исключение. Корневую замену на файлы не делали. 
ДанныеПачки = ПолучитьИзВременногоХранилища(Адрес);
Если ТипЗнч(ДанныеПачки) = Тип("Структура")
    И ДанныеПачки.Свойство("КоличествоПортфелей") Тогда
    // агрегация статистики
Иначе
    ЕстьОшибка = Истина;
    ТекстАварии = ТекстАварии + "При формировании почтовой рассылки произошли ошибки!" + Символы.ПС;
КонецЕсли;
Оценка: fail-safe лучше, чем молчаливая пустая сводка. Но:
  • механизм по-прежнему temp storage;
  • проверка выполняется только при заполненной почте/списке рассылки;
  • на стенде стоит убедиться, что в письме сводка реально ненулевая (агрегация работает), а не только что «нет исключения».

M1. MEDIUM ID воркера + прод-защита → Исправлено

Объект / модульвнВыгрузкаОстатковМО_ФО / ObjectModule.bsl

ФоноваяВыгрузкаПачками стр. 483, 499;
СведенияОВнешнейОбработке - команда пачками удалена из регистрации
Было: воркеры шли с ID ФоноваяВыгрузкаПачками; гард Если ИдентификаторКоманды <> "ФоноваяВыгрузка" Тогда Возврат был снят. Единый вход регламента через КоличествоПотоков при этом был правильной идеей.
Сделано (как рекомендовал CR):

  • регламент по-прежнему зовёт только ФоноваяВыгрузка; при КоличествоПотоков > 1 - координатор;
  • воркерам: КоличествоПотоков = 1 + ID ФоноваяВыгрузка (анти-рекурсия без подмены ID);
  • отдельная команда «пачками / не использовать» убрана из СведенияОВнешнейОбработке.
// Вход (прод-гард + единый вход)
Если ИдентификаторКоманды <> "ФоноваяВыгрузка" Тогда
    Возврат;
КонецЕсли;
...
Если КоличествоПотоков > 1 Тогда
    ФоноваяВыгрузкаПачками(...);
    Возврат;
КонецЕсли;

// Воркеру в пачке:
НастройкиПачки.Значения.Вставить("КоличествоПотоков", 1);
ПараметрыКоманды.Вставить("ИдентификаторКоманды", "ФоноваяВыгрузка");

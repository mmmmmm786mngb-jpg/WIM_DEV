# Скрипты

Автоматизация сборки и поставки внешней обработки.

Планируется:

- сборка EPF из XML-исходников `Обработка/src` в `Обработка/build`
- подключение собранной обработки в тестовую базу для проверки

Путь к каталогу базы брать из `../../../source-path.txt`, не хардкодить.
Платформа: `C:\Program Files\1cv8\8.3.27.1859\bin`.

# Внешняя обработка

| Каталог | Содержимое |
|---------|------------|
| `src/` | XML-исходники внешней обработки |
| `build/` | Собранный файл `.epf` |

Рабочее имя обработки: `внПереносЗапросовКДанным` (уточняется).

Вид для подключения через БСП — «Дополнительная обработка» (глобальная),
тип команды — «Открытие формы».

Исходники создаются после согласования открытых вопросов из
`../Документация/feasibility_and_requirements.md`.

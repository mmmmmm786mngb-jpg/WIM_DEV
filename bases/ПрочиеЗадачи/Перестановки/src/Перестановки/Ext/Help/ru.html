Перестановки символов строки

Обработка выводит все различные перестановки символов введенной строки. Например, для строки 123 будет выведено 6 строк: 123 132 213 231 312 321.

Порядок работы

  1. В поле Строка введите исходные символы: цифры, буквы, знаки, пробелы.
  2. Нажмите кнопку Перестановки или клавишу Enter.
  3. В поле Перестановки внизу формы появится результат: каждая перестановка с новой строки.

Особенности

  • Перестановки выводятся по возрастанию: первой идет строка из символов, упорядоченных по возрастанию, последней - по убыванию. Символы сравниваются по их кодам, поэтому цифры идут раньше букв, а заглавные буквы раньше строчных.
  • Одинаковые перестановки не повторяются. Если в строке есть повторяющиеся символы, строк будет меньше: для 112 выводится 3 строки (112 121 211), а не 6.
  • Длина строки ограничена 9 символами. Число перестановок растет как факториал длины: 8 символов дают 40 320 строк, 9 символов - 362 880 строк, 10 символов дали бы 3 628 800 строк. Для пустой или слишком длинной строки выводится предупреждение.

Алгоритм

Используется алгоритм Нарайаны - перебор перестановок в лексикографическом порядке. Сначала символы строки упорядочиваются по возрастанию: это первая, наименьшая перестановка. Затем из текущей перестановки по одному правилу получается следующая по возрастанию, пока не будет достигнута последняя (символы по убыванию). Каждая перестановка получается ровно один раз, поэтому повторяющиеся символы не дают одинаковых строк.

Блок-схема 2. Переход к следующей перестановке

Массив K из N элементов, позиции нумеруются с 0. Шаг изменяет K на месте и сообщает, была ли найдена следующая перестановка.

┌──────────────────────────────────────┐
│                Начало                │
└───────────────────┬──────────────────┘
                    ▼
┌──────────────────────────────────────┐
│              i = N - 2               │
└───────────────────┬──────────────────┘
                    ├◄─────────────────────────────────────────┐
                    ▼                                          │
╔══════════════════════════════════════╗  да    ┌──────────────┴─────────────┐
║       i ≥ 0 и K[i] ≥ K[i+1] ?        ╟───────►│         i = i - 1          │
╚═══════════════════╤══════════════════╝        └────────────────────────────┘
                    │ нет
                    ▼
╔══════════════════════════════════════╗  да    ┌────────────────────────────┐
║               i < 0 ?                ╟───────►│    Конец: вернуть "нет"    │
╚═══════════════════╤══════════════════╝        └────────────────────────────┘
                    │ нет
                    ▼
┌──────────────────────────────────────┐
│              j = N - 1               │
└───────────────────┬──────────────────┘
                    ├◄─────────────────────────────────────────┐
                    ▼                                          │
╔══════════════════════════════════════╗  да    ┌──────────────┴─────────────┐
║            K[j] ≤ K[i] ?             ╟───────►│         j = j - 1          │
╚═══════════════════╤══════════════════╝        └────────────────────────────┘
                    │ нет
                    ▼
┌──────────────────────────────────────┐
│     Поменять местами K[i] и K[j]     │
└───────────────────┬──────────────────┘
                    ▼
┌──────────────────────────────────────┐
│    Развернуть в обратном порядке     │
│       хвост K[i+1] ... K[N-1]        │
└───────────────────┬──────────────────┘
                    ▼
┌──────────────────────────────────────┐
│         Конец: вернуть "да"          │
└──────────────────────────────────────┘

Смысл шагов:

  • Поиск i. Справа налево ищется первая позиция, где элемент меньше следующего за ним. Правее нее элементы идут по убыванию, то есть эта часть уже в последней перестановке. Если такой позиции нет, вся строка упорядочена по убыванию и перебор закончен.
  • Поиск j и обмен. Справа ищется первый элемент больше K[i]. После обмена позиция i получает наименьшее возможное большее значение.
  • Разворот хвоста. Хвост после позиции i по-прежнему упорядочен по убыванию; разворот делает его возрастающим, то есть наименьшим. Так получается ближайшая следующая перестановка.

Пример для строки 123

ТекущаяijПосле обменаПосле разворота хвоста
1231 (2 < 3)2132132
1320 (1 < 3)2231213
2131 (1 < 3)2231231
2310 (2 < 3)1321312
3121 (1 < 2)2321321
321позиция i не найдена - перебор закончен

Результат: 123, 132, 213, 231, 312, 321.

# Неправильные типы операций с ДС

Аналитическая задача по базе **SBB_Broker** (1С ИЦ, бэк-офис брокера).

Источник претензии: письмо Баулиной Е. М. от 02.09.2026 (тема `1С ИЦ_НЕПРАВИЛЬНЫЕ типы операций с ДС`, важность High). Номера Jira на эту претензию пока нет.

Историческая постановка: [ACCOUNTING-6645](https://jira/browse/ACCOUNTING-6645) (2021, ОТС.РЕПО / маржин коллы). Выгрузка Confluence лежит в `Документация/ОРИГИНАЛ/`. В постановке явно требуется и отдельный документ «Маржинальный взнос», и новые типы в «Операции с ДС» (автосоздание при проведении МВ).

Ответ по типу «Ввод остатков»: `Документация/Ввод остатков.html`.

ТЗ разработчикам (скрыть типы в списке через РС «Параметры глобальные»): `Документация/ТЗ скрытие типов операций.html`.

## База

**SBB_Broker**. Путь к исходникам конфигурации — в **../../source-path.txt**.

Документ на форме: `Документ.ОперацииДС` (синоним «Операции с денежными средствами»).  
Реквизит: `ТипОперации` = `Перечисление.ТипыОпераций`.  
Отдельный документ маржинальных взносов: `Документ.МаржинальныйВзнос`.

## Два предмета разбора

1. **Маржинальный взнос к уплате / к получению** в выпадающем списке типа операции документа «Операции с ДС». Заказчик считает типы ошибочными: в плане ЮАТ был отдельный документ «Маржинальные взносы», а не новые типы неторговых операций с ДС. Просит убрать из ПРОД (сначала удалить, затем — скрыть из доступа и визуализации).
2. **Ввод остатков** — открытый вопрос: что это за тип, каких остатков, на каком основании формируется и исполняется, как отражается во внутреннем учете, брокерском отчете и регуляторной отчетности.

## Структура проекта

- **Документация/** — карточка анализа, переписка, постановка ACCOUNTING-6645, скриншоты, оригиналы, ТЗ разработчикам
- **Тестирование/** — сценарии и отчеты
- **Скрипты/** — выгрузка/загрузка, проверки по базе

- Платформа 1С:Предприятие не ниже 8.3.21

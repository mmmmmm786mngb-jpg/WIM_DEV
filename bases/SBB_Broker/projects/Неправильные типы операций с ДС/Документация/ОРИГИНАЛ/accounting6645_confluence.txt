 8 
 Установка статуса для операции Маржинальный взнос «Возвращен»

 
 Автоматически 
 Исполнение Поручения ДЕПО по 2-й части Сделки РЕПО.

 
 
 
 Так как маржинальные взносы участвуют в расчете по 2-й части Сделки РЕПО, то в Поручение ДЕПО по 2-й части РЕПО необходимо добавить новое поле "Сумма марж. взносов" (в рамках Сделки по 1-й части РЕПО может быть > 1 маржинального взноса). Значение в текущем поле "Сумма" при этом корректировать с учетом суммы маржинальных взносов и направлений маржинальных взносов. Также для текущего поля "Сумма" добавить подсказку, отображающуюся при наличии ненулевого значения в поле "Сумма марж. взносов".


 


 При этом добавление новго поля "Сумма маржин. взносов" в Поручении ДЕПО в ИЦ не влияет на структуру Поручения в Депозитарии.


 


 
 
 
 Функиональные требования


 В 1С ИЦ необходимо создать новый документ «Маржинальный взнос». Доступ к документам «Маржинальный взнос» необходимо организовать через новый подраздел с соотв. названием в разделе «Операции с денежными средствами»:


 


 Также необходимо предусмотреть возможность создания документа "Маржинальный взнос" через пункт меню "Создать на основании" в карточке БП ВнБ.


 


 В новом документе «Маржинальный взнос» необходимо предусмотреть следующий набор полей и кнопок управления:


 
 Стандартный набор кнопок управления, предусмотренный для документов в 1С ИЦ:

 
 


 
 Поле «Номер». Тип – строковое. Недоступно не редактирование. Заполняется автоматически и является счетчиком, начинающимся с 000000001.

 
 
 Поле «Дата возникновения». Тип – дата/время. Доступно на редактирование, является обязательным. По-умолчанию заполняется текущей датой/временем.

 
 
 Поле «Основание». Тип – ссылка. Доступно на редактирование, является обязательным. По-умолчанию не заполнено. В качестве основания указывается ссылка на Сделку по 1-й части РЕПО, в рамках которой возникает маржинальный взнос и которая связана с «Маржинальным взносом» через структуру подчиненности.

 
 
 Поле «Организация». Тип – справочник. Доступно на редактирование, является обязательным. По-умолчанию заполняется значением из Сделки из поля «Основание».

 
 
 Поле «Статус». Тип – справочник . Недоступно на редактирование. Заполняется автоматически одним из значений «Новый», «Подтвержден», «Оплачен», «Возвращен». Более подробно про статусную модель – см. раздел «Основной сценарий использования».

 
 
 Поле «Дата оплаты». Тип – дата. Доступно на редактирование, является обязательным. По-умолчанию не заполнено.

 
 
 Поле «Биржа». Тип – справочник. Доступно на редактирование, является обязательным. По-умолчанию заполняется значением из Сделки из поля «Основание».

 
 
 Поле «Тип деятельности». Тип – справочник. Доступно на редактирование, является обязательным. По-умолчанию заполняется значением из Сделки из поля «Основание».

 
 
 Поле «Вид». Тип – справочник . Доступно на редактирование. Заполняется вручную одним из значений – «К оплате», «К получению». По-умолчанию заполняется значением «К оплате».

 
 
 Поле «Валюта». Тип – справочник. Доступно на редактирование, является обязательным. По-умолчанию заполняется значением из Сделки из поля «Основание».

 
 
 Поле «Сумма». Тип – числовое. Доступно на редактирование, является обязательным. По-умолчанию не заполнено.

 
 
 Блок полей «Сторона 1», аналогичный БП ВнБ, все поля доступны на редактирование, являются обязательным, по-умолчанию заполняются значениями из Сделки из поля «Основание»:
 
 Поле «Клиент/Контрагент».

 Поле «Договор/Код Клиента».

 Поле «Портфель» .

 Поле «Банковский счет».

 

 Блок полей «Сторона 2», аналогичный БП ВнБ, все поля доступны на редактирование, являются обязательным, по-умолчанию заполняются значениями из Сделки из поля «Основание», кроме поля «Расчетный счет», которое заполняется вручную:
 
 Поле «Клиент/Контрагент».

 Поле «Договор/Код Клиента».

 Поле «Расчетный счет».

 

 Поле «Комментарий». Тип – строковое. Доступно на редактирование, не является обязательным, по-умолчанию не заполнено. Предполагаются изменения в логике заполнения данного поля после реализации задачи ACCOUNTING-6649 - Getting issue details... STATUS .

Техническое задание: скрыть типы в списке «Тип операции»

SBB_Broker. Документ «Операции с ДС». Состав скрываемых типов - в регистре «Параметры глобальные».

Задача

На форме документа «Операции с денежными средствами» в поле «Тип операции» видны все значения перечисления. Бэк просит убрать из выпадающего списка служебные типы. Сами значения перечисления не удалять: по ним есть история, а типы маржинального взноса система ставит сама при проведении документа «Маржинальный взнос». Список скрываемых типов должен править поддержка без доработки кода.

1. Что скрываем на старте

Синоним на форме Имя в регистр (как в конфигураторе)
Маржинальный взнос к уплате МаржинальныйВзносКОплате
Маржинальный взнос к получению МаржинальныйВзносКПолучению
Ввод остатков ВводОстатков

Остальные типы перечисления остаются в списке. Журнал документов не фильтруем. Модуль объекта и ОбработкаЗаполнения не трогаем.

2. Как делаем

2.1. Регистр «Параметры глобальные»

Существующий РегистрСведений.ПараметрыГлобальные. Чтение: ЗначениеПараметра. Имя параметра в код и в СуществующиеИменаПараметров записать одно и то же.

Поле Значение
Имя параметра СкрываемыеТипыОперацийДС
Значение Имена значений перечисления через запятую:
МаржинальныйВзносКОплате,МаржинальныйВзносКПолучению,ВводОстатков
Комментарий Типы, скрываемые в списке документа Операции с ДС. Имена Перечисление.ТипыОпераций через запятую.

После выкладки поддержку меняет строку в регистре и переоткрывает форму. Пустая строка - ничего не скрывать. Неизвестное имя пропустить, форму не ронять. Повторно обработчик обновления по этой задаче не гонять: он затрёт правки поддержки.

2.2. Начальная запись - обработчик обновления

Стартовую строку создаёт обработчик в Обработка.ОбновлениеИнформационнойБазыNew, процедура ОбновитьВерсии (как 10642, 10811). Блок - в конец процедуры. Номер задачи подставить, когда заведут карточку. После загрузки конфигурации прогнать обработку по этому номеру.

2.3. Форма документа

В ПриСозданииНаСервере формы ФормаДокумента заполнить СписокВыбора поля ТипОперации и включить РежимВыбораИзСписка (тот же приём, что ЗаполнитьСписокВыбораТипаСделки во «Внебиржевых сделках»). Историю выбора у поля отключить. Если в открытом документе тип уже из скрытых (старый документ или автосоздание с МВ) - добавить в список только его, чтобы поле показало записанное значение.

Скрываемые типы читать из регистра через менеджер документа, не через модуль с повторным использованием значений.

3. Что меняем

Модуль Файл Правка
Менеджер ОперацииДС Documents/ОперацииДС/Ext/ManagerModule.bsl Функция чтения скрываемых типов из регистра. В конец модуля.

4. Проверка

  1. Обработка обновления по номеру задачи создала запись в «Параметры глобальные» со стартовой строкой.
  2. Новый документ: в списке нет трёх служебных типов, остальные на месте.
  3. Убрать из строки ВводОстатков, переоткрыть форму: «Ввод остатков» снова в списке. Вернуть строку.
  4. Старый документ со скрытым типом открывается и записывается.
  5. Проведение «Маржинальный взнос» по-прежнему создаёт операцию с ДС с нужным типом.
  6. Скрытые типы не возвращаются из истории выбора. Опечатка в имени в регистре форму не роняет.

    СкрываемыеТипы = Документы.ОперацииДС.СкрываемыеТипыОпераций();

        ЗначениеТипа = Перечисления.ТипыОпераций[ОписаниеЗначения.Имя];

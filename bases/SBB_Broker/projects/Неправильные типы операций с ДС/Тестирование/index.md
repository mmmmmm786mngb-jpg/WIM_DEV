# Тестирование

Сценарии после внедрения ТЗ (`Документация/ТЗ скрытие типов операций.html`):

1. Обработка «Обновление информационной базы» по номеру задачи создала в РС «Параметры глобальные» запись `СкрываемыеТипыОперацийДС` со строкой `МаржинальныйВзносКОплате,МаржинальныйВзносКПолучению,ВводОстатков`.
2. Новый документ «Операции с ДС»: трёх служебных типов в списке нет, остальные на месте.
3. Убрать из строки регистра `ВводОстатков`, переоткрыть форму: «Ввод остатков» снова в списке. Вернуть строку.
4. Существующий документ со скрытым типом открывается и записывается.
5. «Маржинальный взнос» по-прежнему создаёт «Операции с ДС» с нужным типом.
6. Скрытые типы не возвращаются из истории выбора. Опечатка в имени в регистре форму не роняет.

1. Как устроен рынок

Скиллы

Папки с инструкциями для агента Cursor. Кладётся в .cursor/skills/. Агент сам выбирает нужный навык (собрать форму, выгрузить XML, опубликовать базу).

Правила

Постоянный стиль: как писать BSL, куда класть объекты, какие MCP вызывать. Файлы .cursor/rules/. Часто идут в одном репозитории со скиллами.

MCP

Отдельный процесс рядом с Cursor: синтакс-помощник, линтер, доступ к живой базе, EDT, Напарник. Подключается в настройках MCP. Скиллы MCP не заменяют.

Сводный каталог MCP: Untru/1c-mcp (Awesome 1C MCP). Звёзды ниже — ориентир GitHub на сентябрь 2026, не рейтинг качества.
Многие репозитории cursor_rules_1c — копии одного и того же XML-контура Широкова. Смотреть оригинал, а не десятый форк.

Что не считать отдельным набором

Форки anoda-tech/cursor_rules_1c, olegtrast/cursor_rules_1c и старый Nikolay-Shirokov/cursor_rules_1c — это копии/ответвления XML-контура или раннего comol. Отдельной ценности обычно нет.

Не смешивать Широкова и comol в одном проекте. Это два полных стека. Агент начнёт дергать оба сразу, контекст распухнет. Белый список отдельных скиллов (запросы, ЗУП) — нормально; полный второй набор — нет.

Обсуждения: Telegram t.me/comol_it_does_matter, канал yellow_ai_vibe. Платный конструктор рядом с comol: vibecoding1c.ru — сам git правил при этом открыт.

7. Что имеет смысл брать в Cursor

Минимальный полезный набор для конфигуратора (без EDT), если собирать «с нуля из интернета»:

  1. Скиллы Широкова — XML, расширения, загрузка в базу, веб-тесты. Самый зрелый открытый набор под Cursor.
  2. MCP синтакс-помощник alkoleft — чтобы модель не выдумывала методы платформы.
  3. По желанию MCP BSL Language Server — линтер файлов до синтаксического контроля конфигуратора.
  4. Живая база (feenlace / toolkit / 1c_mcp) — только если нужен запрос к конкретной ИБ, не «чтобы писать правильнее».

Если команда на EDT

Первым MCP брать EDT-MCP. Скиллы Широкова тогда вторичны: EDT и так видит исходники.

Если нужен процесс «агент + субагенты»

Смотреть comol/ai_rules_1c вместо второго полного набора скиллов, не вместе с Широковым.

Если есть ИТС

Напарник как ревьюер — опция. Без ИТС ставить обёртки бессмысленно.

Cursor нормально переваривает ограниченное число MCP-инструментов. Один синтакс-помощник плюс скиллы лучше, чем пять MCP сразу.

8. Выводы

  1. Свободный доступ к гитам есть. Два полноценных открытых стека: Широков (скиллы XML/CLI) и comol (правила/агенты). Остальное — комбайны, форки и прикладные надстройки.
  2. Бесплатных MCP для 1С десятки. Для качества кода в Cursor важны два класса: синтакс-помощник и линтер BSL. Остальное — живая база, EDT, учёт, Напарник.
  3. Платный слой (feenlace Pro, RSV, Infostart, VibeCoding) расширяет поиск по коду и конструкторы MCP, но не обязателен, чтобы начать.
  4. Каталог для навигации: github.com/Untru/1c-mcp.

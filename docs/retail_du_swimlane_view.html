Розничное ДУ: кросс-функциональное (Swimlane) представление

Формат для совместной работы бизнеса и разработки: видно кто, что и когда делает.
Lane 1 - Система (автоматический расчет)
Инициализировать Т-0 (сегодня) и Т-1 (предыдущий рабочий день).
Решение: разница дат > 3?
При <= 3 рассчитать "Последний день квартала/месяца".
Назначить циклы для Т-0, Т-1 и доп. даты.
Lane 2 - Пользователь
Запустить обработку и проверить значения дат.
Если > 3 дней, перейти на Пользовательский лист.
В пользовательском режиме подтвердить/скорректировать параметры.
Запустить выполнение операций.
Lane 3 - Регламентные операции
Выполнить запуск, флаги, фильтры, заполнение, создание.
Дождаться завершения фоновых операций.
Закрыть этап регламентных операций.
Lane 4 - Специализированные обработки
Фоновое исполнение сделок T+n.
Расторжение договоров розничного ДУ.
Установка даты расчетов = Т и запуск "Начитать".

Swimlane flowchart

flowchart LR subgraph L1["Система"] A[Старт] --> B[Т-0 и Т-1] B --> C{Разница > 3?} C -- Нет --> D[Расчет доп. даты] D --> E[Назначение циклов] end subgraph L2["Пользователь"] C -- Да --> F[Пользовательский лист] F --> G[Проверка параметров] end subgraph L3["Регламент"] E --> H[Регламентные операции] G --> H end subgraph L4["Обработки"] H --> I[Сделки T+n] I --> J[Расторжение DU] J --> K[Дата Т и Начитать] K --> Z([Финиш]) end

Замечания и исправления

Не определено: разница дат в рабочих или календарных днях.
Исправление: считать разницу строго по рабочим дням регламентного календаря.
Нет явного правила для пустой доп. даты при назначении цикла.
Исправление: если доп. дата пустая, цикл для нее не создается.

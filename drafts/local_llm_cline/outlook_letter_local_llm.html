Тема письма
Локальная языковая модель для разработки 1С: пилот и рабочая схема на 20-50 разработчиков
Локальный помощник для разработки 1С
Модель на сервере компании, редактор на рабочем месте, код остается в контуре
Дмитрий, Сергей, добрый день.
Сергей ранее спрашивал, можно ли настроить языковую модель для помощи в разработке 1С так, чтобы она стояла на нашем оборудовании и работала автономно, без обращений во внешние сервисы. Такой вариант есть и для короткой проверки, и для постоянной работы отдела из 20-50 разработчиков. Ниже коротко, что имеется в виду. Подробная схема, список моделей и порядок настройки лежат в приложенном файле.
Из чего состоит схема
Модель Открытая языковая модель на сервере компании с видеокартами. Веса хранятся на диске сервера. Во время ответов сервер во внешние сервисы не обращается.
Рабочее место На ноутбуке разработчика остаются VS Code и расширение Cline. Запросы уходят только на сервер модели по локальной сети.
Знания по 1С Подключаются уже готовые навыки по 1С (формы, запросы, обработки, роли, расширения, около 100 штук) и три служебных подключения: справка по платформе, поиск по исходному коду, проверка сценария в тестовой базе. Это тот же формат, который уже используется с Cursor и Claude Code, переписывать его не нужно.
Что это дает
Исходники конфигураций, тексты запросов и данные тестовых баз остаются внутри контура. Оплата за каждый запрос не требуется: затраты складываются из сервера и электричества. Модели с открытыми весами есть китайские (Qwen, GLM, DeepSeek), американские (gpt-oss, Gemma) и европейская (Devstral). Для пилота подходят лицензии Apache 2.0 и MIT. На основной конфигурации модели крупнее, лицензию каждой проверяем отдельно.
Пилот
Одна видеокарта 24-32 ГБ, служба Ollama, одновременно 1-3 человека. Около одного дня на развертывание и две недели проверки на реальных задачах. Нужен, чтобы до закупки большого сервера снять качество ответов и скорость.
Основная настройка на 20-50 разработчиков
Отдельный сервер на 4-8 видеокарт (256-640 ГБ видеопамяти) и служба vLLM. Модели крупного класса: DeepSeek, GLM, Qwen. Сервер держит от 32 параллельных запросов. Этого хватает на отдел такого размера: одновременно с моделью работает часть команды, а не все 50 человек каждую минуту. Рабочие места настраиваются одинаково и ставятся централизованно.
После загрузки весов и пилот, и основная схема работают без доступа в интернет.

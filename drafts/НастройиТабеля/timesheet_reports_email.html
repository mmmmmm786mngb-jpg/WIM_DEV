IM Development
Отчеты по списанному времени
Добрый день.
Ниже постоянные ссылки на отчеты в Jira по проекту IM Development. Даты в адресе не зашиты: ссылка сама открывает прошлую неделю или прошлый месяц. Для текущей недели из адреса уберите кусок offset=-1.
1. ЧАСЫ ПО ИСПОЛНИТЕЛЮ ЗАДАЧИ
Сколько времени списано на задачи конкретного исполнителя. Если в одну задачу писали несколько человек, часы собираются у того, на кого задача назначена.
Открыть отчет по исполнителю
2. WORK LOG ПО ДНЯМ
Кто списал время, в какой день и с каким комментарием. Группировка по полю Worked User, колонки по дням, в строке виден текст work log.
Открыть work log по дням
Первый отчет отвечает на вопрос, на чьих задачах лежат часы. Второй отвечает на вопрос, кто эти часы списал. Дальше четыре разреза, которых в этих двух экранах нет.
3. КУДА УШЛА НЕДЕЛЯ
Табель по сотруднику, одна строка на задачу. Подзадачи собраны в родительскую задачу, лента коротких комментариев скрыта. По строке видно, ушла ли неделя в одну доработку или рассыпалась по многим.
Show Details выключен. Sum Sub-Tasks включен. Group By Field: Worked User. Колонки по дням. Если галка Sum Sub-Tasks не применилась из ссылки, включите ее в Configure и сохраните новый адрес.
Открыть задачи недели
4. МАТРИЦА: ЗАДАЧА И ЛЮДИ
Project Pivot. Строка это задача, колонка это сотрудник, сверху итог по типу: доработка, ошибка, задача, эпик. На одной строке видно совместную работу, которую дневной табель разносит по разным людям.
Если открылась форма настройки, нажмите Next. Отчет также лежит в IM Development, раздел Reports, имя Project Pivot Report.
Открыть матрицу
5. НОРМА КОМАНДЫ
Верхний блок Summary: одна строка на человека и часы по дням. Сразу видно, у кого неделя около полной, у кого часов мало, у кого каждый день одно и то же круглое число. Этот экран удобно открывать в понедельник.
Group By Field: Worked User. Show Details выключен. Collapse Field Groups включен. На этом отчете есть Subscribe: расписание потом правится в меню Issues, пункт Timesheet Subscriptions.
Открыть норму команды
6. КУДА УШЕЛ ПРОШЛЫЙ МЕСЯЦ
Колонки это недели месяца, строки это задачи, подзадачи собраны в родителя. Чтобы увидеть инициативы, а не отдельные доработки: Configure, Group By Field поставьте Epic Link. Если такого пункта нет, выберите Epic Name. Нажмите Next и сохраните получившийся адрес.
Month View включен, период смещен на предыдущий месяц. Show Details выключен. Sum Sub-Tasks включен.
Открыть прошлый месяц
Две круговые диаграммы
График в этом плагине выводится только гаджетом дашборда Worked Time Chart. Это круговая диаграмма. Отдельной страницы отчета с графиком нет. На один дашборд хватает двух гаджетов.
Как поставить: откройте дашборды, выберите дашборд, Add gadget, в поиске наберите Worked Time Chart, нажмите Add gadget. Гаджет ставится два раза, с разной группировкой.
Открыть дашборды
ДИАГРАММА 1. ДОЛЯ ЧАСОВ ПО СОТРУДНИКАМ
Сектор это человек, размер сектора это его доля в часах недели.
Project: IM Development.
Период: 1 неделя, предыдущая. Если есть поле offset, поставьте -1. Если поля нет, над диаграммой нажмите стрелку назад.
Group by: Worked User.
Если в гаджете нет Group by: нажмите Details, в открывшемся отчете выберите Group By Field = Worked User, затем вернитесь на дашборд. Диаграмма подхватит настройку.
ДИАГРАММА 2. СТРУКТУРА ПО ТИПУ ЗАДАЧ
Сектор это тип: доработка, ошибка, задача, эпик, подзадача. По этому кругу видно, из чего собрана неделя.
Project: IM Development.
Период: та же прошлая неделя.
Group by: Issue Type.
Круг по всем задачам сразу ставить не стоит: секторов получается слишком много, диаграмма перестает читаться. Для задач уже есть матрица из пункта 4.

Каждая ссылка сразу открывает готовый отчет по проекту IM Development. Форму настройки нажимать не нужно. Недельные ссылки сами стоят на прошлой неделе, месячная на октябрь 2026.
1. Табель прошлой недели
Сотрудник, под ним задачи, часы по дням. Без ленты комментариев.
Открыть табель прошлой недели
2. Комментарии к списаниям
Та же неделя, но видна каждая запись work log и ее текст.
Открыть комментарии
3. Часы на исполнителе задачи
Сколько времени лежит на задачах человека, даже если списывал не он.
Открыть часы по исполнителю
4. Из чего собрана неделя
Блоки по типу: доработка, ошибка, задача, эпик. Внутри задачи и дни.
Открыть типы задач
5. Календарь октября
Сотрудник и задачи по каждому дню месяца, вместе с субботой и воскресеньем.
Открыть октябрь
6. Прошлый месяц по неделям
Колонки это недели, строки это люди и их задачи. Удобно смотреть месяц целиком.
Открыть прошлый месяц
7. Матрица: задача и люди
Строка это задача, колонка это сотрудник. Сверху итог по типу задачи за прошлую неделю.
Открыть матрицу
8. Норма команды
Только итог по человеку и дням прошлой недели. Сразу видно, у кого неделя полная.
Открыть норму команды
9. Задачи вместе с подзадачами
Часы подзадач собраны в родительскую задачу. Видно, куда ушла неделя, а не номера разделов.
Открыть задачи с родителями
10. Четыре недели одним взглядом
По человеку одна строка на задачу и четыре колонки недель. Видно, что тянется месяц, а что вспыхнуло на одной неделе.
Открыть четыре недели

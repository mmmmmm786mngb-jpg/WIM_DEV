Тип контрагента ЦБ РФ в сделках РЕПО

Ответ пользователю
Добрый день! В сделках РЕПО поле «Тип контрагента ЦБ РФ» заполняется не из карточки контрагента сделки (в вашем примере — не из Банка ВТБ). Это поле из ДУ готовым значением не передаётся. При загрузке сделки в ФИН система сама его проставляет. Если для портфеля включён параметр «Определять тип контрагента по РЕПО от клиента ДУ», тип берётся из карточки клиента портфеля (в примере — АО «НПФ Альфа»), а не из ВТБ. Поэтому в сделке стоит «Негосударственные финансовые организации», хотя у ВТБ в карточке — «Кредитные организации». Это штатное поведение. Как убедиться — см. инструкцию ниже. С уважением.

1. Суть на примере вашей сделки

Кажется, что система «подставила не то». На самом деле тип взят у клиента портфеля ДУ, а не у брокера/контрагента сделки.
Где смотрите Что видите
Сделка РЕПО (обратное) 8298-000000116 Контрагент = Банк ВТБ (ПАО)
Портфель = ДУ 8298 (АО «НПФ Альфа»)
В той же сделке: «Тип контрагента ЦБ РФ» Негосударственные финансовые организации
Карточка Банк ВТБ (ПАО) Кредитные организации
Значения не совпадают — это нормально: при включённом параметре портфеля источник типа — клиент портфеля (НПФ Альфа), а не ВТБ.

2. Как убедиться самостоятельно (пошагово)

Откройте ту же сделку РЕПО, о которой был вопрос, и пройдите три проверки.

Проверка A. Кто клиент портфеля

1 В сделке РЕПО нажмите на поле Портфель (ДУ 8298). Сделка РЕПО → Портфель → карточка справочника «Портфели»
2 В карточке портфеля найдите поле Клиент. Ожидается: АО «НПФ Альфа». Портфель ДУ 8298 → реквизит «Клиент»

Проверка B. Тип контрагента ЦБ РФ у клиента портфеля

3 Откройте карточку клиента из поля «Клиент» (НПФ Альфа). Это справочник Контрагенты. Портфель → Клиент → форма элемента справочника «Контрагенты»
4 На вкладке «Общие» найдите реквизит «Тип контрагента ЦБ РФ» (рядом с полями «Юридическое / Физическое лицо», «Нерезидент»). Ожидается: Негосударственные финансовые организации — то же значение, что в сделке РЕПО. Контрагенты (НПФ Альфа) → вкладка «Общие» → «Тип контрагента ЦБ РФ»
Для сравнения можно открыть карточку Банк ВТБ по той же вкладке «Общие»: там будет «Кредитные организации». Это тип брокера/контрагента сделки, но не источник заполнения поля в РЕПО при включённом параметре.

Проверка C. Включён ли параметр портфеля

5 Откройте учётную политику, действующую для портфеля ДУ 8298 на дату сделки (06.08.2026). Обычно: из карточки портфеля → связанные данные / учётные политики по портфелю. Портфель ДУ 8298 → Учётная политика (на дату сделки)
6 В документе учётной политики откройте вкладку «Сделки», группу «Сделки РЕПО». Найдите галку «Определять тип контрагента по РЕПО от клиента ДУ». Ожидается: включена. Учётная политика → вкладка «Сделки» → «Сделки РЕПО» → галка параметра
7 Альтернатива: регистр сведений «Значения параметров портфеля» — отбор по портфелю ДУ 8298 и параметру «Определять тип контрагента по РЕПО от клиента ДУ». Значение на дату сделки должно быть Да / Истина.

3. Что должно совпасть

Проверка Ожидаемый результат
Клиент портфеля ДУ 8298 АО «НПФ Альфа»
Тип ЦБ РФ у НПФ Альфа Негосударственные финансовые организации
Тип ЦБ РФ в сделке РЕПО То же значение, что у НПФ Альфа
Параметр «от клиента ДУ» Включён
Тип ЦБ РФ у ВТБ Кредитные организации (для сравнения, в сделку не подставлялся)
Если все четыре пункта совпали — заполнение поля в сделке РЕПО корректное и объясняется настройкой портфеля, а не ошибкой подстановки с карточки ВТБ.

4. Коротко: откуда берётся значение

  1. Сделка приходит из ДУ без поля «Тип контрагента ЦБ РФ» (в ДУ у сделки РЕПО такого реквизита нет).
  2. При загрузке в ФИН система заполняет поле сама.
  3. Если параметр портфеля включён — читает тип у клиента портфеля.
  4. Если параметр выключен — читал бы тип у контрагента сделки (ВТБ).

Тема письма: Режим электропитания серверов 1С
Режим электропитания серверов 1С
 
Коллеги,
по материалам 1С на серверах, где работают платформа и СУБД, нужно включать схему электропитания «Высокая производительность» (High Performance). Схему по умолчанию оставлять не следует.
1. Рабочие серверы 1С
Статья «Check-list по настройке рабочих серверов в продукционной зоне», пункт 20 (12.05.2016):
План электропитания: Высокая производительность.
В Control Panel\All Control Panel Items\Power Options необходимо указать "High Performance".
https://its.1c.ru/db/metod8dev/content/5899/hdoc
2. Сервер Microsoft SQL Server
Статья «Настройки Microsoft SQL Server для работы с 1С:Предприятием», пункт чек-листа (15.07.2019):
Схема управления питанием - «Высокая производительность»
https://its.1c.ru/db/metod8dev/content/5904/hdoc
3. Сервер PostgreSQL
Статья по настройке PostgreSQL 9.6 и выше для платформы 1С:Предприятие, раздел «Настройки сервера для PostgreSQL» (19.06.2025):
Рекомендуется отключить Energy Saving, в противном случае могут непредсказуемо вырастать задержки ответов БД.
https://its.1c.ru/db/metod8dev/content/5866/hdoc
В этих текстах схема «Сбалансированный» по имени не указана. Задан целевой режим: High Performance на серверах 1С и SQL Server и отключение Energy Saving на сервере PostgreSQL.
Смежный раздел руководства администратора
Раздел «Использование энергосберегающих режимов работы компьютера» в документации 8.3.27 говорит о режимах Sleep, Standby и Hibernate на клиентских компьютерах в клиент-серверном варианте. Это не настройка плана питания сервера.

Коллеги, добрый день!

Проверили обращение по ошибке при запуске обработки «Проверка реестра обратного выкупа» в базе AVC_PP_PIF (T-1).

Краткий вывод
Проблема не в обработке и не в файле Excel. Ошибка связана с повреждением структуры базы данных после технических работ.

Что происходит

При нажатии «Выполнить проверку» система обращается к плану счетов «Управленческий» и регистру бухгалтерии. В SQL Server отсутствует служебная таблица:

dbo._AccSInf9435

Из-за этого платформа выдает ошибку СУБД:
Invalid object name 'dbo._AccSInf9435' .

Почему это важно

Эта таблица нужна для работы предопределенных счетов плана счетов. Обработка ранее успешно работала на T-1 (задача IMDEV-8515). Сейчас падение связано с состоянием базы после техработ, а не с логикой сверки реестра.

Что нужно сделать

Необходимо восстановление структуры БД силами администрирования / поддержки приложений (App Support / DBA):

  1. Проверить наличие таблицы dbo._AccSInf9435 в SQL-базе AVC_PP_PIF.
  2. Восстановить недостающую таблицу из бэкапа до техработ (либо корректно завершить обновление / реструктуризацию конфигурации БД).
  3. После восстановления выполнить контрольную проверку: открытие плана счетов «Управленческий» и повторный запуск обработки по тестовому файлу.
После восстановления структуры базы обработка должна снова выполняться в штатном режиме. При необходимости поможем с контрольной проверкой сразу после исправления.

Можно ли так удалять пустые проводки?

Конфигурация ПИФ, регистр бухгалтерии Управленческий

Ответ

Да, так удалять можно.

Это штатный способ убрать строки из набора движений в памяти: сначала отобрать записи, потом вызвать Удалить. В ПИФ такой приём уже используется.

Разбираемый код

Процедура УдалитьПустыеПроводки()

    МассивДвиженийУдалить = Новый Массив;

    Для Каждого Движение Из Движения.Управленческий Цикл
        Если Движение.Сумма = 0 Тогда
            МассивДвиженийУдалить.Добавить(Движение);
        КонецЕсли;
    КонецЦикла;

    Для Каждого Движение Из МассивДвиженийУдалить Цикл
        Движения.Управленческий.Удалить(Движение);
    КонецЦикла;

КонецПроцедуры

Почему это корректно

Что проверяли Вывод
Тип набора Движения.Управленческий — набор записей регистра бухгалтерии Управленческий (с корреспонденцией).
Поле Сумма Ресурс регистра Сумма, тип Число(20, 2). Обращение Движение.Сумма допустимо.
Метод Удалить У набора записей регистра бухгалтерии есть метод Удалить(). Параметр — объект записи (как в коде) либо индекс записи.
Два цикла Нельзя удалять из набора внутри Для Каждого по этому же набору: коллекция меняется во время обхода. Сначала отбор в массив, потом удаление — правильный приём.

Уже есть в ПИФ

Тот же фрагмент используется в проведении, после формирования проводок, при Движения.Управленческий.Записывать = Истина:

  • документ Начисление задолженности по купонам — процедура УдалитьПустыеПроводки
  • документ Перевод НКД в задолженность эмитента — та же процедура
  • документ Погашение паев — тот же приём: массив проводок, затем Движения.Управленческий.Удалить(...)
В конце проведения платформа запишет уже урезанный набор. Сам вызов Удалить базу не трогает — только записи в памяти.

На что обратить внимание

  1. Контекст проведения. Набор должен быть уже заполнен (Добавить в этом же проведении либо Прочитать()). Иначе цикл просто ничего не увидит.
  2. Критерий только Сумма = 0. У регистра ещё есть ресурсы Количество и ВалютнаяСумма. Проводка с нулевой суммой, но ненулевым количеством или валютной суммой, тоже будет удалена. Для количественных / валютных счетов это уже не «пустая» проводка.
  3. Не удалять внутри первого цикла — ни по объекту, ни по индексу.

Если нужно учитывать количество и валюту

Тогда условие лучше расширить, например:

Если Движение.Сумма = 0
    И Движение.Количество = 0
    И Движение.ВалютнаяСумма = 0 Тогда
    МассивДвиженийУдалить.Добавить(Движение);
КонецЕсли;

Для текущих документов с купонами, где чистятся именно нулевые суммовые проводки, исходного условия Сумма = 0 достаточно.

Итог

Для очистки нулевых суммовых проводок в модуле документа ПИФ при проведении — так делать можно, платформа это поддерживает, в конфигурации приём уже применяется.

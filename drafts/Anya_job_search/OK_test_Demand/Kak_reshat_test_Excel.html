Отдельный файл Тест_Деманд_ФОРМУЛЫ.xlsx — учебная тетрадь. На проверку логики «как в ТЗ» отправляй вариант …_ФОРМУЛЫ_Массив.xlsx.

Открой (учебный): Тест_Деманд_ФОРМУЛЫ.xlsx

Рабочая тетрадь: синие ячейки — данные из ТЗ, зелёные — живые формулы Excel (клик по ячейке → смотри строку формул).

  • 07_Мини_пример — одна SKU, пошаговые формулы приоритета и переноса остатка.

  • 04_Сводка — =СУММ(), сравнение с целями.

0. Подготовка файла (10–15 минут)

  1. Открой исходный Тест_Деманд.xlsx (не правь оригинал — сделай копию: Тест_Деманд_моя.xlsx).
  2. Лист «Задание» — прочитай целиком. Лист «Массив» — рабочие данные.
  3. В строке 5 над блоком «План мес» лежат целевые планы каналов в тоннах: ФС промо 7358, ФС рег 1582, РДЦ 5373, ФТ 586, ЭК 1300, КПи 748, E-commerce 530, РКП 2686.5, итого 20163.5 т.
  4. Объёмы в таблице (остатки, выпуск, прогноз) — в кг. Лимит канала в кг = тонны × 1000 (например, ФС промо = 7 358 000 кг).
  5. Добавь справа от таблицы (или на новый лист «Расчёт») свои вспомогательные столбцы — так видно, что ты считала сама.
Структура «Массив» (кратко):
  • Столбец A — короткий код SKU
  • F — доступный остаток на начало
  • G — план производства на месяц
  • H–L — план производства по неделям 1…5
  • M–U, V–AD, … — прогноз спроса по каналам на недели 1…5
  • BO–BX (примерно столбцы 67–76) — сюда пишешь итоговый план продаж

Смысл задания одной фразой

Есть фиксированный выпуск и начальные остатки. Есть «хотелки» продаж по каналам (неограниченный прогноз). Нужно собрать реалистичный план продаж:
  • не продать больше, чем остаток + выпуск (с учётом недель);
  • при нехватке — отдать товар важным каналам раньше остальных;
  • лишний товар разложить по SKU, не превысив суммарный план канала в тоннах;
  • в записке объяснить дефицит, логику, риски и действия.

Пункт 1. Перераспределить дефицитные SKU

Задание: по позициям, где конечные остатки ниже потребностей каналов, перераспределить объём.

Шаг 1.1. Найти дефицит

На лист «Расчёт» для каждой строки «Массива»:

Доступно = Остаток_нач (F) + Выпуск_нед1 (H) + … + Выпуск_нед5 (L)
Спрос = сумма прогнозов по всем каналам за 5 недель
Дефицит_кг = Спрос − Доступно
Если Дефицит_кг > 0 → статус «ДЕФИЦИТ»

В Excel (пример для строки 8, подставь свои адреса):

=F8+H8+I8+J8+K8+L8 → Доступно
=U8+AD8+AM8+AV8+BE8 → Спрос (итоги недель, если есть столбец «Итого»)
=MAX(0; Спрос − Доступно) → Дефицит

Отфильтруй статус «ДЕФИЦИТ» → это список для пояснительной записки.

Пример на пальцах
ПоказательЗначение
Остаток + выпуск10 000 кг
Прогноз по каналам14 000 кг
Дефицит4 000 кг — нельзя закрыть все «хотелки»

Значит, кому-то из каналов придётся отдать меньше прогноза. Это и есть «перераспределение дефицита».

Шаг 1.2. Задать приоритет каналов (запиши себе правило)

Рабочее правило (его же использовали в файле-решении):

  1. ФС промо — обязательства / промо федеральных сетей
  2. ФС рег — регуляр федеральных сетей
  3. РДЦ — регионы / сервис
  4. РКП — своя розница
  5. ЭК — экспорт
  6. ФТ — фирменная торговля
  7. КПи — корпоративные
  8. E-commerce — гибче остальных

При нехватке товара: сначала полностью закрываем канал выше по списку, остаток — следующему.

Пример Доступно за неделю: 5 000 кг. Прогноз: ФС промо 3 000, ФС рег 2 000, РДЦ 2 000.
КаналПрогнозПлан (после приоритета)
ФС промо3 0003 000
ФС рег2 0002 000
РДЦ2 0000 (товар кончился)

Шаг 1.3. Как сделать приоритет в Excel без макросов

  1. Для одной недели заведи столбцы: Остаток_к_распределению, затем план по каждому каналу.
  2. Формулы «каскадом» (пример):
План_ФС_промо = MIN(Прогноз_ФС_промо; Доступно)
Остаток1 = Доступно − План_ФС_промо
План_ФС_рег = MIN(Прогноз_ФС_рег; Остаток1)
Остаток2 = Остаток1 − План_ФС_рег
План_РДЦ = MIN(Прогноз_РДЦ; Остаток2)
… и так далее по приоритету

Скопируй формулы вниз по всем SKU. Для 5 недель — либо 5 блоков столбцов, либо сначала сделай месяц упрощённо (см. ниже), а 1–2 SKU посчитай понедельно вручную как демо логики.

Обязательно: недельный шаг и переходящий остаток

В шапке «Массива» прямо написано: строить план по неделям и учитывать переходящие остатки с учётом плана производства. Если продать всё в 1-й неделе «вперёд», останешься без товара на 4–5-ю.
Неделя 1: Доступно1 = Остаток_нач + Выпуск1
Отгрузка1 = распределение по приоритету (не больше Доступно1)
Остаток_конец1 = Доступно1 − Отгрузка1

Неделя 2: Доступно2 = Остаток_конец1 + Выпуск2
… аналогично до недели 5

План_мес_по_каналу = сумма планов канала за 5 недель

Пункт 2. Распределить профицитные объёмы в рамках плана канала

Задание: лишний товар по SKU разложить так, чтобы не выйти за суммарный план канала (цифры в тоннах над таблицей).

Шаг 2.1. Проверить сумму плана по каналу

  1. После заполнения планов по SKU посчитай внизу или на листе «Сводка»: =СУММ(столбец_ФС_промо) и т.д.
  2. Сравни с лимитом в кг (тонны × 1000).
  3. Если сумма больше лимита — нужно урезать (шаг 2.2).
  4. Если сумма меньше лимита, а по части SKU ещё есть свободный остаток — можно докинуть профицит (шаг 2.3), но не выше прогноза/здравого смысла и не выше лимита канала.

Шаг 2.2. Урезать канал до лимита

Простой и понятный работодателю способ — пропорциональное сокращение:

Коэффициент = Лимит_канала_кг / Текущая_сумма_плана_канала
Новый_план_SKU = Старый_план_SKU × Коэффициент

Чуть «умнее» (как в эталонном решении): при урезании сильнее резать локальный ассортимент, федеральный беречь.

Пример Лимит РДЦ = 5 373 000 кг, сумма планов вышла 6 000 000. Коэффициент = 5 373 000 / 6 000 000 ≈ 0,8955. Умножаешь все строки РДЦ на 0,8955.

Шаг 2.3. Куда девать профицит

  1. Найди SKU, где после плана остался свободный товар: Свободно = Доступно − Итого_план.
  2. Найди каналы, где сумма плана < лимита.
  3. Докинь объём в эти каналы по профицитным SKU (лучше туда, где ещё был непрокрытый прогноз), пока не упрёшься в лимит канала или в остаток SKU.
Важно фразой для записки: «Профицит направляю только в пределах целевого плана канала, план производства не увеличиваю».

Куда вписать ответ в файле ТЗ

  1. Итоговые цифры плана продаж по каналам за месяц — в блок «План мес» (столбцы с ФС / ФС промо / … / РКП / Итого).
  2. Выдели этот блок зелёной заливкой — так видно «вот решение».
  3. Дефицитные коды можно пометить оранжевым в столбце A.
  4. На отдельном листе «Пояснительная» — текст записки (жёлтый фон).
  5. На листе «Сводка» — таблица: канал / цель т / план т / отклонение.

Пояснительная записка — 4 пункта из ТЗ

Работодатель просит явно:

  1. Список дефицитных позиций
  2. Почему распределила дефицит так, а не иначе
  3. Какие риски видишь при дефиците
  4. Какие действия предпримешь по дефицитным позициям

Шаблон текста (можешь переписать своими словами)

1. Список дефицита. Приложен на листе «Дефицит»: N позиций, где остаток + выпуск < суммы прогноза каналов. Топ по объёму дефицита: … (3–5 кодов).

2. Логика распределения. При нехватке приоритет: ФС промо → ФС рег → РДЦ → РКП → ЭК → ФТ → КПи → E-com. Расчёт с недельным переносом остатка. Производство не увеличивала. При урезании сверх плана канала сильнее сокращала локальный ассортимент.

3. Риски. Штрафы/cut-off в сетях; падение OTIF и OOS в регионах; искажение сигнала спроса (overforecast); уход покупателя к аналогам; заморозка денег в профицитных остатках при дефиците хитов.

4. Действия. Short-list на S&OP с Sales/Marketing; запрос Production на переброску внутри лимита выпуска; сокращение промо/extra по хроническому дефициту; субституты из профицита; weekly контроль остатка на 1–2 недели вперёд; эскалация decision log.

Как устроено готовое решение в папке (для ориентира)

В папке лежат два файла — это образец логики, не «волшебная кнопка». Твоя сдача должна выглядеть как твой Excel с формулами/фильтрами.

  • Тест_Деманд_РЕШЕНИЕ.xlsx — копия ТЗ: зелёный блок плана в «Массиве», оранжевые дефицитные коды, лист «00_Пояснительная».
  • Reshenie_Test_Demand.xlsx — компактно: сводка каналов, список дефицита (74 SKU), полный план, легенда цветов.

Что сделано в образце по шагам:

  1. Для каждой строки: доступно = остаток + 5 недель выпуска; спрос = сумма прогнозов.
  2. Понедельно: остаток+выпуск → раздача по приоритету каналов → перенос остатка.
  3. Сумма по каналу сравнена с лимитом (тонны×1000); превышение урезано (сильнее локальные SKU).
  4. Свободный остаток частично докинут в каналы с недобором до цели.
  5. План производства не менялся; целевой остаток игнорировался (как в ТЗ).

В образце ФС промо и РДЦ выведены в цель; часть каналов чуть ниже цели — не хватило свободного товара/спроса после приоритезации. Это нормально и честно для записки.

Как пользоваться образцом правильно: открой рядом, посмотри 2–3 SKU (один дефицит, один профицит), воспроизведи ту же логику формулами в своей копии. Не отправляй файл с чужими техническими именами листов «как есть», если не понимаешь каждую цифру.

Как показать работодателю, что сделала сама

Что отправлять

  • Один файл Excel: Тест_Деманд_Фамилия.xlsx
  • Внутри: заполненный план, лист с дефицитом, лист со сводкой каналов, пояснительная записка
  • В письме/чате hh — 4–6 предложений: что сделала, какой приоритет каналов, сколько дефицитных SKU, что план производства не трогала

Что должно быть видно при открытии файла (следы «живой» работы)

  1. Формулы на листе «Расчёт»: Доступно, Спрос, Дефицит, коэффициент урезки — не только вставленные значения.
  2. Автофильтр по статусу ДЕФИЦИТ / ПРОФИЦИТ.
  3. Сводка с =СУММ() и сравнением с целями в тоннах.
  4. 2–3 комментария в ячейках (ПКМ → Примечание): например «режу E-com в пользу ФС промо».
  5. Цвета: зелёный = итоговое решение, жёлтый = записка, оранжевый = дефицит.
  6. В записке — свои формулировки (не копируй текст один в один с обучалки).

Чего не делать

  • Не упоминать Cursor, ChatGPT, «скрипт на Python», «мне собрали файл».
  • Не присылать два файла «эталон + моё», если не готова объяснить расхождения.
  • Не оставлять пустой план и только текст записки.
  • Не увеличивать выпуск «чтобы сошлось» — в ТЗ это запрещено.

Короткий сценарий на созвоне / если спросят «как считала?»

«Сначала по каждой SKU сравнила остаток плюс понедельный выпуск с прогнозом каналов — получила список дефицита. Дальше на недельном шаге распределяла доступный объём по приоритету: федеральное промо и регуляр, потом РДЦ и остальное. Переходящий остаток переносила на следующую неделю. Затем сверила суммы по каналам с целевым планом в тоннах: превышения урезала, профицит направила в каналы с недобором, не выше лимита. Производство не меняла. В записке — список дефицита, приоритет, риски и действия на S&OP.»

Чеклист перед отправкой (15 минут)

  • □ План мес заполнен, заливка зелёная
  • □ СУММ по каждому каналу ≤ цели (тонны × 1000)
  • □ По любой строке: итого план ≤ остаток + выпуск
  • □ Есть лист дефицита и сводка
  • □ Записка закрывает все 4 пункта ТЗ
  • □ Имя файла с фамилией, письмо вежливое и короткое
  • □ Можешь вслух объяснить 1 дефицитный и 1 профицитный SKU

Рекомендуемый порядок работы на 60–90 минут

  1. 0:00–0:10 — копия файла, лист «Расчёт», формулы Доступно / Спрос / Дефицит.
  2. 0:10–0:25 — фильтр дефицита, выписать топ-15 в записку.
  3. 0:25–0:55 — понедельное (или упрощённо месячное + проверка 5 строк понедельно) распределение по приоритету, заполнение «План мес».
  4. 0:55–1:10 — сводка по каналам, урезка до лимита, докидка профицита.
  5. 1:10–1:25 — пояснительная записка, цвета, проверка чеклиста.
  6. 1:25–1:30 — письмо HR + отправка.

Если времени мало: сделай честно упрощённый месячный расчёт + явно напиши в записке: «из-за лимита времени детально проверила недельный перенос на выборке SKU; логика приоритета единая». Честность лучше «идеальных» цифр без понимания.

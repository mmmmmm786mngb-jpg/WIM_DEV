## Краткое содержание

1. **Planicum** — браузерная платформа: визуализация плюс ввод цифр и внутренние пересчёты. Не путать с Loginom. Сначала инструкция и фишки фильтров; мелкие UX-хотелки к Маше не нести.

2. **Команда IT.** Заказчик — Demand. Аналитик Planicum / сборки — Маша Дроздовская; у неё Мика (со стороны Loginom). Руководитель Маши — Юля Семёнова, выше — Женя Михалёв. Еженедельник по понедельникам (спринты ~2 недели) + отдельный Bitrix-чат на короткие косяки (цены и т.п.).

3. **Цепочка данных:** 1С -> хранилище (файловый обмен) -> **Loginom** (ML-прогноз спроса) -> **Planicum** (экспертиза людей) -> обратно в цикл / выгрузка в 1С.

4. **Loginom** строит прогноз **сверху**: регион + категория 2 (не сразу «наименование для прайса / клиент»). Две ветки: матричный и нематричный клиент. Матричный: чистят промо, строят **baseline**, потом накладывают промо из ТМА. Нематричный (~500 клиентов, регионалы и экспорт): статистика валом, без очистки промо; отдел продаж длинный горизонт ТМА не ведёт.

5. **Зачем сверху.** Клиент/дистр закрылся — объём перетекает к другому дистру, в федералы или остаётся в регионе. Планирование снизу «теряет» этот объём. Документация у Жени Михалёва — читать.

6. **Дашборды продаж** специально без «Сохранить» и без ломки кубиков. Копии под логином — можно крутить вид. Данные во всех копиях пишутся в одни таблицы. После доработок (калькулятор, проекты) Анна сносит старые копии — иначе нет новых столбцов.

7. **Калькулятор** грузится в 1С, оттуда в Planicum. Зелёные столбцы — редактируемые, белые — справка. Статпрогноз — рекомендация машины. **База корректировки** — туда КАМ кладёт экспертизу. Итог: база + промо + проекты; рубли = база*регулярная цена + промо*промо-цена + проекты*цена проектов.

8. **Матрица федералов (дашборд 001).** Статусы NPD: регулярный / план / вывод. Ведут Кузьмина Даша совместно с Ритой. География и АКБ по форматам (пример Магнит: ГМ / у дома / МК). Этого справочника в 1С нет — держат в Planicum. Раз в месяц (~28-е) письмо продажам: актуализируйте матрицу.

9. **Цены.** Матричный: срез последних из установки цен номенклатуры 1С. Нематричный: средняя за 4 месяца (с учётом промо).

10. **Основные дашборды Анны:** 004 — всё кроме частной марки; отдельно STM / Светофор; 005 — подарочные наборы. Подарки: статпрогноз **не строить**, потребность жёстко от продаж, СиМ заказывают почти за год. В жёстком фильтре исключены направление 10 (подарки) и 4 (STM), плюс архив.

11. **Выгрузка в 1С:** кнопка «выгрузить прогноз» в любом дашборде -> папка (доступ Анна выдала). Перед циклом Маша запускает **ETL** (машинный прогноз Loginom, подтягивается закрытый месяц). Отбивка в Bitrix.

12. **Сохранить vs дискетка.** Верхняя «Сохранить» пишет весь дашборд (фильтры/вид). Админам (Ира тоже) **не жать**. Цифры — только дискетка в строке. Откат сложный (архив у Маши).

13. **Узкое место.** База корректировки тянется с прошлого месяца; новинка видна в статпрогнозе, но сама в базу не встаёт. Регионалы (много клиентов) это не дотягивают — Анна вручную. ТЗ с Машей: **автопрогноз** по ряду клиентов (база = статпрогноз каждый месяц).

14. **Цикл месяца.** ~5 дней на корректировки в Planicum -> прогрузка в 1С -> **предDemand** уже по 1С. Заморозка в документах **15-е**; фактически правят до ~20-го. После — только **допы** вручную в регистрах 1С. Источник правды для компании — **1С**, не «поправили в Planicum и не сказали».

15. **Промо-фазировка.** ТМА — одна цифра на акцию + даты полки/отгрузки/точек. Чтобы товар доехал на РЦ и на полку, объём режут по неделям справочником (пример: 2 недели = 20% / 80%). Есть недельный виджет.

16. **Стратплан 2027** (дашборд ~007, ещё дособирается). Статпрогноз — тренд за весь период, не «просто 2026». Промо на стратплан обычно приравнивают к этому году. Цели Макарова vs сборка: по дискаунтерам цель **[неуверенно] 234** при сборке **[неуверенно] ~2012 / дельта ~121 млн** — добить проектами. Новинки утра (Настя) в Planicum ещё не прогружены. Пример проекта по Светофору / Михальчевой: мощность по дискам, РЦ не брать, согласование с Дмитрием Станиславовичем (маржа vs объём, перекладка на регионалов / влажные салфетки).

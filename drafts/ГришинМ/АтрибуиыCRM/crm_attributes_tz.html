ТЗ. Блоки атрибутов CRM по системам

Один блок из перечня заказчика читается целиком из одной системы. Поле блока не добирается из соседней базы. Если реквизита в системе блока нет, поле остается пустым.

2. Правило для разработчика

Внутри блока запрещено подставлять реквизит из другой системы. Пример, которого быть не должно: название портфеля из ФИН, а номер лицевого счета из ПИФ, а ответственного из ДО.

Исключение одно, и оно на весь блок, не на поле. Если у клиента нет портфеля в ФИН, а договор есть только в ДУ редакции 1.5, блоки "Клиент" и "Институциональные продукты" переключаются на ДУ оба сразу. Объекты замены перечислены в конце блока институциональных продуктов. Поля при этом все равно не добираются из ПИФ и ДО.

  • Ссылки разных баз не равны. Клиент блока ФИН и контрагент документа ДО сверяются по ИНН, но в поле блока подставляется только ссылка своей системы.
  • Периодические регистры читаются срезом последних на дату запроса.
  • Параметр фонда - предопределенный элемент ПланВидовХарактеристик.ПараметрыФонда, значение - ресурс РегистрСведений.ПараметрыПИФ.Значение.
  • Пустую ссылку и пустую дату не заменять похожим реквизитом.

3. Стратегия. Пул не использовать

Название стратегии институционального продукта берется из регистра инвестиционных профилей, не из пула.

Регистр РегистрСведений.ИнвестиционныеПрофили. В ФИН измерение Портфель, ресурс Стратегия типа Справочник.Стратегии. В CRM отдавать Стратегия.Наименование. Запись делает документ Документ.ИнвестиционныйПрофиль (реквизиты Портфель и Стратегия). Так же стратегию читает отчетность: срез регистра по портфелю, временная таблица стандартных стратегий в ОКУД 0420431 и сведениях о деятельности по управлению ценными бумагами.

Пул - группировка розничных договоров. В коде розница определяется по наименованию: ДоговорДУ.Пул.Наименование = "Розничное ДУ". У элемента Справочник.Пул в метаданных есть реквизит Стратегия. Для этого ТЗ его не читать и в поле "Название стратегии" не писать.

Строка блока - элемент Справочник.Портфели, Клиент = контрагент из блока клиента. Лицевой счет ПИФ, дату формирования фонда и ответственного ДО в эту строку не добавлять.

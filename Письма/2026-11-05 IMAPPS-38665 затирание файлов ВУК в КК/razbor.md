# Разбор: справки ВУК РДУ пропадают в клиентском кабинете

Письмо: Анастасия Хаваева, 05.11.2026 12:04, тема «RE: Отчет РДУ МИ14333 / ASAP не разместилось по РДУ ВУК в КДУ за 1 кв 2026».
Задача поддержки: IMAPPS-38665.
Просят решение: Евгений Горбунов, Мария Смирнова.

## Что произошло

Договор розничного ДУ МИ14333. Клиент внес деньги 20.02.2026.

По итогам 1 квартала 2026 вознаграждение начислено, клиенту должны были уйти справка-расчет ВУК и отчет ДУ. Уведомление о расторжении получено 29.07.2026. При расторжении начислена вторая часть ВУК за 2 квартал и дополнительное вознаграждение за досрочное расторжение. Отчет при расторжении закрывает весь срок управления, поэтому обе комиссии в нем стоят вместе. Это объясняет вопрос клиента про «одну сумму 22 500» в методике от 29.07.2026 и «две комиссии одной датой» в отчете за 20.02.2026-31.07.2026. Расчет здесь сходится с тем, как описал Кукушкин. Пропажа файлов в кабинете к этой арифметике не относится.

06.08.2026 в кабинете не нашли размещенных файлов ВУК за 1 квартал 2026 (проверили МИ14333 и еще одного клиента). Юрашева: расчеты выложены на диск, автоматическая процедура забрала в кабинет 855 файлов. Дальше ДУ к кабинету доступа не имеет.

05.11.2026 причина названа со стороны кабинета: при размещении файл с тем же именем затирает предыдущий. Клиент видит только последний. Повторная выкладка с начала года нужна, чтобы в кабинете появились логи размещений, и оперсбой переводят в риск-событие. Сами файлы прошлых периодов клиент от этого не получит, пока имена остаются одинаковыми.

## Причина в коде

Справку пишет внешняя обработка `внНачислениеВознаграждения_РозничноеДУ`, функция `ИмяФайла`. Формула одна и в оригинале, и в версиях IMDEV-9153:

```1318:1324:bases/Wim_Du/projects/IMDEV-____ Оптимизация начисления ВУК РДУ в регламентные даты/Обработки/внНачислениеВознаграждения_РозничноеДУ_epf/внНачислениеВознаграждения_РозничноеДУ/Ext/ObjectModule.bsl
Функция ИмяФайла(ДоговорДУ)

	КодКлиент = ОбщегоНазначения.ЗначенияРеквизитовОбъекта(ДоговорДУ, "Код, Клиент");
	IDКлиента = ОбщегоНазначения.ЗначениеРеквизитаОбъекта(КодКлиент.Клиент, "ВнешнийIDДляЛК");
	
	Возврат "AM" + СтрЗаменить(IDКлиента, " ", "") + "-ДУ " + КодКлиент.Код + " (" + КодКлиент.Код + ")";
```

Имя вида `AM<id клиента>-ДУ МИ14333 (МИ14333).pdf`. В нем нет даты, квартала и признака «регламент / расторжение». Каждый следующий расчет по договору получает то же имя.

Дальше два разных каталога:

- Архив ДУ (`КаталогСохранения`) раскладывается по папкам `РЕГЛАМЕНТНЫЕ\<год>\<N кв год>\` или `РАСТОРЖЕНИЕ\`. Одинаковое имя в разных папках файлы не уничтожает. Поэтому у Юрашевой на диске история есть.
- Кабинет (`КаталогСохраненияКабинетаДУ`) — одна плоская папка, то же имя. Процедура `ФормироватьСправкуРасчет` пишет туда без подпапки периода. Кабинет принимает файл по имени и оставляет последний.

Для договора МИ14333 справка 1 квартала, справка 2 квартала и справка при расторжении 29.07.2026 — это один и тот же файл с точки зрения кабинета. Клиент видит только то, что положили последним. Отчет управляющего так не устроен: в `СформироватьИмяФайла` отчета по 482-П в имя уже входит дата окончания (`Отчет ДУ ddMMyyyy`), поэтому квартальные отчеты друг друга не затирают.

## Как исправить

Кабинет (Siebel, каталог `Inbox\Report`) забирает файлы из одной папки и оставляет один документ на одно имя. Папка на диске это не лечит: в архиве ДУ период уже лежит в пути (`РЕГЛАМЕНТНЫЕ\2026\1 кв 2026\`), а в кабинет обработка отправляет короткое имя без периода. Повторный запуск начисления за прошлый квартал тоже не годится: он создаст новые документы и снимет обязательства.

Нужны две вещи сразу. Голова имени (`AM<id>-ДУ <код> (<код>)`) остается как сейчас, кабинет по ней узнает договор. В хвост добавляется период, и он разный у разных выкладок.

Регламент, хвост из той же подписи, что уже пишется в папку архива (`Квартал()`):

`AM<id>-ДУ МИ14333 (МИ14333) - ВУК 1 кв 2026.pdf`

Расторжение, отдельный хвост, чтобы не попасть в имя квартала:

`AM<id>-ДУ МИ14333 (МИ14333) - ВУК расторжение.pdf`

Отчет ДУ в тот же `Inbox\Report` уже кладется с хвостом `- Отчет ДУ <дата>`, так что хвост после кода договора кабинет принимает. Повтор той же выкладки заменяет только файл этого хвоста. Соседний квартал и расторжение остаются.

Дальше отдельная команда перевыкладки, без начисления и без удаления обязательств:

1. Берет уже сохраненные pdf из `КаталогСохранения\РЕГЛАМЕНТНЫЕ\<год>\` и из `РАСТОРЖЕНИЕ\`.
2. Квартал читает из имени папки (`1 кв 2026`), не из даты файла.
3. Копирует в `КаталогСохраненияКабинетаДУ` под именем с хвостом. Короткое имя в inbox больше не пишет: иначе последний скопированный файл снова затрет все предыдущие.
4. Идет по кварталам по порядку, расторжение в конце.
5. Пишет протокол: откуда, какое имя в inbox, скопирован или пропущен. Это и есть логи размещений, о которых письмо.
6. Повтор команды за тот же год заменяет файл того же периода и не плодит вторую копию.

Для 2026 у МИ14333 из папки `1 кв 2026` уйдет справка 1 квартала, из `РАСТОРЖЕНИЕ` — справка на дату расторжения. В кабинете будут оба файла. Уже лежащий там документ с коротким именем — это последний расчет; его 1С из Siebel не сотрет, убрать дубль может только кабинет после того, как файлы с хвостами появятся.

С этой же команды `ФормироватьСправкуРасчет` пишет в кабинет только имя с хвостом. Следующий квартал добавит новый файл и не затрет прошлые. В архиве ДУ короткое имя внутри папки периода можно оставить: там период уже в пути, повтор квартала обновляет файл этого квартала.

## Доработка, код

Обработка `внНачислениеВознаграждения_РозничноеДУ`, версия 2.21 (ветка с письмом). `ИмяФайла` и папки архива не меняются. Меняется запись в кабинет, проверка pdf в письме и добавляется команда перевыкладки.

### Запись в кабинет

Было, хвост `ФормироватьСправкуРасчет`:

```bsl
Если Не ПустаяСтрока(КаталогСохраненияКабинетаДУ) Тогда
    ФайлКаталогаКабинета = Новый Файл(КаталогСохраненияКабинетаДУ);
    Если Не ФайлКаталогаКабинета.Существует() Тогда
        Если Не СоздатьКаталогДляСохранения(КаталогСохраненияКабинетаДУ) Тогда
            ВызватьИсключение "Не удалось создать каталог сохранения кабинета ДУ: "
                + КаталогСохраненияКабинетаДУ;
        КонецЕсли;
    КонецЕсли;
    СохранитьНаДиск(СправкаРасчет, КаталогСохраненияКабинетаДУ + "\");
КонецЕсли;
```

Стало:

```bsl
Если Не ПустаяСтрока(КаталогСохраненияКабинетаДУ) Тогда
    ФайлКаталогаКабинета = Новый Файл(КаталогСохраненияКабинетаДУ);
    Если Не ФайлКаталогаКабинета.Существует() Тогда
        Если Не СоздатьКаталогДляСохранения(КаталогСохраненияКабинетаДУ) Тогда
            ВызватьИсключение "Не удалось создать каталог сохранения кабинета ДУ: "
                + КаталогСохраненияКабинетаДУ;
        КонецЕсли;
    КонецЕсли;
    ИмяКабинета = СправкаРасчет.ИмяФайла + ХвостИмениКабинета(Расторжение, ДатаРасчета);
    СохранитьНаДиск(СправкаРасчет, КаталогСохраненияКабинетаДУ + "\", ИмяКабинета);
КонецЕсли;
```

`ДатаРасчета` в этой процедуре уже посчитан. `Расторжение` — тот же параметр, который выбирает папку архива (`РЕГЛАМЕНТНЫЕ` или `РАСТОРЖЕНИЕ`).

Было, `СохранитьНаДиск`:

```bsl
Процедура СохранитьНаДиск(СправкаРасчет, ПутьСохранения)

    Т = Новый ТабличныйДокумент;
    Т.Вывести(СправкаРасчет.ШапкаРасчет);
    Т.Вывести(СправкаРасчет.ТелоРасчет);
    Т.Вывести(СправкаРасчет.ПодвалРасчет);

    Т.Записать(ПутьСохранения + СправкаРасчет.ИмяФайла + ".pdf", ТипФайлаТабличногоДокумента.PDF);

КонецПроцедуры
```

Стало:

```bsl
Процедура СохранитьНаДиск(СправкаРасчет, ПутьСохранения, ИмяФайлаБезРасширения = "")

    ИмяЗаписи = ?(ПустаяСтрока(ИмяФайлаБезРасширения), СправкаРасчет.ИмяФайла, ИмяФайлаБезРасширения);

    Т = Новый ТабличныйДокумент;
    Т.Вывести(СправкаРасчет.ШапкаРасчет);
    Т.Вывести(СправкаРасчет.ТелоРасчет);
    Т.Вывести(СправкаРасчет.ПодвалРасчет);

    Т.Записать(ПутьСохранения + ИмяЗаписи + ".pdf", ТипФайлаТабличногоДокумента.PDF);

КонецПроцедуры
```

Архивный вызов `СохранитьНаДиск(СправкаРасчет, ПутьСохранения)` остается без третьего аргумента.

### Хвост имени

`ИмяФайла` без изменений. Рядом:

```bsl
// Описание: Хвост имени pdf в кабинете. Регламент совпадает с именем папки архива, расторжение отдельно.
//
// Параметры:
//  Расторжение - Булево - Истина для папки РАСТОРЖЕНИЕ
//  ДатаРасчета - Дата - дата, от которой Квартал() дает подпись папки
//
// Возвращаемое значение:
//  Строка - фрагмент вида " - ВУК 1 кв 2026" или " - ВУК расторжение"
//
Функция ХвостИмениКабинета(Расторжение, ДатаРасчета)

    Если Расторжение Тогда
        Возврат " - ВУК расторжение";
    КонецЕсли;

    ГодПапка = СтрЗаменить(Формат(Год(ДатаРасчета), "ЧГ=0"), Символ(160), "");
    Возврат " - ВУК " + Квартал(ДатаРасчета, ГодПапка);

КонецФункции
```

### Проверка в письме об итогах

Было: в каталоге кабинета ищется короткое имя, и успехом считается любой из двух путей.

Стало, в `ТекстРезультатаСохраненияPdf` вместо короткого имени в кабинете:

```bsl
Если Не ПустаяСтрока(КаталогСохраненияКабинетаДУ) Тогда
    ИмяКабинета = ИмяPdfБезРасширения + ХвостИмениКабинета(Расторжение, ДатаНачисления);
    ФайлКабинета = Новый Файл(КаталогСохраненияКабинетаДУ + "\" + ИмяКабинета + ".pdf");
    Если Не ФайлКабинета.Существует() Тогда
        Возврат "Ошибка: PDF не найден в каталоге кабинета (" + ИмяКабинета + ".pdf)";
    КонецЕсли;
    Возврат ИмяКабинета + ".pdf";
КонецЕсли;
```

В письмо попадает имя, которое реально лежит в inbox.

### Команда перевыкладки

В `СведенияОВнешнейОбработке` добавить команду (версия обработки 2.22):

```bsl
ДобавитьКоманду(
    Команды,
    "Перевыложить справки ВУК в кабинет",
    "ПеревыложитьСправкиВУКВКабинет",
    "ВызовСерверногоМетода");
```

В `ВыполнитьКоманду`:

```bsl
ИначеЕсли ИдентификаторКоманды = "ПеревыложитьСправкиВУКВКабинет" Тогда
    УстановитьНастройки(ПараметрыВыполненияКоманды);
    ГодВыкладки = Год(ДатаНачисления);
    Если ГодВыкладки < 2000 Тогда
        ГодВыкладки = Год(ТекущаяДатаСеанса());
    КонецЕсли;
    ПеревыложитьАрхивВКабинет(ГодВыкладки);
КонецЕсли;
```

Год берется из реквизита `ДатаНачисления` сохраненных настроек. Команду в расписание не ставить: это разовая выкладка.

```bsl
// Описание: Копирует уже сохраненные pdf справок ВУК в каталог кабинета под именем с периодом.
// Начисление и удаление обязательств не выполняет. Протокол пишет в каталог архива, не в inbox.
//
// Параметры:
//  ГодВыкладки - Число - год папки РЕГЛАМЕНТНЫЕ и год изменения файлов в РАСТОРЖЕНИЕ
//
// Пример:
//  ПеревыложитьАрхивВКабинет(2026);
//
Процедура ПеревыложитьАрхивВКабинет(ГодВыкладки) Экспорт

    Если ПустаяСтрока(КаталогСохранения) Или ПустаяСтрока(КаталогСохраненияКабинетаДУ) Тогда
        ВызватьИсключение "Не задан каталог архива или каталог кабинета";
    КонецЕсли;

    ГодТекст = Формат(ГодВыкладки, "ЧГ=0");
    КаталогГода = КаталогСохранения + "\РЕГЛАМЕНТНЫЕ\" + ГодТекст;
    ПутьПротокола = КаталогСохранения + "\ПротоколПеревыкладки_" + ГодТекст + ".txt";
    Запись = Новый ЗаписьТекста(ПутьПротокола, КодировкаТекста.UTF8);
    Запись.ЗаписатьСтроку("Перевыкладка ВУК за " + ГодТекст);

    Папки = Новый СписокЗначений;
    КаталогГодаФайл = Новый Файл(КаталогГода);
    Если КаталогГодаФайл.Существует() Тогда
        Для Каждого ФайлПапки Из НайтиФайлы(КаталогГода, "*") Цикл
            Если ФайлПапки.ЭтоКаталог() Тогда
                Папки.Добавить(ФайлПапки.ПолноеИмя, ФайлПапки.Имя);
            КонецЕсли;
        КонецЦикла;
        Папки.СортироватьПоПредставлению();
        Для Каждого ЭлементПапки Из Папки Цикл
            СкопироватьPdfПапкиВКабинет(ЭлементПапки.Значение, " - ВУК " + ЭлементПапки.Представление, Запись);
        КонецЦикла;
    Иначе
        Запись.ЗаписатьСтроку("Нет каталога " + КаталогГода);
    КонецЕсли;

    КаталогРасторжения = КаталогСохранения + "\РАСТОРЖЕНИЕ";
    КаталогРасторженияФайл = Новый Файл(КаталогРасторжения);
    Если КаталогРасторженияФайл.Существует() Тогда
        Для Каждого ФайлPdf Из НайтиФайлы(КаталогРасторжения, "*.pdf") Цикл
            Если Год(ФайлPdf.ПолучитьВремяИзменения()) <> ГодВыкладки Тогда
                Продолжить;
            КонецЕсли;
            СкопироватьОдинPdfВКабинет(ФайлPdf, " - ВУК расторжение", Запись);
        КонецЦикла;
    КонецЕсли;

    Запись.Закрыть();

КонецПроцедуры

Процедура СкопироватьPdfПапкиВКабинет(ПутьПапки, Хвост, Запись)

    Для Каждого ФайлPdf Из НайтиФайлы(ПутьПапки, "*.pdf") Цикл
        СкопироватьОдинPdfВКабинет(ФайлPdf, Хвост, Запись);
    КонецЦикла;

КонецПроцедуры

Процедура СкопироватьОдинPdfВКабинет(ФайлPdf, Хвост, Запись)

    Если СтрНайти(ФайлPdf.ИмяБезРасширения, " - ВУК ") > 0 Тогда
        Запись.ЗаписатьСтроку("Пропуск, хвост уже есть: " + ФайлPdf.ПолноеИмя);
        Возврат;
    КонецЕсли;

    ИмяПриемника = ФайлPdf.ИмяБезРасширения + Хвост + ".pdf";
    ПутьПриемника = КаталогСохраненияКабинетаДУ + "\" + ИмяПриемника;

    Попытка
        КопироватьФайл(ФайлPdf.ПолноеИмя, ПутьПриемника);
        Запись.ЗаписатьСтроку("Скопирован: " + ФайлPdf.ПолноеИмя + " -> " + ИмяПриемника);
    Исключение
        Запись.ЗаписатьСтроку("Ошибка: " + ФайлPdf.ПолноеИмя + " : " + ОписаниеОшибки());
        ЗаписьЖурналаРегистрации(
            "Перевыкладка справок ВУК в кабинет",
            УровеньЖурналаРегистрации.Ошибка,
            ,
            ,
            ОписаниеОшибки());
    КонецПопытки;

КонецПроцедуры
```

Файлы расторжения в одной папке на все годы, поэтому год берется из времени изменения pdf. Это время записи файла при начислении, не дата внутри справки.

## Что проверить после правки

1. Перевыкладка за 2026 не создает документов начисления и не удаляет обязательства.
2. Два квартала одного договора дают два pdf в inbox, расторжение — третий.
3. Повтор перевыкладки заменяет файл того же хвоста и не добавляет еще один.
4. В протоколе есть строка на каждый скопированный файл.
5. После прохода кабинета у клиента видны справки разных периодов.
6. Отчет ДУ по 482-П не менять.
